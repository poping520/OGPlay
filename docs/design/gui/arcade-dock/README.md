# Arcade Dock · 矢量交互原型

独立 HTML/CSS/JS 页面，参考 `source/library-2.png` 的布局和立体卡带风格。
外壳使用内联 SVG，机柜、面板和按钮使用 CSS；页面不加载图片，无外部依赖。
与 OGPlay 运行时无连接，游戏信息和运行记录均为演示数据。

## 使用

直接用 Chrome/Edge 打开 `index.html`，按窗口等比缩放。

- 点击卡带、底部页码，或使用方向键、机柜滚轮切换游戏；Home 回到第一项。
- 悬停卡带抬升并扫光，点击选中卡带弹跳；支持 Tab、Enter 和空格选择。
- 机柜下方「卡带颜色」实时调整当前卡带，切换后保留；刷新恢复默认颜色。
- 游戏封面及图标留空占位；功能按钮仅提示尚未接入运行时。

## 实现

- `index.html` 中 `shell()` 按卡槽几何生成 SVG 外壳、凹槽、高光和边缘。
- 每张卡带以 `--cart-color` 为基础色，SVG 使用 `currentColor` 叠加明暗渐变。
- 标题、包名、版本和编号由 HTML 渲染。动效由 CSS 和 JavaScript 控制。
- `assets/layout.json` 保存布局，`layout.js` 是供页面直接加载的对应数据。
- `source/library-2.png` 仅保留作设计参考，不参与页面渲染。

修改布局数据后运行 `python build_assets.py`，仅更新 `assets/layout.js`，不会生成 PNG。
此版为矢量重绘，不承诺与原效果图逐像素一致。

## 固定尺寸校准

打开 `compare.html`，浏览器缩放设为 100%。原图和页面均固定为 1672×941，支持叠加、划分、灰度和差异视图；小窗口通过滚动查看，不做缩放。可选择同尺寸参考图。

`index.html?compare=1` 禁用自适应缩放和动画，隐藏调色工具。校准顺序为轮廓、明暗、反光，暂不增加纹理。参考图仅由对照页加载，主页面保持无图片背景。
