# 任务单规则与模板

任务单只用于需要跨会话推进的工作；日常局部修复与配方扩充不必建单。
按通用能力组织，明确目标、依赖和机器可判定的验收边界，不按每条报错建单。
本目录只放在办任务。目前没有在办任务。

新方案讨论写在任务单中，不另建 roadmap。每个可执行步骤应能在单次会话完成。
完成后删除任务单：职责、接口、不变量及支持边界归 MODULE，架构决定归 ADR，
仍成立的缺口归 KNOWN-ISSUES，运行状态归 CURRENT，过程留在提交说明中。
结构或关键流程变化时，同次更新对应设计文档；局部修复无需更新设计文档。
规则以 [AGENTS.md](../../AGENTS.md) 为准，背景见 [设计文档](../design/README.md)。

## 简短模板

```markdown
# 任务：能力主题

目标：一句话描述要交付的可观察结果。
依赖：相关模块契约、已有能力与所需输入。
范围：本次包含的行为和明确不包含的内容。

## 当前状态与下一步

记录跨会话继续工作所需的阻塞、决定及下一可执行步骤。

## 验收边界

列出直接相关的检查入口、成功判据和未验证部分。
完成后按事实归属迁移结论并删除本文件。
```
