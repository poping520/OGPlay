目标：让能力覆盖、未实现命中、环形日志和 Agent 查询从首个可执行版本起可用。

依赖：WU-0002、WU-0003。

验收：

- [x] Logger 环形缓冲、过滤、溢出计数测试通过。
- [x] 能力账本 UTF-8/TOML 子集读取、重复项拒绝、命中聚合测试通过。
- [x] `hle.capabilities`、`hle.unimplemented`、`log.tail` 返回结构化 JSON。
- [x] `session.state` 有明确 idle 结果，未装配的 `run.step`/`sym.resolve` 明确失败。
