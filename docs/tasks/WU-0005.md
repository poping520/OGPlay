# WU-0005 · 三平台 CI 与数据目录骨架

目标：让构建在 Windows/Linux/macOS 自动验证，并为配置、Profile、Quirk、Bionic 和黄金帧
建立不会滋生游戏硬编码的入口。

依赖：WU-0002、WU-0003。

验收：

- [x] CI 矩阵覆盖 Windows、Ubuntu、macOS，配置开启 warnings-as-errors。
- [x] 统一配置项带 id、说明、默认值、类型和生命周期。
- [x] Profile 命名、纯数据、身份指纹和 200 行上限已声明。
- [x] Quirk 必需字段、强制测试和可观测性绑定已声明。
- [x] Bionic 来源边界与黄金帧更新规则已声明。
