# WU-0006 · 完成 M0 日志与诊断后端

目标：把当前 Logger 骨架扩展为规划要求的 Console/File/JSONL/Ring/Agent 多 sink、限流、
guest 地址自动符号化和崩溃转储基础设施。

依赖：WU-0004、M2 ELF 符号接口可先以抽象 provider 替代。

验收：

- [ ] 默认配置开销基准 < 2%，全量 Trace < 30%。
- [ ] 固定 message/fields、分类前缀调级、每 N 帧与令牌桶契约测试通过。
- [ ] `GuestAddress` 渲染调用符号 provider；无符号时保留模块+偏移。
- [ ] 异常触发可转储 ring.jsonl、unimplemented.json 和 session.json。
