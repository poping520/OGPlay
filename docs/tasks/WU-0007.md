# WU-0007 · FixedStep Clock 与确定性空会话

目标：建立不依赖 sleep 的统一 Clock 抽象和空会话状态机，作为 Agent 与 JSON-RPC 的
可机器验证执行内核。

依赖：WU-0004、HAL Clock 接口。

验收：

- [x] 固定步长 N 帧后 frame/guest_ticks/wall_ms 精确可预测。
- [x] Open/Close/State/Step/Pause/Resume 状态转换有契约测试。
- [x] `UntilFrame` 达成目标或在 max_frames 后明确返回未达成。
- [x] Clock 与 Session 不依赖 socket、协议或平台时间 API。
