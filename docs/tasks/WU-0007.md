# WU-0007 · Session、Clock 与 JSON-RPC 最小闭环

目标：让 Agent Control 通过 JSON-RPC 驱动一个无 guest 的确定性空会话，验证 M0 的
session/open/close/state、run.step/until 和传输边界。

依赖：WU-0004、HAL Clock 接口。

验收：

- [ ] 固定步长 N 帧后 frame/guest_ticks 精确可预测。
- [ ] stdio JSON-RPC 2.0 请求、响应和错误码契约测试通过。
- [ ] `run.until` 达成 predicate 或在 max_frames 明确超时。
- [ ] Control Service 不依赖 socket；TCP/UDS 仅为可替换 adapter。
