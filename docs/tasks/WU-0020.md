# WU-0020 · GuestAddress 与地址区间

目标：冻结可表达完整 4 GiB 且不会与宿主指针混用的 guest 地址类型契约。

依赖：WU-0019、memory 模块契约。

验收：

- [x] `GuestAddress` 不允许整数隐式转换，算术和对齐不发生 32 位回绕。
- [x] `GuestRange` 使用半开区间并可表达 `[0, 4 GiB)` 与最后一个字节。
- [x] 空区间、反向距离、非二次幂对齐和越界区间明确失败。
- [x] 低 64 KiB 默认保护区有一等类型表示。
- [x] MSVC warnings-as-errors 全量 CTest 通过（38/38）。
