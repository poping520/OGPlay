# WU-0021 · 跨平台宿主虚拟内存 HAL

目标：为 4 GiB guest 直接映射提供不向 memory 泄漏系统 API 的页级宿主内存原语。

依赖：WU-0018、WU-0020。

验收：

- [x] Windows 使用 VirtualAlloc/VirtualProtect，Linux/macOS 使用 mmap/mprotect。
- [x] reservation、commit、protect、decommit 生命周期由 RAII 管理。
- [x] 未对齐、越界、空范围与 write-only 权限明确失败。
- [x] decommit 后重新 commit 的页内容归零。
- [x] MSVC warnings-as-errors 全量 CTest 通过（40/40）；其余平台留到 M1 总体验收。
