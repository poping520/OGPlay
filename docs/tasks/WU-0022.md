# WU-0022 · 4 GiB Guest AddressSpace

目标：在宿主 reservation 上实现有权限账本和结构化 fault 的 32 位 guest 直接地址空间。

依赖：WU-0020、WU-0021。

验收：

- [x] 构造只预留完整 4 GiB，低 64 KiB 不允许映射。
- [x] Map/Protect/Unmap 与宿主权限、页级权限账本同步。
- [x] Read/Write 在复制前验证完整区间，不可访问时抛出结构化 MemoryFault。
- [x] 最高地址 `0xffffffff` 可映射并读写，unmap/remap 内容归零。
- [x] MSVC warnings-as-errors 全量 CTest 通过（43/43）。
