# WU-0025 · CPU 状态与运行契约

目标：在解释器与 Dynarmic 实现前冻结可快照、可诊断的 A32/T32 CPU 公共边界。

依赖：WU-0023、cpu 与 memory 模块契约。

验收：

- [x] A32 状态覆盖 16 个核心寄存器、64 个扩展寄存器、CPSR/FPSCR/FPEXC 和线程号。
- [x] A32/Thumb 状态只由 CPSR T 位表达，切换不破坏其他状态位。
- [x] `Cpu::Run` 使用明确 tick 预算并返回结构化停止原因。
- [x] memory fault 在 CPU 边界保留地址、访问类型、原因和线程号。
- [x] CPU 状态可通过显式版本快照无损复制。
- [x] MSVC warnings-as-errors 全量 CTest 通过（52/52）。
