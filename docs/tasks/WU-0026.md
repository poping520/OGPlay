# WU-0026 · MemoryBus 独立取指权限

目标：让 CPU 通过 MemoryBus 取指时严格检查 execute 权限而不是借用 data read 权限。

依赖：WU-0023、WU-0025、memory 与 cpu 模块契约。

验收：

- [x] `Fetch16/Fetch32` 使用明确的小端取指接口并报告 execute 观察事件。
- [x] execute-only 页可以取指但普通读取失败。
- [x] 可读但不可执行页取指产生带线程号的 execute permission fault。
- [x] 取指仍执行完整区间验证，不返回伪造值。
- [x] MSVC warnings-as-errors 全量 CTest 通过（53/53）。
