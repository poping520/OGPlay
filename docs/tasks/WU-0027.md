# WU-0027 · A32/T32 解释器标量与控制流基础

目标：建立严格失败、可单步和预算确定的 A32/T32 解释器第一段可执行闭环。

依赖：WU-0025、WU-0026、cpu 与 memory 模块契约。

验收：

- [x] A32 支持条件执行、MOV/ADD/SUB/CMP 立即数、B/BL/BX 和 SVC。
- [x] Thumb-16 支持 MOV/CMP/ADD/SUB 立即数、条件/无条件分支、BX、SVC/BKPT 和 NOP。
- [x] tick 预算、外部停止和同步陷阱返回确定的消费量与 PC。
- [x] 取指权限失败完整转换为带线程号的 `CpuFault`。
- [x] 未识别 A32、Thumb-16/32 指令明确返回 undefined 且不前移 PC。
- [x] MSVC warnings-as-errors 全量 CTest 通过（58/58）。
