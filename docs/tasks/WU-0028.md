# WU-0028 · A32/T32 单次数据访存

目标：让解释器通过 MemoryBus 完成最常用的 word/byte 单次 load/store 并保持 fault 原子性。

依赖：WU-0027、cpu 与 memory 模块契约。

验收：

- [x] A32 支持立即数预索引 LDR/STR/LDRB/STRB 及合法 writeback。
- [x] Thumb-16 支持立即数 LDR/STR/LDRB/STRB 和 PC-relative literal load。
- [x] 所有数据访问只通过 MemoryBus 并携带当前 guest 线程号。
- [x] 数据 fault 不前移 PC，不修改目标/基址寄存器，也不产生部分写入。
- [x] 当前未覆盖或 unpredictable 编码明确返回 undefined。
- [x] MSVC warnings-as-errors 全量 CTest 通过（61/61）。
