# WU-0029 · 最小 NDK 出口样例

目标：提供一个可离线构建的 armeabi-v7a NativeActivity APK，作为 M1 三平台画面与输入出口测试载荷。

依赖：M1 路线图、session/input/gles 模块契约、Android NDK r21。

验收：

- [x] API 19 `armeabi-v7a` 共享库不含 Java/Kotlin 或第三方依赖。
- [x] NativeActivity 使用 EGL/GLES 2.0 绘制画面并显式执行 present。
- [x] 触摸和按键均产生可见且确定的颜色变化。
- [x] 构建脚本离线完成编译、APK 打包、zipalign、debug 签名和签名验证。
- [x] APK 包含 `lib/armeabi-v7a/libogplay_minimal_ndk.so`。
- [x] SDK/NDK 的本机绝对路径不进入提交内容。
