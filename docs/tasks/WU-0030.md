# WU-0030 · M1 裸 guest mailbox 样本

目标：提供不依赖后续 Android 运行时和图形能力的 A32/Thumb 纵向集成载荷。

依赖：ADR-0008、WU-0024、WU-0028、cpu 与 memory 模块契约。

验收：

- [x] 样本不依赖 APK、ELF、Bionic、syscall、JNI、Activity、EGL 或 GLES。
- [x] A32 与 Thumb 使用相同的 input/output/sequence mailbox ABI。
- [x] 宿主注入标准化输入后，guest 写回确定性结果并以固定 SVC 协议停止。
- [x] 所有取指和访存事件携带当前 guest 线程号。
- [x] CPU+内存快照复跑产生相同结果、tick 和停止原因。
- [x] MSVC warnings-as-errors 全量 CTest 通过（63/63）。
