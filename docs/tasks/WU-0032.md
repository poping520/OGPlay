# WU-0032 · Dynarmic A32/T32 后端

目标：接入遵守公共 CPU/内存契约的 Dynarmic 后端，并完成 M1 裸 guest 对拍。

依赖：WU-0025、WU-0030、WU-0031、cpu 与 memory 模块契约。

验收：

- [x] JIT 状态可与 `A32State` 双向转换，线程号与 FPEXC 由 adapter 明确保留。
- [x] 取指和数据访问只通过 `MemoryBus`，fault 明确返回且不穿越生成代码栈。
- [x] tick 预算、外部 halt、SVC、异常均映射到公共 `RunResult`。
- [x] A32/Thumb M1 裸 guest 的状态、mailbox、tick 和停止原因与解释器一致。
- [x] Windows/MSVC warnings-as-errors 全量测试通过（65/65）。
