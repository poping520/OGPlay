# WU-0034 · Guest 真线程组

目标：保证每个 guest 线程在独立宿主线程上持有独立 CPU 执行上下文。

依赖：WU-0025、WU-0033、cpu 与 hal 模块契约。

验收：

- [x] 每个 guest thread ID 只对应一个真实宿主线程和一个独立 CPU 实例。
- [x] 初始/退出 CPU 状态及 TLS 基址明确保存，thread ID 写入 CPU 状态。
- [x] join 真正等待线程退出，重复 ID、重复 join、未知线程和线程异常明确失败。
- [x] 八线程同步点压力测试证明并发执行而非协作式串行。
- [x] Windows/MSVC warnings-as-errors 全量测试通过（69/69）。
