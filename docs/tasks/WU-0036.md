# WU-0036 · Gfx/Audio/FS HAL 契约

目标：补齐 M1 要求的 gfx、audio、fs 宿主抽象且不提前实现后续图形/音频栈。

依赖：WU-0018、WU-0019、hal 模块契约。

验收：

- [x] gfx presenter 与 audio output 公共契约不暴露 SDL、EGL、平台句柄或设备 API。
- [x] audio 配置、队列帧数、启动停止和提交边界类型明确。
- [x] 标准宿主 fs 支持状态、建目录、二进制读写，缺失/IO 失败明确报错。
- [x] ANGLE、GLES 和真实音频设备仍留在对应后续里程碑，不伪造成功。
- [x] Windows/MSVC warnings-as-errors 全量测试通过（73/73）。
