# WU-0037 · Memory 跨编译器类型安全

目标：消除 M1 三平台严格告警发现的迭代器符号转换和 8 位越宽移位。

依赖：WU-0023、WU-0024、memory 模块契约。

验收：

- [x] 快照页索引显式转换到容器 difference type 后再参与迭代器运算。
- [x] 小端编解码统一在 64 位无符号值中移位和合并，8/16/32/64 位均无窄化复合赋值。
- [x] 既有 bus 与 snapshot 行为测试覆盖结果不变。
- [x] Windows/Linux/macOS warnings-as-errors 构建与全量测试通过（73/73）。
