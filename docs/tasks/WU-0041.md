# WU-0041 · Bionic API 基线与本地 oracle

目标：把 M2 Bionic 版本矩阵冻结为 API 19/22/23，并安全导入开发期 ABI oracle。

依赖：ADR-0002、M2 路线图、runtime 与 loader 模块契约。

验收：

- [x] 路线图和数据说明只把 API 19/22/23 列为 M2 支持目标。
- [x] 新 ADR 追加并明确取代 ADR-0002 中的旧版本矩阵。
- [x] ROM 提取物复制到 Git 忽略的 `.local/bionic-oracle/`，不进入发行数据。
- [x] 导入器验证期望文件集、ELF class/machine、体积和 SHA-256。
- [x] 本地清单不记录设备身份、外部绝对路径或凭据。
