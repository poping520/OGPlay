# WU-0042 · 远端持久增量构建

目标：把 Linux/macOS 验证从每轮干净克隆改为安全、可复用的增量编译与测试流程。

依赖：WU-0040、CMake 三平台入口。

验收：

- [x] 远端源码、递归 submodule 和 CMake build 目录在多轮运行间保留。
- [x] 每轮只上传当前主分支 Git bundle，远端 checkout 后由 CMake 执行增量构建。
- [x] 平台 CMake/CTest 路径和额外定义可显式注入。
- [x] 主机、账号、密码和远端绝对路径不写入仓库；密码只从环境变量读取。
- [x] 拒绝非绝对或过宽的远端根目录，不执行递归删除。
- [x] 自测试已注册到 CTest。
