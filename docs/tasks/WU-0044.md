# WU-0044 · ELF32 动态依赖字符串

目标：从可信 ELF 事实模型安全解析 linker 建图所需的库名信息。

依赖：WU-0043、loader 模块契约。

验收：

- [x] `DT_STRTAB` 与 `DT_STRSZ` 必须唯一、齐全且非空。
- [x] 动态字符串表必须完整位于单个 file-backed `PT_LOAD` 范围内。
- [x] 按原始顺序解析全部 `DT_NEEDED`，并解析至多一个 `DT_SONAME`。
- [x] 字符串偏移越界或表内缺少 NUL 时明确失败。
- [x] Windows/Linux/macOS warnings-as-errors 构建与全量 CTest 通过（80/80）。
