# WU-0046 · ELF32 PT_LOAD 页级装载

目标：把可信 `PT_LOAD` 事实安全装入 guest 地址空间，并在写入结束后落实 W^X。

依赖：WU-0043、WU-0044、loader 与 memory 模块契约。

验收：

- [x] load bias 按宿主页对齐，ET_EXEC 禁止 bias，所有 bias 加法检查 32 位回绕。
- [x] 重叠段按宿主页合并权限，相同权限的连续页合并为映射区域。
- [x] 代码和数据先以 RW 装入，按程序头顺序复制文件并清零 BSS，随后施加最终权限。
- [x] 最终宿主页同时需要 W+X 时明确拒绝。
- [x] 非零入口必须位于 executable `PT_LOAD`，并返回加 bias 后的强类型 guest 地址。
- [x] 映射、写入或保护失败时回滚本次已经建立的区域，不破坏既有映射。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（83/83）；Linux/macOS 待增量验证。
