# WU-0047 · ELF32 动态符号与 hash

目标：以边界明确的 SysV/GNU hash 推导 dynsym 数量并解析符号查找事实。

依赖：WU-0044、WU-0046、loader 模块契约。

验收：

- [x] `DT_SYMTAB` 与 `DT_SYMENT` 必须唯一、齐全，条目尺寸固定为 ELF32 的 16 字节。
- [x] SysV hash 的 bucket/chain 数量、总尺寸和 file-backed 范围完整校验。
- [x] GNU hash 的 bloom/bucket 前缀、symbol offset、bucket 和有界 chain 终止完整校验。
- [x] 至少存在一种支持的 hash；两种同时存在时推导的符号数量必须一致。
- [x] 解析名称、值、大小、binding、type、visibility 与 section index，符号零必须为空。
- [x] 只有已定义、GLOBAL/WEAK 且 DEFAULT/PROTECTED 的符号标记为可导出。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（86/86）；Linux/macOS 待增量验证。
