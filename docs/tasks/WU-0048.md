# WU-0048 · ELF32 ARM REL 重定位事实

目标：一次解析普通与 PLT REL 表并冻结可安全交给链接器的目标、符号与类型事实。

依赖：WU-0047、loader 与 memory 模块契约。

验收：

- [x] `DT_REL`/`DT_RELSZ`/`DT_RELENT` 必须成组出现，条目固定为 ELF32 REL 的 8 字节。
- [x] `DT_JMPREL`/`DT_PLTRELSZ`/`DT_PLTREL` 必须成组出现，PLT 只接受 `DT_REL`。
- [x] ELF32 ARM 的 RELA 元数据明确失败，不把显式 addend 静默当作 REL。
- [x] 普通表与 PLT 表均须完整 file-backed、互不重叠且所有大小与地址运算不回绕。
- [x] 每个条目保留强类型目标地址、24 位符号索引、8 位原始类型与所属表。
- [x] 符号索引必须位于 dynsym，4 字节目标必须唯一落在 `PT_LOAD` memory 范围（可位于 BSS）。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（88/88）。
