# WU-0049 · ELF32 ARM 基础重定位应用

目标：原子应用无 TLS/IFUNC 依赖的 ARM32 动态链接重定位并始终恢复 W^X。

依赖：WU-0048、loader 与 memory 模块契约。

验收：

- [x] 应用 `R_ARM_NONE/ABS32/REL32/GLOB_DAT/JUMP_SLOT/RELATIVE` 的 ELF32 模运算语义。
- [x] 符号地址由链接命名空间预解析后注入，未解析符号与越界索引明确失败。
- [x] 重定位目标叠加 load bias，且必须与装载计划的 bias 一致。
- [x] 重复目标明确失败，避免依赖隐式次序。
- [x] 先完成全部校验，再临时将装载区域切为 RW；完成或失败后恢复最终 W^X。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（90/90）。
