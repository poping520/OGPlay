# WU-0052 · Bionic profile 与符号路由

目标：冻结 API 19/22/23 的真实 Bionic 集合以及 guest、选择性拦截、HLE 边界三路契约。

依赖：WU-0041、WU-0050、runtime 模块契约。

验收：

- [x] 只接受 API 19/22/23，其他 API 明确失败，不做最近版本猜测。
- [x] 三档固定 `libc/libm/libdl/libstdc++/libz` guest 库集合和发行数据相对目录。
- [x] EGL/GLES/OpenSL ES/android/JNI graphics/log 等系统服务边界库固定走宿主 HLE。
- [x] libc 默认走真实 guest Bionic；仅声明的 str/mem/pthread 热点进入宿主拦截。
- [x] 路由要求非空库名和符号名，不对未知符号伪造处理结果。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（97/97）。
