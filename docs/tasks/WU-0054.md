# WU-0054 · Android 基础内存 syscall

目标：为 Bionic allocator 提供受 guest 地址空间约束的基础映射与 program break。

依赖：WU-0051、memory 模块契约。

验收：

- [x] `mmap2` 支持匿名私有映射、页向上取整、确定性地址分配及安全的 `MAP_FIXED`。
- [x] `munmap/mprotect` 要求页对齐，长度按 Linux 规则向上取整。
- [x] Linux `PROT_WRITE` 映射为 guest RW；任何 W+X 请求返回 `-EPERM`。
- [x] `brk(0)` 查询当前 break，在隔离 arena 内按页增长或收缩，失败保留旧值。
- [x] 文件映射、`PROT_NONE` 和不支持 flag 不伪装成功，返回明确 errno。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（99/99）。
