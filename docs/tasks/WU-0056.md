# WU-0056 · Android VFS 与文件描述符核心

目标：提供不泄漏宿主路径、大小写行为跨平台一致的 Android 文件与描述符语义。

依赖：WU-0036、runtime/HAL 文件边界契约。

验收：

- [x] 只接受 Android 绝对路径，折叠重复分隔符和 `.`，拒绝 `..`、反斜杠与空字符。
- [x] 文件索引按 ASCII 大小写不敏感匹配，大小写冲突明确返回 `EEXIST`。
- [x] descriptor 从 3 开始且每次 open 拥有独立 offset。
- [x] read/write/seek/close 具备 EOF、扩展写、负 seek、坏 fd 和访问模式契约。
- [x] 只读挂载不可写；create/truncate 必须满足相应访问权限。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（103/103）。
