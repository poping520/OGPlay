# WU-0057 · Android 基础文件 syscall

目标：让 guest 通过受检指针和 Linux errno 使用 VFS 的基础文件描述符闭环。

依赖：WU-0051、WU-0056、memory/runtime 模块契约。

验收：

- [x] `open/openat` 有界读取 NUL 路径并翻译 RDONLY/WRONLY/RDWR/CREAT/TRUNC。
- [x] `read` 先验证完整 guest 写范围再推进 fd offset，EOF 返回零。
- [x] `write` 从完整受检 guest 范围复制，不向 VFS 暴露 guest/host 裸指针。
- [x] `lseek` 支持 SET/CUR/END 和有符号 32 位 offset；溢出返回 `-EOVERFLOW`。
- [x] `close` 与所有 VFS 错误保留 Linux errno；坏 guest 指针返回 `-EFAULT`。
- [x] 相对 `openat` 尚无目录 fd 语义时返回 `-ENOTSUP`，不错误拼接路径。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（104/104）。
