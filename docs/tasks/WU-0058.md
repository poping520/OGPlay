# WU-0058 · ELF32 生命周期与 ARM exidx 事实

目标：冻结依赖初始化、卸载清理和 ARM 展开表所需的受检 ELF 事实。

依赖：WU-0043、WU-0050、loader 模块契约。

验收：

- [x] `DT_INIT/DT_FINI` 唯一解析并保留含 Thumb bit 的原始 guest 地址。
- [x] init/fini array 地址与尺寸必须成对出现，尺寸按 ELF32 word 对齐。
- [x] 函数数组必须完整 file-backed 且映射唯一，条目按原顺序保留。
- [x] `PT_ARM_EXIDX` 最多一个，file/memory size 一致且按 8 字节 entry 对齐。
- [x] exidx 非空范围必须由唯一 `PT_LOAD` 完整 file-backed。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（106/106）。
