# WU-0060 · ELF32 ARM TLS 模板事实

目标：冻结 guest 模块静态 TLS 分配所需的受检 `PT_TLS` 模板事实。

依赖：WU-0043、WU-0058、loader 模块契约。

验收：

- [x] 无 `PT_TLS` 返回空事实；每个模块最多一个 TLS segment。
- [x] 保留模板 guest 地址、初始化字节、总内存大小及原始对齐。
- [x] file size 不得超过 memory size，地址范围不得回绕。
- [x] 对齐只接受零或二次幂，file/virtual 地址满足对齐同余。
- [x] TLS memory 与初始化字节必须分别由唯一 `PT_LOAD` memory/file 范围覆盖。
- [x] macOS AppleClang `dev` 预设构建与全量 CTest 通过（110/110）。
