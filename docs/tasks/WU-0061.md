# WU-0061 · ELF32 GNU 符号版本事实

目标：冻结统一动态链接器匹配符号版本所需的 `VERSYM/VERDEF/VERNEED` 事实。

依赖：WU-0047、WU-0060、loader 模块契约。

验收：

- [x] 无版本动态项返回空事实；版本定义/需求不能脱离 `DT_VERSYM`。
- [x] 每个 dynsym 保留 local/global/definition/requirement、hidden bit 和版本索引。
- [x] 定义保留版本名，需求同时保留版本名与依赖库名。
- [x] 所有结构与字符串必须唯一 file-backed，动态 tag 不得重复。
- [x] 链表长度、revision、辅助项、版本索引和 address arithmetic 均严格校验。
- [x] macOS AppleClang `dev` 预设构建与全量 CTest 通过（112/112）。
