# WU-0062 · ELF 动态命名空间扩展与版本匹配

目标：让后续 `dlopen` 在同一个 ELF 命名空间中事务式追加模块并按版本解析符号。

依赖：WU-0050、WU-0061、loader 模块契约。

验收：

- [x] 扩展保留既有模块索引、主程序 load order 与 lookup scope。
- [x] 每个动态根获得独立的依赖优先 load order 与根优先 BFS lookup scope。
- [x] 新模块可依赖已装载模块，`newly_loaded` 只含本次新增闭包且顺序确定。
- [x] 版本化导入按依赖库与版本名精确匹配；普通查询忽略 non-default hidden 定义。
- [x] 别名冲突、版本表尺寸错误、缺失依赖及不可达新增模块事务式失败。
- [x] macOS AppleClang `dev` 预设构建与全量 CTest 通过（115/115）。
