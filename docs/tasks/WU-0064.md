# WU-0064 · guest thread pointer 状态

目标：让每个 guest 线程的 TLS 基址成为 CPU 状态中可验证、可快照的 thread pointer。

依赖：WU-0034、WU-0060、cpu 模块契约。

验收：

- [x] `A32State` 显式保存强类型 guest thread pointer，CPU 快照版本同步前进。
- [x] `GuestThreadGroup` 启动时将 TLS 基址装入线程独立 CPU 状态。
- [x] 非零 CPU thread pointer 与启动 TLS 基址不一致时明确失败。
- [x] join 返回的退出 CPU 状态保留同一 thread pointer。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
