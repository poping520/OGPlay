# WU-0070 · guest 线程退出 syscall

目标：把 `set_tid_address/exit/exit_group` 接入唯一的 guest 线程生命周期状态机。

依赖：WU-0051、WU-0069、runtime 模块契约。

验收：

- [x] `set_tid_address` 保存可为空的 clear-child-tid 并返回当前 guest TID。
- [x] `exit` 记录当前线程退出码并只发出 exit-requested。
- [x] `exit_group` 将同一退出码传播到所有尚未退出的 guest 线程。
- [x] 未知/零线程返回 `ESRCH`，无法表示的 TID 返回 `EOVERFLOW`。
- [x] syscall handler 不伪造宿主线程已经停止，complete 由执行循环负责。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
