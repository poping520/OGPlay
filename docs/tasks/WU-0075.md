# WU-0075 · guest child 生命周期注册

目标：为 clone 提供一次完成 parent 校验和 child 初始状态发布的原子生命周期操作。

依赖：WU-0069、WU-0074、runtime 模块契约。

验收：

- [x] parent 查找、running 状态与 child TID 唯一性在同一临界区校验。
- [x] child 的 TID、TLS、clear-child-tid 与 running 状态一次发布。
- [x] 零 child TID、未知/退出中 parent、重复 child 均明确失败。
- [x] 任一失败不留下部分 child 生命周期状态。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
