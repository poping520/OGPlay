# WU-0077 · clone CPU 上下文

目标：让 ARM clone 请求保留可直接派生 child 的完整调用时 CPU 状态。

依赖：WU-0072、WU-0074、cpu/runtime 模块契约。

验收：

- [x] `SVC #0` frame 携带写回 syscall 返回值之前的完整 A32 状态副本。
- [x] clone 请求保留核心/扩展寄存器、CPSR、返回 PC、thread ID 与 thread pointer。
- [x] frame thread ID 与 CPU state 不一致或缺少 CPU state 时返回 EINVAL。
- [x] A32/Thumb 执行状态不由 syscall handler 猜测。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
