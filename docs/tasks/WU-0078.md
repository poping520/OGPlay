# WU-0078 · clone 真线程执行

目标：让 ARM clone 创建的 child 在独立宿主线程从 Linux child 返回路径继续执行。

依赖：WU-0034、WU-0073、WU-0076、WU-0077、cpu/runtime 模块契约。

验收：

- [x] child 继承完整 A32 状态，仅覆盖 r0=0、SP、thread ID 与 TLS。
- [x] 每个 child 由 GuestThreadGroup 启动一个独立宿主线程和 CPU。
- [x] child 在预算切片间持续执行统一 SVC 循环，直到 exit 或显式 CPU stop。
- [x] parent 获得正 guest TID，child 获得 0，二者从 SVC 后同一 PC 分流。
- [x] child exit 完成 clear-child-tid 并保留结构化运行结果。
- [x] Windows/MSVC warnings-as-errors 构建与端到端契约测试通过。
