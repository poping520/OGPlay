# WU-0082 · 120 项 Android ARM syscall 目录

目标：达到 M2 路线图要求的分组 syscall 目录规模，同时保持所有缺口可观测。

依赖：WU-0051、M2 路线图、runtime 模块契约。

验收：

- [x] 目录声明不少于 120 个 Android ARM EABI 调用，覆盖九个既定分组。
- [x] 文件、内存、线程、信号、时间、进程与 poll 扩展号按 ARM 号登记。
- [x] 声明不等于伪实现；未绑定项仍返回 ENOSYS 并以稳定名字进入能力账本。
- [x] 未知号继续以 `syscall.arm.<number>` 独立记账。
- [x] Windows/MSVC warnings-as-errors 构建与目录契约测试通过。
