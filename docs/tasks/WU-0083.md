# WU-0083 · APK/OBB/外置统一 VFS

目标：让三类 Android 文件来源进入同一个大小写不敏感、事务式 VFS 索引。

依赖：WU-0056、runtime/HAL 文件边界契约、M2 路线图。

验收：

- [x] APK、OBB、external 使用同一 Mount API 和规范化索引。
- [x] Stat 保留来源和可写事实；APK/OBB 只读，external 默认可写。
- [x] 大小写不敏感查找与隔离 descriptor 语义跨来源一致。
- [x] 相对路径逃逸、重复项或既有路径冲突使整批挂载失败，不留下部分文件。
- [x] Windows/MSVC warnings-as-errors 构建与 VFS 契约测试通过。
