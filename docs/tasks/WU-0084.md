# WU-0084 · M2 无界面 NDK 累计载荷

目标：冻结一个导出普通 C 入口并同时使用 pthread、文件 IO 与 malloc 的 M2 出口 `.so`。

依赖：M2 路线图、NDK 21.4、samples 模块约定。

验收：

- [x] API 19 armeabi-v7a ELF32/ARM shared object，不含 Activity/JNI/EGL/GLES。
- [x] 导出 `ogplay_m2_entry(const char*)`，0 成功且每个失败阶段返回不同负值。
- [x] 实际调用 pthread_create/join，主线程与 child 均调用 malloc/free。
- [x] 实际调用 open/write/lseek/read/close 并逐字节校验读回内容。
- [x] 离线构建器校验 ELF、libc 依赖、普通 C 导出和全部契约导入符号。
