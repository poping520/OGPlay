# WU-0088 · Bionic madvise 内存语义

目标：补齐真实 Bionic pthread 路径使用的 ARM `madvise`，且不伪造丢弃页成功。

依赖：WU-0054、WU-0085，受检 AddressSpace。

验收：

- [x] NORMAL/RANDOM/SEQUENTIAL/WILLNEED 与合并/大页 hints 只在完整映射范围上接受。
- [x] `MADV_DONTNEED` 预检完整可写范围并把匿名页内容实际清零。
- [x] `mprotect(PROT_NONE)` 建立 Bionic pthread 所需的不可访问 guard page。
- [x] 未对齐地址、零长度、未映射范围及未知 advice 返回明确 errno。
- [x] Windows/MSVC warnings-as-errors 与真实 Bionic pthread 路径通过。
