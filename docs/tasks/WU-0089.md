# WU-0089 · PROT_NONE 映射状态

目标：把 guest 页“已映射”与“无访问权限”分离，支持 Bionic pthread guard page。

依赖：M1 AddressSpace、WU-0088 的真实 Bionic 执行轨迹。

验收：

- [x] `Map/Protect(PROT_NONE)` 保留映射存在性，访问报告 permission denied。
- [x] guard page 与未映射页可区分，重复 Map 仍被拒绝，Unmap 可正常释放。
- [x] `PROT_NONE` 与 execute-only 页可捕获并事务恢复，恢复后权限不放宽。
- [x] Windows/MSVC warnings-as-errors、内存契约与真实 Bionic pthread 路径通过。
