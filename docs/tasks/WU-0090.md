# WU-0090 · API 19 clone ABI 兼容

目标：让旧 Bionic 的 ARM pthread clone 形态按 AAPCS 栈与 TLS 继承语义创建真线程。

依赖：WU-0074、WU-0078、WU-0085 的真实 API 19 执行轨迹。

验收：

- [x] child stack 接受 AAPCS 要求的 8 字节对齐，4 字节对齐仍返回 EINVAL。
- [x] `CLONE_SETTLS` 继续显式覆盖 child TLS。
- [x] 未请求 `CLONE_SETTLS` 时 child 继承 parent TPIDRURO，不伪造零 TLS。
- [x] Windows/MSVC warnings-as-errors、clone 契约与真实 Bionic pthread 路径通过。
