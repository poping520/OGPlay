# WU-0091 · child TLS 提交与匿名 mmap ABI

目标：让旧 Bionic child 初始化后的 TPIDRURO 与匿名辅助栈映射遵守 Linux ARM ABI。

依赖：WU-0073、WU-0090、WU-0085 的真实 child syscall 轨迹。

验收：

- [x] `__ARM_NR_set_tls` 成功后，统一 guest 执行循环立即把 lifecycle TP 写入当前 CPU。
- [x] 后续 TPIDRURO 读取 child TLS，不再误读或回收 root TLS。
- [x] `MAP_ANONYMOUS` 忽略 fd 参数，仍要求 private/anonymous 与零页偏移。
- [x] Windows/MSVC warnings-as-errors、执行循环契约与真实 Bionic pthread 路径通过。
