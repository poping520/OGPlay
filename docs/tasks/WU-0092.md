# WU-0092 · Bionic 线程信号状态

目标：实现真实 Bionic child 初始化与退出必经的 signal mask 和 alternate stack 状态。

依赖：WU-0082、WU-0091，受检 AddressSpace 与 guest thread ID。

验收：

- [x] legacy `sigprocmask` 与 `rt_sigprocmask` 按线程保存 mask，SIGKILL/SIGSTOP 不可屏蔽。
- [x] `sigaltstack` 按线程启用、查询和禁用，最小尺寸、flags 与指针受检。
- [x] thread 0、坏指针、错误 how/size/flags 返回明确 Linux errno。
- [x] Windows/MSVC warnings-as-errors、信号契约与真实 Bionic 累计样本通过。
