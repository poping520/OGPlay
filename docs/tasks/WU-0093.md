# WU-0093 · Linux ARM kuser helper 页

目标：让 API 23 Bionic 使用的固定高地址 ARM kernel helpers 在 guest 中可执行且可审计。

依赖：M1 AddressSpace/Dynarmic、WU-0087 exclusive monitor、WU-0085 三版本执行。

验收：

- [x] `0xffff0fa0` memory barrier 保持 AddressSpace 的跨线程访问顺序。
- [x] `0xffff0fc0` cmpxchg 使用共享 LDREX/STREX，成功/失败都返回 Linux kuser ABI 值。
- [x] `0xffff0fe0` 返回当前 TPIDRURO，版本字为 5。
- [x] 未定义 helper 位置执行显式 SVC trap，不以零指令静默继续。
- [x] Windows/MSVC warnings-as-errors 与 API 23 累计样本通过。
