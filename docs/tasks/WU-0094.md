# WU-0094 · 独立映射存在性查询

目标：让不要求页可读写的内核元数据操作也能受检，不把 `PROT_NONE` 当坏地址。

依赖：WU-0089 的映射/权限分离账本。

验收：

- [x] `ValidateMapped` 覆盖非页对齐半开区间并携带首个未映射地址与 thread ID。
- [x] `PROT_NONE` 范围通过映射检查，但继续拒绝 read/write/execute。
- [x] Unmap 后同一范围明确报告 unmapped fault。
- [x] Windows/MSVC warnings-as-errors 与 AddressSpace 契约通过。
