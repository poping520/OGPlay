# WU-0097 · 可执行 Bionic 内存拦截与基准

目标：只发布确有生产 handler 的选择性 libc 拦截，并用实际吞吐关闭 M2 性能出口。

依赖：WU-0052、WU-0059、M1 AddressSpace。

验收：

- [x] 仅 memcpy/memmove/memset/memcmp/strlen 路由到 host intercept；其他 libc 走真实 Bionic。
- [x] handler 完整预检 guest 范围，保持 memmove 重叠、memcmp 有符号结果与 strlen 上限。
- [x] 未注册 symbol、零 thread、坏范围明确失败，不存在只有 thunk 没有 handler 的能力。
- [x] Windows/MSVC Debug 实际复制吞吐不低于 4 MiB/s，并输出测量值供回归比较。
