# WU-0098 · pthread 拦截边界决策

目标：消除“pthread 函数 thunk 已登记但无生产 handler”的伪能力，并冻结真线程边界。

依赖：ADR-0002、WU-0052、WU-0085 三版本真实 pthread 轨迹。

验收：

- [x] ADR-0010 明确 pthread 保持真实 Bionic ABI，宿主映射位于 clone/futex/TLS syscall。
- [x] 路线图的选择性拦截表与生产路由一致，不再要求伪造 pthread 内部结构。
- [x] 函数级 intercept 必须同时具备 handler、行为测试与性能基准。
- [x] M2 三版本样本和未实现 syscall 验收项按机器结果更新。
