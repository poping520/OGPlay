# DVM-100 · 可重复构建 API 19 BootDex

## 目标

把 API 19 curated BootDex 从一次性二进制提升为由固定输入、精确类 recipe 和确定性工具生成、
可独立复验的发行制品；后续每次精确类扩展和对应运行时 overlay 都追加记录在本 WU。

## 依赖

- ADR-0030、DVM-99；
- pinned API 19 `core.jar` 与 smali/baksmali 3.0.10。

## 交付与边界

- `tools/bootdex/api19.json` 登记 API level、“源 jar → class descriptor”精确列表及日期闭包审计元数据；
- `tools/bootdex/build_bootdex.py` 提供 `build`、`check`、`audit` 和统一 `--self-test`；
- smali/baksmali 缺失时下载固定 3.0.10 release，并校验 SHA-256；
- 每次 build 双目录组装并比较，JAR 固定 entry、时间、权限和压缩策略；
- payload validator 复核 recipe、精确类集合和 canonical JAR；
- 不引入完整 core/framework；新增类必须来自 pinned AOSP jar、进入精确 recipe、重建
  canonical JAR 并通过 payload validator。

## 验收

- [x] 两个隔离目录生成相同 DEX，且 DEX 哈希与 EnumSet 试点一致；
- [x] `build` 后 `check` 可字节级复现 JAR 和 manifest metadata；
- [x] builder self-test 与 Android payload validator 通过；
- [x] switch/threaded EnumSet 定向回归 1/1、84 个断言通过；
- [x] PvZ exact Profile 仍越过 EnumSet，并停于
  `Executors.newFixedThreadPool(I)`。
