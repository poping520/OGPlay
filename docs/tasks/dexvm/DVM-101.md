# DVM-101 · API 19 Unsafe intrinsic

## 目标

以受检 Java 堆位置实现 API 19 `sun.misc.Unsafe`，让精选 BootDex 的原子类与 AQS 使用真实 VM 原语。

## 依赖

DVM-94～96、DVM-99～100、DVM-48、[ADR-0031](../../adr/0031-bounded-unsafe-locations.md)。
参考固定 AOSP 4.4.4 的 libcore/libdvm Unsafe.java、luni concurrent 与 Dalvik native Unsafe。

## 设计与交付

- 现有 concurrent family 声明 API 19 类、单例、loader 权限、字段/数组位置、int/long/ref
  三组 plain/volatile/ordered/CAS、park/unpark 与 allocateInstance。
- 独立 per-VM UnsafeRuntime 保存字段元数据令牌，访问既有 Java 对象槽和 JNI 数组。
- execution lock 保证原子性；引用写入保留类型和 GC 强边；无宿主地址或影子状态。
- absolute park 将注入 epoch 毫秒转换为同一 Clock 的单调 deadline，复用 Thread 行为。
- 任意字节访问、类型重解释和未发布 API 明确失败；不扩大 BootDex 制品、不承诺完整线程池。

## 验收

- [x] singleton/loader、跳过构造器与 clinit 异常；
- [x] DEX 字段互通、继承、三类 CAS、非法令牌/类型/null/static；
- [x] 数组 scale/对齐/边界和共享存储、引用 identity 与 GC；
- [x] 单许可、纳秒取整、epoch deadline、中断、跨线程 CAS；
- [x] switch/threaded 的真实 BootDex AtomicInteger/AQS/LockSupport；
- [x] 受影响目标构建、定向回归与架构检查。
