# DVM-102 · 日期格式化家族迁入 BootDex

目标：让 API 19 日期格式化与日历算法执行 pinned AOSP 字节码，删除对应 C++ Java 行为副本，
只保留明确登记的 VM、时间、区域数据和 native 边界。

状态：已完成（2026-09-05）。完成项仅指本单冻结的 Locale、固定时区、
整数格式化与日期文本闭包；具名时区库、大数/double formatter 和完整 ICU 查询仍
为明确的 deferred 边界。

独立验收发现的 ICU、日期/时区及基础回归问题已修正，macOS 定向复验完成；
Windows/Linux 构建与全仓既有平台门禁问题不据此宣称通过。

## 依据与已确认问题

以下现状描述保留迁移前基线，最终结果见本文末尾完成与修正记录。

- 依赖 [ADR-0030](../../adr/dexvm.md#adr-0030)、[DVM-100](DVM-100.md)、
  [DVM-101](DVM-101.md)、[DVM-87](DVM-87.md) 和现有 owner state/GC、IO 序列化契约。
- 当前 recipe 有 47 个 class_def；本地 `core.jar` SHA-256 与 builder 固定值相同。
  `java_text.cpp` 仅发布 Format/DateFormat/SimpleDateFormat 层级和指定 pattern/Locale 构造器，
  不存在可复用的 format/parse 实现。
- BootDex 的精确方法 overlay 优先于字节码。旧 SimpleDateFormat 构造器只写 pattern，
  必须随接管删除，否则 calendar、numberFormat、formatData 和两位年份窗口不会初始化。
- AOSP `SimpleDateFormat(Locale)` 会调用 NumberFormat.getInstance、GregorianCalendar(Locale)
  和 Calendar.add(YEAR, -80)。现有 Calendar 缺少这个构造链与 YEAR add，不能直接复用。
- 现有 Date 类方法仍是显式未实现；Object streams 已支持 Date wire format，但读写私有
  `millis` 字段。AOSP Date 使用 `milliseconds`，且 `<clinit>` 通过 new Date().getYear()
  进入 Clock/Calendar；迁移必须同时处理字段和初始化依赖。
- LocaleData 的 `<clinit>` 预热 ROOT、US 和默认 Locale；现有 Locale 只有 ENGLISH 和有界
  语言查询，需补齐真实值、区域及字符串身份，不能让 Locale.toString 沿用 Object 身份串。
- DecimalFormatSymbols 构造会进入 Currency；DecimalFormat `<clinit>` 创建
  ObjectStreamField[] 并引用 RoundingMode。`format(Object,...)` 即使接收 Integer，也先做
  BigInteger/BigDecimal 的 instanceof，不能仅按“游戏没传大数”忽略其类型解析依赖。
- ICU、NativeDecimalFormat、TimeZoneNames 含 native。BootDex 对未绑定 native 在装载时就
  拒绝，必须逐签名提供真实实现或记账并抛异常的显式未实现 handler，不能只覆盖热路径。
- 本地 ICU.java 与 pinned core.jar 的方法表有差异：后者还含 getDisplayScriptNative、
  languageTagForLocale、localeForLanguageTag 等声明。源码用于追溯，实际 descriptor、字段、
  access flags、嵌套类及调用链必须以固定 JAR/DEX 复核；不因此更换 builder 的 pinned 输入。

## 范围与实现选择

日期基础类一并迁入的范围已获用户确认；下表为本批次目标。

| 层次 | 迁移范围 | 所有权 |
| --- | --- | --- |
| 日期文本 | Format、DateFormat、SimpleDateFormat、DateFormatSymbols、FieldPosition、ParsePosition、ParseException，含相关 Field 类 | BootDex，删除旧三个类的全部 intrinsic |
| 字段属性 | CharacterIterator、AttributedCharacterIterator/Attribute、AttributedString 及嵌套类、按需 StringCharacterIterator | BootDex；用于 Field 层级和 attributed 格式化 |
| 数字依赖 | NumberFormat/Field、DecimalFormat、DecimalFormatSymbols、Currency、RoundingMode、ObjectStreamField，以及实际链接所需的大数类型/辅助类 | Java 逻辑进 BootDex，native 另设明确边界 |
| 日期与日历 | Date、Calendar、GregorianCalendar、TimeZone、SimpleTimeZone | Java 字段/算法进 BootDex；Date 与序列化适配同批切换 |
| 区域数据 | LocaleData、ICU、NativeDecimalFormat 及嵌套类、TimeZoneNames 及嵌套类、BasicLruCache | Java 包装优先 BootDex；ICU 数据/native 由 core 窄接口提供 |
| 通用依赖 | Locale、String/StringBuffer、集合、Object.clone、System.currentTimeMillis | 沿用现有 owner，只补实际命中的 API19 缺口；本次不迁整个 java.lang/java.util |

已从 pinned DEX 确认上述主要候选（尚不含大数类型闭包）共 37 个 class_def；这只是
选类起点，不是最终新增数量，也不是已验证闭包。A 阶段必须登记每个实际新增 descriptor。
只选相关精确类及所需嵌套类，不使用 java.text.* 通配符，不装载整个 core.jar。

推荐为 ICU 引入固定、随包交付的 ICU4C 代码和数据，以匹配 pinned libcore 的接口及行为；
先在 A/B 冻结来源、版本、哈希、许可证及平台可构建性。当前仓库尚无对应 ICU 依赖接入。
不使用宿主系统 ICU、locale 或时区数据库作为隐式输入，也不在 C++ 新写一套日期 pattern
解释器或用 strftime 替代 AOSP。引入 native 依赖和下述平台 overlay 边界先写新增 ADR。

首批时区保持 GMT/UTC 与固定 offset，默认值由会话明确注入；具名时区数据库与历史 DST
另立任务。TimeZone 的默认值/查库入口可以保留精确平台 overlay，但必须使用 DEX 的真实
字段和 Java 构造器，复用 AOSP 自定义 GMT 解析和 SimpleTimeZone 算法；不保留旧日历计算。
不支持的数据库查询要可查询并明确失败；AOSP 对非法 ID 的 GMT 回退是 API 行为，必须与
“受支持的真实时区因未提供数据库而无法查询”区分。格式化 z/Z 和自定义 symbols 单独验收。

Locale 暂不整体迁移；补齐初始化链需要的 ROOT、US、ENGLISH、默认值及构造/区域/toString/
equals/hashCode 等实际调用。测试至少覆盖 root、en、en_US 和会话已使用的 zh；数据来自固定
ICU 输入。不得把其他区域静默映射到英语。所有新建引用与缓存遵循现有 GC 契约。

## Work Unit 顺序

### A · 冻结依赖与边界（已完成）

依赖：DVM-99～101。目标：形成可逐项验收的精确类、成员和 overlay 清单。

- 从 pinned core.jar 提取候选类，核对本地源码差异，追踪类初始化、字段类型、instanceof、
  invoke、异常和 clone 路径；复用现有 DEX 工具，派生输出留 `.local/`。
- 每个引用标记为 BootDex / 现有 intrinsic / 新 native 边界 / 明确 deferred，区分装载所需、
  初始化必经和分支才触达。大数类型解析不能用伪造空类绕过。
- 冻结 ICU 来源与 native 方法全表、允许保留的 TimeZone/Locale 边界、首批区域/时区集合，
  新增 ADR；不修改 ADR-0030 的 load-all 与 unbound-native 拒绝规则。
- 验收：清单无未分类依赖，每个保留的非 native overlay 有必要性说明；精确后续任务范围
  能在单会话完成，超出则继续拆分。此阶段不发布声称可用的扩大版 BootDex。

完成结果（2026-09-05）：

- 新增 [ADR-0032](../../adr/dexvm.md#adr-0032)，固定 AOSP ICU4C
  51.1.0.1 的 tag/commit/tree/archive hash、许可证、首批 Locale/时区集合、native 资源所有权
  与保留 overlay；B 负责三平台构建验证，不允许宿主 ICU 回退。

  `Annotation`、`Grego`、`Objects` 及用于真实 `instanceof` 解析的 `BigInteger`/
  `BigDecimal`；大数算法 helper 保持 deferred，不伪造空类。

  Date 对象流切换字段固定为 `milliseconds`。发行 recipe/BootDex 未改，仍为 47 类。

### B · 固定 ICU 依赖与资源生命周期

依赖：A。目标：提供不依赖宿主区域环境的 ICU backend。

- 固定源码/数据与 NOTICE，接入受影响平台目标及 staging/payload 校验；先验证现代工具链
  可构建，版本偏差以 API19 测例裁决，不能用系统 ICU 暗中替换。
- 新 core runtime 仅拥有 native formatter 资源；Java 的 long address 保存受检逻辑令牌，
  不保存宿主指针。定义 clone、非法令牌、close、异常清理、GC sweep 与 VM teardown。
- AOSP finalize 不能成为唯一释放机制；即使 VM 尚无完整 finalizer，也须保证 owner 被回收
  和 VM 销毁时资源释放。缓存不跨 VM 泄漏默认区域或可变状态。
- 验收：固定输入一致性、资源 clone 独立、重复释放/失效令牌受检、GC/teardown 无遗留。

### C · LocaleData、Currency 与时区数据边界

依赖：A、B。目标：让日期/数字格式化所需区域初始化真实完成。

- 补齐 Locale 值接口；接通 ICU.initLocaleDataNative、最佳时间 pattern、货币查询与首批
  时区名称入口，沿用 BootDex LocaleData 缓存和字段布局。
- 对 ICU 类其余 native 全部提供精确登记的失败路径；按 native 清单检测无漏项。
- 补齐这里真实触达的 String.replace/replaceAll、数组 clone、集合等缺口，独立通用测试。
- 验收：ROOT/US/default 冷启动、zh 数据、第二 VM 隔离、缺失数据/不支持请求明确失败；
  DateFormatSymbols/DecimalFormatSymbols 可构造，数组 getter/setter 不破坏共享缓存。

### D · NumberFormat/DecimalFormat 依赖闭合

依赖：C。目标：使 AOSP 日期 formatter 使用真实数字格式器完成数字格式化与解析。

- 选入数字 Java 类及精确依赖；绑定 NativeDecimalFormat 的 open/clone/close、符号/属性、
  formatLong 和日期 parse 必经原语，完整登记其余 native 的实现或显式失败。
- 处理 FieldPositionIterator 的 Java 数组/字段写回、parse 返回值与 ParsePosition 索引，
  不以宿主指针或独立 Java 影子状态传递结果。
- 验收：最小整数位数、补零、禁分组、符号、整数解析、错误索引、formatter clone、
  FieldPosition，以及带 ObjectStreamField/RoundingMode 的冷启动；大数算法长尾仍 deferred。

### E · Date/Calendar/TimeZone 切换与序列化兼容

依赖：C；D 完成后再合入最终组合。目标：日期基础类改用 AOSP 算法且保留既有序列化能力。

- 接管 Date、Calendar/GregorianCalendar、TimeZone/SimpleTimeZone，删除对应 Java 行为
  intrinsic 与 Dvm87CalendarFields/日期换算 helper；只留下 A 冻结的平台事实 overlay。

- 同步将 Date object-stream 特殊段读写适配真实 milliseconds 字段，保留 serialVersionUID、
  wire bytes 和重复引用身份；不借此扩展任意 writeObject/readObject hooks。
- 验收：固定 Clock 下 Date 初始化、Calendar.add(YEAR,-80)、闰日/负 epoch/月末、字段
  set/clear/lenient、固定 offset、自定义 SimpleTimeZone、clone，以及 Date 跨迁移 wire 回归。
