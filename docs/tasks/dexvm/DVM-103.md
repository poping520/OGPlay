# DVM-103 · 集合家族与 Externalizable 迁入 BootDex

## 目标

将 API 19 List/Collection/Map 家族及其实现、视图、迭代器、工具算法迁入 pinned BootDex，
删除相应宿主集合状态与 intrinsic，并闭合 PvZ 当前触达的 Externalizable 接口和对象流回调。

## 依赖与范围

- DVM-78、DVM-79、DVM-94、DVM-99～102；沿用 [ADR-0030](../../adr/dexvm.md#adr-0030)，补充 [ADR-0033](../../adr/dexvm.md#adr-0033)。
- 输入：固定 `.local/aosp/core.jar`，源码对照 `.local/aosp/libcore/luni`。
- 主类清单仍只维护于 `tools/bootdex/api19.json`；继承 Collection/Map 的 java.util 类及其
  内部类一并迁入，包括 Sorted/Navigable、Weak/Identity/Enum 和 concurrent 容器。
- Arrays/Collections 排序与包装、Observable/Observer、Random、ThreadLocal 与弱引用是直接
  依赖；Externalizable/Serializable/ObjectInput/ObjectOutput/DataInput/DataOutput 接口由 DEX 拥有。
- 实际流 IO 继续由 IoRuntime 承担。Externalizable 使用协议 2、公共无参构造、真实回调、
  block-data 和共享对象 handle；完整 ObjectStreamClass/默认 UID、任意 custom serialization
  不因类迁移自动宣称支持。
