# DVM-104 · 后续纯 Java 类库迁入 BootDex

## 目标

在一个 WU 内迁入上轮筛选的小工具/事件、同步器/普通 atomic、格式化、内存流及 X500 名字解析，
删除重复 intrinsic，补齐其直接触达的字符集与 VM 边界，完成定向验收。

## 依赖与范围

- DVM-100～103、ADR-0030/0033/0034；固定 API 19 core.jar，源码对照本地 libcore/luni。
- 小工具：Objects/StringTokenizer/BitSet/MathContext；Event 三类与 java.beans 五类。
- CountDownLatch/Semaphore/CyclicBarrier 与普通 atomic/原子数组；AtomicLong 保留 CS8 native。
- ChoiceFormat/MessageFormat；Input/OutputStream、Reader/Writer、内存/Buffer/Filter/Data 流、
  StreamTokenizer。文件/VFS/ZIP 与 bounded Object streams 保留资源边界，包装改走 guest 方法。
- X500Principal/Name/ASN.1/DER 名字解析闭包；标准字符集值语义与 String 编解码/大小写。
- 按依赖选入简单 security/crypto spec 值对象。
- 完整 crypto provider/证书验证、正则/ICU 分词、URI/UUID、ForkJoin/FieldUpdater、默认 UID/
  任意私有序列化 hooks/对象数组序列化、完整 NIO 不纳入。MessageFormat 仍受既有 formatter
  数值范围限制；不伪造未实现格式或编码。

- [x] recipe 选类、native 边界清单与确定性重建。
- [x] 小工具、事件、同步器与普通 atomic 迁移并删除重复 handler。

- [x] X500/字符集/String、Choice/MessageFormat 和参数值对象。
- [x] 双后端/线程/GC/IO/既有日期定向验收，PvZ 关闭 survey reached-fault 探查。
- [x] MODULE/能力账本/CURRENT/ADR 与制品元数据同步。
