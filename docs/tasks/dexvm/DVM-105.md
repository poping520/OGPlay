# DVM-105 · Cipher AES 经 Conscrypt 与 guest OpenSSL 执行

## 目标

BootDex 执行 AOSP Cipher/Conscrypt AES Java 逻辑，以精简 guest JNI 桥调用 ARM libcrypto，
闭合明确登记的 AES transformation、随机 IV、异常与资源生命周期。

## 范围与依赖

- DVM-104；本地 pinned API 19 core.jar，以及用户授权临时使用的 API 19 ARMv7 设备
  conscrypt.jar/libcrypto.so。设备来源单独登记，不冒充 pinned AOSP 构建。
- AES ECB/CBC：NoPadding/PKCS5Padding；AES CTR：NoPadding。128/192/256 位密钥。
- Cipher/CipherSpi、provider 注册、SecretKeySpec/IvParameterSpec、update/doFinal、实际随机 IV。
- 不扩展证书/TLS、RSA 密钥工厂、Cipher wrap/unwrap 或全部 JCA provider。
- 生产算法执行 guest libcrypto；禁止通过宿主加密算法替代或伪随机生成 IV。

## 工作项

- [x] BootDex 精确选类、来源元数据和确定性重建：新增 45 类，总计 566 类。

状态：完成（限定上述 AES 范围）。

## 验收

- macOS Release，只构建 ogplay_tests 及所需 ogplay/staging，沿用本地 WERROR=OFF。
- `DVM-105*` 与 JNI pending metadata：双解释后端 NIST AES 向量，三种密钥长度、
  五种 transformation、分段、0/1/15/16/17/31/32/65 字节填充、原位/短 buffer、
  bad padding、无效 key/IV、未初始化/失效 token、两条 guest 线程各 16 次往返、
  随机 IV、GC 后存活 context 与 teardown；同时验证默认 AES 与不支持算法明确失败。
- 定向回归 139 用例、13653 断言通过；日志 `.local/review/dvm105/regression.log`。
  后续 GC/类所有权修正另行定向验证，结果见同目录 final 日志。
- BootDex build/check 双目录字节一致；日期 audit 42 类/47 native 保持。
  builder 自测、payload 哈希/ELF/NOTICE、intrinsic 布局、文档布局、能力单调性通过。
- Cipher Java 普通方法保持解释执行，11 个 NativeCrypto 声明无 host handler，实际进入
  ARM libcrypto；JCA fallback 不再误接受 AES/CTR/PKCS5Padding。
- 已修正 JNI ThrowNew 异常降级、CTR null-IV reset、Throwable cause 直接依赖。

## 本地制品与复跑

```sh
python3 tools/bootdex/build_bootdex.py build-cipher
python3 tools/bootdex/build_bootdex.py build
python3 tools/bootdex/build_bootdex.py check
python3 tools/validate_android_payload.py --root data/android/19
cmake --build build/release --target ogplay_tests -j 6
cd build/release
./ogplay_tests --test-case='DVM-105*,JNI pending metadata*'
```

精简 JNI 源在 tools/bootdex/native/cipher.c；原 pinned core.jar 不变。设备 libcrypto
SHA-256 为 `3c7ea441e482f50244f74774bc7230449f82911831ceb4ce937ca176041e6f17`；
conscrypt.jar 为 `43ab6b953bd5a9e25f0f0d4411a5aa3f0660d16954a0a84e95ad834558b21a1e`。
输出与工具链身份以 data/android/19/manifest.json 为准，bootdex.jar 按用户约定不提交。
