# DVM-106 · X.509 Certificate 与 CertificateFactory

## 目标与依赖

在 DVM-105 基础上接入 API 19 Certificate/X509Certificate/CertificateFactory，复用
Harmony Java ASN.1 解析，签名校验调用 guest OpenSSL，不模拟完整 TLS/系统信任库。

## 范围

- BootDex 加入证书 API、Harmony factory、X.509/PKCS7/ASN.1 直接依赖。
- DER/PEM 单证书与证书集合、编码往返、issuer/subject/有效期/序列号/扩展、公钥编码。
- X509Certificate.verify(PublicKey)：原版 Java 经 SignatureSpi 调用 guest OpenSSL，支持
  RSA PKCS#1 v1.5/ECDSA 与 SHA1/224/256/384/512，错误明确失败。
- 长序列号所需 NativeBN 值转换；不扩展任意大数算术或 RSA Cipher。
- PKIX 路径构建/信任锚、系统 CA、撤销网络查询与 TLS 不属于本 WU。

## 验收

- [x] 新增 194 类至 760 类；原版 DRLCertFactory、Signature/JCA 直接依赖闭合。
- [x] DER/PEM/字段/编码公钥、旧 javax API、证书链、PkiPath/PKCS7；两种解释后端。
- [x] 10 种摘要验签、错误公钥/篡改/未知算法/超限、GC 后复用、长正负数与 JNI 数组协变。
- [x] Cipher、X500、NativeBN、JNI 与 GC 定向回归：52 用例/11512 断言通过。
- [x] 760 类全链接；BootDex check、日期 audit、payload/staging、5 项定向门禁通过。
- [x] 模块、ADR-0036、能力账本与 CURRENT 同步；ADR 仍为 6 个主题。

状态：完成。证据：`.local/review/dvm106/`；独立 OpenSSL 生成的公开 fixture 位于
`tests/fixtures/certificates/`，私钥不入库。日期检查使用显式 Date，不依赖宿主时间。

## 实现边界

复用同一 api19.json/build_bootdex.py/crypto_jni.c/manifest.cipher_native，bootdex.jar 不提交。
公钥保留 Harmony 的编码型 fallback；RSA/EC KeyFactory 与数学参数接口、签名生成、
PSS/DSA/EdDSA、PKIX 信任与 CRL 验证长尾、CA/撤销/TLS 不包含。消息和 NativeBN 输入
各限 1 MiB。手机已断开，本轮仅 macOS 定向验收，没有真机/跨平台或游戏 gate 结论。
