# DVM-107 · Activity 组件查询与 framework 值类迁入 BootDex

## 目标与依赖

在 DVM-106 基础上补齐 Activity 组件身份/getLocalClassName，并将 Pair、SparseArray 家族、
ComponentName 与直接依赖从 pinned framework.jar/core.jar 和原始 Java 源码迁入 BootDex，删除普通算法和侧表。

## 范围与验收

- [x] Activity 每实例组件/Intent 身份，根启动与切换接入；包名前缀和 alias 语义受检。
- [x] Pair、五种 SparseArray、ComponentName、Parcelable 接口与数组辅助类、PrintWriter 精确选入。
- [x] 删除迁移类 intrinsic/侧表，普通字段/数组经同一 GC 保存；Parcel 编解码保持。
- [x] 双后端定向测试、全 BootDex 类链接、确定性构建与 payload 校验。
- [x] 同步 MODULE、ADR、能力与 CURRENT；不迁入完整 Activity、Intent、Parcel 或系统服务。

状态：完成。临时 libcrypto 仅本地使用，bootdex.jar 与 libcrypto.so 不提交。

## 实现与边界

共新增 14 类：12 个 framework class_def、core PrintWriter、源码编译 ArrayUtils。
ArrayUtils 原属 framework2.jar，本地没有该 jar；同一 builder 用固定 Java 源及 AOSP dx
源码树编译，不建立额外脚本或 C++ 算法副本。源码与 jar 来源在 manifest 分开记账。
StringBuilder/StringBuffer 补实际触达的 CharSequence 区间 append，UTF-16/null/自追加/
越界无 mutation 均有回归。根 alias 保留组件名，普通显式切换读真实 ComponentName；
一般 manifest resolver、非根 alias 切换解析和系统组件生命周期未扩展。

构建与定向测试记录在 `.local/review/dvm107/`；定向回归 25 用例/8504 断言（含 Cipher/证书）、5 项门禁通过；重复声明和错误
framework/dalvik source pin 的反例均拒绝。
bootdex.jar 和 ROM libcrypto.so 仅本地制品，本轮不提交。未运行游戏 gate、全量测试或
Windows/Linux 验收；当前 macOS Release 沿用既有 WARNINGS_AS_ERRORS=OFF。
