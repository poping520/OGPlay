# DVM-113 · Locale ISO 语言与国家代码枚举

## 目标与依赖

依赖 DVM-112（c7859ed5），补齐 Locale.getISOLanguages/getISOCountries，
让应用使用 API 19 的完整代码表校验语言及区域代码。

## 方案与范围

本地 AOSP luni 的 java/util/Locale.java 委托 libcore/icu/ICU.java，后者缓存 native
数组并每次返回 clone；libcore_icu_ICU.cpp 使用 ICU Locale 的两张 ISO 表。
沿用 [ADR-0032](../../adr/dexvm.md#adr-0032) 的固定 ICU 51 边界：Locale 只作转发，
缓存和复制仍执行 BootDex Java；两个 native 调用固定 ICU，不维护手写代码表。
保留原始顺序和三字母语言，不纳入第一处 NULL 之后的废弃别名。
不扩展 getAvailableLocales、ISO3 转换、LocaleData 支持集合或完整 Locale 迁移。
