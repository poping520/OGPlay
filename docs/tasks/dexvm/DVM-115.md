# DVM-115 · Throwable 家族迁入 BootDex

## 目标与依赖

依赖 DVM-114（1110d661），将 Throwable 的消息、栈数组、原因链和打印协议迁入
API 19 BootDex，闭合 PrintWriter 路径并继续排查 PvZ 启动阻塞。

## 范围

50 个 java.lang Throwable 家族类、StackTraceElement、IOException 和
InvocationTargetException 共 53 类来自 pinned core.jar；BootDex 共 898 类。
Throwable 只保留 nativeFillInStackTrace/nativeGetStackTrace 两个 VM 原语。
消息/cause/suppressed/stackState/stackTrace 为普通 Java 字段，旧状态表只留 VM 故障诊断。
PrintStream 的 Appendable 边界复用结构化日志，PrintWriter/StringWriter 执行原版 Java。
原始栈保存方法 ID 与 dex PC，不保存宿主指针；未解析的源文件/行号诚实显示 Unknown Source。

## 验收

- [x] BootDex 原版打印、suppressed/cause、栈复制和异常子类构造双后端回归。
- [x] 隐式异常、原异常身份、反射/类初始化/GC/对象流定向回归。
- [x] 统一配方审计、全类链接、payload 与架构门禁。
- [x] 原命令复跑并记录下一缺口；更新状态与能力。

证据 `.local/review/dvm115/`；bootdex.jar 与临时 libcrypto.so 不提交。

## 验收结果（2026-09-08，macOS Release）

迁移完成，设计见 [ADR-0043](../../adr/dexvm.md#adr-0043)。core 定向 123 用例/137139 断言，
反射/类加载 22 用例/1510 断言，Android 值类 19 用例/2163 断言，真实 JNI 摘要/对象流
1 用例/3026 断言通过；执行器/服务/ISO/BootDex 最近回归 13 用例/8241 断言通过。新增验证包含 Throwable 的 Java 写读回调与栈数组序列化、共享
cause/suppressed 身份、原始栈和重抛、null/空栈、子类虚分派、GC 以及应急预算恢复。
PrintWriter 暴露的 String.subSequence 缺口同步委托既有 UTF-16 substring，并保留全范围身份。
旧 catalog 验收中的对象流位置、SUID/方法数与已登记的显式失败清单同步到历次迁移后的状态。
