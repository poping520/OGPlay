# DVM-117 · Bundle 与 Intent 对象传递

## 目标与依赖

依赖 DVM-116（65c2d5f2），用 BootDex Bundle 闭合 Intent Serializable extra，
移除重复宿主存储，并继续推进 PvZ。

## 范围

Bundle/CREATOR、ArrayMap/MapCollections 及内部类共 10 类迁入 pinned BootDex，合计 910 类。
Intent.mExtras 指向真实 Bundle，typed put/get/remove/hasExtra 委托 Java；getExtras
调用原版复制构造器，独立映射保留值身份。移除 Bundle 和三种 Intent extra 侧表。
ApplicationInfo 元数据也由 Java Bundle 写入。

Bundle 仅 writeToParcel/readFromParcel 对接既有进程内 typed Parcel：写入普通 Bundle
浅副本，读取再次复制映射；Parcel 持有单一 guest 强引用，不再保存宿主映射副本。
这不扩展为 Android 二进制 Parcel/Binder。Log.w/e 带 Throwable 的结构化日志通过
BootDex PrintWriter/StringWriter 输出真实异常栈，不再丢弃异常参数。
设计见 [ADR-0045](../../adr/dexvm.md#adr-0045)。
