# DVM-118 · 显示值与 Math 迁入 BootDex

## 目标与依赖

依赖 DVM-117（fd76c10c），闭合 Resources.getDisplayMetrics 及其 Math.round 调用，
用原版 Java 维护值对象和数值算法，继续运行 PvZ。

## 范围

DisplayMetrics、TypedValue 来自 pinned framework.jar；Math 来自 pinned core.jar，
BootDex 共 913 类。Resources.mMetrics 保持每实例身份，查询时从同一 managed surface
刷新尺寸/density；Display.getMetrics/getRealMetrics 共用填充入口。DisplayMetrics
仅私有 getDeviceDensity 读取注入 density，普通字段、复制/比较/defaults 来自 Java。
TypedValue 全部普通方法迁入 Java，删除 applyDimension 的硬编码字段槽位。

Math round/abs/min/max/位算法/random 状态归 Java；24 个 native 按本地
luni/src/main/native/java_lang_Math.cpp 对接宿主 libm。不承诺 StrictMath/fdlibm 的
跨平台逐位一致性。日期审计只把 Math 分类改为 boot_dex，其根/native 集合不扩大。

## 验收

- [x] 双后端显示事实/身份/GC、值复制和单位换算。
- [x] Math 原版舍入边界、NaN/有符号零/溢出与 24 个 native。
- [x] BootDex/平台/Math 定向回归及门禁；原命令继续运行。

证据 `.local/review/dvm118/`；bootdex.jar 与临时 libcrypto.so 不提交。
