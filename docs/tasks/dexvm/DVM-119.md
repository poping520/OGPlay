# DVM-119 · Java 布局参数与 RelativeLayout gravity

## 目标与依赖

依赖 DVM-118（df5f5357），迁入布局参数家族并接通显示边界，越过 PvZ DiscoveryStrip
的 FrameLayout.LayoutParams(III) 与 RelativeLayout.setGravity 缺口。

## 范围

ViewGroup.LayoutParams/MarginLayoutParams、FrameLayout/LinearLayout/RelativeLayout.LayoutParams
共 5 类来自 pinned framework.jar，BootDex 共 918 类，无普通方法 overlay。
构造器、字段、copy、margin、规则数组与方向解析由 Java 执行；删除四类旧声明和
ui_layout_params 宿主副本。apply/update/requestLayout 读取参数并生成 UiTree 布局输入。
LTR 方向事实由现有 UI 模型提供，baseline/alignWithParent/动画等未知行为记账明确失败。

RelativeLayout.setGravity/getGravity 保存真实 UI 状态；布局引擎完成相对定位后，
按含 margin 的子节点整体边界计算右/下/居中偏移，GONE 不进入边界。
默认 START/TOP 保留原定位。见 [ADR-0046](../../adr/dexvm.md#adr-0046)。
