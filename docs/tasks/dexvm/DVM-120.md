# DVM-120 · Typeface Java 与内置字体样式

## 目标与依赖

依赖 DVM-119（c39dbbde），为文本外观路径迁入 Typeface，删除其普通 intrinsic。

## 范围

Typeface 来自 pinned framework.jar，BootDex 共 919 类；常量、Java 缓存、样式查询、
相等/hash 和工厂由原版 Java 执行。4 个 native 使用有限不可变字体描述符，pinned jar 额外的 nativeFreeCaches
没有宿主缓存需要释放，两个外部
字体加载 native 记账抛 UOE。内置字体提供 normal/bold/italic/bold-italic，family 保留
身份并使用同一内置回退字形，不宣称 Roboto/Skia/字体文件支持。
TextView.setTypeface 两种签名及 getTypeface 保存普通 Java 引用；测量与绘制消费同一
UiNode 样式，bold 像素并集避免半透明像素被重复叠加。见 ADR-0047。
