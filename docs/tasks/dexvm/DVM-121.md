# DVM-121 · 文本外观与样式资源事实

## 目标与依赖

依赖 DVM-120（6cb4a24e），解决 TextView.setTextAppearance(Context,int)，
按用户收尾要求停在本缺口验收，不继续扩展 Button 构造器。

## 范围

ColorStateList/CREATOR、StateSet、android.R.attr 4 类来自 pinned framework.jar，
BootDex 共 923 类，无普通方法 overlay。颜色缓存、默认色和状态集合匹配来自 Java；
TextView 的颜色列表为普通字段，颜色/字体/尺寸进入既有 UI 后端。

ARSC 保留 bag parent 和 typed items，校验 entry/value 边界、map 数量、重复键和字符串索引。
Manifest 提取 application/Activity theme；alias 继承目标 theme，0 回退 application。
session 注入后在 Activity.onCreate 前 setTheme；ContextWrapper 查询沿 base 解析。

TextAppearance 支持 APK 样式继承、简单资源/主题属性引用、直接颜色、dimension 和
字体样式。平台仅投影 AOSP Theme（含原版 NoTitleBar/Black/Dialog/Light/Translucent 变体）、
Theme.Holo、Theme.DeviceDefault 的 hint/highlight/link 属性，不引入整个 framework-res。
属性 ID 按 BootDex R.attr 验证，只是 metadata bag，不自动解引用为样式。
例如 attr.textAppearanceSmall 不会冒充 style.TextAppearance.Small 来修改字号。
后者及其他未登记 framework 样式仍明确失败。见 [ADR-0048](../../adr/dexvm.md#adr-0048)。

未知引用/循环、stateful TextView 颜色渲染、selector XML、shadow/allCaps 与完整主题系统
仍记账或明确失败；ColorStateList 自身的 Java 状态匹配已受测。
hint/link/highlight 存储可查询，不声称已有选择、链接或 hint 绘制 UI。
