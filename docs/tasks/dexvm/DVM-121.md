# DVM-121 · 文本外观、控件样式与动态 View

## 目标与依赖

依赖 DVM-120（6cb4a24e），完善文本外观、Button 默认样式与动态 View。

## 范围

ColorStateList/CREATOR、StateSet、android.R.attr 4 类来自 pinned framework.jar，
BootDex 共 923 类，无普通方法 overlay。颜色缓存、默认色和状态集合匹配来自 Java；
TextView 的颜色列表为普通字段，颜色/字体/尺寸进入既有 UI 后端。

ARSC 保留 bag parent 和 typed items，校验 entry/value 边界、map 数量、重复键和字符串索引。
Manifest 提取 application/Activity theme；alias 继承目标 theme，0 回退 application。
session 注入后在 Activity.onCreate 前 setTheme；ContextWrapper 查询沿 base 解析。

TextAppearance 支持 APK 样式继承、简单资源/主题属性引用、直接颜色、dimension 和
字体样式。平台仅投影 AOSP Theme（含原版 NoTitleBar/Black/Dialog/Light/Translucent 变体）、
Theme.Holo、Theme.DeviceDefault 的 hint/highlight/link 属性，不引入整个 framework-res。
属性 ID 按 BootDex R.attr 验证，只是 metadata bag，不自动解引用为样式。
例如 attr.textAppearanceSmall 不会冒充 style.TextAppearance.Small 来修改字号。
后者及其他未登记 framework 样式仍明确失败。见 [ADR-0048](../../adr/dexvm.md#adr-0048)。

未知引用/循环、stateful TextView 颜色渲染、selector XML、shadow/allCaps 与完整主题系统
仍记账或明确失败；ColorStateList 自身的 Java 状态匹配已受测。
hint/link/highlight 存储可查询，不声称已有选择、链接或 hint 绘制 UI。

Button/TextView 三参构造从实际 Context/Resources 解析 legacy 默认样式及主题继承、
别名；null Context、非空 AttributeSet、未登记主题/样式/外观明确失败。
TextView compound drawable API 保持 virtual，四个资源全部解析成功后一次发布；
测量与绘制包含四方向图标、空文本和 compound padding，失败保持旧状态。
UiTree 按真实继承链识别控件类型，RelativeLayout 非正 sibling 锚点视为无锚点。
见 [ADR-0051](../../adr/dexvm.md#adr-0051)。9-patch/GradientDrawable、状态色绘制、
guest onLayout、展开交互和联网推广不在范围内。

## 续（2026-09-08）· PreferenceManager 与 SharedPreferences 接口迁入 BootDex

- BootDex framework.jar 增选 `android.content.SharedPreferences`、`$Editor`、
  `$OnSharedPreferenceChangeListener` 与 `android.preference.PreferenceManager`
  （原版 Java/接口形状），923→927 类；删除 integration 的重复接口 intrinsic
  声明，不给接口保留 final handler 或方法 overlay。
- 保留 SharedPreferencesImpl/EditorImpl intrinsic：五种标量读写（含 float）、
  contains、装箱 getAll 快照；独立 Editor 缓冲在 commit/apply 发布，clear 先于
  待写项，putString(null) 删除键。缓冲随 GC 清理，加载失败可重试。
  apply 按 API 19 允许的兼容方式同步落盘；getStringSet/putStringSet 与 change-listener
  注册无受检表示/回调事实，明确失败并记账
  （`dexvm.shared_preferences.string_set` / `.change_listeners`）。
- getDefaultSharedPreferences 经原版 Java 虚派 Context.getSharedPreferences，
  与直接打开 `<package>_preferences` 共享唯一对象/VFS XML 存储。
- 未迁入 android.app.SharedPreferencesImpl、QueuedWork、ActivityThread 与
  完整 Preference UI；边界见 [ADR-0052](../../adr/dexvm.md#adr-0052)。
