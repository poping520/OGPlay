# DVM-125 · Activity/View 窗口焦点闭环

## 目标与依赖

依赖 DVM-121 及提交 `721f24ab`，闭合 API 19 Activity/View 窗口焦点查询与通知，
推进 PvZ `MainActivity.onResume` 首错。

## 范围

- 对照 pinned AOSP 4.4.4 `Activity`、`View`、`ViewRootImpl` 与 `PhoneWindow`，补
  public virtual `Activity.hasWindowFocus/onWindowFocusChanged` 和
  `View.hasWindowFocus`；不迁入完整 framework、WMS 或输入焦点系统。
- `DexActivityLifecycle` 是唯一窗口焦点写者。状态先发布，再虚派 Activity 与当前
  attached UiTree 中的 View；回调是否调用 `super` 不影响事实，重复值不通知。
- 首次 `onResume` 保持 false，Surface 初始化后的下一帧才初始获焦；Suspend、Resume、
  Activity 切换及 Stop 共用同一转换。DecorView/attached View 查询当前窗口事实，
  detached View 与旧 Activity 返回 false。
- 窗口焦点不复用 View `requestFocus`，也不以 resumed 状态推导；无 title 分支。
