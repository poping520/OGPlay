# DVM-130 · JNI 平台入口统一进入 DexVM

状态：完成（2026-09-09）。

## 目标与依赖

复用现有 JNI→DexVM 桥，删除已有 VM 实现的平台 HLE 副本。依赖已落地的 Build /
SystemProperties BootDex 选类、DVM-117 Bundle、DVM-128 Settings.Secure 及 VM AudioTrack。

## 实现

- 删除 guest 会话的 Build/VERSION、SystemProperties、Bundle、Context/Activity、
  ContentResolver、TelephonyManager、Settings.Secure 和 AudioTrack 预注册与重复 handler。
- 类、方法和字段由 `DexVmGuestBridge` 从已链接目录发布；JNI 方法进入 Interpreter，
  字段复用 VM 槽。BootDex Java 与 DexVM Android intrinsic 保持各自现有职责。
- 删除 legacy AudioTrack 播放侧表，构造/写入/控制复用 VM player 与进程 PCM mixer。
- `activity.current` 返回生命周期的 VM Activity；无当前 Activity 返回 null，VM 已退出明确失败。
- 纯 native/HLE 会话不再提供已迁移类，调用方必须装配 DexVM/BootDex。保留 ViewRoot、
  Object 注册依赖、应用兼容回调及独立 headless 契约中的旧 HLE。

架构决定：[ADR-0055](../../adr/dexvm.md#adr-0055)。
