# DVM-132 · `android.net.Uri` 迁入 BootDex

## 目标与依赖

把 pinned AOSP 4.4.4 的 `Uri` 全部内部类及 `libcore.net.UriCodec` 精确选入
BootDex，删除旧 C++ 简化解析器，使 URI 普通状态和算法由 API 19 Java 实现。

## 范围与验收

- [x] `Uri` 14 个 class_def 与 `UriCodec` 进入统一配方，BootDex 增至 968 类。
- [x] 删除 `Declare_android_net_Uri`、五个镜像字段及简化 parser。
- [x] 补齐直接依赖 `String.regionMatches(int,String,int,int)`。
- [x] 双解释器覆盖 parse、层级字段、query、Builder、UTF-8 encode/decode。
- [x] 受影响构建、BootDex/架构门禁与 PvZ 原命令实跑。

## 明确边界

本 WU 不补 `StrictMode.onFileUriExposed`、
`Environment.isExternalStorageEmulated`、
`Environment.getLegacyExternalStorageDirectory`。因此 `checkFileUriExposed` 与
`getCanonicalUri` 的对应分支在实际触达时继续明确暴露缺失；不引入 Android 存储策略、
system service 或宿主路径推断。
