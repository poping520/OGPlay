# DVM-133 · ContentResolver 无 provider 查询

## 目标与边界

闭合 API 19 `ContentResolver.query(Uri,String[],String,String[],String)` 在当前进程
找不到 ContentProvider 时返回 `null` 的分支，使应用可按 Android 约定跳过未安装的外部
provider。仍虚派读取 URI scheme/authority，null URI 与 guest 异常正常传播。

本 WU 不创建空 Cursor，不实现当前 APK 或外部 APK 的 ContentProvider，不引入 Binder、
system_server、provider 目录或宿主数据源；六参 cancellation overload 及实际 provider
查询继续不在范围内。
