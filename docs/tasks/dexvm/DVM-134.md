# DVM-134 · GLSurfaceView render mode

## 目标与边界

按 pinned AOSP 4.4.4 发布 `GLSurfaceView` 的 `RENDERMODE_WHEN_DIRTY`、
`RENDERMODE_CONTINUOUSLY`、`setRenderMode(int)` 与 `getRenderMode()`。mode 以 view
身份保存，默认连续渲染；仅 0/1 合法，其余抛 `IllegalArgumentException`。

OGPlay 的帧生产仍由 lifecycle/managed surface 拥有。本 WU 不创建 GLThread、第二个 EGL
surface/context 或宿主线程；`requestRender` 维持既有无调度边界。
