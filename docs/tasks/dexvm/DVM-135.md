# DVM-135 · View 主线程 Runnable 投递

## 目标与边界

按 pinned AOSP 4.4.4 为 `View` 发布 public virtual `post(Runnable)` 与
`postDelayed(Runnable,long)`，复用 DVM-85 的唯一主 Looper scheduler。

attached View 通过单一 ViewRoot handler identity 直接排队；detached View 按调用
guest 线程暂存，存在 live content tree 后在下一次 lifecycle safe point 转入主 Looper，
delay 从转入时起算。Runnable 不同步执行，不创建宿主 Timer、线程或第二套消息队列。
