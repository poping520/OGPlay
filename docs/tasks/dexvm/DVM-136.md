# DVM-136 · API 19 OrientationEventListener

## 目标与边界

将 pinned AOSP 4.4.4 的 `OrientationEventListener` 及其
`SensorEventListenerImpl` 精确选入 BootDex，使应用子类继承、构造和 enable/disable
执行原版 Java。

OGPlay 当前没有 accelerometer backend，`SensorManager.getDefaultSensor` 返回 null；因此
原版类保持 `canDetectOrientation()==false`，enable/disable 不注册或伪造方向回调。本 WU
不引入宿主传感器、SDL 方向推断、requestedOrientation 映射或 deprecated
`OrientationListener` 家族。

## 验收

- [x] BootDex 确定性 build/check，970 类及 manifest 身份同步。
- [x] 双解释器覆盖应用子类、原版构造、无传感器查询和 enable/disable 无回调。
- [x] 970 个 BootDex class_def 全链接。
- [x] PvZ 原命令越过类层级并记录新首错。
