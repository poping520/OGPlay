# DVM-137 · API 19 Configuration 迁入 BootDex

## 目标与边界

将 pinned AOSP 4.4.4 的 `Configuration` 与 `Configuration$1` 迁入 BootDex，删除仅含
`keyboard/screenLayout` 的 C++ 类壳；`Resources.getConfiguration()` 保留为唯一设备事实
注入边界。

配置对象首次创建时执行原版构造器，之后保持稳定身份并从 managed surface/density 刷新
方向、dp、density 与 screenLayout。桌面输入链发布 touchscreen/finger、外接字母键盘可见、
无独立 navigation device 的一致事实。`Resources.updateConfiguration` 的最小语义还保证
`locale` 使用同一 VM 的 `Locale.getDefault()`，并由原版 Java `setLayoutDirection` 更新方向位。
当前默认 Locale 闭包只覆盖 ROOT/en/zh 的 LTR；其他语言在 ICU likely-subtags 未接入时明确失败。
本 WU 不实现窗口旋转、输入设备热插拔或动态 `onConfigurationChanged`；完整 Android 资源配置
系统仍不在范围内。
