# DVM-138 · API 19 View 父级查询

## 目标与边界

补齐 `View.getParent()Landroid/view/ViewParent;` 及必要类型关系。API 19 `ViewParent`
只发布本 WU 使用的 `getParent()` 接口形状，`ViewGroup` 实现该接口；不引入完整 View
framework、`ViewRootImpl` 或其他 ViewParent 方法。

父子关系继续以 UiTree 为唯一事实。`View.getParent()` 从当前节点读取 parent，并通过现有
UiNode→guest object 绑定返回原 ViewGroup 身份；detached、尚未绑定节点以及 synthetic
ContentRoot 均返回 null，不增加 `mParent` 字段或宿主侧表。

- [x] 既有动态 ViewGroup hierarchy、Android catalog 与 BootDex 全类链接回归通过。
