# DVM-142 · PackageManager 反射类型闭包迁入 BootDex

## 目标与依赖

依赖 DVM-107、DVM-112 与 API 19 BootDex。一次选入 PackageManager 公共签名所需的
`ResolveInfo` 值类闭包，使 `Class.getMethod` 不因未触达方法的返回类型缺失而失败。

## 交付

- 从 pinned API 19 framework.jar 精确选入：ActivityInfo、ApplicationInfo、ComponentInfo、
  PackageItemInfo、PathPermission、ProviderInfo、ResolveInfo、ServiceInfo、PatternMatcher、
  Printer，以及这些类的 10 个匿名 Creator/Comparator 类，共 20 类。
- 删除 PackageItemInfo/ApplicationInfo 的 intrinsic 声明与 catalog 注册；其字段、构造器、
  Parcelable、比较与打印逻辑统一由原版 Java 实现。
- PackageManager 的宿主边界保持不变：当前仍不物化正匹配 ResolveInfo，也不引入外部包目录、
  Binder 或 system_server。
