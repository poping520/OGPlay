# DVM-145 · Field 运行时 marker annotation

状态：完成。

目标：闭合游戏资源注入路径直接调用的 `Field.getAnnotation`，不引入完整 annotation proxy。

交付：loader 保存 runtime-visible 字段 annotation 的类型与元素存在性；linker 将其绑定到
`LinkedField`；`Field` 四个查询接口物化零成员 marker annotation。带成员 annotation 明确抛
`UnsupportedOperationException`。API 19 `java.lang.annotation` 十类进入 BootDex（1051 类）。

验证：dexasm 可生成字段 runtime marker，loader 定向用例检查 readback；Field 查询在 switch/threaded
双后端验证命中、未命中和数组物化；Windows 受影响目标编译；BootDex build/check。游戏启动 gate
留待后续实测。
