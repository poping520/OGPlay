# DVM-146 · 反射成员元数据独立按需构建

状态：完成。

## 目标

修复字段查询提前解析整类方法/构造器签名，导致无关缺失类型阻断 `getDeclaredFields()` 的问题。

## 交付

- 字段、方法、构造器 metadata 使用独立完成标记和异常安全的临时结果。
- 字段枚举、定向字段查询及 Field wrapper 回查只构建字段 metadata。
- 完整方法枚举仍解析方法参数、返回值与异常类型，缺失依赖继续明确失败。
- 不加入游戏名、厂商名、包名或签名特判。

## 验证

- fixture 的普通字段带 runtime marker，同时无关方法引用缺失的 `JarFile` 类型。
- switch/threaded 双后端字段查询与 annotation 物化 36 个断言通过，方法枚举按预期失败。
- reflection 定向集 11 个用例、466 个断言通过。
