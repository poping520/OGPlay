# DVM-147 · API 19 SHA1PRNG 与 AES KeyGenerator

## 目标

补齐游戏进程直接调用的 `SecureRandom.getInstance("SHA1PRNG")` 与
`KeyGenerator.getInstance("AES")`，保持 API 19 provider 路径，并使用 guest ARM
OpenSSL 生成随机数据。

## 范围

- AndroidOpenSSL 注册 `SHA1PRNG` 与 `AES` KeyGenerator。
- SHA1PRNG 首次使用时由统一宿主 CSPRNG 注入熵，随后调用 guest `libcrypto` 的
  `RAND_seed/RAND_bytes`；调用方 seed 只追加熵，不形成可预测随机源。
- AES KeyGenerator 支持 128/192/256 位，返回 BootDex `SecretKeySpec`。
- 不实现其他 PRNG、KeyGenerator 算法、密钥库、TLS 或完整 JCA provider。

## 验收

- [x] NDK r25c 确定性重建 guest JNI。
- [x] 双解释器验证 SHA1PRNG seed/nextBytes 与 AES 128 位密钥生成。
- [x] pvz-amaz 8.1.0 非 survey 实跑越过原 `NoSuchAlgorithmException`。
- [x] 模块契约、能力账本与 CURRENT 同步。
