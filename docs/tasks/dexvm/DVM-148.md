# DVM-148 · Terms 页面布局与文本输入闭环（已完成）

目标：让真实 PvZ APK 在非 survey 模式完整显示 Terms 页面，并由真实年龄输入触发 guest
TextWatcher 更新按钮状态。

本轮已完成：

- `View.getBackground()` 按继承链供 Button 解析；setBackgroundResource/Drawable 与 getter
  保持同一 guest Drawable。
- Button 程序构造和 XML inflation 建立默认背景；Drawable alpha/bounds 为逐实例状态，alpha
  mutation 标记对应 UiNode 重绘，资源位图进入背景绘制。
- API 19 BootDex 增加 `java.util.logging` 与 Dalvik logging 小闭包；System property 双参数
  重载和 Charset displayName 按平台语义补齐。
- 经本 WU 用户明确授权，非 UI 阻塞 `Runtime.addShutdownHook(Thread)` 暂时只校验 null、记录
  `dexvm.runtime.shutdown_hook_registration` 后返回；不宣称执行关机 hook，后续单独完善。
- 同一授权下，非 UI 阻塞 `IoUtils.closeQuietly(AutoCloseable)` 暂时记录
  `dexvm.libcore.io_utils.close_quietly` 后返回；后续补真实 close/异常规则。
- ClassLoader 资源枚举/URL 暂时分别记录后返回空枚举/null；未声明 APK class-resource
  查找支持，后续应接 sealed APK archive。
- Terms 配置 AsyncTask 命中未提供的系统 Apache HTTP 类时，暂时记录
  `dexvm.async_task.background_fault_bypass` 并以 null 结果进入原 guest `onPostExecute` 失败分支；
  这是本 WU 用户授权的非 UI 绕过，不声明通用 AsyncTask 异常语义。
- 资源表保留配置变体，UI 按 API 19、方向、dp 尺寸和 density 选择；真实 800×480 运行
  选择 `layout-land`。TableLayout/TableRow 使用纵向表/横向行规则，权重参与实际测量。
- TextView 多行测量与绘制共用 fixed-font 行高/列宽；ScrollView 用无限高度测量文档、
  viewport 裁剪和同一 screen frame 做滚动后命中。
- 真机截图回归后补齐 XML inflation 的 API 19 widget 默认字号/48dp 控件高度与 framework
  textAppearance，空 EditText 也保留一行字体高度；fixed ASCII 字体保留大小写并按词换行，
  测量和绘制消费同一换行结果。
- 编译 PNG 的 `npTc` 分区与 padding 被解析；五类主题 9-patch 保留边缘并只拉伸中心。
- EditText 区分普通 TextView，点击建立焦点，数字输入和 `maxLength=2` 生效；稳定 Editable
  的 `toString()` 返回权威 UiNode 文本，真实输入调用 guest TextWatcher，最终由
  `TermsActivity.b()` 把 accept 背景 alpha 从 100 更新为 255。
- 无 GLES producer 的纯 View Activity 在 UiTree dirty 时发布软件基帧，仍由唯一
  `ComposePresentedFrame` 完成布局和合成。

真实 PvZ 非 survey 验证：初始 Terms 页面截图 `.local/pvz-terms-final-run.png`；点击年龄框并
通过 SDL/Windows 文本输入键入 `13` 后截图 `.local/pvz-terms-age-13-enabled.png`，输入可见且
accept 按钮由浅绿变为实绿。运行日志 `.local/pvz-terms-input-verified.log`，无 guest fault。
对照真机排版后的截图为 `.local/pvz-terms-optimized.png`，日志为
`.local/pvz-terms-optimized.log`。
