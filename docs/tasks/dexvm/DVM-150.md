# DVM-150 · Runtime shutdown hook 闭环（已完成）

目标：以 API 19 原版 Java 完成 shutdown hook 注册、移除及显式 VM 退出执行，替换 DVM-148 绕过。
依赖：DVM-148 logging BootDex、DVM-48 Thread、既有 VM stop/monitor/统一 Clock。
架构：[ADR-0056](../../adr/dexvm.md#adr-0056)。

- Runtime class_def 迁入固定 core.jar；BootDex 1076 类。普通 hook 方法与状态均归 guest 字段。
- System.exit → Runtime.exit → nativeExit；保存退出码、停止执行并交由 owner join，无宿主 exit。
- Application/Activity 显式退出进入 stopped；已退出 VM 不再运行生命周期 Java 回调。
- root join 阻塞时允许 worker 用原有统一 Clock 补时，纯 Java timed hook 不依赖 EGL。
- 宿主 Stop 仍为取消路径，不自动执行 hook；没有自动 non-daemon 退出或 hook 完成超时承诺。
- gc/堆统计/nativeLoad/Java finalization 不在本 WU；未支持入口明确失败，既有 System.load* 不变。

验证：windows-msvc 受影响 ogplay_tests 目标构建；新增 11 个 DVM-150 用例及 1 项库加载回归合计 12 用例、355 断言通过，
core 用例覆盖 switch/threaded，生命周期集成覆盖实际进程停止和原版 Thread.sleep hook。
覆盖 null/重复/已启动及已结束线程、移除/重新注册、只由列表持有的 GC 强根、先全部 start
再 join、退出中变更拒绝、Thread 异常 handler、halt 跳过/中断退出、worker 退出、VM 隔离、
LogManager 真实 Handler.close、移除后 GC 回收、finalization 启用拒绝、JNI_OnLoad→Java
退出展开，以及 Java catch(Throwable) 不能吞退出。
证据：`.local/runtime-hooks-final-tests.log`、`.local/runtime-hooks-build.log`。
