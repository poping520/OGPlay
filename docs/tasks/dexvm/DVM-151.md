# DVM-151 · StringBuilder/StringBuffer BootDex 迁移

目标：在一个 WU 内把三个 builder 的普通行为迁入固定 API 19 BootDex，删除宿主内容侧表。
依赖：DVM-126、DVM-149、DVM-150。状态：完成。

## 实现范围

- core.jar 新增 AbstractStringBuilder、StringBuilder、StringBuffer、IntegralToString/$1、
  RealToString/$1、libcore.math.MathUtils 共 8 类。三个 builder 和 IntegralToString 无 overlay。
- 唯一可变内容为 AbstractStringBuilder 的 value/count/shared；删除 BuilderBuffer、
  builders map 和 clone/sweep 回调。同步、容量、异常和对象流 hooks 执行原版 Java。
- RealToString 仅保留原生 bigIntDigitGenerator(JIZI)V；受检固定精度 scratch 无对象侧表，
  digits/digitCount/firstK 经绑定字段访问。整数及浮点的 Java 组装算法不再在 builder intrinsic 重复。
- String 保留 VM/JNI UTF-16 owner，增加内部构造 (II[C)V 与 _getChars(II[CI)V。
  内部构造复制快照，不物理共享 char[]；Java shared/COW 分支仍照原版执行。见 ADR-0057。
- Character 仍为现有 primitive-wrapper 边界；补齐五个无 builder 状态的 UTF-16 array 原语：
  toChars、codePointAt、codePointBefore、codePointCount、offsetByCodePoints。
  它们不是 AOSP native，不把本次声明扩大为 Character 家族完整 BootDex 迁移。

## 门禁

- 双后端原版方法来源、Terms 输入 substring 返回 /ge、容量增长、UTF-16、COW、GC、
  对象流 round-trip、异常释放 monitor、整数极值与浮点 native 路径。
- 仅构建 ogplay_tests/ogplay，运行受影响的用例与架构门禁；不运行全量 CTest。
- 真实 APK 非 survey 复跑，区分旧阻塞消失与完整 Terms/在线请求验收。
- 回退必须同时回退配方、产物、catalog 和侧表删除；不发布混合内容源。
