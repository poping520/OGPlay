# DVM-152 · InetAddress BootDex 迁移

目标：在一个 WU 内迁移 API 19 地址类闭包，删除宿主地址与 endpoint 状态副本。
依赖：DVM-88、DVM-149、DVM-151。状态：完成。

## 实现

- BootDex 增加 InetAddress/Inet4Address/Inet6Address、AddressCache、InetSocketAddress、
  NetworkInterface/InterfaceAddress 及其 libcore OS shape，共 44 个 class_def。
- IP 字节、hostname、IPv6 scope、缓存及 socket endpoint 全部使用原版 guest 字段；删除
  NetworkRuntime 的 addresses/endpoints map 和三个地址类 overlay。
- OS 边界仅实现 API 19 常量初始化、IPv4/IPv6 数字解析与格式化、注入 DNS/反向查询、
  确定性 guest uname。Posix 其余 97 个 native 保持明确未实现。
- NetworkRuntime 继续拥有 socket、stream、datagram 资源和策略；默认离线且不读取宿主 DNS。

## 验证

- DVM-152 双后端 62 条断言覆盖 IPv4、IPv6、原版类来源、字段状态和注入 DNS。
- DVM-88 网络回归 9 用例、252 条断言；BootDex check 与 intrinsic architecture gate。
- 真实 APK 非 survey 的 switch/threaded 均越过 InetAddress.getLocalHost，首错前移到
  `java.net.URI.create(String)`；不声明 Terms 或在线请求完成。
