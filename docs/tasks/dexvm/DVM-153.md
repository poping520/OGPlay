# DVM-153 · URI BootDex 迁移

目标：在一个 WU 内把 API 19 URI 完整普通行为迁入 BootDex并删除重复 overlay。
依赖：DVM-151、DVM-152。状态：完成。

## 实现

- BootDex 增加 URI、两个内部 encoder class、URISyntaxException 与 UrlUtils，共 5 类。
- 删除 URI/URISyntaxException intrinsic；字段、解析、create、normalize、resolve、relativize、
  比较、ASCII 转换和序列化执行 API 19 Java。
- 补齐 UrlUtils 所需的无状态 `String.lastIndexOf(int,int)`。URL 仍使用现有有界 intrinsic，
  因此其 C++ ParseUri 辅助函数继续保留。

## 验证

- 双后端 DVM-153：54 条断言；URI/File URI 定向组：9 用例、331 条断言。
- BootDex 1464 类全链接：8266 条断言；BootDex check 与 intrinsic architecture gate 通过。
- 真实 APK 非 survey 的 switch/threaded 均越过 URI.create，首错前移至
  `ProxySelector.getDefault()`；不声明 Terms 或在线请求完成。
