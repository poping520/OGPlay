# DVM-155 · Java EGL10 查询与线程 façade 闭合

## 目标

补齐 Java EGL10 已有单 surface 模型中可由现有事实准确回答的查询与线程入口，减少
Java façade 与 native EGL 的无谓能力差距。

## 范围

- 实现 `eglGetConfigs`、`eglGetCurrentContext`、`eglQueryContext`、`eglQueryString`、
  `eglQuerySurface` 与 `eglReleaseThread`。
- config/context/surface 查询只读取现有 façade 对象和 session 尺寸；current 查询按调用
  host thread 隔离，release 复用唯一 managed-surface currency 释放路径。
- EGL 字符串只声明 EGL 1.4、OpenGL ES client API 与空扩展集，不透传或虚构宿主扩展。
- pbuffer/pixmap/copy/wait、shared context、EGL14/GLES30 继续明确未实现；不建立第二套
  ANGLE Context 或 surface。

## 验证

- Windows `windows-msvc` Debug `ogplay_tests` 构建通过。
- `*EGL facade*`：4/4 用例、94/94 断言通过。

状态：完成。
