# DVM-158 · 旧 Dalvik JNI Object-call/void 兼容

目标：对齐 API 19 非 CheckJNI Dalvik 以 `CallObjectMethod*` 调用 `()V` Java 实例方法的
通用行为。依赖：DVM-130。状态：完成。

## 实现

- `CallObjectMethod`、`CallObjectMethodV`、`CallObjectMethodA` 通用允许目标 descriptor
  返回 `void`；方法仍真实执行，结果丢弃，native 侧得到 null。
- 行为不依赖 Profile 或包名；static/nonvirtual 和其他返回族错配继续失败。
- 依据本地 AOSP 4.4.4 `dalvik/vm/Jni.cpp`：非 CheckJNI 的 `CALL_VIRTUAL` 宏不校验
  MethodID 返回类型，直接调用方法并从 `JValue` 的对象成员返回。

## 验证

- Windows Release `ogplay_tests` 与 `ogplay` 构建通过。
- 定向用例 1/1、8 assertions 通过，覆盖普通/V/A 三槽执行和 null 返回。
- 原 APK 实跑已越过 `startOutput()V` 返回族错误；首错推进到独立的
  `AudioTrack.getPositionNotificationPeriod()I` 缺口。
