# DVM-159 · AudioTrack notification 状态 getter

目标：按 API 19 补齐 AudioTrack notification marker/period getter，复用现有播放通知状态。
依赖：DVM-84、DVM-89。状态：完成。

## 实现

- `getPositionNotificationPeriod()I` 返回同一对象最近成功设置的 period，默认 0。
- `getNotificationMarkerPosition()I` 对称返回 marker，默认 0。
- 非法 setter 不改变旧值；pause、stop、flush 不清除配置。
- 未初始化或 release 后调用 getter 抛 `IllegalStateException`。
- 不增加 BootDex、Profile、音频后端或第二套状态。
