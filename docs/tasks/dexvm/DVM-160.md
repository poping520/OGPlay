# DVM-160 · SystemClock 设备 boot-age 起点

目标：让 API 19 SystemClock 从虚拟设备启动时间计时，不把 APK 进程创建误作设备启动。
依赖：DVM-85。状态：完成。

## 实现

- DexVM Android context 默认以确定性的 60 秒虚拟设备 boot-age 创建。
- `uptimeMillis()`、`elapsedRealtime()`、`elapsedRealtimeNanos()` 和 scheduler 继续消费唯一
  `uptime_millis`；后续 sleep、frame 与 timed-wait 推进路径不变。
- OGPlay 没有 suspend 模型，因此 uptime 与 elapsed realtime 暂时共用同一时间事实。
- 不读取宿主时钟，不增加 Profile、SDK 或包名分支。

## 验证

- Windows Release `ogplay_tests` 与 `ogplay` 构建通过。
- Handler/Clock 定向测试 1/1、31 assertions；AudioTrack 回归 14/14、304 assertions。
- Angry Birds 无 Profile 实跑不再出现 Flurry `ArrayList.remove(-1)`；执行进入新会话路径，
  下一独立缺口为 `Settings.System.getString(ContentResolver,String)`。
