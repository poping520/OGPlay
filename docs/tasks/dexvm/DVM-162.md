# DVM-162 · Context calling/self 权限家族

目标：按 API 19 语义闭合 Context 的 calling/self 权限检查与 enforce 家族。
依赖：DVM-130、DVM-161。状态：完成。

## 实现

- `checkCallingOrSelfPermission` 在无跨进程 Binder 的 OGPlay 中使用 guest self PID/UID，并复用
  Manifest 注入的唯一 granted-permission 集合。
- `checkCallingPermission` 保留 AOSP 的防泄漏语义：没有外部 IPC caller 时始终 denied，不能把
  self 权限误当 calling 权限。
- 补齐 `enforcePermission`、`enforceCallingPermission`、
  `enforceCallingOrSelfPermission`；拒绝时抛 `SecurityException`，null permission 抛
  `IllegalArgumentException`。
- ContextWrapper 全部委托 base；不引入 Binder、ActivityManager、UID 数据库或 Profile 分支。

## 验证

- Windows Release `ogplay_tests` 与 `ogplay` 构建通过。
- 双解释器权限定向测试 122 assertions，intrinsic 架构门禁通过。
- Angry Birds 无 Profile 实跑已越过 Flurry `checkCallingOrSelfPermission` 和位置薄层；下一独立
  缺口为 `org.apache.http.entity.ByteArrayEntity` 类闭包。
