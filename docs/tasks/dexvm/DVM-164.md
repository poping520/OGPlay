# DVM-164 · URLConnection BootDex 与禁用网络边界

目标：先完整承载 API 19 URLConnection Java 状态，同时保持外部网络能力默认禁用。
依赖：DVM-149、DVM-162。状态：完成。

## 实现

- `URLConnection`、`HttpURLConnection`、`HttpsURLConnection`、NoPreloadHolder、
  HostnameVerifier/DefaultHostnameVerifier/DistinguishedNameParser 与所需 net 类型迁入 BootDex。
- 默认 SSL factory/verifier 初始化、setter/getter、请求属性、超时和 HTTP method 校验执行 AOSP
  Java 字节码；删除重复的 `HttpsURLConnection` C++ 类壳。
- C++ 仅 overlay `HttpURLConnection` 的 connect/disconnect/input 外部行为，以及现阶段
  SSLContext/factory 到 NetworkRuntime 的适配边界。
- NetworkPolicy 默认 disabled；离线 factory 不发布 cipher suite，分层 TLS 创建抛可捕获
  `SocketException`，不伪造握手、证书或 TLS 成功。
- 后续启用网络只应补真实 policy-gated TLS transport/PKIX，并继续把 SSL provider 普通状态迁入
  BootDex，不能恢复 URLConnection Java 状态 intrinsic。
