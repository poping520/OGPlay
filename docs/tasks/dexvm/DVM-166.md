# DVM-166 · KeyguardManager 有界服务 facade

目标：让 API 19 应用查询锁屏状态而不引入 Binder/system_server，并为后续宿主状态接入保留唯一接口。
依赖：DVM-165。状态：完成。

## 实现

- `Context.getSystemService("keyguard")` 按 API 19 返回不缓存的 `KeyguardManager` facade。
- `isKeyguardLocked`、`isKeyguardSecure`、`inKeyguardRestrictedInputMode` 读取进程级
  `AndroidKeyguardStateProvider` 快照；当前未注入 provider 时三项均为 false。
- KeyguardManager 保持 intrinsic，不把 AOSP 的 IWindowManager/Binder 闭包加入 BootDex。
  后续宿主集成只替换 provider，Android handler 不直接读取宿主状态。

## 验证

- switch/threaded 均验证服务类型、API 19 非缓存身份、默认未锁屏值和 provider 替换后的快照。
- Angry Birds 无 Profile、关闭 survey 的实跑越过 `MyRenderer.<init>` 的 keyguard 服务缺口；
  下一独立首错为 `RelativeLayout.addView(View,int,int)` 尚未发布。
