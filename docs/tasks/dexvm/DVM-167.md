# DVM-167 · ViewGroup width/height addView 重载

目标：按 API 19 语义发布 `ViewGroup.addView(View,int,int)`，让容器生成自身参数类型并进入唯一 UiTree attach 路径。
依赖：DVM-166。状态：完成。

## 实现

- `addView(View,width,height)` 虚派 `generateDefaultLayoutParams()`，写入 BootDex 参数对象的
  width/height，再委托既有 `addView(View,index,LayoutParams)`，不建立参数侧表或第二条 attach 路径。
- ViewGroup 默认生成 `ViewGroup.LayoutParams(WRAP_CONTENT,WRAP_CONTENT)`；RelativeLayout
  覆盖为 `RelativeLayout.LayoutParams`。当前游戏传入的两个 `-1` 因此保持 MATCH_PARENT。
- LayoutParams 构造统一由 shared helper 执行类初始化、`(II)` 构造器和 Java 异常保真。

## 验证

- Windows Release `ogplay_tests`、`ogplay` 构建通过。
- switch/threaded 验证 RelativeLayout 虚拟参数类型、MATCH_PARENT 字段、child 参数身份和父子关系：
  1 case / 44 assertions。
- Angry Birds 无 Profile、关闭 survey 的实跑越过该重载并进入 GLSurfaceView；下一独立首错为
  `BaseConfigChooser.chooseConfig` 抛出 `IllegalArgumentException: No config chosen`。
