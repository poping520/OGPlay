# DVM-168 · Java EGL 多配置与 RGB565 投影

目标：让 Java EGL10/EGL14 完整返回 Native registry 配置数组，并为桌面 RGBA8888 配置发布兼容的 RGB565 guest 查询视图。
依赖：DVM-167、BND-33。状态：完成。

## 实现

- EGL10/EGL14 的 config wrapper 改为逐 native handle 映射；`eglChooseConfig`/`eglGetConfigs`
  按调用方容量回填全部句柄，创建 context/surface 时仍传回真实 native handle。
- 当 Native config 是请求的颜色位数超集时，仅在对应 wrapper 的 `eglGetConfigAttrib` 查询中
  投影显式请求的 red/green/blue/alpha 位数；不修改 ANGLE 配置、不伪造 depth/stencil。
- EGL14 保持数组 offset 校验；非法 config/output 继续锁存或抛出 API 约定错误。

## 验证

- Windows Release `ogplay_tests`、`ogplay` 构建通过。
- `*EGL facade*`：4 cases / 98 assertions；`*EGL14*`：2 cases / 216 assertions。
- Angry Birds 无 Profile 实跑越过 `No config chosen`，完成 EGL context/surface 建立并进入
  `MyRenderer.onSurfaceChanged`；下一独立首错为缺少 `javax.crypto.Mac`。
