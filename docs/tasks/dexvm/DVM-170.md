# DVM-170 · Activity 主线程投递与 JNI 清理顺序

目标：按 API 19 语义区分 `Activity.runOnUiThread` 的主线程直调与工作线程投递，并在
root JNI 线程 detach 前释放 guest native 资源。依赖：DVM-85、DVM-135、DVM-169。状态：完成。

## 实现

- root context 调用 Runnable 时同步执行；GLThread 等 guest worker 改投进程唯一主 Looper，
  由 lifecycle safe point 泵送，Runnable 异常保持原始 Java throwable。
- lifecycle 已 join 所有 guest worker 后、`AndroidGuestCallSession::Stop` detach root JNI 线程前，
  统一释放 Mac 等 guest native token；bridge 析构仅保留兜底清理。

## 验证

- Windows Release `ogplay_tests`/`ogplay` 构建通过；双解释器线程分流测试 1 case / 16 assertions。
- Angry Birds 无 Profile 实跑越过 Handler/Looper 与 pending-exception 连锁故障，退出无
  `native_cleanup JNI exception thread is not attached`；下一独立缺口为 `java.security.KeyStore`。
