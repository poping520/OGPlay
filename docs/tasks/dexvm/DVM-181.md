# DVM-181 · 类运行时注解查询与注解成员执行

目标：按 API 19 交付 Class 运行时注解查询，以及可走正常接口分派的注解实例与成员取值。
不实现通用 Proxy、动态 classpath 或完整反射。依赖：DVM-145、DVM-69。状态：完成。

## 根因

`VisibilityChecker$Std.<clinit>` 调用 `Std.class.getAnnotation(JsonAutoDetect.class)`，
再读取显式枚举成员和未赋值的 `value()` 默认枚举数组。既有 Field marker 把注解接口
直接实例化，Class 入口仍是 Miranda 抽象方法，因此 abstract method invoked。

## 实现

- loader 解析 runtime/build/system 注解的递归 encoded value，并提取
  `AnnotationDefault`。索引只相对所属 DexUnit 解释。
- linker 把运行时注解和默认值转成稳定描述符/名称；正式接入点
  `DefineRestrictedAnnotationClass` 在初始 Link 之后按已加载的 annotation
  interface 生成具体实现类。
- 每 VM `AnnotationRuntime` 物化实例：成员走 vtable/iftable，数组每次防御性复制，
  equals/hashCode/toString 按 Annotation 契约比较成员。
- `Class.getAnnotation/isAnnotationPresent/getAnnotations/getDeclaredAnnotations`
  按 API 19 处理 null、空数组、`@Inherited`、本类遮蔽和接口不继承。
- Field 查询改用同一后端；`Method.getDefaultValue` 读取注解声明默认值。
  Method/Constructor/参数注解查询仍明确未实现。

## 验证

- 无游戏名称的通用 DEX 夹具覆盖查询、可见性、默认值、嵌套/数组、Inherited、
  异常、GC/隔离、Field 回归与 DexUnit 索引隔离。
- parser malformed 与资源上限定向测试。
- switch/threaded 双后端；`architecture.dexvm_intrinsic_layout`。
- Angry Birds 2.3.0 无 Profile、关闭 survey：插屏路径越过
  `Class.getAnnotation`。Jackson `ObjectMapper` 构造继续到
  `Class.getEnumConstants`。不宣称完整 Jackson 或游戏兼容。
