# DVM-182 · Class.getEnumConstants 浅克隆共享枚举常量

目标：按 API 19 交付 `Class.getEnumConstants`，使 Jackson 等调用方可读取枚举默认配置。
不迁移整个 Class 到 BootDex，不扩展其他反射 API。依赖：DVM-65、DVM-98。状态：完成。

## 根因

`MapperConfig$Impl.collectFeatureDefaults` 调用
`SerializationConfig$Feature.class.getEnumConstants()` 汇总默认序列化开关。
Class 已有 `isEnum` 与 VM 共享枚举常量数组，但公开实例方法未声明，链接失败。

## 实现

- 在 `Declare_java_lang_Class` 登记公开实例方法
  `getEnumConstants()[Ljava/lang/Object;`。
- 对照 API 19 `Class.java`：非枚举返回 null；枚举类调用既有
  `Interpreter::SharedEnumConstants`，再以 `ObjectModel::CloneObject` 返回浅克隆。
- 复用 `Class.isEnum` 判断（直接超类为 `Enum` 且带 `ACC_ENUM`）。不新建枚举扫描、
  缓存或 runtime。返回数组保留具体枚举数组类型；元素保持枚举单例身份。
  跨分配的 guest 引用用 `RootScope` 保护。

## 验证

- 双解释器 `DVM-182 Class getEnumConstants clones shared enum identity`：普通枚举顺序、
  真实数组类型与元素身份；两次调用数组不同且修改一次不影响后续；非枚举返回 null；
  空枚举返回非 null 空数组。
- `architecture.dexvm_intrinsic_layout`。
- Angry Birds 2.3.0 无 Profile、关闭 survey：插屏路径越过 `Class.getEnumConstants`。
  Jackson `ObjectMapper` 构造继续到 `class is not available: Ljava/sql/Date;`
  （`StdDeserializer$SqlDateDeserializer.<init>`）。不宣称完整 Jackson 或游戏兼容。
