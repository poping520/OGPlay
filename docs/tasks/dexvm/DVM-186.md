## 验证证据

- Debug `ogplay_tests` 构建通过；EventLog、损坏库删除重建、原版数据库双解释器及真实 APK Cookie 矩阵定向通过。
- BootDex build/check：1731 类，DEX `82ec782e69ace081f010f3ca77a9a55109e8b9d3bbca203bda8ccca454a4f0f6`，JAR `9fff63a895008cca89441245e59ebd4c46a7e92763041a765feffe151775912e`。
- SQLite statement token 支持绑定、重置、元数据、取消、陈旧 token 与关闭后拒绝。连接 close 会中断活动查询并等待使用者退出，重复 teardown 幂等。
- 文件库与 `:memory:` 均受检；authorizer 明确拒绝 `ATTACH/DETACH` 和 WAL，生产 VFS 的随机字节来自 HAL OS CSPRNG 注入。
- NULL/REAL/Unicode/BLOB、索引、触发器、嵌套事务回滚及 Helper callback 失败后的 schema/version 回滚受检。
- SQLite 本地失败保留错误码并按 API 19 映射为 `SQLiteException` 对应子类；约束、无法打开、只读写入受检，不会泄漏宿主 C++ 异常。
- CursorWindow 逐行填充，不物化完整结果；按 TEXT/BLOB 载荷计费并处理 `requiredPos`、`countAllRows` 和超大行，`copyStringToBuffer`、释放回收和陈旧 token 受检。
- 独立 Android SDK SQLite 3.44.3：工具建库→OGPlay 读改→工具查询/完整性检查，以及 OGPlay 建库→工具修改→OGPlay 重开均通过；工具也能恢复 OGPlay 在主库 sync 点截取的 hot journal。
- Angry Birds 2.3.0 原始 `classes.dex` 类级验收执行真实 `SQLiteCookieStorage`：空库建表、过期行事务删除、有效行 `rawQuery` 读回均通过。有效行的下一独立首错是 JSON 初始化所需的 `NativeDecimalFormat.open`，发生在 SQLite 读回之后。
- 无 Profile、关闭 survey 的完整进程运行越过原 `SQLiteDatabase.rawQuery` 首错，下一独立首错为 Jackson `MapperConfig.<clinit>`。
- 新空沙盒完整进程运行创建标准 SQLite `cookiedb` 并越过 Cookie/EventLog 路径；下一独立首错为 `Utils.encryptedDeviceId` 对空设备标识调用 `String.length()`。

## 边界

首期仍不支持 WAL、跨进程共享和动态扩展。生产代码不识别或迁移旧自定义格式；SQLite 判定文件格式，API 19 默认损坏处理器负责记录、删除和重建。LOCALIZED/UNICODE 当前只提供受限 en/zh UTF-8 稳定排序，不宣称完整 Android ICU collation。
