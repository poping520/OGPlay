# DVM-186 · BootDex SQLite 与 host 真实数据库

日期：2026-09-17。状态：已规划，未开始实现。

## 目标与依据

以 API 19 原版 Java 数据库栈、固定 SQLite amalgamation 和唯一 VFS 替换 OGDB1。
设计与验收唯一详表见 [开发规划](../../design/dexvm/15-sqlite.md)；架构提案见
[ADR-0068](../../adr/dexvm.md#adr-0068)。不按 Cookie 栈创建专用实现。

依赖：DVM-88 既有数据库入口、现有 BootDex/native overlay、VFS/SandboxStore、
VM 线程/GC，以及已加入的 `third_party/sqlite-amalgamation`。

## 当前证据与停止边界

- 子模块版本、Git commit 与源码摘要已核对；尚无真实 SQLite 运行时构建或行为证据。
- 现状仍为 OGDB1；本次仅文档变更，不构建、不运行代码测试。
- 首期不支持 WAL、跨进程共享、OGDB1 自动迁移；旧文件必须保留并明确拒绝。
- SQL-03 记录原首错消失及下一独立首错，不顺带修复后续网络/广告 SDK 问题。
