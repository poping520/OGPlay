# DVM-189 · 音频协议、BootDex 与会话输出收敛

状态：验收修复中；AUD-03 未关闭。日期：2026-09-20。

## 目标与范围

兑现已有 AudioTrack、SoundPool、MediaPlayer、OpenSL PCM 的应用可见音频语义，
修正资源隔离、缓冲/事件/GC/退出问题；原版 Java 按需迁 BootDex，CLI 音频编排归 session。
保留宿主解码和 SDL3，不引入 Android 系统音频服务。

问题清单、证据、支持范围、BootDex 闭包选择、线程/时钟协议和逐批验收统一维护在
[音频审计与开发规划](../../design/dexvm/16-audio.md)，不在本任务重复复制。
架构变更依据 [ADR-0069](../../adr/media.md#adr-0069)（Proposed）。
