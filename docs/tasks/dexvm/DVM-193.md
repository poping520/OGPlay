# DVM-193 · 当前 APK 接收器声明查询

目标：实现 `PackageManager.queryBroadcastReceivers(Intent,int)` 的有界隐式查询。
依赖 DVM-112、DVM-142、DVM-97、DVM-190。状态：完成。

## 边界

- receiver 复用 Manifest intent-filter 结构，逐个保存 action/category、data 条件存在标记、
  signed priority、label/icon，经现有 session 原样注入唯一 context。
- 支持非空 action、无 component/selector/data/type、flags=0；package 可缺省或为当前包。
  所有 Intent category 必须属于同一个命中过滤器，广播查询不要求 DEFAULT。
  跳过禁用 application/receiver；permission/exported 不作为声明查询的授权门槛。
- API 19 `IntentResolver`/`ActivityIntentResolver` 语义：同一 receiver 保留首个命中的
  filter，随后按 priority、preferredOrder、isDefault、match、system 降序稳定排序。
  本范围 preferredOrder=0、match=EMPTY+NORMAL、system=false，因此只需比较 priority/isDefault。
- 真实 BootDex ArrayList/ResolveInfo 执行原版构造，ActivityInfo 复用 MakeReceiverInfo；
  flags=0 不返回 filter/metaData。返回 priority/match/isDefault、filter label/icon 等事实。
- 无 inventory、未知 flags、缺失/空 action、外部 package、显式/selector/data/type 查询，
  或 action/category 潜在命中的未解析 data 条件，记账 `dexvm.receiver_query` 并抛
  UnsupportedOperationException；null Intent 抛 NPE。确认无匹配才返回空列表。
- 不引入 Binder/system_server、外部包数据库、广播投递或推送实现；不需要新架构 ADR。

## 验证

- 定向覆盖 loader 过滤器独立保存、负 priority、data 标记与 label/icon；双解释器验证
  action/category、启用状态、去重/排序、BootDex 字段/构造默认值/GC 与不支持条件记账。
- macOS arm64 Release `ogplay`/`ogplay_tests` 构建通过；Manifest 22 项/1648 断言、
  DexVM 定向 12 项/1571 断言通过。未跑全量测试；构建仍有既有其他文件警告。
- Dead Trigger 无 Profile、空临时沙盒、关闭 survey 的 APK/OBB 启动已越过原方法解析错，
  未记录 RECEIVE/REGISTRATION 过滤器缺失；下一首错为
  `SQLiteGlobal.getDefaultJournalMode` 抛 `Resources.NotFoundException: system string resource is unavailable`。
  仅为 reached-fault，非游戏兼容验收，不继续修下一独立问题。
- 初次测试筛选误包含无关 DVM-182 枚举测试，其夹具报既有
  `CursorWindow.nativeAllocRow` 未绑定；修正筛选后的相关测试全部通过。
  本机从仓库根启动需设置 `DYLD_LIBRARY_PATH=build/release`。

复现命令与本地证据（`.local/` 不入库）：

```sh
cmake --build --preset release --target ogplay ogplay_tests -j 6
DYLD_LIBRARY_PATH=build/release build/release/ogplay_tests --source-file='*apk_manifest_tests.cpp'
DYLD_LIBRARY_PATH=build/release build/release/ogplay_tests --test-case='DVM-193*,DVM-97*,DVM-112*,PackageManager getReceiverInfo*,PackageManager getServiceInfo*,PackageManager getPermissionInfo*'
DYLD_LIBRARY_PATH=build/release build/release/ogplay run-apk .local/games/dt/com-madfingergames-deadtrigger-10000110.apk --obb .local/games/dt/com.madfingergames.deadtrigger/main.10000110.com.madfingergames.deadtrigger.obb --ephemeral-sandbox --exit-after-frames 120
```
