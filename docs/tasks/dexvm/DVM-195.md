# DVM-195 · 进程内 NativeActivity

目标：原版 API 19 NativeActivity Java + 当前进程 NDK 回调桥，不创建第二套进程。
依赖 DVM-142、DVM-190、DVM-194、APS-1。状态：有界能力定向验收完成（2026-09-28）；
游戏兼容与完整 NDK 未验收。

## 阶段与验收

1. BootDex NativeActivity/NativeContentView 与接口闭包；Activity 自身 meta-data 与
   getActivityInfo；nativeLibraryDir 对应 selected-ABI APK 库在 guest VFS 可见。
2. 使用当前进程 loader/JNI/内存/执行器装配 ARMv7 ANativeActivity，通用 guest 测试验证
   真实 Activity 身份、生命周期、未登记回调、缺库/入口与销毁清理。
3. Window Surface/InputQueue 接管、解除及切换，复用 SDL3/ANGLE；定向所有权回归后
   关闭 survey 复现同一路径，仅记录下一首错，不宣称游戏验收。

不降低 SDK、不硬编码应用、不伪造内容 View、不启动 NativeActivitySession。

## 实现与支持边界

- BootDex 保留原版 Java 生命周期及字段；Activity 自身元数据独立保存，
  getActivityInfo 支持当前 APK 的 0/GET_META_DATA/GET_DISABLED_COMPONENTS。
  selected-ABI 库发布到 nativeLibraryDir 对应的只读 guest VFS。
- 当前 loader、地址空间、JNI/JavaVM 与执行器共享身份；NDK 加载不触发 JNI_OnLoad，
  后续 Java 加载在同一映射上执行一次 OnLoad。ARMv7 ABI 使用真实 Activity/AssetManager
  global refs、沙盒路径与 guest 回调槽。销毁解除注册、引用和 ABI 内存；库映射仍按现有
  loader 契约保留至进程 Stop。保存状态上限 1 MiB，复制后调用 guest free。
- Surface 支持首次遍历前解除、销毁及重新接管；每次创建分配独立原生窗口身份，
  旧 EGL surface 在解除或重接管后不能 create/bind/swap。窗口 acquire 引用可保留至 release。
  GlobalLayout 从真实布局传递内容区域；InputQueue 接收当前所有者的 SDL 输入。
- 窗口固定会话尺寸/RGBA8，其他 geometry 返回 EINVAL；InputQueue 仅 ident polling，
  callback looper 明确失败。APK asset 的 open/read/seek/length/remaining/close 有界支持，
  单文件上限 64 MiB。不扩展相机、完整 NDK、输入法或 Android 系统服务。

## 实际验证

- BootDex build/check 通过，生成 manifest 为制品身份依据；运行目录制品与源目录一致。
- release 仅构建 ogplay_tests、ogplay；定向 19 用例、577 断言通过。
  覆盖双解释器原版 NativeActivity 路径、真实 JNI 身份、组件元数据、缺库/入口失败、
  生命周期/保存状态/guest free/销毁、Surface 所有权切换、EGL 退役窗口、assets 与输入。
  复用既有库加载、SurfaceHolder、Looper、最小 APK 与 EGL draw/read surface 回归。
- 无 Profile、关闭 survey，以原 APK/OBB、ephemeral sandbox 和 120 frame 上限复现一次：
  已切换至 UnityPlayerNativeActivity，原 NativeActivity 缺类与代理 finish 后内容视图错误消失。
  下一首错为 Camera$PreviewCallback 缺失，位于 UnityPlayerNativeActivity.onCreate 的
  new-instance（dex_pc=3），尚未到 super.onCreate/native 加载；不宣称 Unity native 实跑通过。
- architecture.dexvm_intrinsic_layout 仍因既有 android_media_bootdex.cpp、encoded_audio_window.cpp
  未列入清单失败，本次未新增 family TU；未扩大为全量测试。
