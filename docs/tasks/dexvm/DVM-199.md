# DVM-199 · SecretKey 公开类型与 PKCS12 SecretKeyFactory

状态：有界实现完成。沿用 ADR-0064 的原版公开 API、自有 Java SPI、guest 密码后端边界。

- 固定 core.jar 补齐 SecretKeyFactory/SPI、PBEKey/PBEKeySpec、DES/DESedeKeySpec
  及对称加密参数类型；既有 SecretKey/SecretKeySpec/KeyGenerator 保留原版。
- OGPlayCrypto 注册 PKCS12 SHA-1/AES-256 SecretKeyFactory 与 SHA1/SHA-1 别名。
  对齐 API19 的固定 256 位、无盐密码编码、元数据、规格转换与 translateKey。
  不注册 BC Provider，不增加 PBE Cipher、PBKDF2、DES/RC/GCM 算法。
- KDF 复用 guest Java Pkcs12Kdf → 原版 MessageDigest → guest libcrypto。
  此 SecretKeyFactory 的资源限制：密码最多 65536 UTF-16 单元，盐最多 65536 bytes，迭代最多 1000000。
  BKS 外部输入限制继续由 BKS 自己校验；普通 Java 行为不新增 intrinsic。
- 验收：固定 API19 BC 静态语义核对、隔离 BC 1.50 oracle、双解释器公开 API/错误路径、BKS 回归、
  BootDex build/check 与 payload 检查；原 APK 路径只记首错推进，不算兼容验收。
