# DVM-200 · JNI 反射成员转换

状态：有界实现完成。沿用 ReflectionRuntime 元数据与 JNI registry 的唯一成员身份。

- 接通 FromReflectedField/Method、ToReflectedField/Method 四槽；Method 包含构造器。
- JniEnvironment 持有显式转换 hooks，guest binder 只解码 A32 参数/返回值；
  DexVM bridge 在执行锁内使用原版反射 wrapper 与已有成员 ID，退出时清除 hooks。
- 校验引用、wrapper 类型、成员 ID、声明类兼容性及 static 标志；无后端或非法调用
  明确失败。转换不执行成员、不检查 Java accessible 标志，也不主动初始化类。
- 返回 wrapper 归调用线程 local frame；ID 不持有 wrapper，不另建字段值或成员身份。
- ToReflectedMethod 按完整 descriptor 定向取得元数据，避免同类无关缺失类型阻断转换。
- 验收：精确槽集合、双解释器四槽真实 guest ABI、字段访问/方法调用/构造器、
  GC/local-global 引用、非法输入与 teardown；原 APK 同路径复现只记录下一首错。
