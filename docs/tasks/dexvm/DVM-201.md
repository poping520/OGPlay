# DVM-201 · CRC32 BootDex 与 guest zlib

状态：有界实现完成。沿用 BootDex-first 与统一 guest JNI 边界，无新架构决定。

- Checksum/CRC32 来自固定 API19 core.jar；公开方法、参数检查与 crc/tbytes 字段归 Java。
- CRC32 两个私有实例 native 按原声明准入，经统一 libogplay_jni.so 调用已有 guest libz。
  数组分块读取，空区间保持累积值，结果按无符号 32 位扩展；异常不得伪造成功。
- 不扩展 Adler32、Inflater/Deflater、ZIP 流或密码 Provider。
- 依赖：既有 BootDex 构建、guest JNI 动态解析、API19 libz 与数组 JNI region。
- 验收：BootDex build/check、native 签名审计、NDK r25c 重复构建和 payload 检查；
  双解释器标准向量、分块/单字节、范围异常、reset/GC/实例隔离及 DigestOutputStream；
  原 APK/OBB 无 Profile、关闭 survey 复跑，只记录 reached-fault。
