状态：有界实现完成。架构边界见 ADR-0084。

- 直接 native 调用把 VmJavaThrow 转为保留身份的 VmCallOutcome。
- 退出前记录并清除已失败调用的 JNI pending，清理失败仍继续关闭进程与 surface；首错优先。
