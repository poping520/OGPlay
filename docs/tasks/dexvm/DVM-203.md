# DVM-203 · intrinsic GLSurfaceView 渲染线程归属

范围：按 [ADR-0085](../../adr/runtime.md#adr-0085) 将 intrinsic renderer 从 Activity 主
线程迁移到独立 Java/host GLThread，复用已有线程运行时，不为游戏设置分支。

- 同一 GLThread 执行 EGL policy、renderer、queueEvent、swap 与 EGL 释放；主 Looper 保留
  在 UI 线程，GLThread 不预建 Looper。guest 自带 GLSurfaceView 路径不变。
- Java EGL/GLES 使用与 JNI 相同的 process TID，避免 Java/native current 分裂。
- 主线程等待绘帧时继续处理主 Looper；空闲及暂停时 queueEvent 仍可执行。
- Activity 切换/退出等待渲染线程与 JNI/TLS 退役；初始化、绘帧或事件异常保留首错。
- 不包含缺失 NDK InputEvent/MotionEvent API、多 GLSurfaceView 或 EGL context-loss 策略。

验证：Windows Release `ogplay_tests` / `ogplay` 构建通过；定向 10 用例/1113 断言
通过，含双解释器的线程身份、Java/native EGL current、主 Looper 往返、回调/事件顺序、
暂停时无绘帧 queueEvent、正常退出、EGL 创建失败及绘帧异常清理。
证据：`.local/glthread-build-final.log`、`.local/glthread-tests-final.log`。
