# DVM-207 · 输入方法服务的无会话边界

目标：按 API19 发布 restartInput / showSoftInput / hideSoftInputFromWindow 的无会话
分支，活跃连接创建明确失败；不通过空实现隐藏输入缺口。

依赖：既有 Context singleton、lifecycle 主窗口 focus owner、UiTree 唯一焦点。
AOSP 依据：InputMethodManager.java:1060 restartInput、1074 startInputInner、1280 checkFocus，
以及 show/hide 入口；均先 checkFocus，焦点切换可能在调用者 View/token 检查前启动连接。

范围：当前无已发布连接，从当前窗口 owner 与 attached focused UiNode 判断候选。
无候选时 restart 返回、show/hide 返回 false；有候选时记入
`dexvm.input_method_sessions` 并抛 UnsupportedOperationException。普通非编辑器 View
也可能供应 dummy InputConnection，不能仅检查 onCheckIsTextEditor。
不建立第二份焦点缓存，不保存连接/served View 引用，不改变物理 KeyEvent 派发。

验收：双解释器下服务单例、初次 onResume、重复调用、window owner 切换、clearFocus、
detach/reset；活跃焦点对正常/无关 View/token 都拒绝并记账；复用既有焦点回归，
原 APK 无 Profile/无 survey reached-fault 复现一次。

后续边界：另行闭合 API19 EditorInfo/InputConnection/BaseInputConnection 的审计依赖、
主 Looper 连接代际及重入、GC tracing、SDL3 文本/组合输入和共享 Editable 事务。
proxy、ResultReceiver、真实软键盘显示和完整 IME 尚未实现；不引入 Binder/system_server。

验证：macOS Release 受影响 ogplay/ogplay_tests 构建通过；双解释器定向 2 用例、546
断言通过，覆盖本阶段与既有 View 焦点回归。原 APK、无 Profile/无 survey、隔离沙盒
越过 restartInput/onResume 并触发 Surface 回调；下一首错为
`SurfaceHolder.getSurfaceFrame()` 在 holder 实现上虚分派失败，未扩展范围修复。
证据：`.local/tales-input-method-fix/`。这是 reached-fault，不是 title gate。

状态：无会话阶段完成；活跃 InputConnection / 桌面 IME 未实现，Windows/Linux 未实跑。
