# DVM-208 · API19 Crypto 确定性播种 PRNG

状态：有界实现完成。
依赖：DVM-147 JCA/AES KeyGenerator、ADR-0086 VFS 随机设备。

## 范围

- 注册名为 Crypto 的受限 Provider，仅公布 SecureRandom.SHA1PRNG。
- 原版 SHA1PRNG/SHA1Impl/SHA1Constants 进入 pinned API19 BootDex；状态在 guest 字段/数组。
- 保留 AndroidOpenSSL 默认顺序与 OS 熵语义。显式初始 seed 按 Harmony 字节流复现；
  未播种和 generateSeed 使用既有 /dev/urandom VFS 设备，失败保真。
- 不注册 DSA/完整 Harmony 或 BC，不绕过签名验证，不引入游戏专属分支。

## 验收

- 双解释器验证 Provider 名称/对象/发现与仅一个服务；默认 Provider 不变。
- 独立 API19 oracle 向量、同 seed 重现、分块连续流、二次播种、实例/GC/线程隔离。
- 熵设备首次自动播种、generateSeed、熵失败异常及 AES key 派生。
- BootDex build/check、依赖/native/overlay 检查，相关 C++ 目标与现有随机/AES 回归。
- 原 APK 无 Profile/无 survey 越过可重复 PRNG 失败，记录下一首错；仅 reached-fault。

证据目录：`.local/tales-crypto-prng-fix/`。

## 结果

- 受限 Provider 仅公布 SHA1PRNG；三项原版算法类无 native/overlay，依赖声明与
  staged 制品哈希一致。BootDex build/check、macOS Release 受影响目标构建通过。
- 四个定向用例共 3702 断言通过，三个 DVM-208 用例均运行双解释器，另复用真实
  guest libcrypto 的 OpenSSL 随机/AES/BKS 回归。独立 JVM oracle 生成的五组向量可重现。
- 原 APK 无 Profile/无 survey、隔离沙盒越过 predictable SecureRandom 错误，
  不再记录 KeySpec 初始化错误；下一致命首错为 getInstallerPackageName(String)，
  退出 1、无超时。此为 reached-fault，不等于完整游戏或在线服务可用。
- 初次测试编译与线程夹具错误已修正；临时根始终在创建它的执行上下文内释放。
  初始失败日志与最终证据均保留在证据目录。PRNG 序列化及 Windows/Linux 实跑未验收。
