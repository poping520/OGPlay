# DVM-214 · API19 字节流压缩与 guest zlib

状态：有界实现与 macOS 定向验证完成；沿用 BootDex-first 和统一 guest JNI，无新架构决定。
依赖：固定 core.jar、已发布 guest libz、JNI 数组/字段边界、VM native 资源回收。

范围：原版 GZIP 读写、DeflaterOutputStream/InflaterInputStream、Deflater/Inflater。
公开算法/参数检查/流头尾及 CRC/长度校验归 BootDex，native 只桥接 guest zlib。
ZipFile.RAFStream 是 InflaterInputStream 的原版类型检查依赖，不引入完整 ZipFile。
setFileInputImpl 继续记账并抛 UOE，不使用 Java FD 打开宿主或 guest 文件。

native 使用正值逻辑 token、registry/per-stream mutex 与引用计数，输入快照复制，输出
scratch 有界。关闭/GC/teardown/库析构释放资源；保留 API19 streamHandle=-1 标记。
Deflater/Inflater 全部 native 声明与可见性由制品审计钉住；FD 方法显式归失败路径。

验收：BootDex build/check 与 native 漂移拒绝、guest JNI 可重复构建、payload 校验；
双解释器独立 GZIP 向量、大数组分块、读写闭环、CRC/长度/截断错误、输入快照、
字典/参数/reset/计数、范围/失效/跨类型 token、重复关闭、GC 和 teardown；
原 APK 同触发路径复跑记录 reached-fault，并关闭所有测试进程。

证据：`.local/gzip-fix-20261004/`。完整游戏、黑屏消失与 Windows/Linux 实跑未验收。
