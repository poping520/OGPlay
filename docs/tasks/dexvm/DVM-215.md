# DVM-215 · API19 十进制 JSON 数值转换

状态：有界实现及 macOS 定向验证完成。依赖：固定 core.jar、受检 NativeBN token codec、既有 guest libcrypto/JNI。

补入原版 Multiplication 和 BigDecimal$1；保留 Java 数值转换/舍入算法，增加有界
BN_mul、BN_mul_word、BN_shift、BN_div、BN_add、BN_exp 值桥。只传编码值，临时
BIGNUM 不发布地址或新持久令牌。输入快照、失败原子性、别名及 GC 生命周期保持。
科学计数法解析所需 String.valueOf([CII) 复用 VM UTF-16 值边界，受检复制区间。
Logical/Primality、模算术、素数及完整密码学不在范围；沿用 BootDex-first 架构。

验收：构建/配方/native ABI/载荷审计；双解释器 JSON 数值转换与真实序列化、独立
IEEE754 oracle、符号/零/商余数/别名/失效 token/预算/GC 回归；原 APK reached-fault。
证据目录 `.local/decimal-json-fix-20261004/`；结束前关闭全部游戏测试进程。
