# DVM-216 · API19 本地 VideoView 生命周期

状态：有界实现及 macOS 定向验证完成。前序：[DVM-215](DVM-215.md)、[BND-51](../boundary/BND-51.md)。依赖：既有 FFmpeg pull 后端、VFS/APK range、BootDex MediaPlayer、UiTree。
决策：[ADR-0094](../../adr/media.md#adr-0094)。

范围：Java 监听器与目标状态，异步 prepared/error/completion、真实播放器身份及控制，
本地路径/file/当前 APK raw URI，左右音量、UiTree 合成和 onTop、代际取消与 GC 释放。
不支持网络、字幕、系统媒体服务或错误对话框；失败不再伪造完成。

验收：BootDex build/check/native ABI；定向异步、控制、错误、重入、GC、音量、画面
回归；原 APK 隔离沙盒 reached-fault 一次，记录下一首错并关闭所有 OGPlay 进程。
证据目录 `.local/videoview-lifecycle-fix/`。跨平台实跑和完整游戏未验收。


实际验证（2026-10-04）：
- Release ogplay/ogplay_tests、BootDex build/check 及视频/native ABI 漂移自测通过。
- 25 用例/823 断言：主线程延迟 prepared、回调播放器身份和音量、预先 start/seek、
  暂停后 seek 出帧、单次完成、替换/停止/回调释放/恢复/ detach、URI 原版解析、
  当前 APK raw 名称/数值 ID、FD 关闭后保留有界 range、GC 监听器追踪与后端回收、
  frame/PCM 解码失败仅交 error、未处理错误明确失败、UiTree bounds/visibility/clip/onTop。
  事件协议在 switch/threaded 两种解释器验证。
- 原 APK 无 Profile/无 survey、隔离沙盒复跑；实际打开 raw 视频，旧监听器方法首错
  消失。45 秒观察窗口最后一次 MCP 采样 f=3834/presentedFrame=1726，无 guestFault；
  frame-24.png 可见星空和飞船开场画面。仅 reached-fault/开场出画，不等于完整游戏验收。

  Windows/Linux、完整 API19、影音同步和 title gate 未验收。
