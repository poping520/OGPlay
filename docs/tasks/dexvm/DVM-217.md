# DVM-217 · 原版原子文件与 native 资源清理异常隔离

状态：有界实现及 macOS 定向验证完成。依赖：既有 BootDex、IoRuntime/VFS、JNI 引用与线程映射。

范围：固定 ROM 的内部 AtomicFile、FileUtils 依赖及 Slog；普通文件算法保持原版，
提交/回滚/备份恢复走唯一 VFS。Log.println_native 支持 main/system 文本日志；
Posix.chmod 明确记账并抛 ENOSYS，FileUtils 按原版转换为 errno，不能冒充权限成功。
ROM 专有 FileUtils.getVolumeUUID 保留明确未实现入口，不扩展宿主卷/权限能力。

资源清理通过 NativeMethodBridge 的 RAII scope 暂存并 root 当前线程 JNI pending，
清理后恢复原异常身份；正常 JNI 调用的 pending gate 保持严格。
静态 native 类 global ref 使用调用线程身份，不借用根线程。

验收：BootDex build/check；双解释器文件提交/回滚/重启恢复；真实 guest libcrypto
清理、待处理异常 GC 保活/恢复及正常 gate 回归；原 APK 相同触发路径一次。
证据目录 `.local/atomic-file-fix/`。跨平台实跑、断电一致性与完整 title gate 不在本次验收内。
