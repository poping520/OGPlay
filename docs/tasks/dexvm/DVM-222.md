# DVM-222 · NFC 类型与无设备发现

状态：有界完成。依赖：API19 BootDex、Context 工厂与 Java 异常边界。
决策：[ADR-0103](../../adr/runtime.md#adr-0103)。

范围：补齐 NDEF 监听接口/事件/值类型，保留 Java 查询与 NfcManager 状态，
只提供无 NFC 设备的发现路径。禁止引入 NFC 通信、标签读写、Beam、扫描、
卡模拟、Binder 或系统 NFC 服务；不修改 APK，也不放宽类链接检查。

实现：NfcAdapter 两个 getDefaultAdapter 方法及两个回调接口沿用 API19 Java；
隐藏工厂只接无设备 native 边界。Context 正常构造并缓存原版 NfcManager，
其构造器捕获 UnsupportedOperationException 并保存 null 适配器。
构造适配器/注册回调等越界调用记账且明确失败，不保存监听器或派发回调。
事件/NDEF 值类及其 Parcelable creator 来自固定 framework.jar 配方；
原版 Java 数据处理不意味着 NFC 通信支持，完整值类/Parcel 长尾另行验收。

验收：BootDex build/check/native ABI 审计及 payload 校验；双解释器类链接、
无设备/参数错误、feature 查询、GC 后 manager 身份、越界注册失败且无回调；
原 APK 同启动路径复现一次，记录首错消失及下一首错。

证据：`.local/wb-nfc-absence-fix/`。完整游戏及跨平台未验收。

实施与验证（2026-10-07）：
- BootDex build/check 与两个精确 native ABI 审计通过；固定 NDK 重建 guest JNI，
  库内容哈希未变化，仅更新 builder 指纹。Android payload 校验通过。
- macOS Release ogplay/ogplay_tests 构建通过；NFC 与相邻 sensor 回归合计
  2 项/308 断言通过，覆盖 switch/threaded。GC 回归使用生产 session roots 入口。
- 原 APK/外部数据、无 Profile/无 survey、隔离空沙盒越过原 NFC 链接错误并进入
  Game.onStart；下一首错为 startInstallerIfNeeded 调用
  startActivityForResult(Intent, int) 方法缺失，退出 1，进程已关闭。
- 原版两个查询方法/两个监听接口已按源码块核对；完整 NDEF/Parcel 算法、
  单独 JNI 查询及跨平台/title gate 未验收。NFC 通信仍不实现。
