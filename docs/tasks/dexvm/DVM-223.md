# DVM-223 · 同进程 Activity 返回栈与结果

状态：有界完成。依赖：BootDex Activity 客户端、sealed Manifest resolver、session 生命周期、
UiTree/GC roots。决策：[ADR-0104](../../adr/runtime.md#adr-0104)。

范围：同包单任务、单前台窗口；standard 新实例与不在栈顶的 singleTop 新实例。
启动/finish 以 FIFO 命令及强类型 owner 身份编排，保留调用方实例及普通 View 内容。
BootDex 保存结果字段/monitor/setResult/两参数转发，native 只解析启动及提交结束快照。
Intent 沿用原版复制算法，不承诺跨进程 Parcel/URI 授权语义。

返回栈与待交付结果受 GC session roots 保活；调用方恢复时交付结果后再 resume，
负 requestCode 不产生回调，未设置结果默认为 RESULT_CANCELED，自定义码不改写。
重复 finish 不重复交付，结束非栈顶实例不改变前台，栈中仍有调用方时不结束进程。
onCreate 内 finish 不 start/resume，onStart 发起启动不先 resume 调用方。
生命周期回调可排队下一转换，不同步递归启动；每轮最多 128 转换，栈最多 32。

首阶段不保留有活动 GL renderer/Surface/native callback 或播放视频的调用方；
已有 startActivity+finish 的渲染退役路径继续可用。后台 setContentView、非空 options、
for-result 非零 flags、同顶 singleTop 复用、singleTask/singleInstance、跨包结果明确失败。
普通 Context.startActivity 的既有禁用浏览器/flags 边界不因此宣称完整验收。
不引入 ActivityManager、ActivityThread、Binder、Fragment、多窗口或手机运行能力。

验收：BootDex build/check/native 审计/payload；Release 定向返回结果、身份/内容/窗口隔离、
嵌套/重复结束/中间结束、GC、onStart 启动/onCreate 结束，以及既有空 Activity/焦点/退出路径。
原 APK 同路径复现一次，记录首错消失及下一首错；不修复下一独立缺口。

证据：`.local/wb-activity-result-fix/`。跨平台与游戏 title gate 未验收。

  重建 guest JNI 更新 generator 指纹，库内容哈希未变化；Android payload 校验通过。
- macOS Release ogplay/ogplay_tests 构建，定向 13 项/2576 断言通过，涵盖双解释器
