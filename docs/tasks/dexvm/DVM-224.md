# DVM-224 · 禁用通知后的空集合取消

状态：有界完成。日期：2026-10-08。依赖：BootDex 客户端、Context 工厂、native 异常/账本。
决策：[ADR-0105](../../adr/runtime.md#adr-0105)。

范围：当前 APK、单应用进程的已知空通知集合。Context 正常初始化并缓存 Java
NotificationManager；构造器、Context 字段、from、cancel(int) 和 notify(int, Notification)
重载转发来自 API19 源码。两个 private native 只验证包身份及取消/拒绝发布。

cancel(int)、cancel(tag, id)、cancelAll 在空集合上完成，允许任意 int id、null/空 tag
及重复调用；不修改 PendingIntent。无发布入口能够加入记录、无外部生产者或持久通知
库存，因此不建立虚构通知表；不能将未知库存默认为空。包不属于当前应用时抛
SecurityException 并记账。notify(null) 抛 NPE，非空发布走记账的
UnsupportedOperationException，不存储通知对象、不伪称显示成功。

不提供 NotificationManagerService/Binder、状态栏/系统弹窗、声音/震动、点击/删除
PendingIntent 派发或通知持久化。Notification/Builder/RemoteViews 数据类型及
PendingIntent.getActivity 尚未纳入本项；公开 notify 原型不代表其构建链可用。
跨用户、跨包或其他未纳入 API 不声明支持。

验证（2026-10-08）：
- BootDex build/check、两个精确 native ABI 审计和 builder self-test 通过；固定 NDK
  重建 guest JNI 更新 generator 指纹，库内容哈希未变；Android payload 校验通过。
- macOS Release ogplay/ogplay_tests 构建通过；通知取消/NFC/既有 JNI framework
  定向 3 项/1808 断言通过，通知与 NFC 用例覆盖 switch/threaded。检查取消重载/重复调用、
  正常 Java 构造与 factory/from 身份、生产 session roots GC、包拒绝、发布拒绝记账及
  PendingIntent 不被失效。
- 原 APK/外部数据、无 Profile/无 survey、隔离空沙盒运行单帧，未再出现原
  notification 服务异常；到达主动停止日志，f=1 长 guest call 后 30 秒退出阶段超时，
  子进程已被复现脚本结束。未取得下一条 Java 异常，阻塞原因尚未定位；不记录为 clean
  shutdown 或游戏 title gate 通过。
- Notification 实例/Builder 构造、单独 JNI 通知入口、跨平台和完整游戏未验收。

证据：`.local/wb-notification-cancel-fix/`。超时是独立后续问题，本项不修复。
