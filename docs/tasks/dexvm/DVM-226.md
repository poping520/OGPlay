# DVM-226 · 原版 PrintStream 与 System 日志端点

状态：有界完成。日期：2026-10-08。依赖：BootDex/core.jar、OutputStream/VFS、String 编码。
决策：[ADR-0108](../../adr/runtime.md#adr-0108)。

从固定 core.jar 选入原版 PrintStream，继承 FilterOutputStream；移除 C++ 类壳和
普通输出方法。构造、目标 out 强边、编码、append/print/println、flush/close/ioError
与 Throwable.printStackTrace(PrintStream) 执行原版 Java，不复制状态或手写算法。

System.out/err 正常构造两个 PrintStream，分别包装新的 Java LogOutputStream；
pending buffer/monitor/closed 归 Java，唯一 private static native emit 写入结构化 logger。
UTF-8 换行/flush/close 提交非空文本；此端点是诊断日志，不提供宿主终端 FD。
普通 PrintStream 写实际传入的 Java OutputStream，不写日志。文件目标沿既有 VFS，
printf/format 沿既有 Formatter/ICU 能力，不能据类形状宣称完整格式化/编码/终端一致性。

为 ByteArrayOutputStream.toString(charset) 补齐 String(byte[],offset,length,charsetName)
VM 特殊构造重载，复用既有范围校验与固定字符集 codec，无新编码算法或 JNI 原语。

验收：双解释器缓冲输出/Unicode/三种流构造器/编码/null 与错误、异常与 cause 文本，
目标流 GC 保活、autoFlush/IO error/close、System 流身份和 logger 路由；配方 build/check、
精确 native ABI、payload、定向构建及原 APK reached-fault。
证据：`.local/wb-printstream-fix/`。
