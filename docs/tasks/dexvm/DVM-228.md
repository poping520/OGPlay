# DVM-228 · ActivityManager 内存查询与统一 1 GiB guest 快照

状态：有界实现及 Windows 验证完成。决策：[ADR-0111](../../adr/runtime.md#adr-0111)。

## 范围与依赖

有界 ActivityManager Java 客户端、原版 MemoryInfo 值对象、统一 guest 内存快照。
默认总量 1 GiB、空闲 512 MiB、缓存 256 MiB；可用值遵循 API19 MemFree+Cached。
依赖 DVM-89 proc facts、BootDex/native overlay、Context 工厂与 session GC roots。
不实现 Binder/AMS/LMK、进程枚举、任务管理或宿主内存采样；不调整 DexVM 堆配额。

## 验收

- BootDex build/check、native/overlay 与 payload 校验；受影响 Windows Release 目标。
- 统一默认值、参考 meminfo 的 free/cached/buffers、自定义与非法事实、只读及冲突检查。
- switch/threaded 的字段/64 位、阈值边界、null、拒绝能力、GC/缓存与 JNI 一致性。
- 原 APK/外部数据、无 Profile/无 survey 复跑一次，记录原错误消失及下一首错。
- macOS/Linux 实跑未取得证据时明确保留缺口。

## 本进程查询扩展（2026-10-28）

- `getRunningAppProcesses()Ljava/util/List;` 每次新建 ArrayList、ROM
  RunningAppProcessInfo（String/int/String[] 原构造器）及 pkgList。一个 private native
  将会话身份与 Activity 栈快照写入临时 Java 数组，由 Java 组装结果；无 C++ 影子状态。
  pid 与 Process/Context 权限查询共用常量 1，uid 来自 application_uid，processName
  取 application_process_name（空时取包名），pkgList 仅当前包。
- 有 Activity 记录置 FLAG_HAS_ACTIVITIES；栈顶未 stopped（含 onCreate/onStart）为 100，
  否则任一 visible 为 200，其余为 400；单一 cached 后台 lru=1，其他为 0。
  trim/reason 字段为无 trim/REASON_UNKNOWN，无来源 pid/component。仅本进程、不枚举宿主；
  删除原 nativeUnsupported 拒绝边界。本节扩展上文历史范围，不引入 AMS/Binder。
- javac 被门面源文件遮蔽的嵌套类型使用组合入口的 compile-only 声明，D8 前删除；
  最终 BootDex 继续选择 ROM 类及构造器，固定 JNI 生成器未改。
- macOS Release `ogplay-cli` / `ogplay_tests` 构建通过；BootDex composition build/check、
  Android payload 及 capabilities check 通过。DVM228 定向 2 项/376 断言通过，覆盖
  switch/threaded、身份/字段、新 List/Info/包名数组、onCreate 回调中前台、stopped 后台、
  非栈顶可见与 GC 后快照。原内存测试显式清除 fixture 默认快照再验证缺事实失败。
- payload 校验发现既有 ICU JNI 两个源文件哈希过期；用固定 NDK r25c 重建，二进制
  SHA-256 未变，仅刷新 manifest 来源哈希。运行目录 BootDex/manifest/JNI 与源制品哈希一致。
- 原命令 `./ogplay-cli library run com.rockstar.gta3`（build/release）复现一次，
  已输出内存查询日志，原进程枚举 UOE 消失；下一首错为 onCreate → getLocalIpAddress →
  NetworkInterface.getNetworkInterfaces → getNetworkInterfacesList pc7 的 NPE
  `array-length on null`，退出 1，未修复。仅 reached-fault，未跑全量或九场景。
- 原生 getpid syscall 20 返回默认 AndroidProcessIdentity.process_id=1000，
  Java PID=1，已核对并记录，不在本任务调整。当前 ADR 文件无 ADR-0111 原文，未追加 ADR。
  证据：`.local/gta3-process-info/`（build/check/payload、Release、tests、run、pid-audit、result.json）。
