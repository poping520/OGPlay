# DVM-229 · 资源 Drawable 到 ImageView 的有界显示链

状态：有界实现及定向验证完成；原 APK 资源路径受后续尺寸回调停滞阻塞。

## 范围与依赖

Resources.getDrawable 复用 ARSC 引用/配置选择与原 APK 解码；普通图片返回实际
BitmapDrawable/BitmapPixels，颜色返回 ColorDrawable。ImageView 保活 Drawable，
实例 alpha 与共享解码输入分离，BitmapPixels 变更通过版本化投影进入原 UI raster。
依赖既有资源 resolver、Drawable owner-attached GC、ImageView scaleType/UiTree。
本轮不实现 XML Drawable/资源 NinePatch 对象，均明确失败；原 XML/背景链保持。
EGL config 故障单独取证，不通过资源改动绕过图形错误。

## 验收

- 图片/颜色、资源引用、实际 subtype/getBitmap/尺寸、独立 alpha、清空/替换、GC。
- BitmapPixels 修改后更新实际 UI 像素；复用既有图片 scale 与背景回归。
- 只构建 Windows Release ogplay/ogplay_tests，定向双解释器与原 APK 复现。
- EGL 记录 chooser/config identity/实际 ANGLE 支持后做直接回归及同路径复验。
