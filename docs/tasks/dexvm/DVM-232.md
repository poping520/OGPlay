## 实现边界

未处理 CPU stop 使用 A32GuestCallFault 保留不可恢复故障类型；进程在 Invoke 展开时
原子标记 native 状态不安全，后续 guest 调用/清理拒绝，Stop 跳过 DSO fini，仍回收
宿主线程、JNI attachment 和 monitor。普通 JNI/HLE 异常、宿主取消及 guest exit
保留原有类型，不按错误字符串判定状态，不把跳过析构冒充成功执行。

Stop 先进入 teardown 门，正常 DSO fini 与已有根清理共同使用不可续期 tick 预算和
Clock 计量的 2 秒累计墙钟预算；嵌套 scope/多个析构器不能重置。SVC/slice/返回检查
deadline，nanosleep 在实际睡眠前拒绝超出剩余预算的请求。超时保留失败，完成
host retirement/detach 后重新抛出；Stop 幂等，健康析构顺序及正常返回保持。
不声称任意 Java 回调/宿主库内部阻塞可被抢占。

CLI 首次运行故障立即记录 structured log，然后执行清理；记录失败不得替换原错。
清理错误独立报告，顶层仍输出原始首错。
