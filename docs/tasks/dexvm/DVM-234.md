# DVM-234 · 有界协作停止与解释器轮转

状态：有界实现及定向验收完成；完整游戏退出未闭合。日期：2026-10-10。
依赖：DVM-218、DVM-232。
决定见 [ADR-0113](../../adr/diagnostics.md#adr-0113)。

## 范围

先完成失焦、暂停与 Surface 退役握手，再进入不可逆 native 取消；保留
线程、图形和 guest monitor 的真实所有权。根回调使用不可续期的 Clock 墙钟
预算，覆盖 Java 指令、monitor/睡眠等待与 native 执行。字节码稳定安全点在
有竞争时公平让出 VM 执行锁，不改变 guest monitor、GC roots 或总 tick 预算。
超时按内部控制故障展开，保留首错并完成宿主回收，不伪造 guest 成功清理。
生产 root 绑定宿主，外部 GC 的 guest native 清理保留在队列；pacer 停止后继续
维护 driver blocked 事实，有界协作阶段保持 worker 定时等待的统一 Clock 补时。
未捕获异常处理器沿用原 worker context，并保活待分派的 throwable。

## 验收

- 双解释器的空转公平性、deadline、无期限 wait/睡眠与 monitor 所有权回归。
- 协作回调保留 worker/Surface，已有退出首错、CPU fault 与 fini 顺序回归。
- Windows Release 原 APK/沙盒副本菜单关窗，以及暂停恢复真实路径。
- 不默认全量测试；不实现新的 Android 系统服务或游戏专属分支。
