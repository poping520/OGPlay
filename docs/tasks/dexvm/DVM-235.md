# DVM-235 · 同进程 Activity 窗口与图形往返

状态：Windows 有界实现与原 APK 复现完成；跨平台及正式 title gate 待验收。
范围：单任务/单宿主窗口、不透明 Activity，原实例及其图形生命周期保留。
依据：本地 AOSP 4.4.4 ActivityThread、SurfaceView、GLSurfaceView、VideoView；
[ADR-0114](../../adr/runtime.md#adr-0114)。不引入 Binder/system_server 或完整窗口系统。

实施单元：
1. 每实例窗口可见性、内容树、命令 owner 与 GC 归属；普通返回/结果/finish 回归。
2. 按窗口派发 Surface，保留 holder/callback，两种 GL driver 暂停/恢复与 EGL 重建。
3. 实际 VideoView/FFmpeg 播放、完成/跳过后恢复同一原 Activity。
4. 重入/旧代回调/GC/退出与资源回收；原有独立退出首错如实保留。

验收：只构建受影响 windows-msvc 目标，定向 fixture 与原 APK 国王村路径；
正式 feature/title gate 按既有 Scenario 流程。跨平台与未覆盖窗口模式不声明验收。

完整研究记录在 `.local/wb-cg-analysis-20261010-145149/aosp-final-plan.md`。

## 交付与验证

- 每 Activity 独立内容 root、窗口可见性、焦点/命令归属；结果先于恢复，未 stop 的实例不重复 start。
- Surface 注册保持，创建/尺寸/销毁按窗口子树派发；后台附着不重新激活 Surface，销毁回调期间
  Surface 仍有效。固定 buffer 请求只支持真实托管尺寸，独立尺寸仍记账失败。
- intrinsic GL driver/队列/EGL 按 View 保留；暂停确认释放 Surface，Context 按 preserve 保留或重建；
  真正 detach/finish 结束所属线程。guest-owned GL 保留原 Java 调度。
- 补齐实际视频链依赖：主题 textAppearance、原版 BufferType、widget 构造、RelativeLayout
  双边约束与受审 API19 中文/标点字形；不删除字幕、不伪造 completion、不加游戏分支。
- `windows-msvc` Release 的 ogplay/ogplay_tests 构建通过；36 项/3004 断言定向回归、
  UI 模块 31 项/202 断言通过。BootDex build/check 与 Android payload 校验通过。
  日志 `.local/dvm235-final-{build.log,focused-tests.log,ui-tests.log}`。
- 原 APK/外部数据、沙盒副本、无 Profile/survey：
  - `.local/wb-cg-analysis-20261010-231301/`：CG 实际播放/中文字幕，自然完成后恢复 Surface
    与原游戏，进入角色操作/教学，guestFault=null。
  - `.local/wb-cg-analysis-20261010-232049/`：播放约 33 秒后点原视频跳过按钮，恢复章节实时场景，
    guestFault=null。
  - `.local/wb-cg-analysis-20261010-232641/`：最终二进制播放中 MCP shutdown，0.608 秒退出。
  三条路径均无 cleanup timeout/强杀，进程/listener 已退出；返回后关窗及播放中关窗仍因
  已知第二个 Game.onDestroy 的共享静态状态 NPE 退出 1，不声明 clean shutdown。

## 保留边界

native window callback、继续保留播放中的视频调用方、多窗口/透明窗口和复杂 task 不在支持范围。
实际 backend context loss、长时往返、完整影音同步、macOS/Linux 与正式 Scenario/title gate
未验收。先前故障驱动 finalizer 的 nanosleep 超时仅有取证，根因仍开放；正常路径未重现不能
代替其修复。字体只支持有界独立 BMP 字形，完整 shaping/bidi、补充平面和应用字体未实现。
