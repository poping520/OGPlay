# DVM-236 · Activity finish 与进程关闭分离

状态：Windows 有界实现与原 APK 路径验证完成。依据：[ADR-0115](../../adr/runtime.md#adr-0115)。

宿主 close/shutdown 只在原预算内协作暂停/停止前台，不合成全栈 onDestroy。
普通 Activity.finish 仍按实例销毁并恢复调用方，Java 异常真实传播。
进程关闭禁止模块卸载式 DSO fini；底层 permitted finalization 保持执行和失败传播。
退出事实优先于关闭原因；发布后不调用 guest cleanup。自进程 kill 经统一 VM Exit 中止 Java。
owner 在取消并 join guest worker 后退役媒体/图形资源，首错、预算与幂等保持。

验证：双解释器多实例/finish/退出事实及旧清理回归，windows-msvc Release；
原 APK CG 点击、自然完成/跳过与播放中关闭。未复现的点击故障不判为已修复。
跨平台与完整游戏/title gate 不在本单验收范围。
