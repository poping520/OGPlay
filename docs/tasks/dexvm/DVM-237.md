# DVM-237 · JNI / NativeActivity 共用 NDK APK Asset

状态：macOS 有界实现与定向验证完成，游戏路径仅 reached-fault。
依赖：sealed libandroid、JNI/DexVM 唯一身份、APK 区间校验与 VFS。
决策：[ADR-0131](../../adr/runtime.md#adr-0131)。

本单闭合 API19 `AAssetManager_fromJava/open`、`AAsset_read/seek/getLength/
getRemainingLength/close` 与 `AAsset_openFileDescriptor`；普通 JNI 与 NativeActivity
共用 manager 身份，Java openFd/raw-resource FD 共用受检 STORED 范围。
不引入原版 libandroid/framework、系统服务或游戏专属配置。

STORED 条目仅验证并保留封存 backing，不整条目物化；FD 指向完整只读 guest APK，
携带物理 start/length。压缩条目可有界读取但不能提供直接 FD；AAsset 独立游标、
GC 不自动保活 Java manager，现存 Asset/FD 的来源不随 manager 退役消失。
manager/Asset 句柄单调分配、数量受限；进程停止线程后撤销 hooks 并回收注册。

验收：真实 ARM/JNI、重复与不同 manager、GC/错误引用/pending、NativeActivity
身份一致、STORED FD→lseek/read/close、大逻辑资源的小窗口读取、压缩 FD 拒绝、
失效句柄与退出，以及原 APK reached-fault。跨平台/title gate 不在本单验收范围。

目录、64 位导出、getBuffer、Java AssetManager close/addAssetPath 及压缩流性能扩展
留待真实调用；不能以导出数量宣称完整 NDK AssetManager。

证据目录：`.local/ndk-assets-fix-20261011/`。
