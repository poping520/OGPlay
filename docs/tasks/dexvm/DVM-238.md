# DVM-238 · GLES OES / core 共用 buffer mapping

状态：macOS 有界实现与定向验证完成，原 APK 已越过库重定位。
依赖：API19 sealed GLES catalog、ANGLE、EGL share group 与 guest 地址空间。
决策：[ADR-0117](../../adr/runtime.md#adr-0117)。

新增 GLES2 extension subset 配方，发布 OES map/unmap/get-pointer 三入口，保持 core
目录不变。GLES1 OES 与 GLES3 range/flush/query/unmap 迁入共用映射服务；两种 library
导出、dlsym 与 eglGetProcAddress 返回 guest callable，映射指针只指向 guest arena。

映射按 share group+buffer 名称保存，删除/重分配/最后 Context 退役清除旧身份；
每次操作校验真实 native mapped 状态与指针。arena 空间统一受界并可回收。
WRITE-only 未 invalidate 时保存旧字节，宿主内部读取须合法；guest 权限/query 保持
原请求。显式 flush 只提交指定范围，unmap 不覆盖已刷新内容；GLES1 buffer 缓存经
显式回调同步，GL error 与坏 guest 指针分别处理。

验收：配方/header/current 校验，真实 ARM GLES2 OES map 写入/查询/解除，跨 GLES1/2/3
身份与读回、partial write、explicit flush、错误/预算、同名 buffer 的 share-group 隔离，
已有 GLES1/core 回归，以及无 Profile/survey 原 APK reached-fault。
EXT range 新导出、内存脏区优化、跨平台/title gate 不纳入本单。

证据：`.local/gles-mapbuffer-fix-20261011/`。

## 验证结果（2026-10-11）

- Release ogplay/ogplay_tests 构建通过。12 项、919 断言定向回归通过，包括 OES 三入口
  metadata、ES2/ES3 ARM 映射、跨 API pointer/unmap、partial write、explicit flush、
  UNSYNCHRONIZED 的合法 flags 与保存内容、预算失败、删除、共享/隔离 Context 与最后
  owner 退役；复用既有 GLES1/core/ANGLE 回归。无全量测试。
- 五个 GLES catalog/header/current 检查、generator self-test 与 boundary_hot_path
  通过；core 142/104/145 的身份保持，新 OES subset 单独发布。现有两处 GLES3 arena
  地址断言更新为共用 arena 边界，GLES1 直接绑定测试补入服务依赖。
- 无 Profile/survey、原 APK、一帧上限：glMapBufferOES/glUnmapBufferOES 重定位首错
  消失，libUnrealEngine3.so 初始化/JNI_OnLoad 各一次，进入 onCreate 后缺
  `android.os.Debug$MemoryInfo`，退出 1；进程已退出。这不是游戏 mapping/首帧/title gate 验收。
- Windows/Linux、游戏实际绘制与长时映射、原生 context-loss、EXT range 新导出及
  脏区优化未验收；必要的 UNSYNCHRONIZED 预取不作无等待性能结论。
