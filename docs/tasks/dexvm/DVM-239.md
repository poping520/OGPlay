# DVM-239 · API19 Debug 进程内存查询

状态：已完成有界能力与 reached-fault 验证。依赖：BootDex 原版 MemoryInfo、VM 堆账本与 guest 私有 RAM。
决策：[ADR-0118](../../adr/runtime.md#adr-0118)。

范围：原版 Debug.MemoryInfo 与 Creator；Debug.getMemoryInfo(MemoryInfo) 的当前
进程 Java/JNI 边界。普通字段、构造、汇总、标签与 Parcel 来自原版 Java。
受检注入快照或显式虚拟私有提交模型，KiB 单位；系统 availMem 与进程统计分开。
数据/数组先校验再提交，缺事实记账抛 UOE，空参数 NPE。

虚拟模型基于 VM 当前堆账本和 AddressSpace 已提交 guest RAM，未分类 ARM 页归
other/unknown，不把整个宿主 RSS、未映射的地址预留、GPU/媒体缓存算进来。
nativePss=0 表示未单独分类；native 分配的总占用仍包含在 other。无 guest 交换或
跨进程共享，清洁/共享/swappable/swapped 分类为已知缺席；不声称 Android 内核实测 PSS。

验收：原版构造/求和/Parcel、非零与重复快照、缺事实/非法数据/空参数、两种解释器、
真实 ARM JNI、默认模型的分配/释放变化，以及原 APK reached-fault。
PID 重载、getPss/native heap API、宿主物理驻留与全面分类不在本单范围。
