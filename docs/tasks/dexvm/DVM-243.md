# DVM-243 · 原版 StatFs 与沙盒卷统计

状态：有界能力/首错验证完成。决策：[ADR-0122](../../adr/runtime.md#adr-0122)。

范围：原版 API19 StatFs，Posix.statvfs → IoRuntime/IoFileSystem → VFS 原子查询，
复用已选入的 StructStatVfs 原构造。统计只支持 attached sandbox writable namespace 及其非根目录祖先（/data 等），
规范路径/别名/存在性与既有 VFS 相同；未知卷/无后端记账明确失败，不使用宿主磁盘采样。

显式模型：4096 字节报告块，字节总量取沙盒 quota、已用取 persisted+dirty delta，
块数向下取整；无 reserved blocks，因此 free=available。元数据预算为 configured
maximum_files，统计持久非 tombstone 项与新 dirty 文件；只读 base 内容不计写预算。
fsid 来源安装身份，所有 writable roots 共用；无配置 mount flags，namemax 为既有
encoded backing name 上限，转义/临时文件/tombstone 开销可能提前拒绝名称。
这是 guest overlay 写配额统计，不是完整物理文件系统；内存预算和宿主 IO 错误仍独立。

删除旧 StatFs 普通方法替身与 external_free_bytes 宿主剩余空间来源。
Java 保留原版快照、刷新失败不覆盖、errno 转 IAE、long/旧 int 转换及字节算法。
fstatvfs/原生 statfs、未支持卷和宿主实际磁盘容量不在本单范围。

验收：VFS 路径/别名/卷身份、dirty/flush/truncate/delete 与元数据预算；原版 Java
构造/restat/快照/异常及大数；双解释器和 ARM JNI，BootDex/载荷校验，原 APK reached-fault。
证据：`.local/statfs-fix-20261011/`。

结果：Release 仅构建 ogplay/ogplay_tests；BootDex build/check 与载荷校验通过。
VFS dirty/flush/truncate/delete、别名/安装身份/目录祖先、metadata 预算、缺路径/未知卷；
双解释器原版 StatFs 构造/restat/失败保留旧值/GC、大数和旧 int 截断；真实 ARM JNI
snapshot/刷新，以及既有 append dirty quota/rename/rmdir 回归，共 6 用例/192 断言通过。
UTF-8/TOML/链接/diff 静态检查通过。

原版迁移使 SQLiteGlobal 的 StatFs("/data") 真正查询，因此补齐同一沙盒目录祖先
视图作为本单必要依赖，不改变写权限。最终原 APK 无 Profile/无 survey 越过空间查询，
PostStartup 下一首错为 BitmapFactory.decodeResource(Resources,int)，dex_pc=209，
resid=0x7f020049。崩溃报告的 LocaleData 初始化失败仍是独立取证项。
进程已退出；仍为 f=0 reached-fault，首帧、跨平台和完整 title gate 未验收。
