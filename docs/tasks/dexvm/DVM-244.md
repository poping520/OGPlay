# DVM-244 · 资源位图解码

状态：有界能力/首错验证完成。决策：[ADR-0123](../../adr/runtime.md#adr-0123)。

范围：有界 BitmapFactory Java 客户端与原版 Options；两/三参 decodeResource、
decodeResourceStream、decodeStream 和 byte-array 重载，共用 private native 解码。
Resources.openRawResource(int,TypedValue) 共用 ARSC 选择/引用，填文件与选中密度；
密度来自 ARSC/DisplayMetrics，非 JPEG DPI。resource 自有 stream finally close，
调用方 stream 不关闭；已知失败 null，未实现 Options 记账 UOE。

ARGB8888、bounds、密度缩放（半像素 bilinear/预乘颜色插值）、inMutable，原 Options
取消标志；普通 Bitmap 共用 BitmapPixels/GC/NDK/UI，查询创建独立存储。编码输入
≤16 MiB、宽高≤8192、像素≤16 Mi；预检/缩放输出先验预算，超预算 OOME。
其他 config、reuse、sample>1、purge/dither/quality、资源 NinePatch 明确未实现。
get/setDensity 与解码结果 mutability 保持相应 Bitmap 状态；不引入完整 Skia。

验收：双解释器资源引用/密度/nodpi/缺资源、bounds/options/取消/坏输入、独立像素/
流所有权/GC、边界预算及滤波；ARM JNI；BootDex/载荷校验；原 APK reached-fault。
证据：`.local/bitmap-resource-fix-20261011/`。

结果：Release 仅构建 ogplay/ogplay_tests；BootDex build/check 与载荷校验通过。
builder Java inventory 改动要求 guest JNI 生成记录一致，本地 NDK r25c 重建/确定性
校验通过。双解释器 DVM-244 资源/引用/density/nodpi/bounds/选项拒绝/取消、可变性/
独立像素、stream 所有权、坏输入/预算/滤波，以及真实 ARM JNI；复用 Bitmap.Config
与 NDK 像素/GC/recycle 回归，共 5 用例/486 断言通过。UTF-8/TOML/链接/diff 检查通过。

原 APK 无 Profile/无 survey 通过启动 JPEG 解码（下一调用实参为非空 Bitmap），
