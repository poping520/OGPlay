# DVM-245 · 稳定窗口内容容器

状态：有界实现与定向验证完成。决策：[ADR-0124](../../adr/runtime.md#adr-0124)。

范围：每 Activity/Window 的真实 FrameLayout 内容容器；Activity/Window 的 setContentView
重载和 addContentView 共用替换/追加链，android.R.id.content、真实父节点及内容回调。
复用唯一 UiTree、LayoutParams、Surface、GC 和每实例窗口可见性；不引入 PhoneWindow
主题/ActionBar、Binder、透明窗口或完整 Android 窗口系统。

依赖：DVM-119 参数、DVM-230 尺寸遍历、DVM-235 每实例窗口与 DVM-236 退出协议。
content_view 保留首个内容 View 的兼容投影；窗口 root 才是全部内容遍历的边界。
布局/XML 替换仅清理容器子树，追加不退役已有 Surface；回调重入检查内容代次。

验收：双解释器替换/追加/ID/父节点/参数/叠层、Surface 身份与顺序、GC、异常/重入；
复用 Activity 往返/延迟内容、XML 与深层触摸回归；真实 ARM JNI；原 APK reached-fault。
只构建受影响 Release 目标，不运行全量测试。首帧/跨平台/title gate 独立记录。

## 验证结果

macOS Release 仅构建 ogplay/ogplay_tests。双解释器和真实 ARM JNI 的容器身份、
参数、窗口隔离、叠层像素、parent/移除/替换、GC、内容异常与重入、Surface 身份及
destroyed 重入、scoped merge/XML 失败清理通过；复用参数、深层触摸、XML、尺寸派发、
Activity result/窗口往返/延迟内容和焦点回归，以及无首内容投影的直接 addView Surface
遍历，共 25 用例/1863 断言通过。
复用断言对齐保留 View 几何及已交付 DVM-236 的 Stop 不合成 onDestroy 契约。
BootDex 未改；证据 `.local/window-content-fix-20261011/`。

原 APK/同沙盒、无 Profile/survey、--exit-after-frames 1 已越过 addContentView。
最终二进制日志推进 f=32，presented=1、Surface 正常 destroyed，退出 0，无运行期
致命首错；见 game-final.log。前置二进制复现推进 f=25，预算退出时报 unknown guest
thread id（teardown.guest_finalize），退出 1，并有 SDK 捕获的 resolveService flags
未支持；见 game.log。此前 DVM-244 已记录清理缺口，本轮未修改其机制，不因最终
一次未复现就宣称已消除。未核验游戏画面/交互、跨平台、长时退出及 title gate；
不将推进帧号/单帧发布视为完整游戏兼容验收。
