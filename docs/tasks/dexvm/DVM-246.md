# DVM-246 · 托管 Dialog 与有界模态提示

状态：有界能力及定向验证完成；原 APK 点击退出仍被独立视频依赖阻断。
决策：[ADR-0125](../../adr/runtime.md#adr-0125)。

范围：服务缺席查询接受 GET_RESOLVED_FILTER；Activity 托管 Dialog 的 API19 创建/
缓存/准备/移除协议，以及 Dialog/AlertDialog 普通状态、标题/消息/三按钮/监听器。
guest Java 管理协议，native 仅投影可见模态 UiTree、输入和 owner 窗口归属。
禁止伪造外部服务或授权；未知查询/对话框配置明确失败。

支持单宿主窗口的普通文本提示；复用 Clock、Looper、Surface、UiTree 和 SDL。
模态捕获输入、窗口焦点与 Activity 可见性分离，不替换游戏内容或重建原 Surface。
任意主题/custom view/items、DialogFragment、系统窗口/远程服务不在本轮范围。

验收：双解释器缓存/参数/回调/异常/重入、按钮/取消/键盘/GC、实际像素与模态输入、
Surface 保持/窗口往返/退出、ARM JNI；BootDex build/check/载荷；原 APK 超过 f=46 的
真实提示、截图与点击行为。本轮只构建受影响目标、运行定向验证，不跑全量测试。

## 实际结果（macOS）

- Release 仅构建 ogplay/ogplay_tests；BootDex build/check、NDK r25c guest JNI 确定性
  重建及 Android payload 校验通过。双解释器 managed cache/Bundle/异常/GC、三按钮
  协议、取消/关闭区别、键盘与模态输入、回调队列/显示代次，以及实际像素/平面缓存、
  ARM JNI/Surface/焦点/窗口往返和相邻回归，共 22 用例/1864 断言通过。
- 原 APK、同沙盒、无 Profile/survey，MCP 手动步进到 f=120，guestFault=null，真实
  截图已显示 Amazon Appstore required。服务返回已知缺席，SDK 报 COMMAND_SERVICE_NOT_INSTALLED，
  不再因合法 flags=64 触发兼容层异常，也不再缺 Activity.showDialog。
- 点击取证推进时遇到 JNI MotionEvent.AXIS_X(I) 静态常量缺声明；为完成当前输入路径，
  从固定 API19 补齐已有 64-axis snapshot 对应的符号常量，真实 ARM JNI 检查 X/Y/generic。
  重跑到 f=160、guestFault=null、presented=2，再次取得真实提示图。
- MCP 点击 OK 并步进后，主线程原应用的视频 Runnable 首错是 getLayoutInflater()，
  dex_pc=12。并非 Dialog/按钮调用栈；原 APK 的按钮→应用退出未验收，不扩大本次范围
  到 LayoutInflater/开场视频。已通过 MCP shutdown 收尾，故障进程退出 1，listener 已关闭。
  正常提示的交互协议有定向与 JNI 证据，但跨平台、长时退出、完整 title gate 未验收。
