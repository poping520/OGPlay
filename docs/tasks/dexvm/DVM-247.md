支持 Activity/Window/LayoutInflater.from 的一致 Context 服务身份、cloneInContext、
resource inflate 重载与 detached/append/merge 协议。复用现有 AXML/include/样式/注册

系统服务。失败仅退役本次新建节点，已执行回调不回滚。

规则、merge/异常/局部清理、onFinishInflate 次序，以及已有内容/Surface 定向回归；
BootDex build/check 与载荷校验。原 APK 同路径无 Profile/survey reached-fault 一次，
记录原错消失与下一首错；结束前关闭所有 OGPlay 进程。不作完整 title gate 结论。
