# DVM-248 · 有界 Surface 层序与窗口开孔

状态：有界能力及定向验证完成；原首错已消失。决策：[ADR-0127](../../adr/runtime.md#adr-0127)。

UiTree 唯一保存普通媒体、媒体叠层及窗口上层配置，两个公开 setter 后调用覆盖前调用。
按绘制顺序为实际视频输出开孔，保留后绘制的普通控件与模态层；不引入 WMS 或
SurfaceFlinger。复用现有 bounds/clip/visibility 和最终 frame handoff。

验收：双解释器 setter 覆盖、跨实例隔离；普通层/媒体叠层/窗口上层像素顺序，
黑背景、上层文字、裁剪、隐藏与退役，原有 VideoView/模态合成回归。

依赖：DVM-249 提供普通 MediaPlayer 的 Surface 视频 producer。

## 实际结果（Windows）

- 双解释器验证两个 setter 的覆盖与实例隔离，媒体叠层优先于普通媒体，普通 UI
  在视频上方、onTop 在普通 UI 上方。黑背景开孔、后绘制控件、祖先裁剪、隐藏及
  最终透明证书通过。不是任意透明 Surface 或完整 WMS/多 GLES 层支持。
- 与 DVM-249 合计新增 8 用例/3342 断言通过；视频/UI/合成定向回归 56 用例/1986
  断言通过。扩展相邻检查 29 用例中 27 通过，两项旧 EGL 回归仍失败：全局策略
  投影断言及未创建 GLThread 的 queueEvent；不在本轮修改这些测试或实现。
- 最终 Release 原 APK、无 Profile/survey：f=160 guestFault=null，presented=2；再推进
  视频任务时，同一 Runnable 已越过 setZOrderMediaOverlay，首错为
  TextView.bringToFront()V，dex_pc=226。实际商店缺席提示已核验，完整视频未触达。
  MCP shutdown 后退出 1（运行首错保留），进程及 listener 已关闭；本次未出现
  unknown guest thread id，不声明该历史退出问题已修复。
