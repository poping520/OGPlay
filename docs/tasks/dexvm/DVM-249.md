# DVM-249 · 普通 MediaPlayer 本地视频输出

状态：有界能力及定向验证完成；完整游戏视频未验收。决策：[ADR-0127](../../adr/runtime.md#adr-0127)。

普通 MediaPlayer 通过受检 Surface 绑定到 UiTree；本地 FD/路径来源复用已捕获区间，
视频复用 VideoView 的 decoder/Clock/PCM/合成底座，不新建独立播放器或系统服务。
原版 Java 保留监听器、Handler 与公开协议。支持真实尺寸、prepared/size/error/completion、
循环、暂停/seek/stop/reset/release，销毁 Surface 后撤销绑定，重新 setDisplay 才恢复。
现有纯音频路径保持。外部商店、授权、网络和 DRM 不在范围内。

验收：双解释器普通 MediaPlayer、FD 关闭后区间存活、事件身份及重入释放、循环/seek、
Surface 退役与重绑、GC/退出；真实 FFmpeg 本地制品。Windows 仅构建受影响目标；
原 APK 无 Profile/survey 同路径 reached-fault 一次，记录原错消失及下一首错。

## 实际结果（Windows）

- 普通 MediaPlayer 与 VideoView 共享视频状态、来源工厂、Clock、PCM 与 frame handoff。
  prepare 优先已有音频后端，失败后启用视频工厂；来源沿用 64 MiB 上限，共享八个
  视频实例。已被音频后端接受的混合容器不再探测视频，不声明完整格式兼容。
- 双解释器验证同步/异步准备、尺寸事件及 player 身份、prepared 回调释放、循环/
  暂停/seek/音量/静音、FD 关闭后的精确区间、Surface 销毁/显式重绑、暂停位置重绘、
  同绑定幂等、双 producer/失效 Surface 拒绝、无输出不发布画面、GC 和 owner 关闭。
  真实 FFmpeg MP4 制品提供非零尺寸、画面及 PCM。无网络或授权成功桩。
- 真实 AndroidAppProcess 双解释器回归确认仅有 MediaPlayer、没有 AudioTrack 时
  lifecycle 仍泵送异步 prepare/事件；关闭后 decoder/source 表为空。
- 新增与共享回归结果见 DVM-248；MediaPlayer/stream 音频定向 5 用例/327 断言通过。
  更宽的 AudioTrack 整文件检查曾停滞并被停止，未完成；不以本次定向结果替代该检查。
- Windows Release 仅构建 ogplay/ogplay_tests；没有修改 BootDex/guest JNI 来源，
  不重建载荷。原 APK 尚在 Surface 回调交付前被 bringToFront 缺口阻断，不能将制品
  解码成功当作真实游戏视频验收。完整影音同步、无缝循环和跨平台未验收。
