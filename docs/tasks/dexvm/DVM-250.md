# DVM-250 · 同包 Activity task 与实例复用

状态：有界完成。依赖 DVM-223/235、Surface owner 生命周期。
决策：[ADR-0132](../../adr/runtime.md#adr-0132)。

范围：sealed 当前 APK、默认 task affinity、单前台窗口、有界进程内 task。
standard 在所属 task 新建，singleTop 复用所属 task 顶部匹配实例；singleTask
复用匹配实例并结束该 task 中其上方实例；singleInstance 独占 task。
从 singleInstance 启动其他组件时离开其 task，task 前台切换保留对象、窗口与 renderer。
复用交付 Intent 副本及 onNewIntent，不自动 setIntent；支持 finish 后返回原实例。
不引入完整 ActivityManager/Binder/system_server。实际需要自定义 affinity 匹配、复杂
flags/options、跨包、跨 task/复用实例的 for-result 请求仍显式失败；普通同 task
启动不使用 affinity，保持既有行为。最多 32 个 live Activity。

验收：双解释器首次创建/复用/clear-top、task 身份、Intent 生命周期、GC、返回与现有
standard/for-result、GL/Surface/视频所有权回归；原 APK 安装器跳转复现并记录下一首错。
不把 reached-fault 验证当作正式 title gate 或全关卡兼容。

验证（2026-10-13）：macOS Release 受影响目标构建及双解释器定向通过；含
首次创建/复用、singleTop 非栈顶新建、同 task clear-top、singleInstance 独占/返回、
Intent 副本/不自动 setIntent、finishing 排除、GC、affinity 继承及旧结果/GL/Surface/metadata。
原 APK/既有 Profile/外部数据、沙盒副本完成安装器→主游戏→开场视频→原游戏恢复，
呈现 240 帧、退出 0；原 launchMode 首错消失，未遇到新的致命首错。
证据 `.local/activity-task-fix-20261013/`；跨平台/正式 title gate/全关卡未验收。
