# DVM-251 · 默认逻辑尺寸下 nativeRender 空指针首错

状态：待办，2026-10-19。前置：[VFS-09](../vfs/VFS-09.md)。

目标：以通用布局/图形/生命周期证据定位 nativeRender 在 800×480 下的空指针。
不恢复 Profile，不增加 runtime 字段，不改默认尺寸或增加尺寸/标题特判。

## 已有证据与复现

macOS Release CLI，原 Dungeon Hunter P1000 APK，profile=none，外部 data/ 挂在
/sdcard/gameloft/games/DungeonHunter，新的持久沙盒、默认 800×480：
安装器和 PyData 加载已经越过，开场 Logo 视频有实际帧，返回游戏后 f=661 失败。
原用户记录 f=635；墙钟驱动视频导致逻辑帧号有变化，不将具体帧号作为稳定判据。

稳定故障：nativeRender，pc=0x30885b08、Thumb，read unmapped addr=0，
r0/r1/r3=0、r2=0x30950200、lr=0x30885afd。退出码 1。
显式用户尺寸 1024×600 的 CLI 900 呈现帧退出 0，GUI 同样可继续；只是对照证据。

命令与完整日志、截图见 `.local/dh-generic-fix-20261019/cli800/`，对照 cli1024/。

## 后续验收

先复现同一故障路径，比较两种逻辑尺寸进入 nativeRender 前的 guest 返回值、布局、
Surface 与资源状态；定位通用契约缺口后再决定修复与直接回归。
验收需默认尺寸原路径不再触发该空指针，记录下一首错；不以调大分辨率通过替代。
