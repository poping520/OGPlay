# DVM-252 · WU2a API19 表面决策与纯形状配方

状态：WU2a 完成，2026-10-20；ADR-0147 Proposed，WU2b 待批准。

## 依赖与范围

- 前置 DIAG-4/WU1 已独立提交 `20d9dc68`；依赖 dump-surface、题库扫描与原回测。
- 固定 ROM 四 JAR、既有 intrinsic/BootDex 与 overlay 归属、现有 smali/baksmali 工具链。
- 修正扫描器 ROM 来源判定；APK 子类继承的 ROM 成员按声明类归并，保留 symbolic_owner。
- ADR-0147 只决定生成形状、按需行为及失败语义；不实施骨架合并、字段状态或 JNI 修改。
- 配方只选已被题库引用的纯接口、注解、常量 final 类；本批保守限定 encoded 常量及空 clinit，
  不接受构造器、行为字节码、枚举；所有依赖须在当前可链接 BootDex/intrinsic 中满足。
- 首先输出候选/冲突/依赖报告，明确 --apply 后才更新配方；跳过 runtime 与既有 intrinsic 策略归属。

## 验收

- 扫描器自测覆盖 support/androidx/google 不冒充 ROM，以及 APK 子类继承 ROM 的正确归并。
- 32 APK 修正前后及配方前后逐项统计，原 WU1 回测不覆盖；所有大制品存本地。
- 选择器自测与来源/闭包/冲突报告；BootDex build、check、validate_android_payload。
- 仅复用已有 CLI 加载新数据，不重编译 C++，不跑全量测试。
- 执行一次 library run com.amazon.games.tilmorningslight，记录真实首错及验证边界。

## 结果

- 32/32 APK 扫描完整：API19 去重缺口由 14,908 修正为 12,208，至少 3 APK 为 4,296→3,868。
  APK 子类的真实继承依赖归并到 ROM 声明类；不靠删除所有库引用降低缺口数。
- 选择报告：666 个缺失纯形状候选，187 个已有归属冲突；49 个被引用且依赖满足的类加入配方，
  包括 43 个接口、6 个注解；成品 DEX 检查无 executable 方法/实例字段，含 176 个常量字段。
  已有 date-family 策略声明 intrinsic 所有的 6 个注解也跳过，不改其归属或审计预期。
- BootDex build/check、validate_android_payload 均通过；1964→2013 类。
  复用既有 CLI 导出 2278 类，无链接错误；只执行数据 staging，未重编译 C++。
- 配方后去重缺口为 12,015；class 840→802（−38），hierarchy 327→292（−35），
  合计 −73（6.3%），跨 APK 对应记录 6630→6103（−527）；不能解释为运行首错减少。
- scanner、选择器自测和 capabilities check 通过；未跑全量测试，未修改 src/运行时语义。
- 按要求单次执行 `ogplay-cli library run com.amazon.games.tilmorningslight`，到达标题画面；
  MCP 点击 Touch To Begin 后退出 1，首错仍是 JNI `Context.DISPLAY_SERVICE` 未声明。
  仅临时启用 MCP，结束恢复原有效设置；非正式场景/全交互验收，无新增首错回归证据。
- 证据目录 `.local/analysis/preflight/wu2a/`：REPORT.md、分类修正/配方后完整清单、
  shapes.json、构建/check/payload 日志、表面、截图、点击及运行日志；保留原 WU1 回测。
- 纯形状选择有意保守：非空常量 clinit、含构造器的 final 常量类和依赖未满足项仍跳过。
  JNI 字符串启发式、公开/保护参考成员、不可达引用等扫描边界沿用 DIAG-4。
