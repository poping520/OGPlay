# DVM-253 · WU2b-1 API19 骨架生成与 Java 懒合并

状态：WU2b-1 完成（JNI/反射与正式场景留 WU2b-2）；依赖 DVM-252（独立提交 ac7db922）、Accepted ADR-0147/0028/0030。

## 验收边界

- 固定四 ROM SHA256，完整 own-member（含非公开/@hide）确定性索引数据及 check/self-test。
- 仅首次解析物化类型；现有类的成员在首次链接前补缺，既有类/成员/handler/字段所有权优先。
- 方法/构造器未实现，非恒定 static/实例字段访问记账失败；常量提供真实值。
- 不执行生成的 clinit：它只是未实现的声明；常量独立物化，非恒定状态仍拒绝访问。
- survey 仍按原路径收割/中性返回，不改变 JNI/反射查找与 NoSuch 异常路径。
- 定向测试懒加载、身份/层次/own-member/优先级、常量、方法/字段失败及关闭即失败。
- baseline 与 after 同参数单次首帧采样/RSS、dump-surface 与32 APK扫描，记录噪声/行为边界。
- 最后 TML library 原路径一次 reached-fault；不做场景回归或独立缺口修复。

基线：.local/analysis/wu2b/baseline；新进程/临时沙盒，OS文件缓存未清，MCP 100ms采样。
TML 3.902s/3659333632B；PVZ 3.031s/937312256B，表面2278类；单样本不代表统计显著变化。
既有文档未提供这两项的固定启动/RSS预算；以基线差异报告，显著回退停止并说明。

## 实现说明与阶段证据

- 原始字节/索引驻留，按类解析 JSON；没有创建全表面运行时类或方法对象的启动循环。
  显式 dump-surface 是诊断例外。索引封装 9,252 类、86,686 方法、58,700 字段，
  32,204 个静态常量；二进制 8,164,184 字节（7.79 MiB），SHA/来源见同名 JSON manifest。
- 既有类的继承 handler 也保留；全新骨架 own 重写不借用父行为，调用仍为未实现。
  元数据 override 校验读取 ROM 父声明原始标志，不改已有手写 final/可见性事实，
  不放宽应用 override 校验；NullVibrator/cancel 与应用 final-host 对照受测。
- 字符串常量保留 UTF-16，包括补充字符；数值按原始位存储。生成器排除 clinit sput 目标。
- 定向导出 1/11；新骨架 6/95（双后端、constructor/override/field 失败与记账、Java loader、
  不物化 findLoadedClass、优先级及关闭对照）；现有 loader 11/882；工具 CTest 2/2 通过。
- 额外执行旧 gap_survey_tests：1/4 通过；3 条在未装配骨架的原夹具 RegisterBootDex 阶段
  因 Activity.nativeFinish 未绑定失败，尚未进入新逻辑。保留证据，不顺带修既有夹具。
  本任务专门的 survey 方法/类中性路径回归通过，不将原夹具错误掩盖为绿灯。
- 导出 9,362 类（含既有 ROM 外类）；3 个 android.test 类型依赖四 JAR 外的 JUnit，
  保留链接失败，不生成缺失依赖桩。没有修改 JNI/反射成员查找或 NoSuch 路径。
- Java loadClass 接入后及 own override 复核后重新构建并复测，早期性能样本分别保留；
  与扫描并行的样本单列，最终对比在题库扫描结束后串行测量，不按数值挑选样本。

## 最终结果

- 32/32 APK 完整复扫：去重 API19 缺失 12,015→118（−99.0%）；
  declared-unimplemented 64→9,000。原缺失成员中 8,639 项转为明确未实现，
  2,164 项不再报告，另 1,094 个 class/hierarchy 项消失；不等价于新增行为支持。
- 118 个余项：116 个因手写层次不重写而缺失的继承成员，另2个属于依赖 JUnit 的
  AndroidTestCase（构造器/getContext）；没有按扫描结果顺手改类库行为。
- 最终串行性能在 after-idle/：TML 首帧 3.902→3.862s（−1.0%），
  RSS峰值 3489.8→3532.2MiB（+1.2%）；PVZ 3.031→3.168s（+4.5%），
  RSS 893.9→928.1MiB（+3.8%）。没有既定数值预算；单次/有文件缓存/采样误差，
  不宣称统计显著或通过正式性能门禁。MCP shutdown 仍可能报既有 unknown guest thread id，
  首帧之后的退出码不作为本次首帧成功指标；原始日志保留。
- 最终 library run 复核原持久实例到达标题画面，点击后首错为
  `MotionEvent$PointerCoords.<init>()V` 未实现，置 UnsatisfiedLinkError；随后 JNI
  NewLocalRef 因 pending exception 被阻断。没有修构造器或修改 JNI 查找/异常语义。
- 核对新增 JSON 字段状态、capabilities check、生成器 check、自测及差异/UTF-8 通过；
  没有跑全量测试或正式场景。证据 `.local/analysis/wu2b/REPORT.md` 与 verify.py。
