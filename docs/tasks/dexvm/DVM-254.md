# DVM-254 · WU2b-2 JNI 与反射表面语义

状态：实现及定向验证完成；游戏冒烟部分未验收（见下表）。依赖 DVM-253（21640a51）、Accepted ADR-0147 第5条。

## 边界与验收

- JNI 五种类/成员查找复用真实链接表面；缺失返回 NULL 并挂起对应 Java Error。
- 描述符/static 校验、无效参数错误及 pending-exception 门禁保持严格。
- 非恒定骨架字段的 JNI/反射访问与解释器共用失败/记账语义；常量保留真实值。
- 反射查找、枚举、修饰符及目标异常包装由现有反射通道验证。
- 现有 JNI/反射主题测试增加存在/缺失、static、构造器、字段、清除/门禁与关闭骨架对照。
- CURRENT 的9款游戏在相同沙盒快照、设置和交互下前后各一次 library run 冒烟；
  本地证据 .local/analysis/wu2b2/，无法到达的交互标记未验收，不等同正式 title gate。
- 出现探测分支回归即停止分析通用规则；不加游戏例外，不实现骨架行为，不修 survey 夹具。
- 只构建受影响目标、定向测试、能力账本 check；最后独立 TML library run 记录首错。

## 实现与定向验证

- 对照 AOSP 4.4 dalvik/vm/Jni.cpp 的 FindClass 与四种成员 ID 查找。
  GetMethodID/GetStaticMethodID 共用查找入口；FieldID 复用已有骨架，不批量捕获绑定错误。
- registry 增加锁外显式 resolver，被动 FindClass 保留；bridge 在执行锁内按需链接/发布。
  FindClass 在 resolver 前检查 pending 门禁；方法查找复用字段 owner 的类初始化回调。
- ThrowableFactory 发布真实 VM Throwable 与当前线程 local ref，保留 ThrowNew 元数据；
  ExceptionOccurred 可继续查询真实类身份；独立 JNI 保留原宿主异常表示。
- 解释器公开共享 RequireImplementedField：JNI owner 挂起 ULE 并以专用信号禁止侧表回落；
  各 ABI getter/setter 只返回带 pending 的异常哨兵。反射字段同守卫，未实现调用沿现有 ITE 包装。
- 新回归在既有 JNI/反射主题文件，真实固定 ROM 数据含关闭骨架对照；反射新增用例显式
  装配完整 Android catalog，满足 curated BootDex native 闭包，不改 gap_survey 夹具。
- ogplay-cli/ogplay_tests 受影响目标构建通过；DVM-254 + API19 skeleton：9/492；
  JNI 五个相关主题文件：59/1626（含前述2条，不将重叠计作独立总数）。
  两后端反射目标调用、构造器及 getCause/getTargetException、字段状态与记账均通过。
- capabilities check：413 项；生产数据/骨架方法行为、pending 白名单和 survey 夹具均未改。
