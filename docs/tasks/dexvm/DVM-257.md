# DVM-257 · WU7-6 guest ICU51 能力补齐

状态：有界交付完成；070 的 direct 共享数组与可选 charset codec 保留缺口。依赖 [WU7-H](../diagnostics/DIAG-7.md#wu7-h--run-dex-平台运行时装配2026-10-21)。

## 边界与验收

- 区域数据、NativeDecimalFormat double/digit-list、Pattern/Matcher、Charset.availableCharsets
  统一使用 guest ICU51 C ABI，不使用宿主 locale/ICU；普通 Java 协议优先使用 API19 BootDex。
- 092 依赖的 Normalizer/ISO3、070 direct buffer 的真实失败作为目标验收依赖处理。
- ICU 双后端回归；070/092/094/062 逐字节检查；全量零回归后更新基线。
- guest JNI 重复构建一致及 payload 校验；WB 新沙盒原路径一次，记录下一首错。
- 九个基础场景正常各一次，精确 fixture/显示配置沿用 WU5，对照最近记录；不冒充 title gate。
- 只构建受影响目标，按真实边界更新契约、能力与 CURRENT，提交 main。

## 实施与验证

- `ICU.initLocaleDataNative` 取消语言白名单，日期/数字模式、符号、星期与货币均读固定
  guest ICU51 区域资源及回退；不使用宿主 locale/ICU，默认值仍由生产 VM 配置注入。
- `NativeDecimalFormat` 的 double/digit-list 与既有 long 共用 ICU C formatter，逐字段恢复
  FieldPosition；clone/close/异常保持同一 token 协议。覆盖小数、无穷/NaN、精确大整数输出。
  BigDecimal 精确解析与具名时区历史仍未纳入，保持明确失败。
- API19 实际使用 Pattern/Matcher native（没有另造 NativePattern 类）。普通协议、异常、
  Splitter、Normalizer/Form 来自固定 BootDex；native 统一走 uregex/unorm C ABI，移除宿主
  std::regex。独立 UTF16 input 副本及逻辑 token 避免保存 Java 字符指针，GC/退出回收。
  ICU51 C `uregex_open` 拒绝显式零长度；空模式使用零终止长度 -1，仍支持空匹配进展。
- Charset.availableCharsets 从 guest ICU provider 名称表筛出运行时确实支持的六种标准编码，
  返回不区分大小写且不可变的 SortedMap；不虚报未接通转换协议的可选 ICU codec。
- 070 修复 byte/short 读回的符号扩展，char 保持无符号；direct arena 与共享 byte[] 尚未打通，
  因而 hasArray 继续诚实返回 false，不用常量伪造与 Dalvik 的共享数组能力一致。
- 字符集 provider 的 ICU 私有名称（含逗号选项）不属于 Java 合法名称，枚举筛选时跳过，
  普通 Charset.forName 的非法名称异常行为不变。
- 最终 guest JNI 按 WU7-2 两次干净构建逐字节一致；manifest 纳入 regex_jni.c 与 ABI 头哈希。
  BootDex 配方审计同步实际闭包，不扩大 native 准入，未登记 native 保留 explicit_failure。
  `build_bootdex.py audit/check` 与 `validate_android_payload.py --root data/android/19` 通过。

### 正常场景与退出依赖

首轮九场景 `.local/analysis/wu7-6/scenarios-summary.json` 的 checkpoint 全部通过，
overall 4/9（原 6/9）；原有 Tales/DT/PVZ 退出失败不变，TML 的 unknown guest thread id
与 WB 的 active chars 暴露退出路径缺口，因此不把首轮作为零退步验收。
为满足本单九场景零退步要求，补两项通用依赖：

- 进程 quiesce 依据 clone runtime 的真实 spawn 所有权筛选 child，不将共享 lifecycle 中
  尚未分配或已退役 native context 的 Java-only 线程交给 clone join。
- JNI string chars/UTF8 lease 在 Release 前是 GC root；即使局部引用/线程已退役，清理 GC
  也不能删除仍在访问的字符串。通过 store 的显式枚举由 bridge 接入，回调在 store 锁外。

最终正常九场景 `.local/analysis/wu7-6/scenarios-final-summary.json`：6/9 overall pass，
所有 checkpoint 通过；TML/Lili/WB/Dungeon Hunter/Asphalt 5/Angry Birds 退出 0。
Tales 仍在退出读 0x315f0001，DT 仍耗尽退出清理预算，PVZ 仍缺 stopService；与上次的
通过集合完全一致，机器比对 `scenarios-comparison.json` 为零退步。不是正式 title gate。
