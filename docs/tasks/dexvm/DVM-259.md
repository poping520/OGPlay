# DVM-259 · Dalvik 4.4 通用动态代理

状态：待办。由 DIAG-7/WU7-5 拆出；依赖既有 ReflectionRuntime、AnnotationRuntime 合成类机制。

## 拆分理由

注解合成类只实现单个受检注解接口，不能直接承担通用 Proxy 的接口集合、重复方法与返回类型
约束、声明异常交集、类加载器身份及序列化语义。完整实现需要独立的合成类所有权和方法分派
回归；与本次注解/泛型元数据局部修复合并，会超出单次工作单的可验收边界。
044-proxy 仍应明确失败于 Proxy.generateProxy，不返回替身类或伪造成功。

## 实施范围

- 使用 intrinsic 合成类，不生成字节码文件；类实现按序指定的全部接口，继承原版 Proxy，
  复用稳定 loader/class 身份和现有 vtable/iftable，不在解释器中按方法名称截获。
- 校验接口、重复项、可见性、loader 可见性和非 public 接口包归属，按 4.4 合并重复方法，
  处理协变返回和声明异常交集；类缓存按 loader 与有序接口集合隔离。
- 调用统一转发 InvocationHandler.invoke，包含 Object.equals/hashCode/toString；传入真实
  Method 和防御性 Object[]，支持 primitive boxing/unboxing、void、null 与类型错误。
- RuntimeException/Error 原样传播，可声明 checked exception 原样传播，其他 checked exception
  用 UndeclaredThrowableException 保留原始 throwable 身份。对象/handler/Method 的 GC 根明确。
- newProxyInstance/getProxyClass/isProxyClass/getInvocationHandler 与原版 Proxy Java 协议一致。

## 验收

- 044-proxy 双后端逐字节 pass；AnnotationRuntime 迁移同一 Proxy 生成机制，核对 004 的实现类身份与命名；补多接口、Object 方法、参数/返回、异常、缓存/loader、GC 回归。
- 全量 --check-baseline 零回归后 --update-baseline；仅构建受影响目标。
- 更新 DIAG-7、真实变化的 MODULE 与能力账本；不能将 044 排除或改 oracle。
