# DVM-259 · Dalvik 4.4 通用动态代理

状态：部分实现，未完成全部验收（2026-11-05）。由 DIAG-7/WU7-5 拆出；依赖既有 ReflectionRuntime、AnnotationRuntime 合成类机制。

## 拆分理由

注解合成类只实现单个受检注解接口，不能直接承担通用 Proxy 的接口集合、重复方法与返回类型
约束、声明异常交集、类加载器身份及序列化语义。完整实现需要独立的合成类所有权和方法分派
回归；与本次注解/泛型元数据局部修复合并，会超出单次工作单的可验收边界。
044-proxy 已通过双后端逐字节比较；不排除用例、不修改 oracle。

## 实施范围

- 使用 intrinsic 合成类，不生成字节码文件；类实现按序指定的全部接口，继承原版 Proxy，
  复用稳定 loader/class 身份和现有 vtable/iftable，不在解释器中按方法名称截获。
- 校验接口、重复项、可见性、loader 可见性和非 public 接口包归属，按 4.4 合并重复方法，
  处理协变返回和声明异常交集；类缓存按 loader 与有序接口集合隔离。
- 调用统一转发 InvocationHandler.invoke，包含 Object.equals/hashCode/toString；传入真实
  Method 和防御性 Object[]，支持 primitive boxing/unboxing、void、null 与类型错误。
- RuntimeException/Error 原样传播，可声明 checked exception 原样传播，其他 checked exception
  用 UndeclaredThrowableException 保留原始 throwable 身份。对象/handler/Method 的 GC 根明确。
- newProxyInstance/getProxyClass/isProxyClass/getInvocationHandler 与原版 Proxy Java 协议一致。

## 验收

- 044-proxy 双后端逐字节 pass；AnnotationRuntime 迁移同一 Proxy 生成机制，核对 004 的实现类身份与命名；补多接口、Object 方法、参数/返回、异常、缓存/loader、GC 回归。
- 全量 --check-baseline 零回归后 --update-baseline；仅构建受影响目标。
- 更新 DIAG-7、真实变化的 MODULE 与能力账本；不能将 044 排除或改 oracle。

## 当前实现与边界

原版 Proxy Java 负责接口/loader/包校验、有序接口缓存、isProxyClass 与 handler 查询；
生成类继承 Proxy，以 vtable/iftable 转发原始声明 Method，支持协变桥、参数 boxing、API19
返回值 unbox/widen 与原 throwable 身份。checked exception 按声明交集传播或包装。
生成方法的 getExceptionTypes 返回空列表与固定 Dalvik 4.4 一致：Reflect.cpp 创建 Method 时
调用 Annotation.cpp 的 dvmGetMethodThrows，生成类没有 DEX Throws 注解；044 的 expected.txt
也不在 upCheck() 后显示 throws。原接口 Method 保留真实声明；转发按独立的异常交集检查。

私有静态 throws 字段只保留 ROM 形状，尚未物化内部内容：Dalvik 在签名为 Throwable[][] 的
数组里原生写入 Class[]，我方受检对象数组不能伪造这种赋值。转发使用合并类型元数据；当前游戏路径未读取该 private 字段，不能据此宣称完整私有布局等价。

AnnotationRuntime 本次保留受限实现：它还负责成员默认值、数组防御性复制、equals/hashCode
及延迟的注解类型错误，替换生成器需要独立迁移这些语义和 004 的类身份/命名验收。
这不是触摸/启动修复的必要依赖，因此仍作为本任务未完成项；004 的既有输出差异不排除。
真实 loader facade 目前仅 bootstrap/application 两个角色，不扩展动态加载器。

回归入口：reflection_tests.cpp 的 DVM-259（多接口/顺序缓存、bootstrap/application loader 隔离、声明异常交集、空值/类型错误、GC），
以及 tools/conformance/dalvik_tests.py 的 044-proxy。完整验证结果见 [DVM-369](DVM-369.md)。
