- 判据为本地 AOSP 4.4 源码及固定 ROM。检查器排除 final ROM 类的 A1，flags 差异仍归 A2；
  新偏差比较去掉类别前缀，类别变化单列。174 条 A1→A2 全部来自 ROM final 类。
  检查器与中间基线已由编排方提交为 `2181ffec`。
- A1/A2/B/C/D：381/384/274/13/74 → 207/558/274/13/74 → **0/542/272/13/74**。
  修正 46 类中 207 条真实 A1：按父声明使用 VirtualMethod / OverrideMethod，保留 handler；
  ROM 接口按 abstract 虚方法声明，具体实现类保留原 handler。A1 无保留项，无新增成员偏差。
- 完整内部调用审查后修改 28 处：Handler 9、HandlerThread 2、ViewGroup 3、Window 2、
  TextView 5、GLSurfaceView 2、ColorDrawable 1、View 2、ZipInputStream 2。复用既有
  CallAndroidMethod / InvokeGuest，默认 C++ 路径移至被调方；不扩充未实现的 ROM 调用方。
  GLSurfaceView 内建 chooser 仅承载既有 component 配置，其余骨架方法仍明确未实现。
