# DVM-262 · B 类同族与构造器缺口收敛（WU9-2）

状态：完成本单契约与转发门禁（macOS，2026-10-23）。
基点：`d20f55f1`。场景与小游戏门禁由编排方在沙盒外运行。

## 分类与实现范围

- 272 条 B 已逐条提取固定 ROM 方法体、smali 声明行号及可用的 Java 调试行号，
  抽象/native 无 Java 调试行号时使用 smali 声明行号，不编造源码行号。
- F=38、S=50、X=184；F/S 共 88，已全部实现。未触发 F+S 超过 200 的上限。
  `classify.json` 逐条保存分类、理由、ROM 调用指令及实现范围；
  `bodies.json`、`audit.json` 保存完整 ROM 方法体与依赖审查。
- F 包括数值 bridge、控件 this/super 链、DatagramPacket 重载、String 工厂、
  Drawable/TextView/Toast 等转发。构造器/静态目标按明确 owner 和签名调用 VM，
  this 虚调用复用 InvokeGuest / CallAndroidMethod；保留 ROM 常量、参数投影与异常身份。
- S 包括 Message 本地池/obtain 重载、RectF/PointF/Criteria/WifiInfo 值复制、
  String/Character UTF-16 操作、CharBuffer.put(String)、本地构造字段及 ZIP metadata。
  String/NIO 复用现有唯一状态表示，不另立可变字符串或 buffer 状态。
  `handler-lines.json` 检查全部 50 个 S，格式化后方法体最多 27 个非空行，均不超过 30。
- Canvas B 条目依赖 native raster，全部保留 X；其既有整数颜色数组 drawBitmap 在 ROM
  1257 行转发到浮点坐标重载，原手写 handler 却为空。本轮将这个既有调用点改为虚分派：
  应用覆写可接收调用，默认未实现的浮点目标仍明确失败；此项不计入 88 条 B 减少。
- ThreadGroup 5 条维持 X，已从必需代表中移除；不补手写组状态。
  **WU9-4 边界下移候选：ROM 为纯 Java（libcore/libdvm ThreadGroup.java），
  应改用原版，而不是扩充手写状态。**
- X 完整清单按子系统列于 [DIAG-9](../diagnostics/DIAG-9.md#x-清单)，仍保留原有记账和异常。
  MODULE 契约未修改，capabilities 未改；本单门禁通过，剩余 X 不作为兼容支持。

## 代表门禁与 X 边界

用两个应用常用的 F 构造链代表替代 ThreadGroup，选择 Button 与 EditText，
没有为 ProgressDialog/BitmapDrawable 扩充 X 能力。ProgressDialog 还有 Object/AlertDialog
层级差异及缺失 helper/协议，BitmapDrawable 缺 BitmapState/密度/native 链，均列 X。
HttpAuthHandler 虽仅调 Handler 父构造器，但运行时父类仍是 Object，因此同样维持 X。

| 代表 | 证明方式 | 格式化后结果 |
| --- | --- | --- |
| Canvas 整数坐标 drawBitmap | 子类覆写浮点重载，检查调用次数及参数换算；基类默认目标仍抛 ULE | 通过，双后端 |
| Message.obtain(Handler,int,int,int) | 为真实无参 obtain 安装计数包装，预置 ROM 池，验证返回同一池对象与字段；空池再分配 | 通过，双后端 |
| Button(Context,AttributeSet) | 包装真实三参构造器，检查进入及 ROM style 常量 0x1010048，再运行原 handler | 通过；明确预期 ULE，消息含 Context.getThemeResId |
| EditText(Context,AttributeSet) | 包装 EditText 三参与 TextView 三参构造器，检查 this/super 及 style 0x101006e，再运行原 handler | 通过；明确预期 UnsupportedOperationException，消息含 defStyleAttr 与投影缺口 |

两个构造用例只证明以 ROM style 常量进入规定的三参重载，并正确传播真实被调方的异常。
测试仍执行原 handler，检查 this/super 调用次数、异常类型和缺失成员/能力消息；不以空替身
伪造构造成功。主题/默认样式解析（Context.getThemeResId、defStyleAttr 投影）按 X 处理，
不在本单扩充；受阻 F 链在 DIAG-9 单独列出，不重复计入 184 个 B 类 X。
