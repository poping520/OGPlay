场景与小游戏门禁由编排方在沙盒外运行。

## 数字与边界

A1/A2/B/C/D：**0/542/184/13/74 → 0/542/183/13/2**。
逐键实测 D=74 包含 34 条接口 null/Object 超类误报、11 条真实超类差异、29 条直接接口差异，
与任务描述的估算不同。消除误报 34、修复超类 9、对齐接口 29，保留 D 类 X=2。
接口对齐含 28 条补充及 GenericDeclaration 多余 AnnotatedElement 的移除；不是新增 29 个接口类型。
HttpAuthHandler 的父类恢复 Handler 后实现真实无参构造器，同时消除 1 条 B。
检查器 check 无新增偏差或重分类，随后 update 收紧基线。

- 检查器仅对 ROM 接口将 superclass 的 null/Object 视为等价，支持两个方向；
  普通类及其他超类仍计 D。新增启动链接错误拒绝规则，防止失败的 dump 被当作偏差减少。
  self-test 覆盖上述阳性、阴性及拒绝情形。
- 9 条超类为 NameNotFoundException、MotionEvent、HttpAuthHandler、WebView、
  AbsoluteLayout.LayoutParams、ScrollView、TableLayout、TableRow、ZipInputStream。
  重名 MotionEvent 方法改为显式 FinalOverrideMethod，原 snapshot handler 保留。
- NameNotFoundException 执行 AndroidException 原构造器，消息/cause 状态归 BootDex；
  MotionEvent 两个生产工厂执行其私有构造器，再进入 InputEvent 原构造器初始化序号。
  LayoutParams 执行父构造并写 x/y；TableLayout/TableRow 进入 LinearLayout；
  HttpAuthHandler 进入 Handler，保留真实 Looper 状态。
- WebView、ScrollView 的既有有界 Context 构造路径改为调用正确父类的现有 Context 构造器，
  WebView 保留自身焦点/线程初始化。没有补齐 ROM this 链的完整默认样式语义；
  AttributeSet/defStyle 重载仍保持骨架记账失败，未把这些 B 类缺口标为完成。
- ZIP 按 ROM 创建 PushbackInputStream、Inflater(true)，执行 InflaterInputStream 原构造器；
  close 进入真实父类，正确关闭输入并释放 inflater native 资源。原 entry/read/skip handler 保留。
- 未实现的接口方法继续由骨架或既有入口记账抛异常，没有补中性 handler。

## 接口解析修复

最初回归在 Link 阶段报 `intrinsic hierarchy is not registered: Lorg/xml/sax/DTDHandler;`。
DTDHandler 确实存在于固定 core.jar 与骨架；它不在原 BootDex 中。现有 Link 的 intrinsic
层级预解析使用 FindClass，只查已注册类，不走 ResolveDescriptor 的按需骨架物化。
这不是 ROM 缺类，也不是 RegisterIntrinsics 时已经完成了层级解析。

完整核对本单新增声明的 33 个不同层级依赖，均属于固定 ROM 且最终可链接。
为同时兼容不注册骨架的现有夹具，使用已有 BootDex 配方准入以下原版接口：
DTDHandler、ComponentCallbacks2、NoCopySpan、ViewDebug.HierarchyHandler、
ViewTreeObserver.OnGlobalFocusChangeListener、OnPreDrawListener、AccessibilityEventSource。
没有修改链接机制；新增接口无 native 方法，依赖闭包和 overlay 冲突经 builder build/check 验证。
生成 JAR、manifest 已更新；类数、哈希等以生成 manifest 为准。

Application/Service 的 registerComponentCallbacks、unregisterComponentCallbacks 四条解析路径，
与基点相比 owner、origin、status、flags 完全相同；实际调用仍明确 ULE 并记账。
补 ComponentCallbacks2 不代表新增了回调注册/分发实现。
