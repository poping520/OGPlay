# DVM-265 · 已有 intrinsic 的 ROM Java 类撤换（WU9-5b）

状态：首批实施及沙盒内门禁完成（2026-10-23）；九场景由编排方在沙盒外验收。
架构依据：[ADR-0154](../../adr/dexvm.md#adr-0154)，补充 ADR-0148。
没有 git commit；没有运行游戏场景或 APK。

## 首批范围与状态所有权

| 类 | 最终处理 | 原因 / 边界 |
| --- | --- | --- |
| org.xml.sax.InputSource | 撤换为 ROM | getter/setter、构造器与值状态归 Java；SAX 解析仍明确失败 |
| java.net.DatagramPacket | 撤换为 ROM | 删除 NetworkRuntime packet 侧表；DatagramSocket 经 VM 虚派 Java 方法读写状态 |
| android.content.IntentFilter | 撤换为 ROM | 附带 IntentFilter$1、AuthorityEntry；删除全部过滤器宿主侧表及 sweep，Parcelable 归 Java |
| java.lang.Appendable | 撤换为 ROM | ROM 抽象接口与真实接口分派，无手写声明 |
| java.util.Timer | 退回 intrinsic | 构造触达 Timer$TimerImpl，继承 intrinsic Thread，ADR-0148 不准入；不扩充线程生命周期设计 |
| android.os.CountDownTimer | 退回 intrinsic | 构造触达 CountDownTimer$1，继承 intrinsic Handler，未准入；不扩充调度生命周期设计 |
| android.util.Log | 退回 intrinsic | ROM println 到达既有 native 并返回 11；getStackTraceString 经 FastPrintWriter 需要未实现的 Charset.newEncoder；不扩充 Charset |

共撤换四类，退回三类，未超过三类上限。Log、Timer、CountDownTimer 的生产代码恢复基点；
Log 保留原有 native 绑定，未新增 native。仅为 Log 试验加入的 Log$1、TerribleFailureHandler、
FastPrintWriter/$1 已从最终配方移除。最终配方只有四类与两个 IntentFilter 配套类型的增量。
普通 Java 状态均不由 C++ 读写，首批没有 ROM 约定给 VM 的私有字段访问例外。

DatagramSocket.send 经 getData/getOffset/getLength/getAddress/getPort 取得一次性传输快照；
receive 经 setLength/setAddress/setPort 提交长度和来源，payload 写入 getData 返回的数组区间。
NetworkRuntime 只拥有网络资源及受策略控制的 transport，不拥有 packet 内容。注入 transport
回归验证偏移区间、字节、长度、地址和端口，不访问宿主网络。
其他 C++ 点名仅保留必要的方法签名、接口关系及通过 VM 调用 Java 的边界；
盘点见 `final-coupling-references.txt`，过滤器侧表及被撤换声明的缺失检查已通过。

## 选择器与契约检查器

- `select_rom_java.py --replace-intrinsic <descriptor...>` 只对显式列出的 intrinsic 使用固定
  ROM own members；仅允许原已 implemented、handwritten 的同签名 native 绑定。
  默认 ADR-0148 行为不变，父类、初始化闭包、Binder、依赖、日期冻结和容量约束保留。
  不允许叠加 --only 或 --cha-precise；默认报告，--apply 才写配方。
- 本类签名/源码交互成为同批清理义务，选择通过不是状态所有权证明。
  自测覆盖默认排除、显式 ROM 形状、旧 native 保留、新 native 拒绝、非 intrinsic 拒绝，
  并确认显式撤换不能绕过 intrinsic 父类和 Binder 拒绝。
- 必要配套类型使用同一选择器的既有 --only 规则，不新增类名豁免。
- framework_contract 原来将 intrinsic 类消失一律视为导出缺失；现在只有完整 surface 中
  明确 source=bootdex 的 ROM 类可作为已迁移类继续记账。类缺失或退回 skeleton 仍失败；
  自测验证允许迁移、拒绝缺失/骨架。没有按具体类名放宽或删除偏差。
