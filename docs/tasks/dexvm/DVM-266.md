状态：完成（macOS，2026-10-23）。执行方按组件加载门禁停止后，编排方按 ADR-0155 的端到端口径补测并验收。
架构依据：[ADR-0155](../../adr/dexvm.md#adr-0155)，修订 ADR-0148 决定 4；
ADR-0154 的显式 intrinsic 撤换不在本次范围。没有 git commit，没有运行游戏或 APK。
证据目录：`.local/analysis/wu10-1/`。

## 范围、规则与缺陷结论

`--scope closure` 从当前 BootDex 配方、实际制品内的 BootDex 类及 intrinsic 声明引用的
类型出发，遍历方法体中的创建、调用目标所属类、字段所属类、类常量/类型检查/对象数组
引用，直到不动点。仅准入类继续贡献方法体，并加入 `closure_of` 的父类和初始化依赖。
实际制品反汇编补足 guest Java、Conscrypt 和已覆盖的 ROM 方法体；准入初始化分析保持
ADR-0148 原规则，不改变 native、Binder、交互、唯一目标或日期冻结条件。
`referenced` 保留作诊断；不新增 native，不修改运行时 C++。

ContentValues 已来自 BootDex，ContentValues$1 则是可准入骨架。
其 `<clinit>` 明确 new-instance 并调用 `$1.<init>`，原准入分析可以识别该依赖。
真正缺陷在选择范围：`closure_of` 只接纳 admitted 候选作为种子，现有 BootDex 类不是候选，
因此旧 referenced 范围从不重新遍历这些类的初始化依赖。历史配方漏项不会自动补回。
本次修复种子与方法体遍历规则，没有按类名豁免。
证据：`contentvalues-rule-defect.json`、`contentvalues-clinit.smali` 与选择器自测。

首轮新增 **969 类**，build/check 后重新导出 surface，再检查闭包为 **0**，无需第二轮。
调研的 1295 类使用 smali 全文类型引用（含签名/注解），本次严格以方法体边迭代，另加入
intrinsic 声明种子，两集合非包含关系；差异见 `scope-comparison.json`。
`--check-closure` 对非零缺口列类并失败，同时检查实际 DEX 索引预算不超过 60000。
自测覆盖方法体与类常量可达、父类/初始化依赖、多跳不动点、拒绝边界与制品内额外种子。

## 定向与主题回归

在现有 platform_tables.dexasm 加两个 DEX 片段，分别由 android_value_tests 与
android_context_services_tests 的 DVM-266 用例调用，双后端共 **2 用例/32 断言通过**。
ContentValues 初始化完成，CREATOR 非空、真实类为 BootDex ContentValues$1，重复读取
身份相同且无未实现记账。没有修改 ContentValues 或 Creator 的 ROM 算法。

AppGlobals 可解析且方法来自 BootDex。AOSP 4.4 AppGlobals.java:58–62 先调用
ActivityThread.currentActivityThread()，其返回 null 后才走默认值分支；当前该目标仍为
骨架，故真实执行抛 **UnsatisfiedLinkError**，精确记账
`dexvm.intrinsic.Landroid/app/ActivityThread;.currentActivityThread()Landroid/app/ActivityThread;`。
测试明确断言错误类型与该一次命中；没有用伪造 null 来声称默认值路径已支持。
独立 run-dex 复现同一结果，见 `appglobals.log`、`appglobals-ledger.json`。

主题覆盖 BootDex、骨架/类链接、framework 服务与资源：基点 215 用例/6 既有失败；
候选 217 用例/5 失败，**无新增失败**。既有失败及逐项结果见 baseline/candidate-themes.json。
并发 PendingIntent 用例从基点失败到候选通过只记观测，不宣称本次修复其时序问题。
framework_contract --check-baseline：前后均无新增、移除、重分类或丢失类偏差。
仅两个已跟踪 C++ 测试文件有改动，已按改动行 clang-format，dry-run -Werror 通过，
格式化后已重建并重跑定向回归；生产 C++ 未修改。
