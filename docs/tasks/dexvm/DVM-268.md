## DEX 回归与原断言维护

八类各一条 DEX 回归，放入现有 core_catalog、android_value、scheduler 主题，共用
rom_java_replacement.dexasm。双后端 **8/8、148 断言**通过（`dex-final.log`）：
Timer 单次任务及 cancel 后拒绝再调度；TimerTask 未调度前 cancel 返回 false；CountDownTimer
onTick 30/20/10 与 onFinish；Location 构造后 time 往返；AnnotatedElement 注解数组、Member
声明类、GenericDeclaration 类型参数，以及 AutoCloseable 接口 close 分派。
Readable 试验没有通过，保留失败证据，撤去其试验断言；不将接口迁移宣称为 NIO 修复。

原有断言/夹具只作以下 ROM 行为调整：
1. core_catalog 的 AutoCloseable shape 从手写目录改取 BootDex，保留完整 close 签名断言；
   接口库存要求不再存在 intrinsic 声明，并验证 BootDex/interface 标志。
2. 从手写未实现列表移除已迁移的抽象接口成员；Readable 的原列表和手写声明均恢复。
3. 原 Timer 综合用例必须真实调用 TimerTask 构造器，初始化 Java lock；不再依赖旧空构造状态。
   ROM Timer 在独立 guest/host 线程执行，推进统一 Clock 后有界等待真实回调，再 cancel 收尾，
   不要求由主 Looper 泵直接执行 TimerTask；旧取消任务及非法 period 断言保留。
4. CountDownTimer 的 Handler 在构造时绑定当前 Looper，故夹具先准备主 Looper，不依赖旧 start
   隐式准备行为。原零时长完成 DEX 用例扩展为正时长 ticks 与完成；综合用例仍验证相同 Clock。
