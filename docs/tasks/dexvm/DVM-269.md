## 基点与超时噪声

修改生产代码前已复制 Release CLI、tests 与同目录 dylib 到 `baseline-bin/`；
HEAD 与 SHA-256 见 `baseline-provenance.json`。基点 loader 114/114、2565/2565 断言通过。
初次误用 doctest 的 `--list-tests` 导致无关测试启动，后改用正确的 source-file 筛选；
误筛选结果不作为 loader 比较证据。初轮 Dalvik 仅 074-gc-thrash/switch 超过 60 秒，
当时负载较高；编排方在沙盒外单独复跑三次均通过，11.22/11.28/11.25 秒，
证据为 `074-recheck-{1,2,3}/summary.json`。用户明确授权将其记为噪声并继续，
`accepted-baseline.json` 保存该判定，不重跑整套基点、不改基线文件或超时预算。

今后的单个 Dalvik fail:timeout 按用户补充规则，以 `--only <case> --backend <backend>`
独立复跑三次；三次都通过才能记噪声，任一次仍失败则停止。
