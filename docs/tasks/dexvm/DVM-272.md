## EOCD 查找与读取阶段

AOSP `dalvik/libdex/ZipArchive.cpp:211–214` 扫描命中末尾 EOCD magic 后即 break；
`:254–257` 检查 comment 是否越出文件，失败直接返回，不回退到更早的签名。
`FindEnd` 采用相同选择规则：允许 comment 之后仍有文件尾字节；一旦选择的签名声明
comment 越界，就明确失败。`WU11 ZIP does not backtrack past a malformed last EOCD signature`
以有效 ZIP 后附畸形末尾 EOCD 证明该语义，修复后通过，预期未放宽。

普通 ZIP 读取依据 central metadata；local header 仅用于签名、加密标志和受界定位，
冗余 local/descriptor 不一致不提前拒绝。4.4 普通提取不比较 CRC，不另造一个后续 CRC
失败阶段；载荷仍原样交付，真实格式/解压错误继续由消费者报告。
Deflate 在完整流结束后停止，仍核对输出尺寸/回溯；空距离表仅在不使用距离码时允许。
空 native 库保留 ABI/identity/空文件 SHA-256，直到实际 ELF 读取时失败。
stored range 无 CRC 扫描，实际扫描统计为 0，Deflate 仍统计完整输出扫描量。

## 字符串、清单与消费者

字符串池按需解码，未使用坏字符串不拒包；转换失败返回 null，由具体 getter 取默认值、
忽略或拒绝，metadata 的 TYPE_STRING null 保留为 Bundle null string，不替换为空串。
NUL/孤立 UTF16 单元以 WTF-8 code-unit 投影交付 Java。原始 package 属性名使用
string8At 风格原字节匹配；编译后 Android typed 属性按 resource ID 取首匹配。
重复 application 跳过整个后项子树，跳过时仍检查节点结构。节点采用声明 headerSize、
最小扩展和受界属性读取，忽略 Res_value.size/res0、未知节点与 END 名称匹配。

permission 按声明顺序保留，registered 标明已知 group 的首项；group 来自固定 API19
平台清单与当前包声明，未知 group/重复后项不注册。protectionLevel、flags、description
采用 4.4 数值/资源规则。uses-permission 忽略 null、保留空串、去重并处理整数 maxSdkVersion。
supports-gl-texture 在 4.4 属未知 tag，但 ADR-0128 的 OGPlay 压缩纹理策略独立消费该事实。
保留顶层合法 android:name 原名，按声明序去重（含未知扩展）；缺名、空名、非字符串或
字符串取值失败仅跳过该条并记诊断，不拒包，也不丢弃其他合法声明。嵌套声明仍忽略。
PackageManager 回归验证注册过滤与首项结果，Bundle 验证 containsKey、null、NUL/孤立单元。

ResourceTypes.cpp:567/:615 及官方
[API19 libutils/Unicode.cpp](https://android.googlesource.com/platform/system/core/+/android-4.4_r1/libutils/Unicode.cpp)
为字符串转换依据；完整源码保存为 `Unicode-api19.cpp`（:435/:489/:519/:545）。
4.4 使用 lead-byte 长度与 mask 转换，不套用现代严格 UTF8 校验；仍核对声明 UTF16 长度，
并在宿主转换前防越界。UTF16 每字符串终止字节不作检查；4.4 setTo 的 UTF16 pool 末尾
检查因运算符优先级不生效，未补造该拒绝。UTF8 pool 整体末尾校验仍保留。
