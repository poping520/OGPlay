# DVM-275 · View 布局入口收口（VD-01）

状态：本 WU 实现与沙盒验证完成；GPU 与九场景待编排方外验。
路线：D′，Java 最终拥有 guest View 几何与遍历，integration 在 owner 线程调度，UiTree 接收投影。
本单只整理 Legacy 调度，不迁移 Java 状态，不启用 JavaTraversal。
设计及编排决定：`.local/analysis/view-dir/DECISION.md`、`REPORT.md` §4.2、§4.3、§6。
基点：`3d38fd4d0b31c6366705b13c8ebb746aff84fdd6`；证据：`.local/analysis/vd-01/`。

## 范围与行为

- `EnsureAndroidUiTraversal(vm, context, reason, phase, viewport)` 是唯一 integration/session
  布局门面；bool 保留原尺寸派发“布局或通知有变化”语义。
- 13 个生产调用点：getter 1、输入/触摸/命中 5、Dialog 构造/输入 2、StepFrame/Compose 2、
  内容同步（含窗口切换/恢复/managed 尺寸变化）1、初次/动态 Surface attach 2。
  兼容 `DispatchAndroidViewSizes` 包装不另计；7 处原 LayoutUiTree 直调变为调度器内 1 处，
  调度器外剩余 0，无纯宿主 helper 豁免。
- GeometryRead 脏布局前才刷新 LayoutParams；输入、帧、尺寸派发、Dialog 沿旧路径不刷新。
  Compose 使用传入 frame 尺寸，ResolveOnly 不派尺寸回调、不新增 owner 校验。
  Notify phase 保持旧 root guest 线程校验、重入返回 false、RootScope、attachment/content revision
  复核、尺寸缓存、8 轮上限及异常身份。Dialog 暂保留整树布局，VD-10c 再隔离。
- UI 层不获 Interpreter/Java 引用；无用户配置，无配方、loader、class linker 改动。
  CURRENT 增量 0 字节；能力范围不变，账本不改；closure 与 BootDex 不因本单变化。

## 验证

`baseline-bin/` 保存改动前 release CLI/tests；tests 独立链接，不依赖 libogplaycore。
CLI 是 dylib 启动壳，复制壳不等于冻结其 core；不得将后续 CLI 调用当作 HEAD 基点证据。
基点先行结果保留在 baseline 日志及 JSON；实际沙盒主题、差分与格式化结果见本地验证记录。

新增回归复用 egl_facade 与 activity_window_lifecycle 主题：ResolveOnly 消费 layout dirty、
保留 draw dirty；无 dirty 不改几何/计数；输入与 render-list 同 node 的 screen_frame 一致；
present viewport 与 managed metrics 差异；回调重入/异常身份与 dispatching 复位；Compose 不增加
真实 guest onSizeChanged 计数。Compose 夹具只创建 VM，不启动图形 Activity。
静态门禁 `ctest --test-dir build/release -R '^architecture.ui_traversal_entry$'`，
或 `python3 tools/check_ui_traversal.py`：integration/session 只允许统一函数体内 1 处直调。

最终对比：原有 CPU 用例 134 项（120 通过、14 既有失败），新增回归 3/3 通过；
最终 137 项（123 通过、14 既有失败），5838 断言；既有失败名与错误签名逐项不变，新增失败 0。
失败包括轻量无 JNI bridge 夹具的 ROM Rect→regex native 缺口及 SurfaceTexture GC 既有断言；
原尺寸/Surface 测试中受此阻塞的路径仍不宣称通过。`test-comparison.json` 保存完整逐项对比。
初次尝试 lifecycle 主题发现所有 16 项均依赖 Metal，日志保留为环境证据，之后不在沙盒重跑。

仅构建 `ogplay_tests`、`ogplay-cli` 目标；改动行 clang-format 23.1.3 dry-run + `-Werror`
通过，格式化后重建及最终主题复测完成。静态 CTest 1/1 通过；负例证明其他文件及同文件
函数体外直调均被拒绝。未运行 dalvik/JNI、一致性全套、APK 或九场景。
外验过滤：`*activity_window_lifecycle_tests.cpp,*activity_task_stack_tests.cpp`（排除 `VD-01*`），
以及 egl_facade 中实际 native ANGLE/GPU 用例；完整精确参数及九场景约束见
`.local/analysis/vd-01/external-validation.txt`。C++ 构建日志、格式化日志、基点/最终哈希与
payload 身份见同目录；保存的 CLI 壳缺少冻结 HEAD core，外验需使用编排方 HEAD build。
