## 支持范围与发布协议

- `UiTree(UiGeometryOwner)` 构造时固定 HostLayout / ExternalProjection，不能运行中切换。
  每个外部分区提交一个窗口 root；纯宿主分区保留独立 C++ 布局根。当前生产 guest 窗口
  仍只使用 HostLayout / Legacy，投影 API 仅由测试树使用，未改宿主 Dialog 根划分。
- owner 先 `SetProjectionTarget` 固定 root、window generation、content/metrics revision 和 viewport；
  同代 revision 不回退，尺寸改变必须推进 metrics revision。批次不能自行推进 target。
- `CommitProjection` 提交完整窗口节点集合，包含 parent/顺序、局部 frame、measured size、
  visibility、padding、scroll_y、clipChildren/clipToPadding；节点使用现有强类型 UiNodeId。
  batch 必须与当前 target 完全匹配，epoch 非零且严格递增；窗口换代仍不可倒退 epoch。
- 节点存在性/唯一性、root/parent 完整性、连通性、环与层级上限、非法尺寸/可见性、
  坐标溢出都在临时副本校验；成功后整体替换 hierarchy/id index/geometry/dirty。
  遗漏节点脱离层级与 id index；非法/旧代批次零修改，不产生半批次投影。
- ui 单向计算 screen_frame 和 screen_clip，measured 与 frame 可不同；无 guest 执行、
  Java 引用或字段读取，不回填 Java。未来字段收集及 binding/owner 校验仍由 integration 负责。
- `PublishedProjection` 返回 `shared_ptr<const UiTree>`，携带完整 target 与 epoch；
  仅成功提交原子替换快照，target 更新或失败不覆盖上一完整快照。consumer 原子获取快照，
  上层串行 target/commit；ui 不新增可并发修改的树。
- 外部分区的 `BuildUiRenderList`、`HitTestProjection` 只接受完整快照，共读其
  screen_frame/screen_clip；旧快照可安全保留到下一 epoch，presenter 不访问构建树。
  `LayoutUiTree` 在修改前明确拒绝外部 owner；直接层级/visibility setter 同样拒绝。
- `EnsureAndroidUiTraversal` 预留 Legacy / JavaTraversal 选择点，编译期常量固定 Legacy；
  JavaTraversal 分支明确未实现，无用户配置。不装载 ROM measure/layout、不改变生产入口。
  BootDex、配方、loader、字段可用性与 closure 均未改变，closure 增量 0。
