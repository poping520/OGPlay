# DVM-281 · ADR 修订与 Java ViewGroup hierarchy（VD-06a）

状态：已完成（固定实验配对的测试容器）；Legacy 仍为唯一生产默认。前置：
[DVM-278](DVM-278.md)、[DVM-279](DVM-279.md)、[DVM-280](DVM-280.md)。
决定：[ADR-0158](../../adr/dexvm.md#adr-0158)、[ADR-0159](../../adr/dexvm.md#adr-0159)。
证据：`.local/analysis/vd-06a/active-body/`，总表 `../validation.json`；
初次、第二次及第三次阻塞证据分别保留在证据根、`revision/`、`implementation/`。
不提交、不启动 APK；GPU、九场景与 Windows 交编排方外验。

## 三次阻塞背景及实施规则

1. 最初 ROM assignParent 的非 null writer 违反 VD-05 的 null-writer 准入门槛。
   第二次编排方允许构造器/宿主不可分配证明 (b)，但 Unsafe、JNI AllocObject 和原始宿主
   分配可绕过 failure 构造器，不能据此保证实例不存在。两次分析及原负对照保留。
2. ADR-0159 第三次修订将 (a)/(b) 降为 `a/b/unproven` 封存信息。每个字段接收者 failure
   目标仍记录 writer、构造器及机器扫描的宿主分配证据；检查重算并拒绝篡改/过期账。
   共用 `host_allocation_scan`，逐目标引用哈希/索引，不扩大运行时 JSON 限额。
   failure 运行时始终记账并明确失败。严格 direct/static/super/精确接收者、failure 字段、
   DYNAMIC_TARGETS、clinit 未放宽；raw host allocation 双后端负对照保留。
3. 第三次阻塞是 ADR-0156 对禁用方法体的全 own-body 父成员审计：候选有111条拒因，
   涉及95个禁用调用者，包含焦点、绘图、系统附着等范围外能力。
   编排方最新 ADR-0158 补充只让组合类的 rom/clinit 活动体参加父引用审计；
   全部成员仍检查 overrides-nonoverridable，默认整类 selector 规则完全不变。
   自测证明禁用体通过、同体启用后严格父调用拒绝，以及形状检查和原默认行为保持。

`select_rom_java --bootdex` 仅增加显式配对制品输入，不改变准入或 closure 规则；
替代 payload 禁止 `--apply`。closure 仍扫描保留的全部 DEX 方法体，因此实验额外装入
5个经默认规则准入的 ViewGroup 内部辅助类（`$1/$2/$3`、ChildListForAccessibility、
ViewLocationHolder）；与组合 ViewGroup 合计6个新增实验 class_def。ListenerInfo 已在生产
配方内，不算新增。生产配方和 BootDex JAR 字节不变，不启用任何生产容器切换。

## 方法与字段迁移账

精确签名、原 flags、方法体 hash、字段初始化和全部 failure 项以
`tools/bootdex/view-group-sources.json`、`view-measure-sources.json` 及封存成员表为准。
ROM 字节码未改写；每类保持单一原版 class_def 和原 clinit。

| 范围 | 本批来源与行为 |
| --- | --- |
| View.mParent/mLayoutParams/mID | Java 唯一：assignParent、getParent、get/setLayoutParams、get/setId、findViewById/findViewTraversal、generateViewId 为 ROM |
| Group.mChildren/mChildrenCount | Java 数组/计数唯一；5个 addView 重载、addViewInner/addInArray、两个 removeFromArray、removeViewInternal、removeView/removeViewAt/removeAllViews/removeAllViewsInLayout、bringChildToFront 为 ROM |
| 参数与子测量 | getChildAt/getChildCount/indexOfChild、generateDefaultLayoutParams/checkLayoutParams、generateLayoutParams(copy)、measureChildren/measureChild/measureChildWithMargins/getChildMeasureSpec 为 ROM；参数对象仍用现有原版 LayoutParams/MarginLayoutParams |
| 多级父链依赖 | Group.layout、方向/RTL/padding/layoutMode 解析及 reset 闭包、onSetLayoutParams/onViewAdded/onViewRemoved 为 ROM；View/ViewGroup 的 text direction/alignment、hasFocus/hasTransientState 等实际读取闭包补为 ROM |
| 有界 accessibility 读取 | 原版 isImportant/isActionable/isAccessibilityFocused、liveRegion/provider、getListenerInfo/hasListeners 供原移除路径读取真实 Java 值；不新增 listener/focus/accessibility 服务或 setter 能力 |
| 未迁移方法 | XML/AttributeSet 参数生成、in-layout add/remove 专用入口、完整 transition/animation、dispatchAttached/Detached、输入分发、焦点/listener/flags setter 等保留 failure；removeAllViewsInLayout 是普通 removeAllViews 的内部 ROM 依赖，不代表专用入口族全部准入 |

实验方法数：View **19 overlay / 99 rom / 526 failure**；ViewGroup **4 / 52 / 201**。
字段：View **325 rom / 46 failure**；ViewGroup **57 / 20**。
部分 flags/focus/listener 引用仅因 ROM 闭包读取而开放字段，不宣称 VD-06b 完成。

## Adapter review 与系统接缝

| adapter | 输入、输出、owner 与拒绝边界 |
| --- | --- |
| View(Context)、getContext | 真实 Context/resources；延用 VD-04/05 默认值/SDK 分支，补 mID/mLabelForId=NO_ID；parent/params 由 VM 清零后交 ROM；无 ViewConfiguration 或系统对象伪替身 |
| Group(Context) | 调 View 初始化，置真实12项 children 数组/count=0、mGroupFlags=0x24053（SDK≥11 再含 split 标志）、layoutMode=-1、lastTouchIndex=-1，以及 WILL_NOT_DRAW/SKIP_DRAW；普通构造的 transition listener、绘图缓存等未选字段保持 failure，不能以零值读取冒充支持 |
| requestLayout、isInLayout | 真实 Java parent 链、cache/flags 与 owner phase；cache clear、FORCE_LAYOUT/INVALIDATED 和虚派父传播归 Java；宿主只保存弱 requester 身份，首轮先筛完有效请求、再清全部请求链 FORCE_LAYOUT，避免 GONE/重叠链残留或漏测；第二轮延至下一 tick，脱树/GONE/失效身份过滤，持续不收敛沿 VD-05 watchdog 明确失败 |
| isLayoutModeOptical(Object)、hasRtlSupport | 实际 Group 虚派 ROM 查询；其他对象非 optical。RTL 查询真实 Context/ApplicationInfo，不复制 SDK/方向权威 |
| getPaddingLeft/Right、setPadding、internalSetPadding、setMinimumWidth/Height | 延用已审绝对 padding/minimum adapter，写 Java 后真实虚派 requestLayout；无宿主参数或几何回填；scrollbar/inset 等范围外组合拒绝 |
| invalidate(Z)/(IIII)、notifySubtreeAccessibilityStateChangedIfNeeded、needGlobalAttributesUpdate | 当前进程 software dirty/已审 Java flag masks；检查真实硬件、动画、变换、overlay、AttachInfo、delegate 状态，非空记账拒绝；不产生系统 accessibility 回调 |
| updateMatrix | 仅实际 null transformation 的原快速路径；非空记账拒绝，不伪造 identity matrix |
| notifyGlobalFocusCleared、rootViewRequestFocus | 纯系统/焦点边界，记账抛 UOE，不宣称实现焦点迁移 |
| cancelTouchTarget/cancelHoverTarget | 只允许真实空目标的原路径；非空目标记账抛 UOE，不复制输入状态 |
| addDisappearingView | 动画/transition 服务未启用，记账抛 UOE；独立动画移除负对照确认到达这一接缝 |

根 View 的 mParent 在 OGPlay 为真实 null，不存在 ViewRootImpl，这是 REPORT §4.4 的系统
接缝偏差。测试子类的 Java onMeasure/onLayout 真实驱动所有子节点；不装 Binder/WMS、
完整 TextView 栈，不扩充 FrameLayout/LinearLayout 算法、生产 listener/焦点或完整 flags。

## 投影、GC 与动态证据

integration 在 owner 线程/VM 锁和发布期 RootScope 下，从真实 Java 数组、parent、ID、
frame/measured/padding/clip 收集整批，验证计数、双向 parent、cycle/depth、绑定和代际。
UiTree 同一 commit 派生 parent/children/id 索引并原子发布；回调换内容、旧 generation/revision
或非法 child parent 均零 publish，不回滚已经发生的 Java 修改。

Java mChildren 数组、mParent、mLayoutParams 强边由 VM 正常扫描。JavaTraversal 的绑定表、
requester 队列和 watchdog 身份不作 GC roots；只有 content root 与发布期临时根保活。
被 sweep 的绑定只退役 UiTree 构建缓存身份，最后不可变 epoch 保持到下一完整发布。
无第二套可变宿主 hierarchy/参数引用表；Legacy 原强绑定、参数表与遍历行为保持。

双后端回归包括 add/remove/reparent/bring 顺序、重复 parent ISE/非法 index、ROM 与投影
ID/NO_ID、layout params/margins、两轮/下一 tick、旧代及回调失效零发布、畸形 parent 拒绝、
在树强边/脱树回收、pending request 不保活脱树，以及单独持 child 保活 parent/清 parent 可回收。
方向继承 fixture 显式打开真实 ApplicationInfo RTL 标志，让 root→Group→Group→leaf 的
getTextDirection/getTextAlignment 父查询实际执行；不靠默认禁用 RTL 避开父目标。

`hierarchy-{switch,threaded}.trace.json` 封存完整 method_enter；`runtime-targets.json` 将实际
进入签名与 dispatch ledger 全目标集合及最终表面交叉核对，记录 ROM/overlay 状态和次数。
支持路径未实现记账为0；动画拒绝、raw allocation 等故意负对照使用独立 ledger。
逐目标完整列表与方法/字段迁移差分分别见 `runtime-targets.md`、`migration-ledger.json`。
