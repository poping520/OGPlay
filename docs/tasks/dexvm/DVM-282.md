## 状态与字段账

- View.mViewFlags 的 visibility（0x0c）、enabled（0x20，零为 enabled）、clickable（0x4000）、
  longClickable（0x200000）、focusable（0x1）、focusableInTouchMode（0x40000）由原版
  setFlags/setter 唯一写入；getter 执行 ROM。宿主只保存不可变投影，不从 UiNode 回写。
- View.mListenerInfo 及 ListenerInfo 的全部 On* 引用由 ROM setter/getListenerInfo 保存，
  是正常 Java GC 强边。integration 通过绑定 token 读取 click/touch/longClick/focusChange，
  不写 Legacy 的 ui_click_listeners/ui_touch_listeners 或 focus_listener 表。
- View.mPrivateFlags 的 PFLAG_FOCUSED 与 ViewGroup.mFocused 的转移、父链、清除及查询全部
  沿 ROM；宿主无第二个焦点 owner。InputMethodManager 每次操作从 Java findFocus 捕获候选。
- 新开放 View.mDrawingCache/mUnscaledDrawingCache 与 Group.mCurrentDrag；初始化均为真实
  VM null，绘图缓存原版回收路径保留，非空 drag/transition 的服务接缝拒绝。
- UiProjectedNode 批次可携 enabled/clickable/focusable/touch-mode；Java collector 必填，和
  visibility/hierarchy/geometry 同事务发布。ui 不获 Java 引用，ExternalProjection.RequestFocus
  明确抛错，测试断言 UiTree.Focused 始终为空。

## Adapter review

| 接缝 | 实际 owner、输出与拒绝范围 |
| --- | --- |
| AccessibilityManager.getInstance/isEnabled | 仅实验表组合；测试必须显式配置 disabled provider。ROM clinit 唯一初始化，Java sInstance 保存 singleton，mIsEnabled 显式初始化 false 并为查询唯一来源。无 Binder、伪 AttachInfo 或系统订阅者；未配置记账抛 UOE，其余 manager API/构造器 failure，不宣称完整服务构造 |

| drawableStateChanged | refreshDrawableState、Group.drawableStateChanged 与父 childDrawableStateChanged 为 ROM，保留应用虚派；base adapter 仅真实无背景的软件路径，已有背景及系统状态拒绝；不缓存 drawable state 权威 |
| onCancelPendingInputEvents | cancel/dispatchCancel 为 ROM，保留应用覆写及 CALLED_SUPER 检查；base adapter 写 Java PFLAG3_CALLED_SUPER，清当前子树的单目标捕获。延迟 click/long-press 执行器不在支持范围 |
| clearAccessibilityFocus | 只允许实际无 accessibility focus、无 AttachInfo 的测试状态；已有状态记账拒绝，无虚假系统全局焦点清理 |
| initialAwakenScrollBars | 附着态 scrollbar 服务始终记账抛 UOE；ROM onVisibilityChanged 在真实 null AttachInfo 路径不调用它 |
| Group.onChildVisibilityChanged | 实际 transition/currentDrag 都为 null 才走原空路径；非空记账拒绝 |
| View/Group.dispatchTouchEvent、View.onTouchEvent | 复用 integration 单目标、不 split 协议，enabled listener 优先；click/touch 从 Java 强边读取，回调后复核实际 Java flags/root。无完整 ROM touch 状态机、长按计时器或 split 扩展 |
| Group.cancelTouchTarget | 原 Java touch target 必须真实 null；同时取消被移除子树的 integration 捕获，不另建 Java touch-target 镜像 |

BeforeInput 仅在测试容器 owner 线程执行同一遍历/投影入口；detach 清捕获，换根/隐藏/禁用
在下一受检发布清捕获。输入重入尚未完成的 traversal 记账拒绝，不读取旧 epoch 冒充当前状态。
