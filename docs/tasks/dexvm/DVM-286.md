## 契约与边界

loader 的 CompiledXmlDocument 拥有输入 bytes，只发布 const ownership 和 const view。
保留 string pool 原索引与按需受检 WTF-8 转换、resource map、节点类型/line/comment/
namespace、文本 typed value、属性 typed size/reserved/type/data 与 raw 索引。缺席索引、
有效空串、非法索引和转换失败分别可辨；resource ID 只取 resource_map[name_index]，
同名不同 namespace 不合并。start/end 双向关联，parent_node 指向父 START 节点。

id/class/style 保留原始一基索引，零为缺席，不按属性名重建。loader 不增加布局默认值、
主题值、资源解引用或属性消费语义。新接口对不支持的 chunk/位置、非法引用/特殊索引、
越界、未闭合/错配标签及 namespace 明确失败；原始 bytes 保留扩展数据与字符串池。

integration 的 XmlCursorRegistry 为 DexVmAndroidContext 独占，在 VM 锁下访问；
document token 与 cursor token 分型，32 位非指针 ID 跨 context/生命周期不复用，
耗尽抛 overflow_error。当前状态初始 START_DOCUMENT，Next 前进至 START/TEXT/END，
namespace 节点内部跳过；END 事件仍保留标签深度，下一事件才降低。
Current/StartTag/Attribute/FindAttribute 均验证活 token；属性查询要求当前 START，
namespace 查询用 nullopt 区分缺席与池中空 URI。查询返回快照或不可变文档所有权。

Close 立即撤销 parser；RetireOwner 同时撤销其所有 parser；Shutdown 清零并拒绝新创建，
bridge teardown 显式调用，context 析构也释放 registry。非法/旧/跨 context token 为
invalid_argument，非 START 查询为 logic_error，属性越界为 out_of_range。
本单无 guest native、无构造/Theme/applyStyle 准入、无 inflater 切换；guest owner/GC
绑定及 native 异常翻译留 09a-2。未调整任何组合/准入审计规则。

baseline-fields.json 由 HEAD 旧解析器源码独立编译同一 fixture 生成，逐字段比较。

| 输入事实 | 验证 |
| --- | --- |
| 同名 same，namespace urn:a/urn:b；名称与 ID 故意不同 | 原 pool index、namespace 与 resource map ID 分别断言 |
| REFERENCE/ATTRIBUTE/DIMENSION/INT/BOOLEAN/STRING/@null | 原 type/data/size/reserved 逐项断言，不做属性语义推导 |
| raw 缺席、raw 空串、typed string 空串 | raw_index 与 typed data 独立；Legacy 仍保留 typed-string fallback |
| UTF16 孤立高/低 surrogate，UTF8 WTF-8 | code-unit 投影及 pool identity 原样往返；未用坏串不拒包，访问明确失败 |

| 非法 pool/special 索引、越界 chunk/stride、坏节点/namespace | 确定异常类型/消息，不以空事实替代 |
| 两 parser、close/旧 token/跨 context/owner 退役/Shutdown/析构 | 独立推进；owner 退役和 teardown 活跃 cursor/document 均为零 |

坏字符串 fallback。逐字段核对 Elements 的 name/parent/id/width/height/gravity/
layout_gravity/padding_top/src、每个 attribute 的 namespace/name/type/data/raw，
以及 PullEvents 的 type/name/text/depth，未修改生产 BootDex 字节。
