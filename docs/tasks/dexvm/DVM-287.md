review 依据 AOSP4.4 `android_util_XmlBlock.cpp`、ResourceTypes.cpp 的 ResXMLParser、
XmlBlock.java/StringBlock.java，与固定 ROM 方法体核对；不引入宿主地址或系统对象。

| 接缝组 | 输入/输出与 owner/失败边界 |
| --- | --- |
| Create/Destroy | 受检 byte slice→强类型 document 或独立 pool token；ROM 字段保存逻辑 ID。无效 slice/畸形数据抛异常，旧 token 不复用，跨 context/种类拒绝；destroy 必须 live |
| CreateParseState/Next/DestroyParseState | live document→独立 cursor；只推进 start/text/end，namespace 内部跳过。Java 管理事件/depth/关闭计数；旧 cursor 明确失败 |
| GetStringBlock/Size/String | document 借用池与独立池分型；索引→原 WTF-8 字符串，未解引用资源；无效索引抛 IndexOutOfBounds，失效池抛 IllegalState，任何含样式池记账/UOE |
| Name/Namespace/Text/Line | 当前节点的原 pool index/line；节点种类不匹配按 AOSP 返回 -1，START_DOCUMENT line=-1；活 token 检查先于 sentinel |
| Attribute* | 当前 start-tag 的原 namespace/name/raw/type/data/resource_map 值；有效 token 上非法属性按 AOSP 返回 -2/-1/0，由 ROM getter 转成异常/默认值；这些是源码规定的 sentinel，不是未实现成功 |
| Id/Class/Style/Index | 只用原一基特殊索引，Id/Class 返回 raw index；Style 只接受 REFERENCE/ATTRIBUTE；Index 精确匹配 namespace 的缺席/空串/实际 URI 与 UTF-16 name，不按 resource ID 猜属性 |

StringBlock.get 的原版体无条件调用 nativeGetStyle，因此本批使用受审 plain-string adapter；
缓存仍仅在原 Java mStrings/mSparseStrings，稀疏阈值250、重复读取身份、Java GC强边保持。
缓存命中也验证 token/索引/无样式边界；nativeGetStyle(II)[I 未获批准，直接调用按ADR-0147
记账失败。样式 helper 与 StyleIDs 不启用，不把 span 当普通字符串成功；保守拒绝整个含样式池。
构造和 StringBlock.finalize 走 ROM，mOwnsNative 区分独立池和 XML 借用池。

AssetManager.openXmlResourceParser 的 `(String)`、`(int,String)` 两个普通 adapter 是等价
APK打开入口：只接受当前 APK 的 res/路径及 cookie0/1，读取原 bytes 后执行 ROM byte[]构造、
newParser、block.close。系统 AssetManager/cookie、缺失/非法路径明确失败；没有准入
openXmlAssetNative 或 AssetManager整类组合。Resources.getXml/inflater不改，Theme、TypedArray、
applyStyle/retrieveAttributes、控件属性构造留09a-3/4。

## Parser 语义与源码期望

合成VD09A1事实 fixture 扩一项FLOAT，期望来自 XmlBlock.java/ResXMLParser 原逻辑，
不以Legacy输出作ROM oracle；两解释后端执行真实ROM字节码并检查method.code。

| 判据 | 源码推导及断言 |
| --- | --- |
| next/event/depth/line | 第一次next返回START_DOCUMENT，之后root START深度1/line41，child START深度2，TEXT深度2/line43，END child仍2，END root仍1/line49，下次END_DOCUMENT深度0并自动close；两个parser独立 |
| name/namespace/text | root/urn:a，TEXT返回raw且name=null；非namespace返回空串，未开始line=-1 |
| 属性身份 | same在urn:a/urn:b分别查询；resource map故意与名称不同，两个NameResource都只取原0x01010002 |
| raw/typed | REFERENCE无raw转十进制@2130772259；@null是REFERENCE0→字符串@0且ResourceValue为0；STRING无raw→TypedValue.coerceToString(TYPE_STRING)原样null，raw空串仍为空串 |
| Int/Boolean/Resource/Float | Int仅INT区间，Boolean仅INT区间的非零；Resource仅REFERENCE，ATTRIBUTE不冒充资源；FLOAT按0x3fc00000为1.5，非FLOAT原Java抛RuntimeException，不返回default |
| ListValue | STRING按typed data池索引匹配options，空字符串命中索引1；非STRING直接返回原data（-2），不使用default替代 |
| 特殊索引 | 不按id/class/style名字重建；raw缺席class=null；正对照raw-id/raw-class，Style为REFERENCE或ATTRIBUTE返回0x01010099，为INT返回0；显式@null返回0 |
| 关闭与退役 | Java close/重复close依原ROM幂等，纯Java getDepth/getEventType/next保留原语义；需要native状态的访问失败。重复nativeDestroy(ParseState)失败，旧token/真实跨context/document退役/池种类混用均失败 |
| StringBlock | pool索引/上下界/空串、UTF16与WTF-8孤立surrogate往返；dense/sparse缓存身份；缓存后销毁仍拒绝；nativeGetStyle及含样式池负对照失败 |
| GC/退出 | Java Parser→block→strings强边保活；原finalizer正常关闭，owner sweep兜底按live检查退役；借用池不得单独destroy；最终document/cursor/pool均零，Shutdown不再创建 |

“重复close均失败”与原ROM Java close的幂等行为不相容：本单遵循原字节码，确定失败边界
落实在重复native退役/旧token访问；不改写ROMclose。GC用例先清VM exit-result根，走原
RunFinalization再检查sweep，未把仍排队的finalizer误当泄漏。

Parser.require 为failure：其原字节码通过Parser持有接口静态TYPES字段，当前组合父成员检查器
不能解析此接口继承字段；该非本单验收成员未扩入支持路径。此处没有放宽规则、改DEX或伪造字段。
**按常设原则自行决定的审计范围调整：无。** direct/static/super/精确接收者、本类failure字段
与clinit规则均不变。支持路径动态未实现命中0，负对照另验且保留账目。
