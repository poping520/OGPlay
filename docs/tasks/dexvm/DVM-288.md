# DVM-288 / VD-09a-3 · 有界主题投影与 TypedArray ABI

状态：实现完成，验收结果见文末。类型：新能力（ADR-0160 第三步）。
前置：[DVM-286](DVM-286.md)、[DVM-287](DVM-287.md)；
决定：[ADR-0160](../../adr/dexvm.md#adr-0160)。证据目录：`.local/analysis/vd-09a3/`。
生产默认 Legacy；实验配对含本能力，控件属性构造（09a-4）与实验 inflater（09a-5）不在本单。

## 固定输入与原阻塞

原预检发现 values 中114个 Theme/Theme.* 中22个没有固定 ROM R.style 字段绑定。
这不证明资源不存在，也不能据源码分配顺序猜私有 ID。原停止分析见证据目录的
`input-preflight*.json` 与原 `validation.json`；没有寻找或引入替代 ROM。
编排方2026-10-24决定已写入 ADR-0160 末节：只登记可证明名→ID的92个主题；
其余22个逐项列账，按名称请求明确失败并含“无 ROM ID 绑定”。其 XML parent 可按名称
参与合并，不需要其自身 ID；本批没有因 parent 需要 ID 而额外降级的主题。

生成器 `tools/bootdex/theme_projection.py` / `theme_inputs.py` 输入为固定
framework.jar、framework2.jar 与固定 AOSP `core/res/res/values/*.xml`。
`theme-projection-inputs.json` 固定全部输入哈希；不依赖宿主资源、aapt 猜号或手工数值表。
直接解码 ROM 的 R.attr/R.style 常量与 R.styleable 数组，逐项核对公开 ID、同名内部字段、
十组134槽的名称/index/ID；去重128个属性。私有 foregroundInsidePadding 仅由原数组证明。
missing-rom-style-field 使该主题不登记；public-id-mismatch、数组/输入哈希不符及别名冲突
仍拒绝整个构建。生成器按 XML parent/name 完成有界合并后才决定属性三态。

## 制品与查询所有权

输出为确定性 canonical JSON：schema `ogplay.bounded-theme`、version1/API19/values，
含全部输入哈希、逐槽验证、92个已登记与22个未登记主题及原因、每主题128个属性三态。
计数为确证缺席11130、已知值462、不支持184。基础 Theme/Holo/DeviceDefault 的七项 scrollbar
属性为250、300、10dip、两个不支持 drawable 和两个已知 @null，其余登记属性确证缺席。
派生主题按各自 XML 内容合并，不能套用基础主题的缺席结论。

theme entry 为 `META-INF/ogplay/theme-projection.json`，随实验 BootDex 封存，实验 manifest
记录独立 entry/schema/version/hash；生产 `data/android/19/manifest.json` 的独立
`boot_dex.experimental_theme_projection` 记录实验域、制品及输入策略哈希，生产 JAR 不含该 entry。
ADR-0077 小型系统资源仍走既有独立查询入口；构建检查 name/ID 所有权冲突即失败。

复现入口（生成过程内部亦做两次生成比较）：

## 宿主状态与 native review

ThemeResources 由 integration context 独占，强类型32位 ThemeToken 不含宿主指针、永不复用；
VM锁串行访问，copy 独立，force=false 保留已有值，force=true 覆盖并合并配置 flags。
APK style bag 经 loader ARSC reader，原 parent/type/data/typeSpec flags/density/字符串池索引
保留；parent/reference/?attr 链有64步上限和循环检查。Theme/AssetManager GC sweep 不引入强根，
delete/destroy/Shutdown 退役 token。跨 context、旧 token 或不匹配 owner 明确失败。

`view-theme-sources.json` 逐签名封存 review：本批批准14个 AssetManager native（13个新接缝，
另将既有 list handler 纳入原 ROM native 签名批准），加上 DVM-287 的25个，阶段累计39个。
新增四类组合238个方法/85个字段（323行）：56个 ROM 方法、34个 overlay、148个 failure；
57个 ROM 字段、28个 failure 字段。原 DEX 方法体与 flags 不改，非活动字段保持布局并明确失败。
既有 selector 随资源接缝新增可达的 AssetManager$AssetInputStream 与 IconPackHelper 三个类
一同加入实验闭包，仅保留原版 Java，不新增其 native 或成功功能声明。

| 批准签名（AssetManager） | 输入、输出与 owner / 失败边界 |
| --- | --- |
| `newTheme()I` / `deleteTheme(I)V` | 当前 APK owner；创建/退役 token，错误 owner、旧 token 失败 |
| `copyTheme(II)V` | 两个活 token；复制独立快照，跨 context 失败 |
| `applyThemeStyle(IIZ)V` | 活 token、登记/应用 style、force；原值合并，未知/循环失败 |
| `loadThemeAttributeValue(IILandroid/util/TypedValue;Z)I` | 原 TypedValue 六字段；有值 block0、确证缺席-1；不支持失败 |
| `applyStyle(IIII[I[I[I)Z` | theme/XML token、默认 style、受界数组；原六槽与 indices，发布前验证容量 |
| `retrieveAttributes(I[I[I[I)Z` | APK owner/start-tag；只取 XML/资源，token/容量非法失败 |
| `init(Z)V` / `destroy()V` | APK owner 生命周期；isSystem=true、重复初始化/销毁失败 |
| `getStringBlockCount()I` / `getNativeStringBlock(I)I` | 真实 APK 原池0/1；非零池索引或无池失败，不合成系统池 |
| `loadResourceValue(ISLandroid/util/TypedValue;Z)I` | APK scalar、density override=0、resolveRefs；原字段/block0，非零 override/未知/文件资源失败 |
| `loadResourceBagValue(IILandroid/util/TypedValue;Z)I` | 已登记/应用 bag、attr、resolveRefs；父链合并原值/block0或-1，不支持失败 |
| `list(Ljava/lang/String;)[Ljava/lang/String;` | 保留既有 APK asset 目录枚举 handler；非主题功能，无新增算法 |

普通 AssetManager 构造 adapter 初始化原 mOpen/mNumRefs/mValue/mOffsets；makeStringBlocks
绑定实际 APK 原池与 ROM StringBlock。Resources 应用对象工厂初始化原 mAccessLock/mMetrics；
clinit、Theme/TypedArray 构造、缓存及 recycle 执行 ROM。资源池 context 持有至 Shutdown，
StringBlock 为借用 owner。固定配置沿已有 ARSC table 选择，不宣称动态 locale/density qualifier。
DVM-287 的 openXmlResourceParser 普通 APK adapter 沿用，openXmlAssetNative 仍 failure。

## AOSP 优先级与失败边界

| 层级 | 实际选择与对照 |
| --- | --- |
| 1 显式 XML | 优先于所有 bag/theme；原池字符串 cookie=-1 |
| 2 XML style | 原 style index，支持 ?attr 找 theme 中 style reference |
| 3 默认 style | 非零 defStyleAttr 找到 reference 时替代 defStyleRes；未替代时沿 defStyleRes |
| 4 theme 同名 attr | 无较高层值才取 theme；?attr/reference 按原链解引用 |
| null | 原 TYPE_NULL 继续回退；REFERENCE0 在选择后转 TYPE_NULL，遮蔽低层 |

六槽为 type/data/assetCookie/resourceId/changingConfigurations/density；APK pool cookie=1。
保留 AOSP block 在属性迭代间的延续；indices[0] 为非 null 数，后续为原请求下标。
retrieveAttributes 不读取 style/theme，?attr 保留类型而不套 theme。原 ROM
selectDefaultTheme 按 targetSdk（10/11/14）选择 Theme/Holo/DeviceDefault。

未知主题/属性、无 ROM ID 绑定、未支持 projected drawable/selector/ninepatch/animation、
资源文件、带样式字符串池、未知 typed value、循环/深度、系统 AssetManager 与非法 ABI
均按 ADR-0147 记账并明确失败。不将不支持当缺席，不生成空 Drawable 或颜色列表。
TypedArray getDrawable/getColorStateList/getTextArray 仍 failure；不引入完整 TextView/System 服务。
