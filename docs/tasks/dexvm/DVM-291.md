# DVM-291 · VD-10a-1 纯叶测量服务与 line-plan

状态：实现与沙盒 CPU 判据完成；GPU/九场景/Windows 交编排方外验。

## 范围与纯接口契约

依据 [ADR-0161](../../adr/dexvm.md#adr-0161) 和
[VD-10 报告](../../../.local/analysis/vd-10/REPORT.md) §2、§3、§7。

- `ui_leaf_measure.h` 独立提供 Size/Insets/MeasureSpec、固定字体测量/换行声明与
  `MeasureTextLeaf(const TextLeafInput&, width, height)`、`MeasureImageLeaf(...)`。
  输入仅为文本、px 字号、固定字体四样式/固定 API19 fallback、行策略、四槽 compound、
  padding/minimum/intrinsic 值；const 输入不会被改写，无 children/tree/node/VM 依赖。
- 输出为 desired/constrained size、每轴 AT_MOST 截断的 TOO_SMALL 位、baseline 缺席与可选
  `shared_ptr<const TextLinePlan>`。这是有界 fixed-cell 服务，未实现 Android baseline、完整
  TextView measured-state 组合、shaping/bidi/StaticLayout；不把缺席 baseline 伪造为0。
- line-plan 冻结实际行文本、字号/样式/fallback 与 metrics，DrawText 携带 plan 时直接使用
  这些值，不重新换行/测量。空串 desired 仍占历史 M cell，plan 为空文本，不绘制 M。
- image/intrinsic 使用原 intrinsic+padding/minimum+Clamp 规则，不新增比例或 scaleType 算法。
  Legacy Measure 调纯服务取 desired，再自行合并容器结果并写 node.measured。
  纯函数不写 geometry，不执行 Java、不创建临时树。
- 固定字形表、MeasureFixedText、WrapFixedText 从 renderer 原样移至纯服务实现；renderer
  通过内部字形声明复用同表。UiFallbackFont 实现与固定 payload 身份保持。
- 不开放 Java 构造/onMeasure adapter，不扩大 JavaTraversal 成功面。
  loader/integration 契约未变化，MODULE 不作无关同步；ui MODULE 更新纯值接口边界。
  capabilities 只更正既有条目对 Legacy 共用换行的过度描述；CURRENT 无运行状态变化，不修改。

## Legacy 不变与 line-plan 差异账

Legacy 显式选择 `TextWrapWidth::LegacyPadding`：仍只从 spec 扣 padding；原 renderer 仍从
最终 frame 扣 padding 与左右 compound，再换行。新服务默认 CompoundPadding，并直接消费
同一 line-plan 光栅；本单不将统一公式接入 Legacy，不宣称 Legacy 已同断行。

回归输入：8px、`HI HI`、maxLines=3、padding=(1,2,1,2)、左右各6×7、AT_MOST32。

| 路径 | 行文本 | desired | constrained |
| --- | --- | --- | --- |
| 原 Legacy / 提取后 LegacyPadding | `HI HI` | 43×11 | 32×11 |
| 新服务 CompoundPadding | `HI\nHI` | 25×19 | 25×19 |

该差异覆盖四槽尺寸贡献之外的真实换行变化。AOSP 4.4.4_r2.0.1 本地
`TextView.java:6380–6395` 的 want/布局宽度扣 getCompoundPaddingLeft/Right；新服务按此
可用宽度方向实现，保留已有有界按词算法，不声称完整 ROM 等价。留待 **10a-4** 决定 Legacy
迁移与最终 frame/spec 不同的情况，届时需结合九场景差分，不能在本单静默改变。
