# DVM-293 / VD-10a-P · TextView clinit 有状态 Paint 前置

状态：沙盒实施与CPU判据完成；GPU/九场景/Windows交编排方外验。
依据 [ADR-0161](../../adr/dexvm.md#adr-0161)、[DVM-291](DVM-291.md)、
[DVM-292](DVM-292.md)。证据：`.local/analysis/vd-10ap/`。

## 范围与迁移账

仅固定实验 JavaTraversal 配对替换 Paint、TextView、RectF 和 RectF$1 的行为来源；
生产仍为 Legacy。原 ROM shape/clinit 与未启用方法形状完整保留；原方法体不改写。
完整逐签名 flags/hash、字段初始化与 adapter review 见
[view-paint-sources.json](../../../tools/bootdex/view-paint-sources.json)。

新增组合形状共715成员（553方法/162字段）：5个ROM方法、15个overlay、533个failure。
15个adapter中5个启用原ROM native声明；新增native声明0个。

| 迁移 / adapter | 输入、状态归属、输出与审查 |
| --- | --- |
| TextView.<clinit> | 原ROM真实构造RectF、空SpannedString、Paint、BoringLayout.Metrics；执行setAntiAlias(true)、measureText("H")，不跳过未使用结果 |
| RectF.<clinit>/<init>、RectF$1.<init> | 原ROM执行Creator创建及真实Java零初始化；不提供Parcel协议 |
| Paint.<clinit> | 原ROM初始化Style/Cap/Join/Align数组；复用已准入原版enum |
| Paint两构造 | 每实例flags=(输入或0)\|0x500、textSize=12px、Java mTypeface=null；flags/size由实例拥有的宿主测量状态维护，无native指针 |
| get/setFlags、is/setAntiAlias | flags仅支持0x501位集；antiAlias位真实保存、互不串扰；固定cell测量无抗锯齿advance差异 |
| get/setTextSize | 有限1..128px，范围外明确失败；固定cell服务按既有字号量化计算 |
| get/setTypeface | 原ROM mTypeface为唯一Java强边；setter返回传入引用，style沿原Typeface查询；无另一份Java引用侧表 |
| finalize | 释放同一实例测量状态，并精确调用Object.finalize；原native finalizer(I)保持failure，不伪造Skia指针或资源 |
| measureText四重载 | String全串、String[start,end)、char[index,count)、CharSequence[start,end)；按实际字符切片，最多1024 UTF-16单位；返回纯服务MeasureFixedText真实宽度 |

空SpannedString/SpannableStringInternal、BoringLayout.Metrics/FontMetricsInt及Paint枚举复用
现有已准入ROM字节码，不新增空对象桩或native。TextView所有构造和实例字段仍failure；
完整TextPaint/Layout/Editor不开放。实验catalog不再声明Legacy TextView额外mTypeface，
Legacy Paint/Typeface/TextView原handler保持。实验EditText同步撤下Legacy getText服务，
避免在未开放的Editor边界以继承handler取得信用；不改变Legacy EditText。

字体为DVM-291同一固定5x7与UiTree已注入的受信API19 fallback对象，不读取宿主字体。
字集上限为可打印ASCII与基本CJK（仍须纯服务或固定fallback真实提供字形）；不支持字形、
换行、代理对、combining/bidi/shaping明确失败并记账。无完整Android/Skia宽度等价承诺；
空串宽度真实为0，H非零；不是以Legacy空串占位M冒充Paint测量。
shader/path effect/mask filter等未选方法均沿ADR-0147失败，包括传入null。
不支持flags/字号/字形/长度记入dexvm.paint_measure；非法null/range沿Java参数异常。
失败不发布测量计数/宽度，保留此前状态；真实finalize、GC sweep及teardown退役每实例状态，
Typeface通过普通Java字段保活，无全局强根。

保留的未启用ROM方法体按ADR-0155额外需要20个可准入纯Java helper，详见
compose_bootdex.py的固定实验集合；原算法不改写，不据此开放完整Editor/TextView。

## 审计规则与契约

**按常设原则自行调整审计范围：无。** clinit及传递闭包、direct/static/super/精确接收者、
本类failure字段全部沿原规则。未修改selector/member_sources审计或ADR-0147。
新RectF$1仅准入真实构造，其他方法failure，不以ParcelableCreator形状冒充Parcel能力。
loader使用已有封存来源协议，接口与不变量未变化，因此不改loader MODULE；
integration契约增加测量状态owner与GC退役。CURRENT增加0字节。

## 判据与验证

改动前复制build/release/ogplay_tests与生产BootDex至baseline-bin，哈希见baseline-sha256.txt。
基点CPU主题148项：143通过、5项既有失败（均Rect.clinit→Pattern.compileImpl缺JNI bridge）：
ViewGroup child access；DVM-247 public inflate；DVM-245 Window append；APS-11 SurfaceView；
managed dynamic SurfaceView attach。完整名称和失败栈见baseline-tests.log。

- 双后端：原ROM TextView clinit与依赖构造轨迹、H调用一次与12px纯服务结果一致、
  非零宽度、重复初始化不重复测量；两个Paint字号/AA/flags/typeface互相隔离。
- 重载：String切片、char[] count、真实StringBuilder CharSequence、空串、CJK fallback和normal/bold-italic样式。
- 负对照：分别撤销构造、setAntiAlias、measureText批准，由实际组合validator的严格clinit闭包拒绝；
  shader/path effect/mask filter、shaping、不支持字形、越界/超长、非法flags/字号明确失败。
- 支持路径ledger未实现命中0；TextView构造负例在该检查之后执行。
- 实际结果见下方；不将CPU通过当作游戏兼容验收。

Paint 具有真实 ROM finalize 声明，GC 首轮会排队而不立即回收。新增回归调用
RunFinalization 后再收集，验证有根实例及Typeface保留、无根实例测量状态退役；
不放宽或绕过GC/终结规则。adapter surface 从同一ROM DEX的诊断配对导出，
仅将已绑定finalize标记为overlay以观察实际handler（未执行），其余native failure保留；命令及归档在证据目录。
默认12px另核对固定API19 SkPaintDefaults.h，来源及哈希见source-review.json。
