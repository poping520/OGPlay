## 迁移与 adapter review

新增组合成员5（完整 ROM Button：方法5、字段0），三个构造为 rom，两个 accessibility
覆写为 failure；原 flags/body/hash 不变，无 clinit（rom-absent）。新增 adapter1、native0（继承的 TextView.onFocusChanged）。
逐成员来源见 [view-button-sources.json](../../../tools/bootdex/view-button-sources.json)，
固定源码/ROM身份和计数审查见 `adapter-review.json`、`source-review.py`。

- Context→两参→三参，原 ROM 常量 buttonStyle=0x01010048，三参将调用方 defStyleAttr
  原样传入 TextView；未改为0，无 Button 构造 overlay。
- 继承既有 TextView 构造、字体/文本/compound与 onMeasure adapter；View 的 ROM
  measure/cache/layout、listener/focus 保持原有协议。plain 文本的 onFocusChanged 受审接缝执行真实 View 父协议；
  不创建 Editor/spans/marquee/transformation，不赋予原 ROM TextView 焦点体实现信用。文本仍只有宿主输入一个 owner，
  Typeface/compound 身份沿已有 View adapter trace/sweep，几何仍由 Java 唯一拥有。
- 初始化类型守卫与完整 epoch 文本 line-plan 投影接纳 Button。实验路径明确排除 UiNode
  的 Legacy Button 默认背景、padding、clickable、maxLines及固定 Widget.Button 投影。
  构造真正解析出的值随后沿原 TextView/View 服务生效，Legacy 分支保持原值。
- loader 仍消费原成员来源协议，没有接口/不变量变化，故不修改 loader MODULE；
  integration MODULE 更新上述 owner及复用边界。CURRENT增加0字节。

## 默认消费闭包与失败边界

`default-button-consumption.json` 保存来自实际配对投影的每个 styleable 查询、来源及
?attr解析链，按 View→TextViewAppearance→TextAppearance→TextView→View 顺序逐项裁决。
Theme=0x01030005，buttonStyle→Widget.Button=0x01030014；
Widget.Button 的 textAppearance→?textAppearanceSmallInverse→TextAppearance.Small.Inverse。

| 实际请求 | 裁决 |
| --- | --- |
| scrollbarThumbHorizontal/Vertical→scrollbar_handle_horizontal/vertical | 未支持系统 Drawable，明确失败；不因scrollbars未启用而删除查询 |
| background→@android:drawable/btn_default（selector下含ninepatch） | 明确失败，不展开系统皮肤、不以Legacy九宫格像素支持冒充Java对象协议 |
| textColor→@android:color/primary_text_light；appearance textColor→?textColorSecondaryInverse同值 | stateful系统色资源明确失败，不取默认色或降为null |
| Widget.Button gravity=center_vertical\|center_horizontal；appearance textStyle=normal | 当前生成投影对这些源码符号值标unsupported，保留明确失败，不猜数值补丁；应用显式整数可遮蔽 |
| Theme选择句柄、编辑弹窗layout等非空请求 | 沿既有边界明确失败；需要应用显式@null覆盖，不静默过滤 |
| textSize、focusable/clickable、纯色/单态色、支持字体及绝对compound | 沿已验收TextView/View消费；保留显式XML > XML style > defStyleAttr > theme |

原始Theme构造首先失败于scrollbar_handle_horizontal；应用遮蔽滚动条后失败于btn_default；
再用显式style遮蔽background、gravity、appearance后仍失败于primary_text_light。
显式受支持应用主题/style通过构造、测量、focus/click及compound。
两 accessibility 覆写及所有未迁移 TextView/Drawable 成员仍按 ADR-0147 记账并失败；
支持 fixture 明确禁用 accessibility，不能据此宣称完整系统附着/字体/状态皮肤可用。
