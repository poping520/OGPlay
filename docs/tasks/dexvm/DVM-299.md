# DVM-299 / VD-10b-1 · ScrollView ROM 形状与构造接缝

类型：新能力，实验配对构造范围；生产默认仍 Legacy。
依据 [ADR-0161](../../adr/dexvm.md#adr-0161)，前置
[DVM-283](DVM-283.md)、[DVM-289](DVM-289.md)、[DVM-295](DVM-295.md)。
证据：`.local/analysis/vd-10b1/`。不启动完整 APK、不运行 GPU、不执行 git commit。

## 迁移、adapter 列账与 review

[view-scroll-sources.json](../../../tools/bootdex/view-scroll-sources.json) 封存两类完整 ROM
形状、原 flags/body/hash、逐字段初始化策略及 failure 来源；每类只有一个 class_def。
固定输入两类均无 clinit，owner 为 rom-absent，不添加空初始化器。
另收录水平 SavedState 及其 Creator 两个原 ROM 声明依赖，满足 disabled body 的 closure；
Scroll 保存/恢复入口并未开放。新增组合成员183（135方法、48字段），adapter4，native0。
共享 View.getOverScrollMode、setWillNotDraw、willNotDraw 升级为 ROM，其余 View 形状不变。

| 类 | ROM / overlay / failure 方法 | 字段 |
| --- | --- | --- |
| ScrollView | 8 / 2 / 58 | 完整25字段；EdgeGlow、SavedState、VelocityTracker 为 failure |
| HorizontalScrollView | 8 / 2 / 57 | 完整23字段；EdgeGlow、SavedState、VelocityTracker 为 failure |

两类各8个 ROM 方法：三个构造、fillViewport 与 smoothScrollingEnabled 的 getter/setter、
requestLayout。ROM 构造实际执行 FrameLayout 属性构造、new Rect、layoutDirty=true、
smoothScrollingEnabled=true、activePointer=-1、其余原零/null 默认；无宿主几何回填。
requestLayout 只沿原父协议更新 Java 请求标志，不开放 onMeasure/onLayout。

四个逐签名受审 adapter 为两类各自的 initScrollView()V、setOverScrollMode(I)V。
review 固定在来源表及 `adapter-review.json`：

- 只支持真实主题解析所得的显式 overScrollMode=never。setter 委托真实 View 父协议；
  默认/always/ifContentScrolls 需要 EdgeEffect 的系统 overscroll_edge/glow Drawable，
  记账并明确失败。EdgeGlow 字段保持 failure，不写 null 冒充 ROM 初始化。
- init 从实际 Context.getResources→getDisplayMetrics/getConfiguration 读取 density 与
  screenLayout。按固定 ViewConfiguration:276–340 推导 touchSlop=round(8*density)、
  minimum/maximumVelocity=round(50/8000*density)、overscroll=0、
  overfling=round(6*sizeAndDensity)；XLARGE 的 sizeAndDensity=1.5*density。
  touchSlop 的8dp来自已有哈希封存 config.xml；不把 deprecated 无 Context 构造当设备配置。
  不创建不完整 ViewConfiguration，不声称支持其 WMS/menu/cache 查询；无资源 overlay 能力。
- 真正执行 ROM OverScroller(Context) 及两个 SplineOverScroller(Context)，保留 clinit
  spline 表、finished=true、物理系数和 Java 强边。不得用空对象/空字段声称动画初始化成功。
  adapter 仅写五个配置字段及 mScroller，并调用 Java focus/descendantFocus/willNotDraw 协议。
- fillViewport 包括 null attrs 仍沿 ROM obtainStyledAttributes/getBoolean/recycle，保留
  scrollViewStyle=0x01010080、horizontalScrollViewStyle=0x01010353 和调用方 defStyleAttr。
  AOSP 两组 styleable 均只有 fillViewport；smoothScrollingEnabled 没有 XML 槽，
  真实语义是 ROM 默认 true 与 getter/setter，不虚构属性解析。

## 失败边界与审计决定

fling、smoothScroll、overscroll glow、scrollbar Drawable、非空 SavedState、focus 驱动滚动、
本类 onMeasure/onLayout/滚动输入继续按 ADR-0147 明确失败。默认主题可能先因实际
scrollbar 请求失败；应用可显式 @null 遮蔽，不能删查询、偷改 defStyleAttr 或默认启用 never。
本单不开放布局/滚动投影，Java mScrollX/Y 唯一 owner 不变，后续交10b-2/3。

**按编排方常设原则自行调整审计规则范围：无。** 未改 selector/member_sources/clinit 规则，
未放宽 ADR-0147。原 validator 的正例及撤销 direct 依赖、adapter review 的负例见
`negative-check.log`。loader 的来源协议与接口没有变化，故无需修改 loader MODULE；
integration MODULE 更新构造/配置/失败契约。capabilities 新增 partial 构造项；CURRENT增加0字节。

## 判据与验证

改动前复制 ogplay_tests、生产 BootDex 与实验配对至 baseline-bin，身份见 baseline-sha256.txt。
CPU基点169项164通过、57729断言全通过；5项既有 Rect.clinit→Pattern.compileImpl 缺 JNI bridge。
