## 迁移与逐签名 review

`view-scroll-sources.json` 保留两 Scroll 的完整 ROM shape/hash，新增 EdgeEffect 的完整
成员来源；`view-measure-sources.json` 登记 View 直接依赖与通知接缝。实验 DEX 原始字节码
不改写；生产 BootDex 要求与冻结基点逐字节相同。

纵向 ROM：onMeasure、measureChild/WithMargins、四个 addView、requestLayout、onLayout、
onSizeChanged、scrollTo/clamp，及 isViewDescendantOf、scrollToChild、isWithinDeltaOfScreen、
doScrollY 直接依赖。FrameLayout 真实调用 child measure/layout，纵轴先 UNSPECIFIED；
fillViewport 补测高度只扣 padding，宽度补测也不扣 margin，严格保留 API19 原式。
View 的 scrollBy、scroll getters、isLaidOut、postInvalidateOnAnimation、awakenScrollBars
执行 ROM。mScrollCache 的真实 null 初始状态可用，不创建滚动条对象。

| adapter | 输入与输出、owner、失败边界 |
| --- | --- |

纵向 setOverScrollMode 升为 ROM，保留默认/always/ifContentScrolls 的真实 EdgeEffect 身份。

## 投影与输入契约

View.mScrollX/Y 是唯一位置。新增两个受绑定的只读 token；本单 collector 只提交纵轴。
`screen(child)=screen(parent)+local(child)−scroll(parent)`，clip/raster/hit 共用完整 epoch。
`ScrollAndroidViewBy` 验证 owner/已发布根内身份，经 Java scrollBy→scrollTo/clamp 后只发布
新投影；不调用 measure/layout/requestLayout，不写 child measured/frame。
宿主保留捕获/slop/delta，拦截时 CANCEL 单一旧目标；session 的位置写入仅在显式 Legacy
分支。`tools/check_ui_traversal.py` 检查该分支边界；Legacy 算法保持原式。

loader 的来源/调用/GC 协议不变，无 loader MODULE 契约改动；integration 与 session
MODULE 更新新增 owner 接缝。UiTree 投影算法复用既有契约，无 ui MODULE 变化。
CURRENT 增加0字节；capabilities 维护既有 partial 项。
新增组合成员63（EdgeEffect 11方法/52字段），新增 adapter5，native0；原纵向 setter
从 overlay 升 ROM，adapter 总量净增4。精确变更及输入哈希见 source-review.json。

## 失败边界与审计决定

水平布局、fling/smoothScroll、glow 激活/绘制、scrollbar Drawable、SavedState 恢复、
focus 驱动滚动及完整 ROM touch 分发继续明确失败。有限输入不触发 EdgeEffect pull。
不引入 WMS/Binder/system_server 或新时间源。

按编排方常设原则自行调整审计规则范围：**无**。未放宽 ADR-0147、clinit、精确调用或
failure 字段规则；原 validator 正例与撤销直接依赖/review 的负例保留。
EdgeEffect idle 接缝是编排方预先决定，非实施方审计规则调整。
