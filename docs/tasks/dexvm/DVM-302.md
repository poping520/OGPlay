## 迁移与 adapter review

新增6个完整 ROM 组合类、105个形状成员（50方法/55字段）、组合 adapter7、native0。
SurfaceView 与其五个内部类保留原 flags/body/hash/全部字段；无 clinit 的类保持 rom-absent。
两个活动 ROM 方法为 `onMeasure(II)V`、`isFixedSize()Z`，仅 mRequestedWidth/Height 字段可用。
内部类全部 failure，保留声明以满足未启用原方法体的闭包，不实例化匿名 WMS holder。
另由未改变的默认准入规则收录纯 ROM PixelFormat，闭合禁用方法体的引用。
唯一成员账为 [view-surface-sources.json](../../../tools/bootdex/view-surface-sources.json)，
逐项源码身份及审查见 `source-review.json`；运行表面封存于同名 surface。

| 受审接缝 | 输入、输出、owner 与失败边界 |
| --- | --- |
| 三构造（3） | 精确调用对应 View 构造，原样传 Context/AttributeSet/defStyleAttr，真实主题错误透传；初始化 Java 请求为 −1，真实 setWillNotDraw(true)，登记现有 managed holder；WMS/Handler/Surface 原实例初始化未启用的字段均 failure |
| setFrame（1） | 精确调用 ROM View.setFrame，Java 写 bounds/flags 并同步 onSizeChanged；返回真实父结果；不执行 ROM updateWindow 尾部，不制造 buffer |
| getHolder（1，复用既有服务） | 返回本代真实 managed holder，代内身份稳定；退役后按既有策略分配新 holder；不激活 Surface；ROM mSurfaceHolder 保持 failure，无第二份 holder 权威 |
| 两个 Z-order 方法（2，复用既有服务） | 写实际 UiNode.surface_layer，沿既有 compositor 语义；缺节点失败，不复制 WMS mWindowType、不承诺 WMS 重建 |
| 既有 holder 两方法适配（非新增 ROM/native 声明） | setFixedSize/setSizeFromLayout 在实验分支读取 Java 请求；双轴先验真实 managed buffer，改变才写两轴并真实 requestLayout；Legacy 保留原路径 |

实验 Impl 不声明 Legacy 请求字段；Java mRequestedWidth/Height 是请求唯一 owner。
宿主非正请求规范为 ROM −1（尤其 0 不能成为 ROM fixed=0）；正数只允许匹配当前真实
managed buffer 的轴。setSizeFromLayout 恢复双 −1；同值请求不额外触发布局。
ROM onMeasure 对非负请求使用 resolveSizeAndState，否则 getDefaultSize(0,spec)。

managed viewport、View local bounds/measured、holder surfaceFrame/真实 buffer、呈现超采样
像素是独立事实。setFixedSize 和 View 重排不发布 buffer/Rect；回调前仍只发布真实 managed
尺寸，Rect 为 holder 的 Java 强边，代内身份稳定，旧代保留末值。

## 失败边界与审计决定

不匹配正 fixed-size 在任何请求/flags/投影/frame 写入前按 ADR-0147 记账并抛 UOE。
WMS/updateWindow、attach 系统协议、独立 buffer resize、SurfaceFlinger、完整绘制/透明区域
及其余未选 ROM 成员仍明确失败；不引入 Binder/WMS/system_server。
端到端 size-before-Surface 与生命周期接入仍由 VD-11 收尾，本批只运行定向 holder fixture。
fixture 先执行真实 OwnerTick 发布几何，再在局部作用域使用既有重入调度 guard 隔离 holder
回调服务；不切换 geometry owner，不给仍关闭的 BeforeSurfaceCallbacks 遍历任何实现信用。

按编排方常设原则自行决定的审计规则范围调整：**无**。
direct/static/super/精确接收者、本类 failure 字段与 clinit 规则全部保持；撤销请求字段
可用性或构造 adapter review 均被实际 validator 拒绝，见 `source-validation.log`。
未修改 selector、member_sources 或 ADR-0147，ADR 无需规则修订。

integration MODULE 更新请求 owner/sentinel/buffer 接缝契约；loader、VM、ui 接口及不变量
未变，不修改其 MODULE。capabilities 维护现有 surface_view_lifecycle 的实验 partial 范围。
CURRENT 增加0字节，生产 BootDex 不变。
