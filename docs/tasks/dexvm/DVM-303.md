## 迁移与 adapter review

新增 ROM 组合成员0、受审 adapter1、native0。保留生产有界 VideoView 与内部
VideoMediaPlayer 的 Java 字节码及媒体 native owner，不迁完整 ROM VideoView shape。
既有 mGeneration 仅增加 bound token 读取，不新增 Java 字段或代际侧表。
唯一新增方法为实验 intrinsic override `VideoView.onMeasure(II)V`，逐签名 review 见
[view-video-adapter.json](../../../tools/bootdex/view-video-adapter.json)。
review 作为实验 JAR 的独立资源与 manifest 来源哈希封存，生产不含该资源。
runtime surface 保持真实 handwritten/intrinsic，同时明确标记
`implementation_source=adapter` 与 `adapter_review`，不授予 ROM 算法信用。
诊断标识不改变准入、失败或 dispatch 规则；来源变为 rom/failure 时清除标识。

| 接缝 | 输入、输出、owner 与失败边界 |
| --- | --- |
| onMeasure（新增1） | 仅 owner；读取已交付 intrinsic，虚派 Java padding/suggested minimum；复用 DVM-291 MeasureImageLeaf constrained 结果，忽略 TOO_SMALL 以保持原 ClampSize；真实虚派 setMeasuredDimension，不写 measured/bounds/flags |
| 打开源（既有 native） | 实验只保存 decoder metadata/本代 pending event，不写 UiNode intrinsic 或发布快照；Legacy 保持原打开即导入尺寸 |
| metadata 交付（既有 owner event） | 同时核验 native state generation 与 Java mGeneration，成功才更新 intrinsic 输入并 requestLayout，再沿有界 dispatchEvent；未持视频锁调用 Java，非 owner 在保护引用/进入 Java 前拒绝 |
| 释放/换源（既有协议） | 仅匹配 native generation 的释放撤销实验 intrinsic 并 requestLayout；Java 原 releasePlayer 先推进代际；旧事件不能恢复旧尺寸，旧快照仍完整 |
| 视频合成/opaque 证书 | 实验从 PublishedProjection 取 frame/clip/hierarchy，与 raster/hit 使用同一完整 epoch；不得从构建树读未发布 geometry。Legacy 沿原树 |

原服务与 ROM 比例行为分列：320×240 源、双 EXACT 200×100 时，本 adapter 与原服务为
200×100；AOSP 4.4 VideoView.java:137–231 的比例分支为133×100。后者是源码推导，
不是本单运行的 ROM 算法，不能计作 ROM onMeasure 通过。

## 失败边界与审计决定

字幕、AudioManager、MediaController、错误 AlertDialog、网络/loop/reset 无新增成功路径；
未处理错误及不支持请求仍沿 ADR-0147 记账并抛 UOE。不引入 Binder/WMS/system_server、
完整 TextView 或其他系统栈。解码/音频 worker 不执行 Java 或修改几何/已发布快照。
Legacy Java 协议与 BootDex payload 不变。

按编排方常设原则自行决定的审计规则范围调整：**无**。
direct/static/super/精确接收者、本类 failure 字段、clinit 与 dispatch ledger 规则保持。
本单未修改 member_sources/selector，不需审计规则 ADR 修订。

loader MODULE 记录可选诊断来源契约；integration MODULE 记录测量、代际交付及快照读取。
ui 纯叶接口与投影契约未变，不修改 ui MODULE。capabilities 维护既有 partial 项；
CURRENT 增加0字节。
