## 审计决定与失败边界

按编排方常设原则自行调整组合/准入审计规则范围：**无**。
未修改 selector/member_sources/clinit 或放宽 ADR-0147。
静态布局门禁增加独立宿主分区，是 ADR-0161 已授权的职责变化；不放开 guest 重排。
不引入 Binder/WMS/system_server、完整 TextView 栈或任何系统模拟能力。

保留既有8窗口、文本长度、density、viewport、owner及代次边界；容纳失败保留旧modal，
Java 自身已经完成的标题/消息赋值仍归 Java，不声称回滚 guest 协议字段。
loader 的制品加载接口/来源契约不变，故不修改 loader MODULE；integration MODULE 与能力
现状按独立树/延期合成边界更新。ui MODULE 原已规定独立 HostLayout/ExternalProjection，
本单不改其接口/不变量；CURRENT 增加0字节。
