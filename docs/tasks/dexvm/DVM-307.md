## 交付及失败边界

VM 主 context 注册 Android 状态表时绑定宿主 owner；View 构造只校验 token=1 与线程。
Activity Window 的稳定 FrameLayout 内容根为空时也由 owner 屏障建立，首个 child 不代替根。
生产默认 viewport 来自 managed surface，density 取已注入配置；既有显式 viewport 参数
保留给受控测量夹具，用于与实际 holder buffer 区分，不由 Profile 或用户成员配置注入。

OwnerTick 是逻辑 tick 边界，BeforeInput 是同 tick 读屏障；每稳定根保存请求、延期、
watchdog 与成功身份/metrics。clean 不 measure/layout、不推进 epoch；ROM 的静默 ID/flags/
scroll 改变仍核对 Java 投影输入；沿用 Image 叶服务的 Bitmap 版本/锁/回收与弱索引
失效事实，clean 判断只读这些事实，不准备像素或执行 guest。首轮有效请求可第二 pass，第二 pass 请求与后续同 tick
屏障留至下一 OwnerTick；跨 tick 8 次 watchdog 是宿主预算，不宣称 AOSP 固定8轮。
异常不回滚 Java，旧完整发布保留；中断尝试不证明 clean，换内容/根/代次/metrics 取消旧提交。

`ReadAndroidUiGeometry` 读取当前 Java 字段，在副本校验/解析临时 const 投影，不准备叶光栅、
不发布、不派 Surface、不执行 guest。GeometryRead 仅允许进行中回调；输入重入明确失败。
生产只开放 OwnerTick/BeforeInput ResolveOnly，其他 phase 仍记账失败。Legacy 算法保持。

帧安全点、窗口软件回调、Surface 接入、输入事件事务、窗口切换恢复与呈现事实分别属于
VD-11-3～8；不引入 AttachInfo、ViewRootImpl、Binder/WMS 或完整系统，不宣称 E2E 验收。
