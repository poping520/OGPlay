## 编排方沙盒外门禁与端到端结果（2026-10-25）

- 静态：`tools/capabilities.py check`、`tools/check_ui_traversal.py`（1 scheduler call，0 bypass）通过；git-clang-format 无改动；生产 BootDex SHA-256 仍为 `909a702b…acbe8`。
- A 组：复用 11-4 门禁九场景（同一 HEAD `a054c4d8` 构建，`.local/analysis/vd-11-4/gate`），不重建冻结源码。
- B 组（候选 Legacy）：GPU/EGL 4/5、lifecycle 11/18 失败用例名与基点相同；九场景首轮 dead_trigger 在 baseline 出现 Unity `nativeActivityIndicatorStyle` 空指针（读 0xa4），两次复跑均回到基线退出阶段失败，判偶发并记入 `.local/analysis/next-dir/FINDINGS.md`；其余与基点相同，6/9 保持。
- C 组（JavaTraversal staging，配对 JAR `a9185c1d…`）：仅 dungeon_hunter、asphalt5 通过；pvz 与 B 同为退出阶段 `ContextWrapper.stopService` 首错。新首错 6 个，按 ROM 依赖类别归为 4 类：
  1. 窗口系统成员缺口：`View.getViewTreeObserver`（tml、dead_trigger，NativeActivity.onCreate）、`View.setSystemUiVisibility`（tales）。
  2. 构造 adapter 覆盖：wild_blood `Game.onCreate` 构造的 View 种类无受审 adapter。
  3. 主题投影值：angry_birds `View.<init>` 读 `@android:drawable/scrollbar_handle_horizontal` 不受支持。
  4. Surface 重建：lili 销毁后重建只派 surfaceCreated、缺 surfaceChanged，Unreal 等待不出帧（presented 0，wall-time 超时）。
- 比较器：B→C 判 `invalid`（`unrecognized first fault`）——startup 的 `error [ogplay]` 报告与无异常的 wall-time 超时尚无受审归一化，按设计 fail closed。
- 结论：VD-11 接线完成，端到端未通过；按 ADR-0162 第 5 条，上述 4 类与比较器归一化合并为一个通用能力单 VD-11-6（DVM-314）。证据在 `.local/analysis/vd-11-5/gate/scenarios-{candidate,c}`。
- Windows windows-msvc 未验证（本机无环境）。
