## 未闭合的输入依赖与停止边界

固定 framework/framework2 JAR 的 `com.android.internal.R$drawable` 没有四个 scrollbar 名称：
scrollbar_handle_horizontal、scrollbar_handle_vertical、scrollbar_handle_holo_dark、
scrollbar_handle_holo_light；本地也没有 framework-res.apk。旧 VD-09a 报告已明确该资源未提供。
不能从 SDK android.jar、AOSP 资源排序或别的 ROM 猜 private ID：这会违反 ADR-0160。
取得并认证同 ROM 系统镜像/资源是本会话输入之外的依赖；若直接绕过它则必须放宽既有
“不猜值/不伪造成功”约束，因此停在可核验的部分交付，不用新增用例失败作为停止理由。

`theme-input-gap.json` 列出实际缺失清单；当前只能证明并投影 `btn_default`，尚有两个
Button Holo 背景同样缺名绑定。没有给 scrollbar 造 ID，没有把缺值改为 null/缺席，
未改变 APK、请求或 Profile。默认 ROM View 属性构造仍明确报告原 scrollbar 首错。
配对构建通过不代表该首错已消失。

## 常设原则决定

组合/准入审计规则范围调整：**无**。direct/static/super/精确接收者、本类 failure 字段、
clinit 与 dispatch ledger 规则均未放宽；没有更改 ADR-0147。
原始 native 首报告仅增加离线证据封装和强制 review，不赋予归一化的 module+PC 身份。
