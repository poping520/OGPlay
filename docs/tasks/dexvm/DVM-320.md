## 迁移 / adapter 列账与 review

新增组合成员 / adapter / native：**0 / 0 / 0**。无 ROM/配方/ABI/准入/加载变化。
按编排方常设原则自行决定的审计范围调整：**无**；ADR-0147、clinit、虚派 ledger 保持。
loader MODULE 已复核，加载契约未变；integration/session MODULE 仅更新诊断契约。
capabilities 维护既有 partial 条目的验证入口；CURRENT 增加0字节。

- 每次 owner 投影后的既有重评估只读 Java 字段，比较原因、UiNode 绑定、当前投影包含性、
  每级对象/Android id/类/visibility/mParent/测量尺寸、首个阻断祖先及所属 Java Window。
  visibility!=VISIBLE、无绑定、非根空父均可成为 first_break；cycle/depth/collected 明示终点。
- `ui.surface.producer_state` 变化事件禁用 Logger 默认 first-and-count，相同事实不重复。
  epoch/tick 是事件字段，不因 tick 单独变化逐帧刷日志；投影可用性/包含性属于事实。
- 统一 Surface 诊断记录原消息/字段/限流策略，累计所有原因（含 reason/phase），
  traversal 原每根首次记录机制保留，另累计不随窗口退役清除的进程总数及最后 epoch/tick。
- 进程 Stop 在任何清理回调前汇总一次：summary、逐原因 reason、每个已注册 producer 的
  终态 producer。只存数值/字符串历史，无 guest GC 强根；已退役 producer 明确为
  retired + last_observed，不能把过期快照当当前对象。正常/failed/重复 Stop 同一幂等协议。
- Legacy 守卫在采集入口，既有选择、Surface 激活、失败与退出顺序不变；没有新 worker、
  guest 调用或时间源。不引入 Binder/WMS/system_server/完整 TextView。
