## 交付、迁移与 review

相对 DVM-322 新增组合成员 / adapter / native：**0 / 0 / 0**；既有成员来源、ROM 方法体与逐签名
adapter review 不变，不给任何 failure 成员新增实现信用。没有审计规则适用范围调整。

`tools/bootdex/java-traversal.json` 将原实验分支中的固定类集合增量、View policy 和各
组合来源表迁为生产候选配方；基础仍为 api19.json，包含 DVM-322 ROM Inflater。
迁移前后完整来源→类集合由 recipe-before.json 精确比较；原实验输出入口继续使用
同一配方，不维护第二套集合。生产默认入口及 `data/android/19/framework/bootdex.jar`
保持 Legacy；默认切换与 guest Legacy 清理留 VD-12-3。

```text
python3 tools/bootdex/compose_bootdex.py build --candidate-output build/release/bootdex-candidate/bootdex.jar
python3 tools/bootdex/compose_bootdex.py check --candidate-output build/release/bootdex-candidate/bootdex.jar
```

独立输出为上述 JAR 及同目录 bootdex.manifest.json，不将候选二进制放入生产 data。
候选与实验 fixture 的完整 JAR 相同；拒绝通过候选/实验参数覆盖默认 BootDex。
配对 mode=java-traversal/version=1，封存 DEX、成员表、主题投影、video review 与配方
provenance 的 entry 哈希。provenance 记录基础/候选/成员配方、主题输入清单与生成器、
video review 文件 SHA-256；manifest 指向实际候选配方，完整 identity 见 artifacts.json。
新增 video/recipe 哈希只用于构建审计，不改变 VM 装配 schema 或运行时校验范围。

主题投影仍由既有生成器按真实输入重算；输入改变须先更新受审清单及哈希，再运行同一
build/check，全部配对哈希随之更新。未修改主题输入、未造 scrollbar ID/缺席值。
缺同 ROM framework-res.apk 的四场景失败保持；本单不承诺其默认主题已可运行。

selector closure 计数直接读取 --bootdex 指定归档，不再读取固定 builder.OUTPUT；
method_ids 与 field_ids 均须严格小于60000。自检覆盖非默认归档的不同计数、59999
通过、任一60000/超界拒绝；实际三域 closure 报告与独立 DEX 头读取互相核对。

integration MODULE 仅明确候选构建审计与既有 VM 校验的边界；loader/ui/session API、
加载及运行时协议不变，不改其 MODULE。capabilities 保持 partial，仅修正严格预算描述
并加入候选 check 入口。CURRENT 增加0字节。

## 外验与失败边界

`.local/analysis/vd-122/external-validation.txt` 交接指定 e2e 命令、GPU过滤及候选替换 staging
JAR 跑 C 组的命令，预期与 12-1 C 组逐项相同；本单不运行这些命令。
GPU/实窗过滤：`*egl_facade_tests.cpp,*activity_window_lifecycle_tests.cpp,`
`*angle_backend_tests.cpp,*angle_frame_tests.cpp,*egl_lifecycle_tests.cpp,*ui_compositor_tests.cpp`；
另含 `DVM-246 ARM JNI Dialog preserves Surface owner focus modal pixels and window return`。
过滤也保存在 cpu-args.json 的排除参数中。Windows 仍须 windows-msvc 外验。

不引入 Binder/WMS/system_server/PhoneWindow 或完整 TextView 栈；scrollbar 输入缺口
保留明确失败。静态 closure 不代表所有 failure 成员可运行，也不替代 GPU、九场景、
性能≤10%与默认切换发布门禁。按常设原则自行决定的事项：**无**。
