## 迁移 / adapter review 与失败边界

新增支持组合成员 **62**（29 ROM 方法、25 overlay 方法、8 ROM 字段）；新增 adapter
**27**（25 组合 adapter + 2 进程内 token 有效性查询），native **0**。
另有7个 token Binder 操作端点仅记账失败，不计入支持 adapter；12条既有 adapter review
按类型/资源池/状态边界修订。完整逐签名清单见 `migrations.json`。

实施以固定 ROM 完整形状和逐签名来源表封存，不复制或改写 ROM 方法体。
`view-skin-sources.json` 与 `view-measure-sources.json` 封存受审接缝、原始 flags/body hash；
`adapter-reviews.json` 与 `migrations.json` 留证据目录。生产默认仍为 Legacy。
三种新 Drawable 及三个签名闭包内部类保留 ROM 形状；内部类全部方法保持 failure，
仅为 DEX 签名/形状 closure，不取得执行信用。不扩展 Drawable 状态/ConstantState 实现。
loader 二进制 XML/ARSC 接口未变，复核其 MODULE 后不改契约；integration 两级 MODULE
与既有能力条目按上述真实支持范围更新。

- format/枚举名称直接来自同 ROM framework-res 的 attr bag；名称按属性隔离，未知名称
  保持 unsupported，消费即记账并失败。字符串为独立真实 StringBlock/cookie2，不借 APK 索引。
- 默认背景仅开放 edit_text selector 和其 ninepatch 闭包；解析器拒绝其他 XML 结构、
  selector 选项、配置维度或非 ninepatch 叶。PNG 解码使用已有解码服务，padding 来自
  npTc，密度选择与缩放按 ROM 规则；默认 selector 使用全部子项的最大 padding。
  Drawable 基础 bounds/state/callback 字段和协议归 ROM，子项、尺寸/padding、选择状态
  为逐对象 adapter backing，GC 从 selector 追踪子项。未开放动画/过渡、未知皮肤或任意绘制。
- View 状态索引读取 Java flags、真实焦点/窗口事实及 ROM VIEW_STATE_SETS；缓存与刷新
  归 ROM getDrawableState/refreshDrawableState，不建立第二份 View 状态表。
- 每窗口根追踪稳定进程内 token，token 仅弱记窗口根，窗口退役撤销有效性；内容替换
  保持身份，未附着返回 null。transact、marshalling 等 Binder 操作明确失败。
- showSoftInput/hideSoftInputFromWindow 在 JavaTraversal 中按 ADR-0161 决定7记账失败；
  Legacy 原行为保持。restartInput 既有有界焦点检查保持。

按常设原则自行决定的审计规则适用范围调整：**无**。
严格 direct/static/super/精确接收者、本类 failure 字段、clinit、dispatch ledger 和
ADR-0147 不伪造成功均保持；本单未引入 Binder/WMS/system_server 或完整 TextView 栈。
