## 迁移 / adapter review 与失败边界

新增支持组合成员 **8**：Resources.getColor 原 ROM 方法；TextView 的四个颜色字段及
getHintTextColors/getLinkTextColors/getHighlightColor 三个 ROM getter。
新增 adapter **0**、native **0**；8条既有 adapter review 更新，逐签名清单及原 body hash
见 `migrations.json`。ROM 方法体不改写，完整形状与来源封存保持。

- 同 ROM framework-res 哈希锁定；color 目录按 selector/item、android:color 与 state_* 结构
  开放全部同构 XML，不按名称白名单。原始编译 XML 交现有 XmlBlock 与原版
  ColorStateList.createFromXml/inflate；标量颜色引用沿同 ROM ARSC，普通颜色按 format=color。
- 结构外 XML、未知属性、未知/非标量引用、未登记配置明确失败；不回退 APK，不伪造成功。
  ROM 路径字符串用独立 cookie2；无 APK ARSC 的 owner 保持 cookie1 StringBlock 槽缺席，
  对缺席池查询仍失败。XML cursor/Java 颜色字段沿既有 GC 规则退役。
- show/hide/restart 共用 CheckInputFocusWithoutConnection；无当前窗口附着焦点候选时
  show/hide 返回 false；需要 InputConnection 时记账并抛明确异常。Legacy 分支逐值保持。
- loader 的 XML/ARSC 接口未变，已复核 MODULE，不修改；integration 两级 MODULE 及
  既有能力条目按颜色、叶冻结、焦点边界更新。未引入 Binder/WMS/system_server/IME。

按常设原则自行决定的审计规则范围调整：**无**。严格 direct/static/super/精确接收者、
本类 failure 字段、clinit、dispatch ledger 与 ADR-0147 保持。
