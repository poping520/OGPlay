## 迁移 / adapter review 与失败边界

新增支持组合成员 **5**（TextView 原版 int 字段：mTextSelectHandleLeftRes、
mTextSelectHandleRightRes、mTextSelectHandleRes、mCursorDrawableRes、mTextEditSuggestionItemLayout），
新增 adapter **0**、native **0**；更新既有三参 TextView 构造 adapter 的1条 review。
逐签名 flags/source、review 前后对照见 `migrations.json`；原 ROM body/hash 与完整形状保持。
不新增 Java 方法，不迁 Editor，不改写原 ROM 算法，不给予原字段之外的第二份身份表。

- theme_inputs 在既有同 ROM ARSC/R 常量身份审计后导出所有资源的类型/名称→id。
  theme_projection 不再按属性名限制 drawable，也不展开 color/dimen/string 等引用内容；
  ARSC 存在的任意类型名称统一生成 TYPE_REFERENCE/id，真实缺名保留原文本并 unsupported。
  类型编号必须与 id type 段一致，名称/ID/类型冲突拒绝；继承、属性环与深度界限不变。
- runtime 校验封存的类型编号与引用身份，允许所有已封存类型的引用取 id；
  保留既有非引用标量绘制属性门控。未知加载目标可取 id，
  实际加载在消费者调用处按 ADR-0147 明确失败。既有颜色六槽运行期解析保持，unsupported
  color 不因只取 id 提前失败；显式资源加载仍检查既有颜色支持边界。未扩 drawable/动画加载器。
- 五个字段严格对照 ROM getResourceId 的 pc1524/1540/1556/1572/1588，构造 adapter
  读取真实 TypedArray 并写原字段。TextView styleable 的四个旧 paste-layout 槽65/66/68/69
  在固定 ROM pc625 packed-switch 全部指向 pc628 默认分支，没有 getter/字段写入/加载；
  adapter 保持相同不消费语义。可复算目标表为 `rom-switch.json`，不是静默实现未支持加载。
- loader ARSC/XML 读取接口未变化，复核其 MODULE 后不修改；integration 两级 MODULE 与
  既有 bounded_theme 能力按引用身份及消费边界更新。生产默认继续 Legacy。

按常设原则自行决定的审计规则范围调整：**无**。strict direct/static/super/精确接收者、
本类 failure 字段、clinit、dispatch ledger 和 ADR-0147 不伪造成功保持。
