## 迁移 / adapter review 与失败边界

新增支持组合成员 **1**、adapter **0**、native **0**：实验
`Landroid/view/View;->bringToFront()V` 从 failure 改 ROM；生产成员表不变。
flags/body hash/来源变化与依赖逐项见 migrations.json。ViewGroup.bringChildToFront、
removeFromArray/addInArray、indexOfChild、mChildren/mChildrenCount/mParent 已为 ROM，
本单复用，不重复登记新增。原版调用父 bringChildToFront，真实重排子数组并 requestLayout/
invalidate；collector 按同一子序提交完整投影，CPU raster 锁定重排前蓝色、重排后红色。
无 Java 算法复制，无新增 Java/native 方法，无游戏专属生产分支。

- 调度：保留 owner/token/线程、phase、回调重入、输入/Surface 租约、两 pass/延期和 watchdog
  门禁。进入遍历前读取稳定 Window 根身份、真实根 FORCE_LAYOUT 与已登记请求；首次附着、
  generation/content/metrics/density 变化、真实绘制失效继续触发工作。干净屏障不调用 guest，
  不逐节点比较/重建投影；只复用最后完整成功快照，不跳帧、不降频、不缓存过期内容。
- 节点：Surface owner、producer 选择及现有宿主 input/video 快照消费，按真实 View 重查
  绑定并先查所持快照中节点存在性；缺失意味着本轮未发布/已失效，不激活，下一安全点再查。
  UiTree::Require 的 stale 失败、guest 不可达查询和旧快照不可变性保持。
- 比较器：只对精确 frontend.run_apk.fault / UI node is stale 分类为 host_ui_stale_node，
  保留 message/boundary、证据哈希、阶段与 requires_review；不同/未知文本仍拒绝，绝不隐藏故障。
- loader 输入/ABI/配对格式不变，复核 MODULE 后不修改；integration 两级与 session 的调度/
  消费契约更新。capabilities 只维护既有 partial 条目，生产默认 Legacy 不变。

按常设原则自行决定的组合/准入审计规则适用范围调整：**无**。direct/static/super/精确
