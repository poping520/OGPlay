sample 均只读；哈希、Result 与诊断摘录见 static-evidence.json，CPU 采样摘录见
b-sample-excerpt.txt / c-sample-excerpt.txt。B/C 热点仍为 guest GLES1 路径，不能据 CPU
采样推断墙钟 present 成本。C 的 TML 旧 frame_timing 中位为911832 ns。

固定原 APK/ROM 的逐 PC 摘录见 apk-path.txt、rom-path.txt：

- `Game$2.handleMessage` pc77 调 RelativeLayout 继承的 removeViewInLayout 后，pc80 跳到
  pc11 return；pc449 的另一调用后，pc452 只写 reshowProgressbar，pc454 同样跳到 pc11
  return。两条路径本消息内均无下一 invoke；下一消息取决于真实队列，不能把相邻 switch
  分支或其后物理排列的 setVisibility 当作顺序后继。本单不扩展后继能力。
- ROM removeViewInLayout 仅精确调用 removeViewInternal(View)，后者 indexOfChild 后精确
  调 removeViewInternal(index, View)。子数组、parent、焦点及现有移除协议复用原路径。
  该 API 不自行 requestLayout/invalidate；定向用例用调用方真实 invalidate 触发新投影，
  不因绘制缓存而私加 Java 请求或逐节点扫描。
- 原游戏错误在 frame7848 的 handleMessage 中明确失败；本单只做无头 reached-fault
  定向证明，不宣称真实 APK 已越过此处，也不宣称 title gate 已通过。

## 迁移 / adapter review 与失败边界

新增组合成员 **1**、adapter **0**、native **0**：仅实验
`Landroid/view/ViewGroup;->removeViewInLayout(Landroid/view/View;)V` 从 failure 改 ROM。
flags=1、原版 body hash/来源不变；完整前后行在 migrations.json。生产成员表不变。
无 Java 算法复制，无新增平台 handler，无游戏分支，无新增依赖。

session 持有 AndroidPresentationCache：只按已成功发布的不可变窗口树/冻结 modal 身份、
viewport 及冻结 bitmap 输入复用对应 RGBA 平面；同一 presentation 直接复用，video-only
新发布也复用未变 UI 平面。缓存仅保留当前发布的平面与快照，重建全部成功才替换。
尺寸错误或栅格失败不替换完整缓存；新 producer 底图每帧仍按 video下层→逆序guest UI→
video上层→modal 混合、上传并正常呈现，不复用含旧 producer 的最终帧、不跳帧、不降频。
透明平面沿既有 fully_transparent 快路；没有新增 GPU UI 纹理上传路径。

OGPLAY_FRAME_BENCHMARK 保留原 active frame median，新增 step_median_ns /
present_median_ns，分别包围 driver.step 与 present_latest；未呈现的 step 累积到下一呈现样本，
两项各取原4096样本窗口中位。原总计仍包含中间音频/视频节奏阶段，两个中位数之和不等于
总中位数。真实 SDL/GPU 路径由外验采集，无头夹具不伪造上传或 guest GLES 时间。

session MODULE 更新缓存职责。loader/integration 及其子模块 MODULE 已复核：装配 ABI、
配对、Java字段/几何权威、发布序列及输入租约契约未变，故不修改；runtime/ui 算法与契约
未变。capabilities 仅维护既有 partial 条目。生产默认 Legacy 保持。

按编排方常设原则自行决定的审计规则范围调整：**无**。direct/static/super/精确接收者、
本类 failure 字段、clinit、dispatch ledger 和 ADR-0147 不伪造成功全部保持。
LayoutTransition/动画、未实现 View 边界仍记账并明确失败；未引入 Binder/WMS/system_server、
完整 TextView 栈或其他 Android 系统能力。
