状态：本地实现与判据核对完成；CPU 无新增失败（保留2项基点失败）。编排方外验九场景9/9与冻结Legacy持平、EGL失败集相同；lifecycle夹具补齐后待实窗复验，帧时与Windows未验。

依赖 [DVM-322](DVM-322.md)、[DVM-323](DVM-323.md)、[DVM-330](DVM-330.md)。

## 交付、迁移与 adapter review

- 默认 composer 与候选共用当前 java-traversal.json，包含同 ROM policy inflater、主题、皮肤及 framework-res 输入。
- context 固定为 JavaTraversal/ExternalProjection；三前端入口仍统一 AssembleAndroidContext。缺模式、未知版本或五项配对身份不符均在 catalog/VM 前失败。
- 删除 guest HostLayout 遍历、多轮宿主 size 派发、session 几何写入/旧合成与默认 Legacy 分支；删除旧 native registry inflater。
- Dialog 必须有独立 HostLayout 树，保留 ui_layout.cpp 文本/几何服务；不移除 legacy JNI、targetSdk 及 Sensor 兼容。
- 组合审查全部指向同一 JavaTraversal runtime 表面；100 条已被 ROM/failure 取代的旧 C++ catalog handler 移除清单见 removed-catalog.json。
- 新增组合成员 / adapter / native：**2 / 1 / 0**（第三轮将两个既有failure成员迁为ROM；未新增声明）。既有 setClickable(Z)V 从 rom 改受审 overlay：按原 setter 虚派 ROM setFlags(II)V（CLICKABLE=0x4000）；实际位改变只标 owner 投影 draw-dirty，不测量、不改几何。原异常透传，Java flags/ListenerInfo 仍为唯一权威，已有输入租约不发布中途 mutation。
- 既有 adapter 修正：AbsoluteLayout 构造经真实 ViewGroup 父构造初始化；WebView 聚焦写 Java flags；decor 的 ViewGroup 分发经受审 window_owner 委托 Activity。输入必须存在于完整投影，禁止缺节点继续分发。未新增成员/native，未实现滚动条、完整 AbsoluteLayout 测量仍记账失败。
- 新 adapter 修复默认路径的干净投影点击资格滞留；正例由原 visible button 用例及点击主题验证，未借主动 requestLayout 隐藏回归。
- 封存表面先用旧固定 DEX、相同实际 catalog 和新来源行导出；临时 bootstrap JAR 仅作链接导出，不启动 VM/游戏、不作为默认制品。随后严格 compose 重算所有来源/配对。无审计规则放宽。
- AndroidValue/Click/Video 夹具迁为实际 API19 native/JNI bridge，复用原 payload/ICU/VFS；不模拟 Pattern 或伪造 native 成功。View 经 Java 构造、owner 与完整投影，原手工重复注册的状态表由 bridge 统一建立。

按编排方常设原则自行决定的组合/准入审计范围调整：**无**。direct/static/super/精确接收者、本类 failure 字段、clinit 与 dispatch ledger 规则不变，支持路径动态未实现命中仍须为0。
