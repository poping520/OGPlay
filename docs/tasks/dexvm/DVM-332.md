# DVM-332：API19 进程内 ContentObserver

范围：Java ContentResolver URI 树注册/全量注销/通知、自通知开关、ROM Handler 派发；
无 Handler 改主 Looper；System 写入有效变更后通知。query/getType 保留 integration overlay。
不含 Provider 事件、跨进程/跨用户、sync、Transport/Binder 或下一运行首错。

依赖：原版 BootDex ContentObserver/NotificationRunnable、Uri、Handler/Looper，既有
Settings.NameValueCache 进程存储及 Java 客户端与 intrinsic 精确 overlay 机制。
观察者只由 Java static 树保活，无 C++ 影子表或 session root。

验收：双解释器定向回归、BootDex build/check、受影响目标构建，以及真实启动一次确认
原 registerContentObserver 缺成员消失，记录下一首错。证据见下。

## 实现与准入

- 新有界 ContentResolver（API19 abstract Object 层级、公开观察者签名），Java static
  authority/path 树保存强引用；锁内收集、锁外原版 dispatchChange。
- private native hasHandler 只读取 ContentObserver 定义类的 mHandler，避免子类同名字段
  遮蔽；无 Handler 经主 Looper。没有 Transport/Binder 或宿主注册表。
- System 写入比较原值，实际改变后调用原版 Settings.System.getUriFor 与 resolver
  notifyChange；Secure/Global 原有失败记账保持。
- composer 扩展固定 Java 源清单并核对 ContentResolver 的三个 native 签名；原 JNI
  payload generator 未修改。query/getType 的 C++ 方法体未修改。
- 保留开始前已有 Activity.java 改动，生成 manifest 同时反映该工作区源码；除 boot_dex
  外的 manifest 顶层内容与开始时一致。

## 后续局部修复：Window 背景与系统标量颜色（2026-10-27）

- Window 的两个背景 setter 原先均无 handler；现在资源 setter 经 mContext 虚派
  getResources/getDrawable/receiver.setBackgroundDrawable。Activity 惰性建 Window 时补写
  Java mContext；mBackgroundDrawable 为 GC 强边，同一值跳过，已有根立即套用，首次建根
  套用已保存背景，null 清除。不增加宿主影子状态、窗口格式变化或主题默认背景。
- MakeResourceDrawable 对包号 0x01 仅接收封存 ThemeResources 中无 XML/unsupported 的
  type 28–31，复用 ColorDrawable(int) 构造及 ui_drawables 登记；其余原先不支持的系统 ID 明确失败。
- 实际 JavaTraversal 封存表与最初任务假设不同：Resources.getDrawable(I) 和 View 背景
  setter 均为 ROM（基础 member-sources.json 中的 View overlay 被组合配方覆盖）。因此只把
  Resources 单参数入口改为受审 overlay；APK 仍委托原 ROM getDrawable(IZ) 选择/缓存路径，
  getSystem 保留既有 intrinsic 拒绝分支；既有受审 ROM drawable skin 保留原通道。View 背景仍执行 ROM。
- ROM View 背景协议的必要依赖：ColorDrawable.getOpacity 由既有 ARGB alpha 返回
  OPAQUE/TRANSPARENT/TRANSLUCENT；View.unscheduleDrawable(Drawable) 仅实现 ROM 的
  null Drawable/null mAttachInfo 无操作分支，其他情况记账抛 UOE，不模拟 Choreographer。
- 运行时证据通过已构建 CLI 的 dump-surface 导出，仅保留 View/Resources/ColorDrawable
  及 drawable skin 类，存于 window-background.surface.json.gz；skin 配方引用同一份新
  证据，防止组合审计的末尾旧表面覆盖新 handler 事实。未修改 skin 实现或成员选择。
