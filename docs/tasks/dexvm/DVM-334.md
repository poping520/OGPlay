# DVM-334：受管 Activity 的 Window.Callback 附着（WU-1）

状态：WU-1 有界完成；新增定向回归通过，原 APK 已进入附着回调；资源查询首错已修，当前阻塞为 WU-2 addView。

## 范围与依据

仅由 session 向受管 Activity 虚派 API19 Window.Callback 的
onAttachedToWindow/onDetachedFromWindow；不构造 AttachInfo/ViewRootImpl，不向 View 树
派发 dispatchAttachedToWindow。Dialog Callback 附着未支持。
WU-2（应用子窗口 addView/removeView）与 WU-3（属性动画及帧调度）为后续独立工作。

固定 AOSP Android 4.4.4：PhoneWindow.java 2658–2686 的 DecorView 将主窗口附着/分离
通知 Callback；ActivityThread.java 2819–2838 在 resume 后检查 willBeVisible/!mFinished
并添加窗口，首次 traversal 附着先于窗口焦点；3501–3519 先 performDestroyActivity，
再 removeViewImmediate。pause/stop 不移除窗口。

ActivityRecord.window_attached 是唯一回调附着事实，resume 返回后且窗口将可见、未 finish
才置位并虚派；恢复或隐藏不重置。实例退役在 performDestroy 后、UI 子树退役前清位并
虚派分离。进程关闭不合成分离；异常复用现有生命周期失败协议。
