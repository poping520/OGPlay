# DVM-335：有界应用附加窗口（WU-2）

状态：有界实现完成，定向回归及原 APK reached-fault 通过；当前首错为 WU-3 属性动画。依赖 DVM-334 及其 getIdentifier 局部修复，均保留未提交。

范围：Activity 专属稳定 WindowManager，type 1..99、MATCH_PARENT 全屏普通 Java 根，
支持 flags NOT_FOCUSABLE/NOT_TOUCHABLE/NOT_TOUCH_MODAL/KEEP_SCREEN_ON/LAYOUT_IN_SCREEN/FULLSCREEN，
format 保存。无 ViewRootImpl/AttachInfo，根 Java mParent=null，不派发 View 树附着。
共享最多 8 个 Dialog/附加窗口；子窗口类型/系统类型、其他尺寸/位置/gravity/flags 明确记账失败。
WU-3 属性动画/Choreographer/View.setAlpha 仍为独立后续工作。

AOSP 4.4.4 依据：WindowManagerGlobal.java 189–254 的校验、重复添加及 setLayoutParams；
272–309 的更新/移除，Window.java 489–541 的 app token/缺省标题，
ActivityThread.java 3535 的 closeAll，以及 ViewRootImpl 的 BadTokenException。
宿主生命周期拥有焦点事实；共同 PresentationSnapshot 冻结附加窗口根/flags/代次/投影，
同 token 可见性跟随 owner。最上层全屏可触窗口阻断下层，按键只交焦点窗口；
改变窗口集合取消旧手势并吞尾，失焦先于获焦。owner destroy/detach 后清泄漏并 warn；
进程关闭只退役附加窗口，无合成 View 附着/分离回调。

## 原 APK reached-fault

在 `build/release` 执行一次 `./ogplay-cli library run com.g5e.islandcastaway.full`：退出 1，
原 addView 缺口越过，下一首错为 scheduled callback 的
`Landroid/animation/ObjectAnimator;.ofFloat(Ljava/lang/Object;Ljava/lang/String;[F)Landroid/animation/ObjectAnimator;`，
`Lcom/g5e/g;.run (pc 57)`，f=442。未修 WU-3，未做 title gate 或三轮场景。

结构化投影证据：`android.window application window published above Activity`：
owner=2349、root=4598、generation=1、800×480、partitions=2、image_bytes=2908160、
presentation_epoch=2。该图像根是独立顶层分区，不属于主窗口投影；定向测试另确认实际
合成像素覆盖主窗口。焦点证据：`managed window focus changed owner=2349
activity_focus=false application_root=4598`；直到下一首错无 Activity 重新获焦日志。
日志 `.local/application-windows-repro.log`，机器核对摘录 `.local/application-windows-proof.json`。
这是投影/焦点 reached-fault 证据，未以画面外观推断完整兼容。

## 剩余边界

WU-3 ObjectAnimator/Choreographer/DisplayEventReceiver/View.setAlpha、View 树 AttachInfo/
附着分离、Dialog Window.Callback、完整 WMS/系统或面板子窗口、其他窗口几何/flags
仍不支持。窗口根 `dispatchKeyEvent` 的 guest 覆写能正常虚派，控件自身尚未实现的按键
行为仍依既有机制明确失败；本任务不扩展完整按键控件算法。Windows 与 GPU 窗口外验未做。
