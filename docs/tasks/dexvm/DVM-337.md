# DVM-337：ROM 属性动画与 View alpha（WU-3b）

状态：有界完成；定向验证及原 APK 淡出/移除、前台焦点恢复已取证。保留 WU-1/2/3a 及 getIdentifier 未提交改动，不提交。

范围：API19 ROM ValueAnimator/ObjectAnimator/PropertyValuesHolder 与四个逐签名 native；
Java TransformationInfo alpha 唯一权威，沿既有 Choreographer 帧源推进，软件投影与窗口 alpha 合成。
不开放 ViewPropertyAnimator、LayoutTransition、ViewGroup transition、postOnAnimation 或动画 XML。

依据：AOSP 4.4.4 animation 三类、android_animation_PropertyValuesHolder.cpp 与 View.java。
软件渲染按逐绘制有效 alpha 相乘；重叠子树的组不透明度差异是已知缺口。

## 实现边界

- 新增固定 ROM ValueAnimator/$1/$AnimationHandler、ObjectAnimator、PropertyValuesHolder/$1/
  $FloatPropertyValuesHolder/$IntPropertyValuesHolder、FloatEvaluator/IntEvaluator；闭包补 IntProperty。
  普通算法和方法体不改，未开放动画 XML、LayoutTransition、ViewPropertyAnimator 或 postOnAnimation。
- 四个 PVH native 按 `(class, name, (F)V/(I)V)` 解析实例方法（含继承/私有），
  表内 1-based int ID 稳定复用、无宿主地址；调用验证 ID/签名/target，按实际类型虚派，
  私有方法直接调用，原 Java 异常对象传播。缺方法 NoSuchMethodError 由 ROM 捕获，随后实际
  Class.getMethod 反射；ROM primitive float 对 boxed-only setter 的反射仍不匹配，保留原版行为。
- setAlpha/getAlpha/ensureTransformationInfo/onSetAlpha、invalidateViewProperty/getFinalAlpha/
  hasOverlappingRendering 选原版成员。TransformationInfo 与 mAlpha/PFLAG_ALPHA_SET 归 Java。
  现有软件 dirty adapter 登记每个窗口的 draw-only 请求，避免主窗口清 dirty 吞掉子窗口更新。
  alpha-only 的 Matrix 必须确实已构造为 identity，几何字段保持中性；ROM setFrame 因尺寸变化
  置 mMatrixDirty 并不构成几何变换。不构造 display list、不代写 alpha、不发 requestLayout。
- 外部投影携自身×祖先有效 alpha；onSetAlpha=true 的自身 opacity 归子类处理。
  没有离屏层，已知“重叠子树的组不透明度差异”。光栅是预乘 RGBA，呈现端明确使用预乘
  source-over；TRANSLUCENT(-3)/TRANSPARENT(-2) 保留逐像素 alpha，其他窗口 format 覆盖下层。
- ROM ValueAnimator 的 Trace.isTagEnabled/asyncTraceBegin/End 仅 View tag=8 连接结构化
  debug 日志（名字/cookie）；其他 tag 仍记账拒绝。没有新增时钟、scheduler 或结束捷径。

## 原 APK 到达点与下一缺口

在 `build/release` 执行 `./ogplay-cli library run com.g5e.islandcastaway.full`。
首次 `.local/property-animation-repro.log` 已越过ofFloat并记录alpha=0移除，但默认日志限流隐藏
中间alpha和重复焦点事件。仅完善诊断（每1/4 opacity区间采样、不限流焦点过渡），再做一次
有界取证 `.local/property-animation-repro-evidence.log`，未修下一独立问题。

第二轮 root=4598：Clock uptime 66660→alpha0.999289、66948→0.743289、67076→0.4816、
67172→0.2256；67252记录removeView时alpha=0。按原Accelerate曲线从0.4816样本推算起点
66644，结束为608ms（600ms后的首个16ms帧）。中间与结束证据见
`.local/property-animation-repro-proof.json`；移除来自游戏onAnimationEnd调用链，随后进入视频Surface路径。

正常运行新触及的缺口为 `ParcelFileDescriptor.adoptFd(I)` 未实现，游戏在视频打开时捕获并输出
Unable to open res/video/sg_video.mp4；观察期未出现新的终止首错，不能把该捕获日志称为进程崩溃。
有界观察后SIGINT停止，onDestroy另报 `System.runFinalizersOnExit(Z)` 未实现。两项均不在本任务修复。

原APK在动画前已记录宿主失焦（activity_focus=false、application_root=0）；电脑使用工具明确报告
Mac锁定且不能自动解锁，故没有伪造焦点。当时已请求用户解锁，原APK的onWindowFocusChanged(true)
尚无实际证据（现已由下述补验闭合）。新增夹具在宿主保持焦点的前提下验证onEnd移除→Activity true恰一次。
该焦点外部验证已由下述补验闭合；重叠子树组不透明度差异仍为允许的支持边界。
