## AOSP 语义对照

- 本地 `.local/aosp/framework/base/core/java/android/widget/TextView.java:2723`：
  setShadowLayer 委托 Paint，保存 radius/dx/dy 并 invalidate；四 getter 返回所存参数
  （颜色由 Paint.shadowColor 返回）。本实现四参数仅由 UiNode.TextShadow 权威保存，
  projection/DrawText 按同一 epoch 复制；不另写 Java mShadow*/Paint 第二份状态。
- 本地 `.local/aosp/framework/base/graphics/java/android/graphics/Paint.java:1129`：
  hasShadow = radius > 0，同时保存参数；JNI Paint.cpp:684 在 radius <= 0 时清除 looper。
  因此有限负半径与零保留 getter 原值，但不绘制阴影。setter 只调用真实 invalidate，
  不发 requestLayout，不改变测量或 line-plan 缓存。
- AOSP Java/JNI 入口没有显式非有限值校验，不能声称它抛 IllegalArgumentException。
  本有界服务对 NaN/Inf 和 |dx/dy| > 4096 的输入采用明确失败边界：在状态发布前，
  经现有 TextInputFailure 记账并抛 UnsupportedOperationException，不伪造绘制成功。
- XML shadowColor 原拒绝分支与 shadowDx/Dy/Radius 未开放范围保持。

## 阴影模糊口径与支持边界

复用现有正文光栅路径，以不透明白色生成同一字形掩码，包含粗斜体、fallback、冻结
line-plan 和换行；先偏移/模糊并按 shadowColor alpha × 节点 alpha 混合阴影，再绘制正文。
为保留 clip 外投射入 clip 内的阴影，掩码先扩边，最终绘制沿原 clip 裁剪，不扩测量框。
分数 dx/dy 通过模糊掩码双线性采样实现，不截成整数。

本地没有 Skia 实现，使用公开的
[SkBlurMask::ConvertRadiusToSigma](https://skia.googlesource.com/skia/+/2f538e329a7d/src/core/SkBlurMask.cpp)
换算：sigma = 0.57735 × radius + 0.5（radius > 0），归一化可分离高斯卷积截断到
ceil(3 × sigma)。实际 radius 钳制到 32 px（最大支持宽度 57 px），getter 保留原始值；
防止不受控卷积成本，超限仍真实绘制有界阴影，不静默丢弃。该近似不承诺 Skia 像素一致。

## 自行决定事项

**实施方按编排方常设原则决定，待编排方复核。**

1. 使用上述可分离高斯、3 sigma 截断与分数偏移双线性采样；复用正文路径生成掩码，
   无需新字体引擎/Skia 依赖。
2. 实际模糊半径钳制 32 px、getter 保留原值；非有限值或超 ±4096 px 偏移原子失败并记账。
   非有限值是明确的有界支持差异，并非虚构 AOSP 校验。
3. 首轮 DEX 验证证实 source=failure 的成员准入表会抹除已注册 handler；因此必须将
   view-paint-sources.json 中仅这五个既有 TextView 签名改为 reviewed overlay。
   不改类集合、DEX 算法、dexvm 核心或 JNI 桥；共享 surface 从真实 dump 仅更新这五项，
   其引用文件仅机械更新校验和（旧快照会覆盖单独的 TextView 快照，不能只换一个指针）；
   同步生成 manifest，并按任务的实际触及条款
   补跑 compose、dalvik/JNI。未放宽 ADR-0147，其他未实现签名继续失败。
