# DVM-341 · USB 无设备客户端与 Context 工厂

状态：有界完成。依赖：API19 BootDex、Context 工厂、DVM-222。

范围：提供进程内 UsbManager 的无设备查询，使获取 manager 不提前拒绝。
不实现宿主 USB 透传、UsbService、Binder、UsbDeviceConnection、UsbRequest、
USB 通信、热插拔派发或权限授权；不增加其他服务，不改 title_preflight。

实现：
- UsbManager 来自固定 AOSP 4.4.4，保留许可证、全部常量/公开签名和
  (Context, IUsbManager) 构造器；服务调用替换为 private static native。
- Bundle 不写入设备；原列表循环返回空 HashMap，原配件分支返回 null。
  openDevice 保留 getDeviceName 和 catch，native 记账，不创建连接；null 由 ROM 捕获 NPE。
  hasPermission 记账并返回 false；请求权限、打开配件和设置功能/存储记账抛 UOE，
  不保存或派发 PendingIntent。三个 SystemProperties 算法原样保留。
- 工厂先初始化类，调用原构造器（service=null），在 session singletons 缓存并经既有根集保活。
- overlay 纳入 FRAMEWORK_JAVA_NAMES 与 native ABI 表，移除 framework.jar 重复 UsbManager。
  IUsbManager、UsbAccessory、UsbEndpoint、UsbInterface 来源不变；不加入三个设备传输类或 native。
  公开 SDK 缺少 IUsbManager/SystemProperties，builder 生成仅编译声明，并在 D8 前移除对应 class；
  生产定义仍由原配方唯一提供。
- 新增 dexvm.usb_absent_facade（partial）及 dexvm.usb_transport（unimplemented）。

验收边界：macOS Release ogplay/ogplay_tests；新增 DVM-341 与相邻 DVM-222、DVM-136
定向用例（switch/threaded），BootDex build/check/native ABI、Android payload、能力账本检查。
原命令 `./ogplay-cli library run com.rockstar.gta3` 仅复现一次，记录退出码与下一首错，
不修下一错误；仅为 reached-fault 证据，不代表 title gate 或兼容验收。

证据：`.local/gta3-usb-fix/`（不入库）。Windows、真实 USB 设备及完整游戏未验收。
