## 阶段 1：ROM 基线统一

统一为 AOSP android-4.4.4_r2.0.1 原版 ROM；固定点见本地 `rom-inputs.json`。
重新生成 skeleton、policy reference、逐成员来源/指纹、主题投影及 BootDex manifest。

验收：BootDex build/check/audit、payload，macOS Release 受影响定向测试，GTA3 原命令一次。
必须保持 Locale.getDisplayLanguage 首错；有回归先修，阶段 1 通过前不进入阶段 2。

### 阶段 2 实现

六个 ICU native 使用 C ABI；显示名走共享预探测/分配/重试缓冲，错误经既有 ICU→Java
异常映射；未知 ISO3 保留空字符串供 ROM Locale 抛 MissingResourceException。
Locale 在 core.jar 配方与日期审计均归 boot_dex；保留原版常量、字段、缓存与 setDefault。
新增 DeviceLocale 严格校验投影，System 初始化与 AConfiguration provider 同源。
Configuration 每次查询更新 locale；既有 TextUtils 的布局方向仍仅支持 en/zh，未扩大边界。


### 全量与冻结基点对照

按授权仅运行一次全量：ogplay_tests=2105 通过/94 失败/7 skip；ogplay_app_tests=95 通过/1 失败。
给定的 1903/1903、89/89 不是当前测试数量。冻结 SBX-16 基点测试程序对这 94 个失败用例
定向复跑（配套旧 CM BootDex，结束后精确恢复最终 JAR SHA-256）：92 个同样失败，2 个通过。
未重跑第二次全量，未修复其余历史失败。

两个差异已按 AOSP/实际并发路径处理：
- Intent.putExtras(null)：CM 有 null guard，AOSP 原版抛 NPE；仅修正旧 CM 测试期望，不改 ROM。
- PendingIntent：复制原版 Intent/分配 wrapper 时可暂停，旧候选快照后另一调用可能已发布 token；
  在发布前检查新候选并重试，保持同一键唯一身份。不在 guest 回调外持宿主锁。
  复用 DVM-211 并发与控制 flags 回归，不增加能力范围。

app 唯一失败为 DIAG-4 对 GLSurfaceView.onPause 的旧不可覆写断言；旧 CM 和 AOSP 的声明
均为 public onPause()V，现有 VirtualMethod 实现未改。保留该无关断言缺口。

JNI 双后端各399/399、静态233/233，与基线无变化。dalvik 全套初跑出现 074/080/096 超时；
独立按180秒预算定向复跑三个用例双后端均通过，合并后各85/91；原超时日志完整保留。

GTA3 最终原命令一次：getDisplayLanguage 首错消失；退出1，下一首错为
ActivityManager.getRunningAppProcesses 的显式 UOE（WarMedia.GetMemoryInfo pc119），未修复。

以旧哈希目录下的原 smali 与新 ROM 逐签名比较实际 handwritten 表面，发现并删除剩余四个
CM native 声明：Typeface.nativeFreeCaches、MediaPlayer._suspend/_resume、FileUtils.getVolumeUUID。
前两类不再返回无效果的成功/固定 false；API19 不声明对应 CM 包装 API，调用按缺失成员失败。

普通 Java 缓存不变。旧 TypeFace 用例的该断言改为 AOSP 缺失成员判据，其后原有 Legacy UI
投影缺口不在此修复。
