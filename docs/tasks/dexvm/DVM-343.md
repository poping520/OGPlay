# DVM-343 · 离线拓扑的 guest 网络接口视图

状态：实现及有界验证完成；保留既有失败。依赖：DVM-241、API19 ROM NetworkInterface/Posix。
决策：[ADR-0168](../../adr/runtime.md#adr-0168)。证据：`.local/gta3-network-interfaces/`。

## 范围与验收

integration 从 offline_connectivity 派生不可变接口表，发布可撤销只读 sysfs/proc 文件；
同表回答 Posix 的三项 IPv4 ioctl。只有 lo；不读宿主网络，不合成 WiFi/MAC。
IoRuntime 拥有仅供接口查询的逻辑描述符，AF_INET/AF_INET6 + SOCK_DGRAM + protocol 0；
close 幂等，其余操作明确失败。本地查询不受 transport NetworkPolicy 的 IO 授权限制。
缺拓扑或 context 在线策略按 ConnectivityManager 的未知事实边界记账抛 UOE。

双解释器检查 ROM 枚举、IPv4/IPv6 回环、前缀/广播、flags/MTU/MAC、名称查询；
检查 errno/记账、关闭及五个发布路径的冲突回滚。复用既有网络主题文件，
本次仅加入网络接口用例，不整理已有网络/SQLite 夹具与历史测试。
macOS Release 仅构建 CLI/ogplay_tests，定向运行；九基础场景各一次，与既存结果比较；
GTA3 原命令一次，仅记录下一首错，不修复。不跑全量、不提交、不全文件格式化。
