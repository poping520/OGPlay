# DVM-344 · API19 UI 字体链与同源注入

状态：实现与定向回归完成；真实 EULA 呈现/交互受下一阻塞限制。依赖：DVM-235、DVM-342。
决策：[ADR-0169](../../adr/runtime.md#adr-0169)。证据：`.local/gta3-dialog-font/`。

范围：原版 API19 Roboto-Regular → DroidSansFallback 两级不可变字体链，各自固定 SHA-256；
ASCII 保持5x7像素/度量，粗斜体合成。会话宿主树统一工厂同源创建，复制保留链身份。
UI 覆盖检查供 Paint、TextView 构造/setText、EditText 实际输入和 raster 共用；失败携带
码点，保留现有记账与 Java 异常。整链缓存128项，保留 BMP/shaping/combining/bidi 限制。
不读宿主/应用字体，不引入其他字体或完整排版。

验收：macOS Release CLI/ogplay_tests、payload 校验、UI renderer/Dialog/Paint/EditText
定向回归；九基础场景各一次，与既有6/9比较。GTA3 原命令 cwd=build/release 运行一次，
截图对话框并按既有 MCP 输入点 Accept，只记录下一首错。不得提交、全文件格式化或跑全量。
