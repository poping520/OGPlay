# DVM-345 · 未 queue buffer 的 Surface 不阻止 Dialog 呈现

状态：实现及定向回归完成；真实 EULA/Accept 验收受后续阻塞限制。依赖：DVM-339、DVM-344。
证据：`.local/gta3-surface-unbuffered/`。

范围：按 holder 的 created 生命周期保存真实 buffer queue 事实；created 复位、destroyed/退役清除。
Canvas post、媒体帧与 surface_pixels 发布记录出帧；Java/native 共用 EGL 成功 window swap
通过显式身份回调上报，boundary worker 不获取 VM 锁、不保存 Java 引用，退役与上报串行。
创建 EGLSurface、lockCanvas 或 Java 生命周期本身都不算出帧。

API19 中未 queue 的 Surface 不提供合成层，SurfaceView 开孔后是黑色底，Dialog 独立叠加。
无 GL renderer 时，统一判定仅允许纯 View 或全部活跃 holder 均有保留像素/尚未出帧的情况
按 presentation_epoch 发布软件底帧；已出帧但无保留像素的 producer 保持底帧权威。
保留已有 GL renderer、视频泵与 retained-surfaces 合成路径。

验收：macOS Release CLI/ogplay_tests，双解释器 surface/dialog/video 定向及相邻回归；
九基础场景各一次，无新增失败（基线6/9）。GTA3 使用 DVM-344 原命令与临时 MCP 设置，
截图 EULA（含 ©），MCP 点击 Accept，仅记录下一首错/阻塞；结束恢复设置。
不提交、不全文件格式化、不跑全量。
