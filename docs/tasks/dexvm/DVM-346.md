状态：实现与本次验收完成；下一native首错保留。依赖：DVM-344、DVM-345。证据：`.local/gta3-dialog-visibility/`。

范围：宿主 modal 可见性仅从 Dialog 与 owner 状态推导；UiTree 的 owner 修改单调计数，
冻结树复用同时匹配 partition、revision 与修改计数。共同呈现拒绝原因及 modal 的 live/frozen
状态通过既有 Dashboard dexvm section 记账，不改变 Java facade、按钮协议或 holder 出帧事实。

## 实现与验证

- 移除 show、show/hide 与 synchronize 中的 modal SetWindowVisible；筛选、TopDialog、
  HasAndroidModalDialog、焦点与捕获清理共用 DialogVisible。宿主根保持可见。
- UiTree 结构、owner 属性访问、布局结果、窗口事实、焦点与按下态进入单调修改计数；
  复制保留，uint64 溢出明确失败。窗口事实专用投影提交从当前构建计数推进，不能沿旧冻结值回退。
  纯只读消费使用 const Get；dirty 消费不登记为新内容。冻结复用增加该计数，same_modals
  由冻结树身份自然反映变化。Java facade、按钮回调与 DVM-345 holder 判定未改。
- PublishAndroidPresentation 每个拒绝出口进入原因枚举/累计计数；Dashboard dexvm.presentation
  保存最近拒绝与分原因计数，以及每个 modal 的可见事实、revision、live/frozen 修改计数和根可见性。
  VM 竞争时 presentation 为 null；沿用既有 try-lock 来源，不增加诊断框架。
- 修复前双解释器回归失败16条断言，覆盖隐藏冻结根、缺焦点、epoch不变、按钮像素为零及无点击回调，
  见 `repro-before.log`。修复后新增回归与 UiTree、DVM-345、retained-surface 定向4项/391断言通过。
  Tab 只改变焦点时推进共同 epoch，新冻结焦点正确，旧冻结树不变；干净同步复用同一快照。
- macOS Release CLI/ogplay_tests 构建成功。相邻8个主题文件154项中原有17项失败，
  44条失败断言/异常与 `.local/locale-rom-java/frozen-failed-cases.xml` 一致；无新增失败。
  ARM JNI Dialog 旧断言改为宿主根始终可见、共同快照中 modal 已移除；仅重跑此用例与新增回归，
  原有两个 getSurface identity 失败不变。两次日志及逐用例替换规则见 `adjacent-comparison.json`。
- BootDex build/check、Android payload、433项 capabilities check通过；仅宿主审计配对元数据
  与 manifest 更新，classes.dex SHA保持不变，未改配方/Java算法。
- 九基础场景各一次，仍6/9。Tales退出读0x315f0001、Dead Trigger teardown预算、PVZ
  stopService的状态、firstFailure和实际首错行均与DVM-345相同，见 `scenario-comparison.json`。
  不是正式title gate；所有场景及真实GTA3使用同一最终CLI与运行时库。
