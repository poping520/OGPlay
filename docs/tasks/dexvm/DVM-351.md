## 迁移与 adapter review

`view-absolute-sources.json` 加入唯一生产 `java-traversal.json`；两个类均保留完整 ROM
class shape、字段、flags 和原方法体 hash。删除 AbsoluteLayout/参数的 intrinsic 声明及 catalog
登记，无宿主 x/y 字段读写或替代构造。原字节码未经改写，无新增 native 或 overlay。

| 接缝 | 输入、owner 与失败边界 |
| --- | --- |
| 构造 | 三个 Context/AttributeSet/style 构造保留 ROM，调用既有受审 ViewGroup；属性由真实 TypedArray 消费，未知资源延用原有记账失败边界 |
| 参数 | x/y 与宽高为真实 Java 字段；四整数、复制和属性构造、检查、默认及转换生成全部 ROM；addView 沿原检查/转换逻辑 |
| 算法 | onMeasure 的子元素外接、padding、suggested minimum 和 resolveSizeAndState；onLayout 的 padding+x/y 与 GONE 跳过均执行原版 Java |
| 宿主 | 构造守卫按真实 AbsoluteLayout 可赋值关系准入任意 guest 子类；宿主只从成功遍历收集投影 |
| kind | 保持 FrameLayout kind，不新增 UiClass；ADR-0157 下 ROM 是 guest 几何唯一所有者，kind 仅供宿主 Dialog HostLayout 等分类用途 |
| WebView | 自有 protected onMeasure 为 UnimplementedOverride，对应 API19 provider 委托而本平台无浏览器后端；不声明 onLayout，继承 ROM AbsoluteLayout |
| 诊断 | LayoutParams.debug 沿 FrameLayout/RelativeLayout 同类入口设 failure；不获得字节码或成功 handler，命中按 ADR-0147 失败记账 |

不修改组合审计、父链、开放世界虚派或闭包规则。DVM-314 原断言不改，只将用例名中的
父类失败边界表述改为 WebView 自有边界，继续要求消息含 onMeasure 且 ledger 有记录。
