# DVM-352 · ROM View 背景颜色与失效回调投影

状态：完成。证据 `.local/dvm352-background-color/`。

## 实现与支持边界

View.setBackgroundColor、invalidateDrawable、verifyDrawable 执行固定 API19 ROM。
ColorDrawable 的构造、get/setColor、get/setAlpha、getOpacity、mutate、ConstantState 与
mState/mPaint/mMutated 均归 ROM；draw(Canvas)/inflate 保持未准入。
ColorState 已在基础配方；Paint 无参构造复用既有受审接缝，无新 native。
Drawable.mutate 仅 return this，无 native/依赖，作为必要父类闭包补为 ROM。

全部颜色状态由 Java 拥有，删除宿主影子颜色。两个资源工厂均调用 ROM 构造器，宿主仅
登记 resource ID/像素元数据。Resources.loadDrawable 不再假定 ROM 构造器创建宿主记录。
背景及 ImageView 投影每次虚派 getColor，复用集中 ARGB→RGBA 转换；背景 alpha=1，
零 alpha/null 清空颜色和资源。其他非空背景不绘制、不抛异常，记录
`dexvm.view_background_draw` 与 first_and_count 的 `ui.background.unreviewed` warn。

DVM-329/DVM-285 旧夹具改用 Java setter，保持原像素/顺序断言；未审查背景用例使用
测试 DEX 的普通 Drawable 子类，通过 Java setBackground 安装。
纯绘制失效能刷新投影而不重排，测试检查像素与失效结果，不误断言每次都发生 layout。

## 子类拒绝审查

对照固定 AOSP drawable 源逐个审查（drawable-state-audit.json）：

- BitmapDrawable、DrawableContainer、NinePatchDrawable、StateListDrawable 原有 failure
  成员阻止静默继承；相关未准入状态重写现明确记账并抛 UOE，受审 skin opacity 查询保留。
- PaintDrawable 宿主扁平层级漏掉 ShapeDrawable 的重写，现显式拒绝五项状态方法。
- ShapeDrawable、GradientDrawable、LayerDrawable 仅骨架，保留原始成员的 ULE；
  动态测试同时检查它们不落到 Drawable 默认返回。

拒绝接缝有明确 overlay review，用编译后的真实 catalog handler 条目更新相关 surface
成员及固定 hash；未改审计规则。raw-catalog-surface.json 是未装配 ROM 的声明提取，
有无关 core 层级缺口，不作为完整平台链接证据；最终以组合审计与动态分派为准。
