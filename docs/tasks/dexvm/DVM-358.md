# DVM-358 · XML drawable 共用准入与 JNI 反射异常链

状态：按确认后的验收边界实施完成；XML 位图背景 opacity 为后续独立能力缺口。证据 `.local/dvm358/`；未提交。
依赖：[DVM-292](DVM-292.md)、[DVM-316](DVM-316.md)、[DVM-355](DVM-355.md)、[DVM-357](DVM-357.md)。

## 根因与修改

1. Styled 对 drawable_attributes_ 只放行 projected_reference_ids_，提前拒绝应用纯色和位图，
   比 loadDrawable 真实能力严格。复核临时诊断 `.local/dvm358-probe/gtasa-current.log`，
   GTASA loading screen 根 LinearLayout 的背景 @color/black 因此失败。
2. JNI ExceptionChain 只读 ClassNotFoundException.ex，否则读 Throwable.cause，漏掉
   InvocationTargetException.target 与 ExceptionInInitializerError.exception；解释器另有一套规则。

ThemeResources.CanLoadDrawable 是 Styled/loadDrawable 唯一准入入口；不改属性集合、皮肤或投影生成器。
Resolve 原有文件预检保留；判据复用 APK owner 注入的配置选择和 DecodeLeafBitmap 验证回调。
返回 false 或文件验证异常均沿 ThemeChecked 记 dexvm.theme.unsupported 并抛 UOE。
未封存 ROM 引用在 Styled 提前拒绝，不将已有“投影身份”当作可加载信用。

| 输入 | 准入 |
| --- | --- |
| type1、data=resourceId、ROM 0x01 | 仅 Drawable 封存 skin；沿 MakeRomSkin |
| type28–31 | 纯色；沿 ROM ColorDrawable |
| type3、cookie1、有效非 ROM resourceId | 配置选中的标量 drawable entry，type/data/density 匹配；res/ PNG/JPEG，解码/编码/尺寸/npTc/npLb 等既有验证通过 |
| 应用 XML/selector/shape、ninepatch、其他值 | 明确失败并记账 |

Interpreter.DiagnosticThrowableCause 只读 ITE.target、EIIE.exception、CNFE.ex，其他读 Throwable.cause；
DescribeThrowableCauses 与 JNI 共用。原两种输出格式、16/8 层上限、JNI 消息/长度限制及环检测保留。
不执行 guest getCause，不改变 pending、异常身份或 ThrowableCause 基类读取语义。
