# DVM-361 · TextView 横向滚动（不按宽度折行）状态

状态：实现、macOS 定向验证及 reached-fault 完成；Paint 保留既有负例失败。未提交。证据 `.local/dvm361/`。
依赖：[DVM-295](DVM-295.md)、[DVM-360](DVM-360.md)。

## 根因与状态归属

GTASA andLabel$andLabelImpl.<init> pc27 调用 failure 成员 setHorizontallyScrolling，抛 ULE。
API19 TextView.java:3019/3038 的 setter/getter 与 :5929/6383/7098 已复核。
Java mHorizontallyScrolling 是唯一权威，字段与 getter 改为 ROM，准入审计无放宽。
setter 是具备五项 review 的 overlay，同值直接返回；变化才写字段并走既有 changed(c)，
清测量缓存、推进 text_revision、requestLayout/invalidate。构造默认 single=false，字段为 false；
singleLine 样式构造及 setSingleLine(Z) 同步写该字段，与 applySingleLine 一致。

## 折行与单行拆分

TextLeafInput 新增 no_wrap；single_line 或 no_wrap 均跳过 WrapFixedText，
只有 singleLine 执行换行转空格。maxLines 截断不变，EXACTLY/AT_MOST 仍约束视图尺寸，
只取消文字布局宽度限制。onMeasure 和子类自定义测量后的光栅计划均读取 Java 权威，
沿现有裁剪；不实现滚动偏移或 marquee。

快照仅更新 TextView 的上述 setter、getter、字段三项真实声明，引用配方 SHA 同步；
原版字节码、flags/body SHA 不变。首次 build 因快照 setter 尚标未实现被拒绝，更新后重验。
