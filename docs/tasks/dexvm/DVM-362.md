# DVM-362 · TextView 文字状态与固定字体度量

状态：实现、macOS 定向验证及 reached-fault 完成；保留既有 Paint 负例失败。未提交。证据 `.local/dvm362/`。
依赖：[DVM-293](DVM-293.md)、[DVM-361](DVM-361.md)。

## 状态归属与支持范围

每个 TextView 在构造中创建自己的 TextPaint，Java mTextPaint 强边保活，getPaint 执行 ROM，身份稳定。
PaintMeasureState 的字号、Java Paint.mTypeface 是唯一权威；UiNode 字号/样式仅是供现有测量服务消费的投影。
TextView setter 写穿 Paint 并同步投影、清缓存、requestLayout/invalidate；getTextSize/getTypeface 从 Paint 读取。
移除原 adapter Typeface 身份侧表。AA 构造固定为 true；直接改此 Paint 的字号、字体或 flags 记账并抛 UOE，
不留下两个可独立漂移的状态。普通独立 Paint 仍可修改已有支持的状态。

mHint/mFilters 由 Java 字段持有，getHint/getFilters/getPaint 与资源 setHint(int) 执行 ROM。
空正文时，普通测量与 guest onMeasure override 的冻结光栅计划均选 hint，颜色取当前 hint 色；
有正文时恢复正文，密码类型仅变换显示，不改 getText 返回的文本。Spanned 输入/输出仍明确失败。
当前颜色字段由既有状态色解析路径更新，getCurrentTextColor/getCurrentHintTextColor 执行 ROM。

输入类型保存在 View owner-attached 的有界 adapter 状态，getInputType 使用 overlay；
ROM getter 依赖 mEditor.mInputType，不能在无 Editor 的叶路径直接执行。setInputType 不构造假 Editor，
按 API19 isMultilineInputType 的 class/0x20000 组合经 setSingleLine 同步横向滚动位。
0x81/0xe1/0x12 使用等价 U+2022 密码显示变换；进入密码/可见密码时选择 monospace，退出时恢复默认字体。
先验证字体覆盖，缺掩码字形明确失败。KeyListener、IME 选项、数字/邮箱键盘不实现，但不据此拒绝输入类型。

setFilters 保存原数组身份，null 抛 IAE；TextView 与 EditText 的 setText 都顺序虚派 filter，
参数为当前 source、0、length、ROM EMPTY_SPANNED、0、0；非 null 结果传给下一个 filter。
不把匿名游戏 filter 替换为宿主回调，不在 setFilters 时改写已存正文。

## FontMetrics 推导

用户修订约束为 ascent < 0 ≤ descent，保留既有高度和 baseline。
MeasureFixedText(u"M",size,style,font) 单行高度为 7×scale；现有 baseline 为 7×scale。
固定 ASCII 字形格子七行，基线在底部，无下伸部，因此 top=ascent=−7×scale，
descent=bottom=leading=0。返回行高来自 MeasureFixedText，满足 descent−ascent=行高、−ascent=baseline。
MeasureFixedText 对回退 BMP 的单行布局高度仍为 7×scale，无单独的行高口径。
回退字体的真实位图由 Glyph(unit,8×scale−1) 生成，其墨迹边界可能不同；本单以统一服务的行高为准，
不修改原光栅位置，也不导出字体文件自身的 ascent/descent 或墨迹边界。
不宣称等价 Skia。无参数 getFontMetrics 执行 ROM 分配并调用受审 (FontMetrics)F seam，null 参数只返回行高。

Paint 两个 getTextBounds 重载复用已有 measureText 的范围/覆盖检查及 MeasureFixedText，
TextPaint 移除旧 8×16 估算并继承 Paint 实现；bounds 为基线坐标的固定格子范围，不是 Skia 墨迹边界。

## 缺口与边界

不实现 guest onDraw/Canvas 文字绘制、Paint 颜色/样式、StaticLayout、完整 Editor/IME、Spanned 样式、
复杂 shaping、宿主字体原始 metrics、密码短暂明文显示/跨度观察器或触摸键盘。
本单不修改 DVM-293 setShader(null) 旧负例，不处理下一独立首错。
