# DVM-363 · ImageButton 默认背景与 View 配置杂项

状态：实现、macOS 双后端验证及两款游戏 reached-fault 记录完成，未提交。证据 `.local/dvm363/`。
依赖：[DVM-355](DVM-355.md)、[DVM-362](DVM-362.md)。

## 实现与准入决定

theme_projection.drawable_closure 仅新增同 ROM btn_default（0x01080004）封存根，
递归取 selector 引用的五个 nine-patch：btn_default_normal、btn_default_normal_disable、
btn_default_normal_disable_focused、btn_default_pressed、btn_default_selected。
保留原配置、密度、PNG/npTc 和引用闭包验证，不加入其他按钮样式，也不跳过构造时默认背景加载。

StateListDrawable 尝试 ROM 构造/addState 的准入审计明确失败（rom-audit.log）：
`ADR-0156 parent-intrinsic-unimplemented-member DrawableContainer.<init>()V`。
其 private 构造还需 StateListState 构造、setConstantState；后续 addStateSet/DrawableContainerState
状态链未开放，不能只切最外层构造而混用空 Java 容器字段与既有宿主 backing。
因此沿 DVM-326 已有 selector backing 扩充受审 overlay，不新增整套 DrawableContainerState。
构造、addState、count/state/child 查询五项 review 齐全；状态数组和子 Drawable 保留原身份并参与 owner GC trace，
匹配执行 ROM StateSet.stateSetMatches，按 API19 保留顺序、负状态、0 终止符和 wildcard 回退。
封存资源也经同一 addState 接缝构造，不再维护另一份状态数组内容。
运行时 selector 只更新状态，不能获得 ROM skin 绘制信用；背景投影沿既有未审背景记账不绘制边界。
无 ConstantState clone、过渡/动画或 guest Canvas 绘制支持。

ImageView.setAdjustViewBounds/getAdjustViewBounds 及状态字段、onCreateDrawableState/mState/mMergeState
执行 ROM；后者是替换 ImageButton 背景触发 drawable-state 的必要依赖。
ViewGroup.onCreateDrawableState 同样按 ROM 准入，是 DVM-358 的 LinearLayout 使用 btn_default 所需依赖。
View 四方向 nextFocus setter/getter、sound effects flag、horizontal scrollbar flag 及 toString 执行 ROM；
复用已有 computeOpaqueFlags/resolvePadding 闭包，不新建 flags 副本或宿主焦点导航机制。
setAdjustViewBounds(true) 仍由 ROM 设置 FIT_CENTER，false 不改变 scale type；FIT_XY 沿已有支持路径。
本单验证配置状态往返，不扩展既有有界 ImageView 叶测量为完整 adjust-bounds 布局算法。

View.toString 原样保留类名、identityHashCode、flags、坐标、id 与 NotFoundException 捕获。
Resources 三个名称查询依赖未开放的 AssetManager native，使用明确受审 overlay 接现有 ThemeResources。
应用名称取当前应用 ARSC 的身份记录（不解析引用、不依赖所选值配置）；系统名称取同 ROM ARSC 封存名称表，
不从数字猜名字，也不授予内容加载支持。缺失抛真实 Resources.NotFoundException，ROM toString 保留十六进制 id。
外部包、不存在名称和系统未知 id 无伪造成功；封存表重复 id、非法类型/包、越界和冲突拒绝。
