# DVM-364 · Spinner 构造—适配器—布局—选择回调链

状态：实现、macOS 双后端定向、关闭反证、制品终检与 reached-fault 完成；未提交。证据 `.local/dvm364/`。
依赖：DVM-326/355/357/358/362/363；准入政策见 [ADR-0174](../../adr/dexvm.md#adr-0174)。

## 验收边界

同 ROM DIALOG Spinner、ArrayAdapter 原版布局内容及异步选择回调整链；
严格 ROM 成员审计，默认 btn_dropdown 沿既有皮肤封存。
不实现点击弹窗、DropdownPopup/ListPopupWindow、触摸选择和 guest Canvas/onDraw。

## 后续依赖

ProgressBar.setIndeterminate、ListView、ExpandableListView 不在本单范围。

## 准入与实现记录

- 构造、适配器、计数/选择、测量/布局、选择通知及观察者 onChanged 执行固定 ROM，
  strict parent/dependency/dispatch 规则不变。DropdownPopup 与转发 listener 的构造器为
  明确拒绝的 overlay，保留原 Spinner 构造器两个分支而不授予弹窗运行信用。
- 原版 dropdown selector 有七条状态项，引用五张不同 nine-patch；PNG 有两个纵向伸缩区。
  backing 保留全部分割点，宿主 nine-patch 采样按伸缩区总长度分配、保留中间固定带。
- 两系统布局以同 ROM 原始 binary XML 封存；生成与加载分别核验身份/默认配置/引用与内容 SHA。
  getLayout 复用真实 XmlBlock/Parser，未封存系统布局保持 NotFoundException。
  dropdown 布局的真实根是 CheckedTextView；只封存内容，不授予该控件构造或弹窗支持。
- TextView 接受并保存 MARQUEE 枚举；未选中的普通单行文本可测量布局，实际启动 marquee
  动画仍记账失败。没有实现 Layout/Editor/Canvas 绘制。
- ViewGroup 附着父协议执行 ROM；View 接缝仅接受无 AttachInfo、无 IME 焦点、无 accessibility
  服务和静态封存背景的软件路径，按原 flags 唤醒 scrollbar、清理标志和重置子树通知位。
  不伪造系统附着，无障碍通知须有明确无服务事实。
