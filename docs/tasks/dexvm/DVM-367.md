# DVM-367 · 水平 ProgressBar ROM 资源与状态闭包

状态：已完成本单范围；证据 `.local/dvm367/`。依赖 DVM-365、ADR-0174。

## 范围与验收

封存同 ROM Holo dark horizontal 的 layer-list/scale、三个 ninepatch 及八帧 bitmap；
保留原始 XML、资源身份、配置、引用闭包和内容 SHA 校验。ProgressBar 的 tileify、
level、测量与帧集合使用原版 Java；无宿主 progress/max 副本。
允许静态 AnimationDrawable 构造与查询；实际 start/run/帧调度及 guest draw 明确失败。
Small/Large、Light、任意 Drawable XML 与动态皮肤不准入。

验收：制品 build/check、投影正反检查、双后端水平构造/层 ID/level/尺寸/帧数与拒绝边界，
关闭必要接缝/资源的反证；原 APK 同路径运行一次，记录下一首错。仅 reached-fault，不作 title gate。

## 接手的局部修复

Posix.fcntlFlock 支持单 guest 进程记录锁；主题投影区分 inert ROM 样式与未准入样式；
ContextImpl 基础主题按 selectDefaultTheme(0,targetSdk)，Activity 再叠加自身主题。
遗留检查：file_streams 13 用例/598 断言、投影 self-test、BootDex check、能力账本 check 通过。

## 实现与边界

同 ROM 的 LayerDrawable/ScaleDrawable/ClipDrawable/ShapeDrawable、AnimationState 与
BitmapShader 进入逐签名配方；新 surface 来自已编译 handler，未放宽成员来源或依赖审计。
封存 parser 仅在同步 ROM inflate 范围内可递归分派，任意应用 drawable XML 仍拒绝。
原版 tileify 保存 layer ID、level 和帧集合；有界接缝只承接像素 backing、Paint 副本、
BitmapShader 状态与 RoundRect Path 命令。GC 由真实 Java 引用保活位图和 shader。

Paint alpha/滤镜和 Drawable 镜像状态可读写的已准入子域不授予效果绘制信用；
ImageView 投影遇到不能呈现的非默认效果明确记账拒绝。帧调度、fade、ShaderFactory、
Small/Large/Light 与内容绘制仍不支持，ProgressBar 内容每 View 记账一次。
Posix 锁的负长度范围校验先排除负起点，避免 INT64_MIN 加法溢出。
