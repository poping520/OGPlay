# DVM-368 · TextView 最小尺寸与隐藏子树呈现

状态：已完成本单范围；游戏仍阻塞。依赖 DVM-367、ADR-0161；证据 `.local/dvm367/`。

下载布局越过水平条后，Holo dark Button 先遇到未封存背景，再遇到 minWidth/minHeight 拒绝。
背景仅补入同 ROM selector/ninepatch 数据闭包，不增加渲染机制。

TextView 构造按原版默认初始化 Java 最小值及模式字段，消费样式/XML 像素尺寸；
四个 getter/setter 执行原版 Java，setter 保留真实 requestLayout/invalidate。
现有叶测量合并像素最小值后受 MeasureSpec 约束，不把 TextView 字段写入 View 同名字段。
非零最小行数、ems、最大尺寸及完整 Layout/Editor 不在本单范围。

同路径下一错：GONE 容器的可见子 TextView 不经 ROM 测量，投影却要求已有行计划。
绘制准备现按祖先可见性剪枝；仍收集原始层级/几何，不为隐藏子树制造测量或内容。
可见分支仍按原有路径准备内容；回归只覆盖初始隐藏及可见对照。
TextView.onVisibilityChanged 仍未准入，本单不扩展其生命周期回调。
