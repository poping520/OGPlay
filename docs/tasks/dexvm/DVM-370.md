# DVM-370：AlertDialog 长文本滚动

状态：本次范围完成；定向主题保留 4 项历史失败；用户 2026-11-05 用 release OGPlay.app 手测反馈正常。

## 范围与决定

- 宿主 Dialog 共享 show/resize 布局；标题最多两行，消息独立 ScrollView，按钮固定在消息外。
- 消息超高收缩视口，按钮超宽等分且最多两行；chrome 超高夹紧并记录 UI 降级。
- 支持 8dp 阈值拖动、DPAD 上下半视口步进；resize 保留并夹紧偏移。
- 未发布树计算成功后提交，冻结快照不可变，不调用 guest 布局/回调。
- 消息预算沿用 kMaxFixedTextUnits；原有 owner/线程/窗口/文本合法性边界保留。
- 不改 ui_layout.cpp，不引入 ROM AlertController，无游戏专属逻辑，无需 ADR。

## 缺口

滚轮输入、滚动条、fling/overscroll 未支持；ASCII 5×7 字体宽度和非 ASCII 折行保持现状。
真实接受按钮与滚动交互由用户手测；运行证据仅算 reached-fault，不是 title gate。

手测：用原命令启动，拖动消息及按上下方向键，确认标题/按钮固定、消息不越界；调整窗口大小后
确认偏移夹紧；最后点击接受按钮确认回调与后续流程。滚轮不在本次范围。
