# DVM-371 · WebView 配置链的 scrollbar style 与惰性动画

状态：实现及定向回归完成；用户 2026-11-05 用 release OGPlay.app 手测反馈正常。依赖：[DVM-363](DVM-363.md)、[DVM-365](DVM-365.md)。

## 问题

Angry Birds 2.3.0 进入游戏换卡时，WebViewWrapper 构造 Runnable 调 `setScrollBarStyle(0)`，
抛 `UnsatisfiedLinkError: intrinsic handler is not implemented`。member-sources 把该方法标为 overlay，
但 handler 已不存在。同一 wrapper 的 show/hide 还调 startAnimation、clearAnimation 和
`new AlphaAnimation`，后者经 Transformation 构造调 `Matrix.reset()`，同样未实现。

## 决定

- View 的 setScrollBarStyle、getScrollBarStyle、setAnimation、startAnimation、clearAnimation 按 ROM 执行，
  加入 view-measure-sources；`mViewFlags`、`mCurrentAnimation` 是唯一事实，不新增 C++ 状态。
- 没有动画执行器。`mCurrentAnimation` 是惰性 Java 状态，视图直接显示最终状态，所以 invalidate、附着和
  drawable state 不再因它拒绝；invalidate 时记录 UI 降级 `View.animation`。其他系统状态仍明确失败。
- Matrix 仍是 identity-only，`reset()` 不改变状态，未初始化时抛 ISE；变换与 native_instance 继续失败。
  overlay 需要快照声明，view-horizontal.surface 只改 Matrix.reset 一行（同 DVM-360 做法）并同步 SHA。

## 验证

- `tests/dexvm/android_view_state_tests.cpp#DVM-371` 双后端通过：View/WebView 四种 style 往返；
  AlphaAnimation + LinearInterpolator + startAnimation + clearAnimation，附着后 invalidate 与可见性切换。
- DVM-331 负例改用 setScrollBarSize、setHovered。`compose_bootdex.py check` 通过。
- 定向筛选 83 项中 79 通过。DVM225 与两项 crypto 已列于 DVM-370 的历史失败。DVM-296 ImageView XML 的
  断言（`theme_resources_tests.cpp:2298`）期望 maxWidth 等属性抛异常，而 `android_widget.cpp:588-594`
  已将其改为 UI 降级，本单未改这段；该用例不在历史失败表中，未对照基线重跑确认。
- `library run com.rovio.angrybirds` 有界运行 20 秒无错误，但当时 `ogplay-cli` 目标不会重新 stage 运行时数据，
  这次运行很可能用的是旧 BootDex，不算修复证据。换卡路径未自动复现，由用户手测。
- 重建 BootDex 后要构建 `ogplay_bundle`，运行时数据才会更新到 `build/release/data` 和 OGPlay.app。

## 缺口

- 动画不逐帧推进；`AnimationListener` 回调不触发（BannerAdWrapper 会设置 listener）。
- `WebViewWrapper.executeJavaScript` 同步等待 JS 回调，而 `javascript:` URL 只记账，走到该路径时调用线程
  会永久等待。需要 JS 引擎才能解决，本单未处理，也未伪造返回值。
