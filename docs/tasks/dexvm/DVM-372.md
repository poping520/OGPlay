# DVM-372 · UI 显示设置统一降级

状态：实现及定向回归完成；用户 2026-11-05 用 release OGPlay.app 手测 Wild Blood 反馈正常。依赖：[DVM-371](DVM-371.md)、ADR-0147 修订。

## 问题

7133a3a0 已把 AGENTS.md 的“禁止伪造成功”换成 UI 降级规则，但只改了 TextView、ImageView 的部分属性。
没准入的方法仍走 interpreter 的 `UnsatisfiedLinkError`，手写 handler 也还在抛 UOE。Wild Blood 进入关卡时
`setText("", NORMAL)` 抛 “only EditText EDITABLE buffer”（3dd82b46 收窄）就是这一类。

## 决定

选择顺序：能执行 ROM 的优先 ROM；否则无返回值的显示设置降级；影响逻辑的继续明确失败。

- 新增配方来源 `ui-degraded`，名单在 `tools/bootdex/ui-degraded.json`，共 158 个方法。只接受 public、
  非静态、非抽象、返回 void 且当前为 failure 的成员，由 member_sources 与 class_linker 双重校验。
  ROM native setter 也可列入（Paint 大多如此）。运行时绑定为记录一次警告后返回的 handler。
- getter 不跟随降级：继续失败或保持 ROM，所以不会报告未应用的状态。
- 不降级：监听器注册（`addOn*`、`setOn*`）、层级变更、输出参数方法、`setTransformationMethod`、
  `setKeyListener`、Matrix 变换和所有返回值。
- ROM 准入：View 的 tag、scrollbar、hovered、activated、keepScreenOn、setBackgroundResource、isShown 等，
  TextView.setText(int)，ImageView 的 max/baseline/crop，FrameLayout.setForeground，Spinner.setEnabled，
  ShapeDrawable 的状态 setter。逐个经 member_sources 闭包校验。
- 受审 overlay：TextView 的 setEnabled、setTextKeepState、setText(char[],int,int)。ROM 版本依赖
  InputMethodManager 或 mText，因此委托既有有界路径；快照只改这四行并同步 SHA（同 DVM-360 做法）。
- 手写 handler 改为降级：TextView BufferType 和最小 ems/lines，Paint 的 flags、alpha、ColorFilter、文本尺寸
  及 TextView 持有的 Paint，Drawable.setAlpha、animate、autoMirrored，AnimationDrawable 调度，
  SurfaceHolder 窗口缓冲尺寸与 keepScreenOn，SurfaceView secure 和 window type，RelativeLayout 的
  alignWithParent、ALIGN_BASELINE，WindowManager 非标准几何与 flags（type 超范围仍失败），
  ImageView 不支持的 scaleType 和 Drawable，Dialog 的 outside-touch、theme、非 String 文本和超长文本。

## 缺口

- 被忽略的设置只留警告：旋转、缩放、平移不生效，复合图标、提示色不显示，可能造成显示偏差。
- 名单按方法名和 getter 状态人工审核，没有逐个核对 ROM 方法体的所有副作用。
- DVM-303 的 `requestAudioFocus` 查找失败，与本单无关，未修。
