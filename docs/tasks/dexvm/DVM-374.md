# DVM-374 · Manifest 主题元数据与空样式

局部修复完成。2026-11-08 在 macOS 越过原启动首错。

## 根因与改动

- 用 `aapt2 dump xmltree --file AndroidManifest.xml` 核对游戏库中的 1.9.1 APK。
  `Theme.NoTitleBar`（`0x01030006`）写在 `<manifest>`，`<application>` 无主题。Unity 读到 0 符合
  API19，随后 `setTheme(0)` 经 `Resources.Theme.applyStyle` 触发 APK 资源查询并抛
  `UnsupportedOperationException: UI resource id is missing: 0`。
- API19 `AssetManager` 忽略 `ResTable::Theme::applyStyle` 找不到 bag 的返回值。`ThemeResources::Apply`
  在校验 token 后对样式 0 返回，保留已有主题状态。非零未知或不支持的样式仍按既有策略失败。
- 补齐通用元数据缺口。Context、PackageManager 安装/归档查询及组件的 `applicationInfo` 共用
  `MakeApplicationInfo`，发布应用清单主题。`MakeActivityInfo` 发布 Activity 原值，alias 沿用 loader
  快照，缺省为 0，由 ROM `getThemeResource()` 回落。启动预合并主题和 ContextImpl 默认主题维持原逻辑。
