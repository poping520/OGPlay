# GUI-14 · 启动器界面中英文切换

状态：macOS 前端完成，2026-10-24；OGPlay.app 内点击待验。依赖：GUI-10（WebView 启动器）、全局设置 `language`。

目标：全局设置“语言”从预留项变为生效项，启动器主窗口（游戏库、导入向导、数据包提示、
全局/实例设置页、3D 卡带印刷）可在简体中文与 English 之间切换，切换即时生效。

## 范围

- webui：`i18n.ts` 以中文原文为键，`t()` 在 en-US 时查英文表，缺词回退中文；带占位符的句子
  用 `{name}` 参数，含 JSX 的句子拆为节点数组。根组件订阅语言变化后整体重绘。
- 全局设置页编辑“语言”时即时预览，放弃修改或未保存离开时回到已保存语言；`<html lang>` 同步。
- 宿主下发的设置字段名、说明与预留文字按其中文原文翻译显示，宿主 schema 不变。
- 3D 卡带的“版本/导入/副标题”经 CartFace 传入当前语言文字。
- host：`language` 字段去掉“预留”标记。

不做：宿主返回的状态详情、错误消息与 next_step、原生选择器标题、按键设置窗口与 Dashboard、
CLI 与游戏窗口文字；这些需要宿主错误码化，另立任务。

## 验证

`npm run check` 53 用例通过，其中 `i18n.test.ts` 扫描 GUI 源码：中文字面量均在英文表、模板字符串与
JSX 文本中无裸中文；宿主 settings.cpp/game_settings.cpp 字段文字按设置页拆分规则均有英文；占位符一致。
浏览器以模拟宿主核对：设置页点 English 即时预览，返回放弃后恢复中文，保存后主界面、设置分组、
导入向导为英文并写入 localStorage；重载时以宿主设置为准。重建 OGPlay.app。

缺口：未在 OGPlay.app 内实际切换；宿主文字（如数据包“未指定”、退出/错误消息）仍为中文。
