# GUI-15 · 卡带展示视图

状态：macOS 前端完成，2026-11-01；OGPlay.app 内点击待验。依赖：GUI-10（3D 卡带 cart3d.js）、GUI-14（界面语言）。

目标：把 `.local/gui-concepts/model.html`（卡带模型预览）中面向玩家的部分并入启动器：
从游戏库打开选中实例的 3D 卡带全屏查看，旋转/缩放、六个预设视角、拆开看电路板、自动旋转、
指向部件看名称，←/→ 沿游戏库当前列表切换。印刷、状态灯、磨损与金手指仍只反映宿主事实。

## 设计

- 入口：点击主视觉卡带（未拖动的单击）、“更多 › 查看卡带”、键盘 V（脚注 ⧉ 提示）。
  CSS 卡带或 3D 加载失败时菜单项禁用并说明到“设置 › 常规 › 主界面卡带”开启，脚注不显示。
- 视图沿用主界面的顶栏/脚注/背景（`.console.viewer`），返回按钮与面包屑为 ui-kit 共享控件（设置页同款），
  动作胶囊 A 拆开/合上、Y 自动旋转、X 复位；L/R（Q/E）或 1–6 切视角，B/Esc 返回且保留所选游戏。双皮肤生效。
- 3D：cart3d.js 新增 `inspect()`，复用英雄画布、渲染器与已预热的外观（同一 GL 上下文，不重复编译），
  OrbitControls 只开旋转/缩放；拆解位移表与预设视角取自概念页，部件按网格识别（外观替换了 GLB 材质名）。

不做（概念页的开发/宣传功能）：模拟游戏与状态切换（违背只显示宿主事实）、部件/贴图/AO/曝光/线框面板、
外壳材质（珠光/果冻）着色器、截图 PNG 与演示录像（WebView 无宿主保存通道）。

## 验证

`npm run check` 56 用例通过（i18n 覆盖新文案）。浏览器模拟宿主（3D 开）核对：点击主视觉打开、
V 键打开、拆开后电路板滑出且缺数据包实例无金手指、2 键/Q/E 切视角并停自转、Y 切自转、
←/→ 换游戏并在返回后保持选中、X 复位、Esc 返回、玻璃紫背景与部件提示；CSS 模式菜单禁用、无脚注提示。
设置页计算样式与改动前一致（返回按钮/面包屑迁入 ui-kit 后无差异）。顺带修正背景层签名：
无图标艺术图时（玻璃紫或无图标游戏）新挂载的背景此前不出现。

缺口：未在 OGPlay.app 内实测；手柄仅以键盘映射体现。
