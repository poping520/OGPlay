# GUI-22 · Windows 窗口外观

状态：首版已在 Windows 构建并目测通过，2026-11-05 放大确认框并换成应用图标，待用户再次目测。

范围：启动器和游戏窗口标题栏与启动器视觉一致，游戏关闭确认框不再使用系统旧式对话框。
不改 macOS，不改关闭流程和文案，不引入第三方依赖（系统库 d2d1、dwrite、dwmapi）。

实现：

- 标题栏：`window_chrome.h` 经 DWM 设置深色模式及标题栏、文字、边框颜色（`--bg`、`--ink`、`--line`），
  启动器在首次显示前设置，游戏窗口在 `SDL_CreateWindow` 后设置。辅助窗口（Dashboard、按键设置）同用此外观。
- 确认框：`game_window.cpp` 自绘圆角深色面板，黄色为焦点按钮，默认焦点“取消”，并压暗游戏画面。
  图标取 EXE 的 `OGPLAY_ICON` 资源，读取失败时退回绘制的警告徽标；macOS 仍用系统弹窗。
  行为以 [hal/windows 契约](../../../src/hal/windows/MODULE.md)为准。

已知边界：标题栏仍由系统绘制，是纯色，不随封面主色渐变；要融为一体需改无边框窗口，未做。
游戏运行中切换系统明暗主题时，SDL 会重设深色属性，最小化/关闭按钮图标颜色可能随之变化，未处理。

## 验证

开发机为 macOS，无 Windows SDK，每次改动先做以下检查，再由用户在 Windows 构建：

- 按 API 声明写桩头文件，对 `game_window.cpp` 做语法与严格告警检查（不等于 MSVC 编译）。
- macOS 构建 `ogplay_hal`，确认 `sdl_window_input.cpp` 的非 Windows 分支不受影响。
- `python3 tools/capabilities.py check`、`git diff --check`。

## 待人工验证（Windows）

1. 启动器、游戏窗口标题栏为深色，首次显示无白色闪烁；Dashboard/按键设置窗口同样。
2. 点击游戏窗口关闭：画面压暗，确认框居中；鼠标悬停/按下有反馈。
3. 回车或 Esc 继续游戏；Tab 切到“关闭”后回车退出；游戏恢复后按键正常，游戏窗口重获焦点。
4. 不同缩放比例（100%、125%、150%）文字和图标清晰，图标边缘无黑边、白边，英文文案不溢出；
   游戏窗口最小化时从任务栏关闭也能正常显示。
