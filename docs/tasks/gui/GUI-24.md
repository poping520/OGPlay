# GUI-24 · 游戏标记（内置颜色与自定义）

状态：未开始（2026-11-09 记录，暂缓）。前置：[GUI-23](GUI-23.md) 运行结果与“待排查”分类。

目标：用户可给游戏打标记并按标记筛选，覆盖系统无法自动判定的问题（画面错乱、无声等）和个人整理需求。
“待排查”仍由宿主事实自动判定，标记不参与、也不替代它。

方案（实施前复核）：

- 定义存库级 `tags.toml`：每项 id、名称、颜色、顺序。内置 7 个颜色标记（可改名），用户可新建自定义标记。
- 分配存条目目录，只记标记 id；改名只改定义，删除条目时分配随之删除。不放 meta.toml（只记导入事实）
  或 settings.toml（启动设置继承链）。
- GUI：“更多”菜单加“标记…”（勾选/新建）；卡带标签显示颜色点；顶部 L/R 依次为
  全部 · 可启动 · 待排查 · 标记▾，标记收进下拉避免顶栏拥挤。
- CLI：`library list --tag <名称>`，`library tag add|remove <id> <标记>`，`library tags list|create|rename|delete`。

可选后续：`library triage` 输出待排查清单（结局、错误摘要、日志尾部、复跑命令），视实际使用再定。

验收：GUI/CLI 增删改标记与筛选结果一致；库锁下原子写入；移除条目不残留分配；标记名 UTF-8 与长度校验。
