# GUI-5 · 每实例设置

状态：Windows 每实例配置主流程完成；运行时与沙盒管理预留项保持明确标记。
依赖：[GUI-4](GUI-4.md)。Linux 暂缓。

- 九组设置按 installation id 保存到 settings.toml；严格 schema 1，与全局配置共用私有 TOML 入口和恢复流程。
- 缺省键继承全局/默认值；数据包目录继承导入记录。保存校验版本与目录，覆盖不影响同包其他实例。
- 参数预览及正常/预检/诊断启动复用 BuildLaunchPlan；临时沙盒与持久沙盒参数互斥。
- 无 CLI 配置入口的运行时字段只落盘并标记预留；设备预设列表归 GUI-7。
- 沙盒身份重生、重置和存档导入导出缺少独立安全管理接口，UI 明确禁用；不直接改写沙盒内部文件。

支持：Profile/数据包目录、超采样、解释器、MCP 开关/端口/手动步进、临时沙盒；
正常/预检/诊断启动共用参数生成，预检不传 MCP。库状态与目录打开同步消费实例覆盖，
单个实例的损坏配置或 Profile 目录错误不影响其他实例。

边界：帧率、Clock 模式/倍率、输入模板覆盖尚无 CLI 入口，和显示/音频/网络/设备字段一起
只落盘。ANDROID_ID 查看/重新生成、存档导入导出及重置沙盒尚未接入；现有 SandboxStore
仅提供会创建目录/恢复临时文件的 Open 和稳定身份生成，不提供独立只读检查或重置管理接口。
GUI 不绕过该契约直接解析/改写沙盒内部文件。以上入口在 UI 显式禁用，不声称已生效。
