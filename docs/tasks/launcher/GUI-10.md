# GUI-10 · 宿主选择器期间保持导入模态

## 目标

让不可编程关闭的 SDL 宿主文件/目录选择器与 ImGui 导入模态保持同一生命周期。

## 依赖

- GUI-5：异步 APK/数据包目录选择器与导入摘要状态机。

## 结果

- APK 选择器未决时，导入页只提示用户在系统选择器中完成选择或取消，不再提供会让
  工作流先行销毁的 ImGui“取消”按钮。
- 数据包目录选择器未决时，摘要页同时禁用确认和取消；SDL 回调到达后才恢复操作。
- `CanDismissImportModal` 是不依赖 SDL/ImGui 的唯一策略事实，避免后续页面再次引入
  悬挂选择器。

## 验收

`gui_import_tests` 机器断言宿主选择器未决时模态不可关闭；Windows/MSVC `/W4 /WX`
构建与真实 GUI 冒烟通过。
