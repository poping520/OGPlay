# GUI-11 · 运行结果延后排队呈现

## 目标

让游戏退出或启动失败的诊断消息不打断导入、设置、删除和退出确认工作流。

## 依赖

- GUI-6：子进程非阻塞回收和运行结果呈现。
- GUI-7：设置、删除与退出确认模态。

## 结果

- `GuiMessageQueue` 按 FIFO 保存所有非零退出和启动诊断，不再由后一条覆盖前一条。
- 仅当 ImGui 当前没有任何其他 popup 时激活下一条消息；已有活动消息关闭后才呈现后续
  消息，因此不会顶掉导入摘要或丢失其内部状态。
- 退出确认优先于诊断消息，避免同帧两个根级模态互相替换。

## 验收

`gui_view_model_tests` 机器断言 popup 未决时不激活、激活后不抢占、关闭后保持 FIFO；
Windows/MSVC `/W4 /WX` 构建与两个真实 GUI 冒烟通过。
