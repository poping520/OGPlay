# GUI-18 · 双栏主面板与现有动作接线

## 目标

把游戏库网格重构为左侧列表、右侧详情的 SDL3 + ANGLE + Dear ImGui 主界面，并只接入
已经存在的导入、设置、启动和删除工作流。

## 依赖

- GUI-17：选择、详情和运行条件模型。
- GUI-8/11/14：按钮 ID 审计、popup FIFO 与视觉/空闲质量。

## 结果

- 默认窗口 1280×720、最小 960×640；深色主题使用绿色主操作、橙色缺失与红色破损/
  删除，继续使用可缩放 18px CJK 字体和 ANGLE GLES2 renderer。
- 顶栏绘制无外部资源的 OGPlay 标记及导入/设置；主区按约 31%/69% 呈现 64px 条目列表
  和 128px 详情图标、package、版本、状态原因及 Profile/external/system 三项条件。
- 单击只选择，ready 或缺 Profile 的可启动条目双击/详情主按钮复用唯一
  `BuildLaunchPlan`；详情删除和右键删除共用既有确认控制器，运行中禁用。
- 空库、导入/设置模态、退出确认、子进程退出诊断和 FIFO 呈现保持既有边界；没有搜索、
  筛选、替换导入、常驻日志、游戏设置或伪造 API/ABI 信息。

## 验收

Windows/MSVC Release 构建 `ogplay-gui`/`ogplay_tests`；空库与非空库真实 ANGLE 冒烟、
按钮 ID 审计和 GUI 模型/启动/删除定向测试通过；1280×720 本地窗口完成视觉检查。
