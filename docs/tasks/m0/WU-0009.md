# WU-0009 · stdio JSON-RPC Agent 闭环

目标：通过标准 JSON-RPC 2.0 逐行请求驱动 M0 空会话，验证接口、脚本与 CI 共用执行层。

依赖：WU-0004、WU-0007。

验收：

- [x] `session.open/close/state`、`run.step/until/pause/resume` 走同一 Control Service。
- [x] stdio adapter 保留字符串/整数 id，并返回标准 parse/request/params/method 错误码。
- [x] 空会话从 open 到逐帧 step/until 全程不使用 sleep。
- [x] `ogplay agent-stdio` 可持续处理一行一个请求；TCP/UDS 可复用 adapter。
