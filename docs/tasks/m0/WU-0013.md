# WU-0013 · Agent 符号与静默失败查询

目标：补齐 M0 Agent 的 `sym.resolve`、`hle.unimplemented` 与 `hle.null_calls` 主动查询面。

依赖：WU-0006、WU-0009、WU-0012。

验收：

- [x] `sym.resolve(address)` 返回 module/symbol/offset/source_hint。
- [x] 无 provider、无地址或未命中时结构化失败，不伪造符号。
- [x] unimplemented 与 null-call 使用同一运行时账本，返回稳定 JSON 数组。
- [x] 直接 Control Service 与 JSON-RPC adapter 结果一致。
