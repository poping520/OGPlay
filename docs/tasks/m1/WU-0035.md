# WU-0035 · Futex 等待唤醒

目标：提供按 guest 地址同步的 futex 比较等待与精确唤醒核心语义。

依赖：WU-0023、WU-0033、cpu 与 memory 模块契约。

验收：

- [x] WAIT 在队列锁内读取 guest word；值不匹配立即返回且不入队。
- [x] WAKE 精确释放最多 N 个 waiter，不存在 waiter 时明确返回 0。
- [x] 地址必须 32 位对齐，memory fault 原样保留，不伪造成功。
- [x] 十六线程压力测试覆盖分批 wake 与最终完整回收。
- [x] 本阶段只提供无超时核心；M2 syscall 超时必须接统一 Clock。
- [x] Windows/MSVC warnings-as-errors 全量测试通过（71/71）。
