# WU-M10-001 · LUI-1 Generic compiled AXML

## 目标（一句话）

让 layout AXML parser 输出通用 typed element/attribute，同时保持既有 layout 调用方行为。

## 依赖

- 无。

## 范围

- 保留严格 chunk、string pool、元素 nesting 校验。
- 每个 attribute 保留 namespace、name、typed value type/data 与可用 raw string。
- 既有布局字段作为单向兼容 adapter；新 widget 语义不得继续进入 loader。
- 不修改 binary Manifest parser。

## 验收

- UTF-8/UTF-16、reference、dimension、enum/flags、raw string 与未知 namespace 有机器测试。
- malformed chunk、未闭合/错配元素明确失败。
- 既有 layout attribute fixture 等价通过。

## 实施结果

- `BinaryXmlAttribute` 成为 generic typed 输出，Android 与非 Android namespace 均保留。
- typed string/raw string 索引与 string-pool chunk 内边界受检。
- 旧 `BinaryXmlElement` layout 字段暂作兼容 adapter，待 inflater 迁移后删除。
