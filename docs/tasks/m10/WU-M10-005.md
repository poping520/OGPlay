# WU-M10-005 · LUI-5 MeasureSpec 与 FrameLayout

## 目标（一句话）

以正式 measure/layout traversal 取代 fullscreen root 特判，使 content 与 external child
获得同一份 resolved geometry。

## 依赖

- WU-M10-002、WU-M10-004 / LUI-2、LUI-4。

## AOSP 4.4.4 语义参考

- `View.MeasureSpec` / `View.resolveSizeAndState`：EXACTLY、AT_MOST、UNSPECIFIED。
- `ViewGroup.getChildMeasureSpec`：fixed/match-parent/wrap-content 的 parent constraint。
- `FrameLayout.onMeasure/layoutChildren`：独立 child measure、match-parent second pass、
  padding/margin 与 child gravity。

## 验收

- root surface EXACTLY constraint，fixed/match/wrap 与 intrinsic measure。
- fullscreen、bottom、center、padding/margin 和重叠 document order geometry exact。
- layout 成功后清除 dirty，所有 descendant 得到 screen frame。

## 实施结果

- `runtime/ui/ui_layout.cpp` 提供无 DexVM/session 依赖的 traversal。
- synthetic ContentRoot 采用 FrameLayout 语义；输入尺寸非法明确失败。
