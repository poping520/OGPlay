# WU-M10-008 · LUI-8 Present composition

## 目标（一句话）

在 session present 边界把 VideoView/GLES base 与 UI overlay 合成后再交给窗口与截图。

## 依赖

- WU-M10-007 / LUI-7。

## 验收与结果

- `session::ComposeUiOverlay` 严格校验相同 RGBA layout，以整数 source-over 合成。
- frontend 在唯一 frame handoff 调 session `ComposePresentedFrame`，layout/raster UI 后返回
  同 sequence 合成帧，不抢占 guest GLThread 的异步 frame store。
- 透明 UI 保持 base pixels 逐位相同；可见 UI 只改变 expected region。
- VideoView playback/seek/completion/audio 回归全绿；video module 未增加 UI 依赖。
