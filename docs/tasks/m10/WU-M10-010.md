# WU-M10-010 · LUI-10 Asphalt 6 P0 exact gate

## 目标（一句话）

用真实 APK 三轮证明启动视频上的 XML skip 控件能由 Java 状态驱动显示、点击并继续游戏。

## 依赖

- WU-M10-004..009 / LUI-4..9。
- `docs/playbook/SCENARIO-RUNNER.md`。

## 验收与结果

- 新增 `asphalt6.layout_ui_skip` exact scenario：启动视频推进超过 3 秒，点击非 UI 区域，
  skip 在 bottom-center 以固定 RGBA golden
  `c85f6587a5ea55b519b5c8fa0cabca87a5589075f6b20bd85af35d3f2e454280` 出现。
- 点击 skip 后 guest listener 切换到后续 Activity，并继续提交 GLES frame；全程无 guest
  fault，显式 shutdown 返回 0。
- FFmpeg 音频拉取对共享 demux cursor 增加 bounded video backpressure，长视频不再因音频
  预读填满 64 帧队列；无丢帧或 fake EOF。
- 真实后续路径所需 GLES1 `glFlush` 转发当前 ANGLE frame，不隐式 present。
- 清理路径补齐 JNI primitive-array critical 成对 lease；DexVM stopped context 只在 host
  thread join 后显式展开 native/A32 重入遗留外层帧，普通 discard 仍拒绝活动栈。
- macOS arm64、FFmpeg 7、API 19 Bionic oracle 下三轮独立 evidence 均 passed，且无
  survey/title-specific runtime branch；本地证据为 `m10-lui10-gate-final-2/3/4`。
