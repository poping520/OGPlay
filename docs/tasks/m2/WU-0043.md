# WU-0043 · ELF32 ARM 可信事实解析

目标：为 M2 linker 提供不映射、不执行 guest 的 ELF32/ARM 可信解析边界。

依赖：WU-0041、loader 与 memory 模块契约。

验收：

- [x] 只接受 little-endian ELF32/ARM ET_EXEC/ET_DYN，并保留入口和 ARM flags。
- [x] 程序头表的偏移、项尺寸、数量和乘加范围全部校验。
- [x] `PT_LOAD` 校验文件/内存尺寸、文件范围、guest 回绕、对齐及地址同余。
- [x] `PT_DYNAMIC` 最多一个、尺寸为条目倍数、文件范围有效且必须 `DT_NULL` 终止。
- [x] 未知程序段和动态 tag 作为事实保留，不猜测、不静默忽略畸形数据。
- [x] Windows/Linux/macOS warnings-as-errors 构建与全量 CTest 通过（78/78）。
