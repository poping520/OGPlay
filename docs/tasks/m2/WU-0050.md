# WU-0050 · ELF32 多模块链接命名空间

目标：把多层 `DT_NEEDED` 模块冻结为确定性的装载顺序、查找作用域和已解析符号表。

依赖：WU-0049、loader 模块契约。

验收：

- [x] 模块文件名与 `DT_SONAME` 建立唯一别名，缺失依赖和歧义名称明确失败。
- [x] 递归依赖按依赖优先生成装载顺序；循环依赖有限终止且每模块只出现一次。
- [x] 符号查找按根模块开始的 `DT_NEEDED` 广度顺序，先定义者胜出。
- [x] local/hidden/protected 定义绑定本模块，默认可见全局定义允许正常抢占。
- [x] 未定义 weak 解析为零；未定义 strong 明确失败；`SHN_ABS` 不叠加 load bias。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（92/92）。
