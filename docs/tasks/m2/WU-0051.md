# WU-0051 · Android ARM syscall 分派基线

目标：建立不伪造成功、可按组统计且所有缺口可观测的 ARM EABI syscall 入口。

依赖：M1 CPU/能力账本契约、runtime 模块契约。

验收：

- [x] A32 frame 明确携带 syscall 号、7 个参数、PC/LR 和 guest thread ID。
- [x] 预声明 Android 老版本常见内存、文件、线程、时间、信号、进程、poll、网络和 ARM 私有调用。
- [x] 已声明但未实现调用以 `syscall.<name>` 记账，未知号以 `syscall.arm.<number>` 记账。
- [x] 所有未实现路径返回 Linux `-ENOSYS`，不静默成功。
- [x] getpid/getuid/getgid/geteuid/getegid/gettid 使用一致的可注入 guest 身份。
- [x] 覆盖率可查询总数、已实现数及各组数量。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（95/95）。
