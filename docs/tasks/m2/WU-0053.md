# WU-0053 · Android 时间 syscall

目标：让 Bionic 的基础取时路径只使用统一 Clock 并安全写入 A32 guest 结构。

依赖：WU-0051、HAL Clock、memory 模块契约。

验收：

- [x] dispatcher 只能为已声明且未实现的 syscall 绑定一次 handler。
- [x] `clock_gettime` 支持 realtime/monotonic/boottime ID，写入 32 位 timespec。
- [x] `gettimeofday` 写入 32 位 timeval，可选 timezone 明确写零。
- [x] 时间全部来自统一 Clock，暂停/倍速/固定步长语义不被宿主墙钟绕过。
- [x] 坏 guest 指针返回 `-EFAULT`，非法 clock ID 返回 `-EINVAL`，秒溢出返回 `-EOVERFLOW`。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（98/98）。
