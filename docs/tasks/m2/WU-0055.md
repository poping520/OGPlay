# WU-0055 · Android futex 与线程 syscall 装配

目标：让 Bionic 的无超时 futex WAIT/WAKE 使用 M1 真线程同步核心并返回 Linux errno。

依赖：WU-0035、WU-0051、CPU/memory/runtime 模块契约。

验收：

- [x] `FUTEX_WAIT` 比较 guest word 后真实阻塞，值不匹配返回 `-EAGAIN`。
- [x] `FUTEX_WAKE` 返回实际唤醒数量，支持 `FUTEX_PRIVATE_FLAG` 和精确 WAKE N。
- [x] 未对齐地址返回 `-EINVAL`，坏 guest 地址返回 `-EFAULT`。
- [x] 未装配的超时与 realtime-clock 模式明确返回 `-ENOTSUP`，不静默忽略超时。
- [x] 未支持 futex command 返回 `-ENOSYS`；`sched_yield` 显式让出宿主线程。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（100/100）。
