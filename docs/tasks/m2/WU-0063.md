# WU-0063 · ELF dlopen/dlsym/dlclose 生命周期

目标：在统一命名空间上冻结动态库 handle、引用计数、符号查找和卸载顺序。

依赖：WU-0058、WU-0062、loader 模块契约。

验收：

- [x] `Open` 事务式扩展命名空间并返回稳定非零 handle 与依赖优先初始化顺序。
- [x] 重复打开同一根复用 handle 并增加引用，不重复初始化。
- [x] `Symbol` 仅在有效 handle 的 BFS 作用域内查询，空名和关闭 handle 明确失败。
- [x] 不同 handle 共享依赖引用；最后一个引用关闭前不得安排依赖反初始化。
- [x] `Close` 在引用归零时返回根优先反初始化顺序，base namespace 永久固定。
- [x] 已卸载模块保留稳定索引，可再次打开并获得新的 handle 与重新初始化顺序。
- [x] macOS AppleClang `dev` 预设构建与全量 CTest 通过（117/117）。
