# WU-0065 · ARM TPIDRURO 读取

目标：让解释器与 Dynarmic 都从线程独立 CPU 状态执行 `__aeabi_read_tp` 所需的 TPIDRURO 读取。

依赖：WU-0064、cpu 模块契约、Dynarmic 公共 coprocessor 接口。

验收：

- [x] A32 `MRC p15,0,Rt,c13,c0,3` 返回当前 guest thread pointer。
- [x] Thumb-2 同一 MRC 编码在解释器中保持相同行为。
- [x] Dynarmic 仅为精确 TPIDRURO 编码注册 CP15 provider，其他 CP15 操作继续失败。
- [x] CPU SetState/GetState 跨 JIT 往返保留 thread pointer。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
