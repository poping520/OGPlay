# WU-0066 · Bionic ARM TLS block

目标：按 API 19/22/23 的旧版 Bionic 契约为每个 guest 线程建立可供 TPIDRURO 使用的 TLS slot block。

依赖：WU-0064、WU-0065、runtime/memory 模块契约。

验收：

- [x] block 固定包含 64 个 32 位 slot，并由独立 guest 页承载。
- [x] slot 0 自指，slot 1 指向非空 guest thread info，其他 slot 默认清零。
- [x] 主线程可选 preinit 写入 slot 3，工作线程不伪造该值。
- [x] 地址未按页对齐、thread info 为空或映射冲突均明确失败且不覆盖既有内存。
- [x] 销毁释放完整映射，descriptor 不一致时拒绝操作。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
