# WU-0067 · guest ELF 生命周期执行

目标：把动态链接器返回的模块顺序转换为受检的 guest init/fini 调用并交给统一执行入口。

依赖：WU-0058、WU-0063、runtime/loader 模块契约。

验收：

- [x] 初始化按链接器模块顺序执行每模块 `DT_INIT` 后正序 `init_array`。
- [x] 反初始化按链接器返回顺序执行每模块逆序 `fini_array` 后 `DT_FINI`。
- [x] 所有函数地址加入模块 load bias，保留 ARM/Thumb 低位。
- [x] array 中 0/-1 哨兵跳过，地址回绕、未知/重复模块在任何调用前明确失败。
- [x] invoker 为空时明确失败，实际调用顺序可机器判定。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
