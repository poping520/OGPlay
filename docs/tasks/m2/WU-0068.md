# WU-0068 · ARM set_tls syscall

目标：让旧版 Bionic 的 `__ARM_NR_set_tls` 更新当前 guest CPU 的 TPIDRURO 状态。

依赖：WU-0051、WU-0064、WU-0066、runtime/cpu 模块契约。

验收：

- [x] `0x0f0005` 将第一个参数作为强类型 guest thread pointer 交给显式 setter。
- [x] setter 同时收到 guest thread ID，不允许跨线程静默修改。
- [x] 未知/零线程返回 `ESRCH`，setter 异常返回 `EINVAL`。
- [x] 空 setter 在绑定阶段明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
