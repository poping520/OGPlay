# WU-0069 · guest 线程运行时生命周期

目标：为线程 syscall 建立唯一、线程安全且只前进的 guest 生命周期状态机。

依赖：WU-0034、WU-0064、runtime/cpu 模块契约。

验收：

- [x] 保存 thread ID、thread pointer、clear-child-tid、退出码与显式状态。
- [x] 单线程退出和 exit-group 都只产生 exit-requested，不伪装宿主线程已经退出。
- [x] complete/reap 分离，ID 只在 exited 状态 reap 后才允许复用。
- [x] 未知线程、重复注册、越级 complete/reap 和退出后修改均明确失败。
- [x] 快照按 thread ID 稳定排序，访问受锁保护。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
