# WU-0071 · clear-child-tid 退出清理

目标：在线程退出完成时写零 clear-child-tid 并按 Linux 语义唤醒一个 futex waiter。

依赖：WU-0055、WU-0069、WU-0070、runtime/cpu/memory 模块契约。

验收：

- [x] 非零且对齐的 clear-child-tid 在退出时通过受检 MemoryBus 写零。
- [x] 写零后在同一 guest 地址精确唤醒最多一个 futex waiter。
- [x] 未请求 clear-child-tid 不触碰 guest 内存或 futex。
- [x] 未对齐地址与 memory fault 通过 completion 状态明确报告。
- [x] 清理失败不回退已经完成的 exited 状态。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
