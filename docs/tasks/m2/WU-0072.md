# WU-0072 · ARM SVC syscall 桥

目标：把 CPU 的 `SVC #0` 停止结果无损转换为 Android ARM EABI syscall 调用并写回 guest 状态。

依赖：WU-0027、WU-0051、runtime/cpu 模块契约。

验收：

- [x] syscall number 来自 r7，七个参数来自 r0-r6。
- [x] frame 保留陷阱 PC、LR 与 guest thread ID。
- [x] dispatcher 的有符号返回值按位写回 r0，PC 继续保持 CPU 已推进的位置。
- [x] thread pointer、执行状态和其他寄存器不因桥接丢失。
- [x] 非 `SVC #0` 返回未处理，非 supervisor-call 输入明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
