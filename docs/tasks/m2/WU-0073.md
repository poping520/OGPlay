# WU-0073 · Android ARM guest 线程执行循环

目标：让单个真实 guest CPU 在线程预算内连续执行 Linux SVC，并正确完成退出清理。

依赖：WU-0070、WU-0071、WU-0072、runtime/cpu 模块契约。

验收：

- [x] CPU 在总 tick 预算内连续运行，`SVC #0` 返回后继续执行下一条 guest 指令。
- [x] `exit/exit_group` 请求由循环消费并调用唯一的 CompleteExit 清理路径。
- [x] 返回累计 tick、最后 CPU stop 与结构化 exit completion。
- [x] 非 Linux SVC、breakpoint/fault/undefined 等停止原因不被吞掉。
- [x] 零 thread ID、未注册或非 running 生命周期明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
