# WU-0074 · ARM pthread clone 请求

目标：将 Linux ARM `clone` 五参数 ABI 解码为受限、强类型且可提交的 guest 线程请求。

依赖：WU-0051、WU-0072、runtime 模块契约。

验收：

- [x] syscall 120 按 flags、child_stack、parent_tid、tls、child_tid 的 ARM 顺序解码。
- [x] 仅接受 pthread 所需的共享地址空间 flags，进程 clone 与未知 flags 返回 ENOTSUP。
- [x] stack、parent/child TID 与 TLS 指针对齐和空值进入明确 EINVAL 路径。
- [x] 未置位 flag 的可选参数不会泄漏给创建器。
- [x] 创建器返回 guest TID 或 errno；零返回 EAGAIN，异常返回 EINVAL，不伪造成功。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
