# WU-0076 · clone TID 与生命周期提交

目标：把已解码 clone 请求提交为可观察的 guest TID 写回和完整 child 生命周期状态。

依赖：WU-0074、WU-0075、memory/runtime 模块契约。

验收：

- [x] CLONE_PARENT_SETTID 与 CLONE_CHILD_SETTID 只在对应 flag 置位时写 guest TID。
- [x] CLONE_SETTLS 与 CLONE_CHILD_CLEARTID 成为 child 的初始 lifecycle 状态。
- [x] parent/child 指向同一 Bionic TID 地址时只保存一份回滚基线。
- [x] 所有 TID 地址在首个写入前完成受检内存预检，坏地址不产生部分写入或 child 状态。
- [x] 失效 parent、重复/溢出 child TID 与请求形态错误返回明确 Linux errno。
- [x] Windows/MSVC warnings-as-errors 构建与相关契约测试通过。
