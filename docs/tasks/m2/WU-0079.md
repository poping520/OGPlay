# WU-0079 · ELF32 多模块事务装载

目标：把既有 ELF 事实组件装配成可直接加载真实 Bionic 依赖闭包的事务入口。

依赖：WU-0043..WU-0063、loader/memory 模块契约。

验收：

- [x] 每个输入统一解析动态依赖、符号、REL、生命周期、TLS 与符号版本事实。
- [x] 依赖闭包先构建命名空间，再按依赖优先顺序映射并应用版本化符号重定位。
- [x] 返回每个模块的 load plan、relocation、lifecycle 与 TLS 事实。
- [x] 任一解析、依赖、映射、解析或重定位失败均恢复完整调用前地址空间。
- [x] Windows/MSVC warnings-as-errors 构建与事务契约测试通过。
