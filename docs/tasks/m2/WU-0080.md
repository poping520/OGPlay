# WU-0080 · 三版本 Bionic libc 自检

目标：对 API 19/22/23 的真实 ARM libc/libdl 执行可机器判定的装载与 ABI 出口自检。

依赖：WU-0041、WU-0052、WU-0079、runtime/loader 模块契约。

验收：

- [x] 自检只接受支持矩阵中的 API 19/22/23，并要求 libc.so 与 libdl.so。
- [x] 两库完成真实解析、映射、版本化符号解析与全部 ARM REL 应用。
- [x] malloc/free、pthread_create/join 与 open/read/write/close 出口必须可解析。
- [x] 符号、重定位、版本、生命周期与 ARM exidx 形成结构化报告。
- [x] oracle 路径只由测试环境注入；缺少二进制时常规单测不读取本机数据。
- [x] Windows/MSVC warnings-as-errors 构建通过；三版本本地 oracle 自检通过。
