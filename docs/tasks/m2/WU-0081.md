# WU-0081 · GNU base symbol version

目标：正确解析真实 Bionic 使用的 GNU VER_FLG_BASE 版本定义。

依赖：WU-0061、WU-0080 真实 Bionic 自检、loader 模块契约。

验收：

- [x] VER_FLG_BASE 只允许使用保留索引 1，并保持对应 VERSYM 为 global。
- [x] 普通命名 definition 仍要求索引大于 1。
- [x] 旧版 Android libdl 的 local undefined 动态符号按无版本导入解析。
- [x] base flag 与索引不匹配明确失败，不放宽未知版本引用。
- [x] Windows/MSVC warnings-as-errors 构建与回归测试通过。
