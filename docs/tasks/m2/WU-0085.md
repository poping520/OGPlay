# WU-0085 · 真实 Bionic 无头执行总装

目标：用生产入口执行 API 19 Bionic 上的 M2 NDK 累计载荷，而非测试专用模拟替身。

依赖：WU-0078、WU-0079、WU-0080、WU-0083、WU-0084，Dynarmic 主后端。

验收：

- [x] 按真实依赖闭包装载样本、libm、libdl、libc 并运行 guest init/fini。
- [x] root 线程使用受检 stack、Bionic TLS 与 TPIDRURO，普通 C 入口正常返回。
- [x] pthread clone 启动真实宿主线程并由 guest join/clear-child-tid 闭环。
- [x] 文件输出从统一 VFS 读回 32 字节，入口返回 0 且无未实现 syscall 命中。
- [x] Windows/MSVC warnings-as-errors 构建与真实 Bionic 集成测试通过。
