# WU-0086 · 旧 Android provider 版本兼容

目标：让新版 NDK 的 `LIBC` 版本化导入按旧 Android linker 语义解析 API 19/22 无版本 provider。

依赖：WU-0059、WU-0081，API 19 真实 Bionic 与 M2 NDK 累计载荷。

验收：

- [x] provider 存在 GNU 版本定义时继续精确匹配版本名与依赖库。
- [x] provider 完全没有版本表时，版本化导入可按符号名解析。
- [x] 回退只影响旧 provider，不放宽已有版本表的错误版本。
- [x] Windows/MSVC warnings-as-errors 构建与真实 API 19 装载测试通过。
