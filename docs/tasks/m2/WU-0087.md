# WU-0087 · Dynarmic 多线程 exclusive monitor

目标：让真实 Bionic mutex 使用的 ARM LDREX/STREX 在同一 guest 进程的 JIT 线程间正确工作。

依赖：M1 Dynarmic、真线程模型，WU-0085 真实 Bionic 执行轨迹。

验收：

- [x] 同一 execution context 中每个活跃 CPU 获得唯一 processor ID。
- [x] CPU 共享 Dynarmic global exclusive monitor，析构后归还 ID 和 reservation。
- [x] 默认单 CPU 构造保持兼容，显式共享构造用于真线程组。
- [x] LDREX/增量/STREX 契约测试与真实 Bionic mutex 路径通过。
