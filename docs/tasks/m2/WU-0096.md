# WU-0096 · dladdr 活跃命名空间反查

目标：让 `dladdr` 与 dlopen/dlsym 使用同一 ELF 命名空间和模块生命周期。

依赖：WU-0062、WU-0063、WU-0079。

验收：

- [x] 总装载器把实际 `PT_LOAD` 页范围保留到链接模块事实。
- [x] 地址反查返回模块名、load bias，以及不大于目标地址的最近 dynsym。
- [x] 符号前地址保留模块事实但符号为空；范围外与重叠模块明确失败。
- [x] dlclose 后引用归零的动态模块不再被 `dladdr` 命中，base 模块保持活跃。
- [x] Windows/MSVC warnings-as-errors 与动态链接器契约通过。
