# WU-0099 · M2 三平台出口验收

目标：证明 M2 的真实 Bionic、ELF linker、syscall、VFS 与无界面 NDK 累计载荷在三个宿主平台形成可交接闭环。

依赖：WU-0080、WU-0082..0085、WU-0096..0098、WU-0100..0103。

验收：

- [x] Windows/MSVC、Linux/GCC、macOS/AppleClang 均以 warnings-as-errors 构建成功并通过全量 CTest 159/159。
- [x] API 19/22/23 真实 Bionic 各自通过 libc/libdl 多模块装载与重定位自检。
- [x] 三版本普通 C 入口均返回 0，完成真实 pthread child、malloc/free 与 32 字节 VFS 写入读回。
- [x] 样本不依赖 Activity、JNI 或 GLES，执行轨迹不存在未实现 syscall 命中。
- [x] M2 相关模块契约与 ADR 已同步，能力账本只前进并交接到 M3。
