# WU-0103 · 固定 Android guest 页面粒度

目标：让 4 KiB Android guest 页在 4 KiB 与 16 KiB 宿主页平台上保持一致的独立映射和权限语义。

依赖：ADR-0011、WU-0102、三平台 M2 出口。

验收：

- [x] `AddressSpace::PageSize()` 固定返回 4096，宿主页尺寸仅用于内部后备提交。
- [x] 相邻 guest 页即使共享宿主页，也能独立映射、保护、释放与零初始化重映射。
- [x] 快照、低地址 guard 与末页边界继续按 4 KiB guest 页工作。
- [x] Windows/Linux/macOS warnings-as-errors 构建与全量 CTest 通过。
