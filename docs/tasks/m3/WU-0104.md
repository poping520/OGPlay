# WU-0104 · 可扩展文档状态与任务归档

目标：让每次会话读取的交接上下文保持有界，并把全部既有 Work Unit 按里程碑稳定归档。

依赖：WU-0099、WU-0103、ADR-0012。

范围说明：这是用户明确授权的一次性文档拓扑迁移；103 个既有任务单只执行 Git 路径
移动，不改写任务结论，因此不按普通行为 Work Unit 的八文件上限拆散迁移事务。

验收：

- [x] M1、M2 验收文档记录路线图出口、三平台证据和明确范围边界。
- [x] 仓库入口、工作流和任务索引不再引用旧的扁平任务路径。
- [x] 文档布局机器门禁与 Windows/MSVC 全量 CTest 160/160 通过。
