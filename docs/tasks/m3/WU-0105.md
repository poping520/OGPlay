# WU-0105 · JNI ABI 与显式失败底座

目标：冻结旧版 Android ARM JNI 的精确类型和完整函数槽目录，使所有未绑定入口可观测并明确 trap。

依赖：WU-0104、M3 路线图、runtime 模块契约。

验收：

- [x] JNI primitive、reference、method ID 与 field ID 不继承宿主指针宽度且保持强类型。
- [x] `JNINativeInterface` 精确覆盖索引 0..232，关键槽号与名称符合 Android NDK `jni.h`。
- [x] 函数表只允许初始化期绑定并封口，保留槽、空地址、重复绑定和封口后修改明确失败。
- [x] 未绑定函数按稳定 capability ID 聚合首次/末次 LR，并抛出携带槽号的异常。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 162/162 通过。
