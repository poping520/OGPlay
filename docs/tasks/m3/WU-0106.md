# WU-0106 · 常用 JNI 函数优先范围

目标：保留完整 JNI ABI 与显式失败能力，同时把 M3 实现顺序调整为常用函数优先。

依赖：WU-0105、M3 路线图。

验收：

- [x] 233 槽 `JNINativeInterface` 目录保持完整，暂缓函数不从 ABI 中删除。
- [x] 引用、异常、查找/调用、字符串、数组、RegisterNatives、JavaVM 线程接口列为优先范围。
- [x] 未实现槽继续以稳定 capability ID 记账并明确 trap，不伪造成功或零返回值。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 162/162 通过。
