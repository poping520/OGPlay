# WU-0107 · JNI Local/Global/Weak 引用表

目标：实现可同时承载宿主与未来 DEX VM 对象的线程安全 JNI 引用生命周期。

依赖：WU-0105、WU-0106。

验收：

- [x] Local 引用按 guest 线程和 local frame 隔离，跨线程、失效引用与 base frame 弹出明确失败。
- [x] EnsureLocalCapacity、frame capacity、Global/WeakGlobal 上限均在改变状态前检查。
- [x] PopLocalFrame 可把一个结果提升到父 frame，detach 清理全部 Local 引用。
- [x] Global 跨线程共享；WeakGlobal 可被清除并按 null 参与 IsSameObject。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 164/164 通过。
