# WU-0108 · JNI pending exception 状态机

目标：让每个已附着 guest 线程拥有独立、不可静默覆盖的 JNI pending exception 与调用门禁。

依赖：WU-0107。

验收：

- [x] Throw/Occurred/Check/Clear 按 guest 线程隔离，throwable 保存对象身份而非易失 Local handle。
- [x] 重复附着、未附着访问、空 throwable 与覆盖 pending exception 明确失败。
- [x] pending 时只允许异常检查/清理、引用删除、MonitorExit 和资源 Release 等白名单。
- [x] 普通 JNI 调用在 pending 时被携带原因的错误阻断，Clear 后恢复。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 166/166 通过。
