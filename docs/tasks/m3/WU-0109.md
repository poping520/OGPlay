# WU-0109 · JNI 字段与方法描述符解析

目标：为 GetFieldID/GetMethodID 和三种调用变体提供唯一、严格的 JNI 参数类型布局。

依赖：WU-0108。

验收：

- [x] primitive、对象、数组与方法 void 返回均解析为显式类型事实。
- [x] 对象内部名、数组维数、返回类型、尾随字节和括号结构严格校验。
- [x] long/double 参数计两个 JVM 槽，引用和数组计一个，方法总参数槽不超过 255。
- [x] 字段拒绝 void，参数拒绝 void，数组拒绝 void 元素。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（169/169）。
