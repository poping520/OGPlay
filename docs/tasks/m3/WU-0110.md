# WU-0110 · JNI Modified UTF-8

目标：为常用 JNI 字符串函数提供唯一、严格且与 UTF-16 code unit 对称的 Modified UTF-8 编解码器。

依赖：WU-0109。

验收：

- [x] ASCII、嵌入 NUL 与非 ASCII UTF-16 可无损往返。
- [x] 代理项按两个 UTF-16 code unit 编为六字节，孤立代理项不被擅自替换。
- [x] 原始 NUL、过长编码、截断、坏 continuation 与标准 UTF-8 四字节序列明确失败。
- [x] 编码长度预计算与实际 payload 长度一致，返回值不隐含 C 字符串尾 NUL。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（172/172）。
