# WU-0111 · JNIEnv 核心常用操作

目标：以单一环境对象闭合线程附着、引用与异常的首批常用 JNIEnv 行为。

依赖：WU-0107、WU-0108。

验收：

- [x] 线程附着同时建立引用和异常状态，任一步失败均回滚。
- [x] GetVersion、local frame、Local/Global/WeakGlobal 引用操作走统一异常门禁。
- [x] ExceptionOccurred/Check/Clear 复用线程独立 pending exception 状态。
- [x] null 引用复制、比较与删除遵循 JNI 语义，detach 后调用明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（175/175）。
