# WU-0112 · JNI 字符串对象

目标：闭合常用字符串槽共享的 UTF-16 对象、region 与 chars 访问生命周期。

依赖：WU-0110、WU-0111。

验收：

- [x] UTF-16 与 Modified UTF-8 均可创建字符串并取得两种精确长度。
- [x] UTF-16/Modified UTF-8 region 按 UTF-16 code unit 校验边界。
- [x] chars、UTF chars 与 critical 访问返回稳定副本和显式 token。
- [x] release 必须匹配对象、token 与访问类别，活动租约阻止对象销毁。
- [x] 字符串身份可发布为 JNIEnv local reference。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（178/178）。
