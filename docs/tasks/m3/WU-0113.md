# WU-0113 · JNI 基本类型数组

目标：统一实现八种 primitive array 的创建、region 与 elements/critical 生命周期。

依赖：WU-0111、WU-0112。

验收：

- [x] boolean/byte/char/short/int/long/float/double 数组按请求长度零初始化。
- [x] Get/Set region 严格检查元素类型、负数、范围和回绕。
- [x] elements/critical 返回带 token 的稳定副本，对象和访问类别必须配对。
- [x] 普通 release 回写并关闭，commit 回写且保留，abort 不回写并关闭。
- [x] 活动访问阻止数组销毁，数组对象身份可发布到 JNIEnv 引用表。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（181/181）。
