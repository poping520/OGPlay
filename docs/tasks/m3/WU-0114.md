# WU-0114 · RegisterNatives 注册表

目标：以事务式注册表闭合游戏 Java 层声明 native 方法的常用主路径。

依赖：WU-0109、WU-0111。

验收：

- [x] 注册键由类对象身份、方法名和严格 JNI 方法描述符共同组成，支持重载。
- [x] 空名称、非法描述符、空 guest 地址和批内重复明确失败。
- [x] 整批预检后才提交，任一非法声明不得留下部分注册。
- [x] 相同目标重注册幂等，不同目标冲突不得覆盖既有声明。
- [x] UnregisterNatives 只清除目标类，host 与 DEX VM 类身份可共存。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（184/184）。
