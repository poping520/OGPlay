# WU-0115 · JavaVM 线程槽

目标：冻结 JavaVM ABI 并闭合 native 线程回调 Java 所需的附着、查询和分离行为。

依赖：WU-0111。

验收：

- [x] JNIInvokeInterface 精确包含 3 个保留槽和 5 个函数槽。
- [x] GetEnv 对已附着线程返回稳定 env，对未附着和不支持版本返回标准 JNI 状态。
- [x] 普通与 daemon Attach 创建引用/异常线程状态，失败不留下部分状态。
- [x] 重复 Attach 返回同一 env，不改变首次附着的 daemon 属性。
- [x] Detach 清理环境线程状态，重复 Detach 返回 JNI_EDETACHED。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（187/187）。
