# WU-0116 · 声明式类与成员查找

目标：为常用 FindClass/GetMethodID/GetFieldID 槽提供无游戏硬编码的声明式事实模型。

依赖：WU-0109、WU-0112。

验收：

- [x] 类按内部名事务注册，父类必须先存在，类身份使用统一 host object ID。
- [x] FindClass、GetSuperclass 与 IsAssignableFrom 遵循显式类层级。
- [x] 方法/字段生成不同的稳定强类型 ID，名称和描述符共同区分重载。
- [x] 查找区分实例/静态成员并沿父类继承，构造器只在声明类查找。
- [x] 非法类名、成员、描述符和重复声明不得留下部分状态。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（190/190）。
