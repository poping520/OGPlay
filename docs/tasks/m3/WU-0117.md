# WU-0117 · JNI 常用方法调用分派

目标：让常用实例、非虚和静态 Call*Method 三种参数入口共享唯一、严格的调用引擎。

依赖：WU-0109、WU-0116。

验收：

- [x] `...`、`V`、`A` 参数源归一化为同一 JniValue 序列并按描述符逐项校验。
- [x] 虚调用按 receiver class 选择最近 override，非虚调用固定 method ID 实现。
- [x] 静态调用与实例调用严格区分，receiver/dispatch class 必须与声明类兼容。
- [x] void、primitive 与引用返回值按描述符校验，错误返回类型明确失败。
- [x] 缺失、重复或空实现 handler 明确失败，不提供默认零返回。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（193/193）。
