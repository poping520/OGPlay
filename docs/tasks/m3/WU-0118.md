# WU-0118 · 常用 JNI/JavaVM 槽绑定

目标：只把已有真实行为支撑的常用槽映射到稳定 thunk，并封口两张 ABI 函数表。

依赖：WU-0111..WU-0117。

验收：

- [x] 169 个常用 JNIEnv 槽映射到环境、类、调用、字符串、primitive array 或 native 注册 handler。
- [x] Attach、Detach、GetEnv 与 daemon Attach 四个 JavaVM 槽映射到线程 handler。
- [x] thunk 地址由 ABI 槽号稳定派生，可从地址反查名称、槽号与 handler 类别。
- [x] 安装后 JNIEnv/JavaVM 函数表同时封口，禁止运行期覆盖。
- [x] 字段访问、对象数组、反射、monitor、direct buffer 与 DestroyJavaVM 等未实现槽继续记账并 trap。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（195/195）。
