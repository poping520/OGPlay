# WU-0119 · 最小框架生命周期 HLE

目标：以声明式类和 invocation handler 实现无界面 JNI 样本所需的最小 Activity 生命周期。

依赖：WU-0116、WU-0117。

验收：

- [x] 声明式安装 java/lang/Object、android/os/Bundle 与 android/app/Activity。
- [x] Activity 构造及七个生命周期方法使用普通 JniClassRegistry/JniInvocationEngine。
- [x] 生命周期严格按 construct→create→start→resume→pause→stop→destroy 前进。
- [x] 每次迁移记录稳定序号、线程、receiver、回调和前后状态。
- [x] 跳步、重复构造、重复安装和未知实例明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（198/198）。
