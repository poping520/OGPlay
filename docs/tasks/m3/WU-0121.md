# WU-0121 · JNI 字段存储

目标：实现 descriptor 驱动且遵循继承关系的实例字段与静态字段存储。

依赖：WU-0116、WU-0117。

验收：

- [x] 八种 primitive 和引用字段返回 Java 规定的类型化零/null 默认值。
- [x] 实例字段按对象身份隔离并可显式清理，继承字段可从子类实例访问。
- [x] 静态字段按 field ID 共享，允许由声明类或其子类分派访问。
- [x] 错误字段类别、不兼容类、空对象、未知字段和值类型不匹配均明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（204/204）。
