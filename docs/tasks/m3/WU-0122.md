# WU-0122 · 无图形双向 JNI 契约样本

目标：用一个确定性累计样本闭合 HLE→guest native 与 native→Java/HLE 两个调用方向。

依赖：WU-0112、WU-0113、WU-0114、WU-0115、WU-0119、WU-0120、WU-0121。

验收：

- [x] Java/HLE 侧通过 RegisterNatives 解析 guest 地址并由注入 executor 执行 `(I)I` 方法。
- [x] native 侧通过 invocation engine 驱动 Activity 完整无图形生命周期。
- [x] 同一运行验证 VM attach/detach、字段、字符串、primitive/object 数组与确定性 trace。
- [x] Local/Global 引用和 pending exception 均在返回前闭环清理。
- [x] 缺少 executor、错误 native 返回类型及执行异常均明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（207/207）。
