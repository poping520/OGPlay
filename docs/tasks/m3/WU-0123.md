# WU-0123 · DEX header 与 map_list

目标：为 DEX L1 建立只读、边界受检且不执行字节码的基础事实模型。

依赖：M3 路线图、loader 模块契约。

验收：

- [x] 只接受 little-endian DEX 035..040 和固定 0x70 header。
- [x] 固定 ID 表的 size/offset、对齐、乘法和文件范围均完整校验。
- [x] map_list 条目唯一、按 offset 严格递增，并与 header 固定表事实交叉验证。
- [x] 未识别 map type 被保留为原始事实，不据此猜测内容。
- [x] 截断、错误 magic/version/endian、范围和 map 冲突均明确分类失败。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（210/210）。
