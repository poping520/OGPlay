# WU-0124 · DEX 字符串、类型与 prototype

目标：把 DEX 字符串、类型和方法原型解析为索引完整受检的只读事实。

依赖：WU-0123。

验收：

- [x] ULEB128 拒绝溢出、非最小和截断编码。
- [x] Modified UTF-8 解码为 UTF-16，拒绝非法 continuation、过长序列和长度不符。
- [x] type_id 解析 ASCII descriptor 并校验 primitive、对象和 255 维数组边界。
- [x] proto_id 解析 return/parameter type，type_list 对齐、范围和索引均受检。
- [x] shorty 与返回值、参数数量及参数类别严格一致。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（213/213）。
