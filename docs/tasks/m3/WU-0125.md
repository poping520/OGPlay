# WU-0125 · DEX member ID 与 class_def

目标：解析 DEX 固定宽度成员表和类定义，不读取或执行字节码。

依赖：WU-0124。

验收：

- [x] field_id 保留声明类、字段类型和名称索引，全部交叉校验。
- [x] method_id 保留声明类、prototype 和名称索引，全部交叉校验。
- [x] class_def 保留 access flags、父类、接口、源码和三个 data offset。
- [x] 类定义类型唯一且必须为 class descriptor；父类与接口也必须是 class descriptor。
- [x] annotation、class_data 和 static value 非零偏移必须位于 data section。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（216/216）。
