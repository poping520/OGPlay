# WU-0126 · DEX class_data 与 code 元数据

目标：解码类成员定义和方法静态规模，不解释任何 Dalvik 指令。

依赖：WU-0125。

验收：

- [x] 四组成员数量和 delta index 使用严格 ULEB128 解码。
- [x] 字段/方法必须归属当前类、组内严格递增且跨组不重复。
- [x] static/instance 与 direct/virtual 分组必须匹配 access flags。
- [x] native/abstract 方法无 code，普通方法必须引用对齐且完整的 code_item。
- [x] code_item 保留寄存器、输入/输出、try、debug offset 与 instruction units 事实。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（219/219）。
