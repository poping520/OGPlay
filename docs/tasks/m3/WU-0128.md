依赖：WU-0118、WU-0120、WU-0121。

验收：

- [x] New/Get/SetObjectArray 三个槽映射到 object array handler 类别。
- [x] 九种实例字段 Get/Set 共 18 个槽映射到 field handler 类别。
- [x] 九种静态字段 Get/Set 共 18 个槽映射到 field handler 类别。
- [x] 公共目录累计 208 个 JNIEnv 槽与 4 个 JavaVM 槽，地址仍由 ABI 索引确定。
- [x] direct buffer 等未实现槽继续记账并明确 trap。
