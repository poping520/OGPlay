# WU-0130 · HLE 受检引用解析

目标：为框架 HLE 提供从 JNI reference 到不透明对象身份的唯一受检解析边界。

依赖：WU-0107、WU-0129。

验收：

- [x] null reference 解析为空对象身份。
- [x] local reference 只能由所属附着线程解析。
- [x] host 与 DEX VM 对象域和值均原样保留。
- [x] pending exception 时解析被普通 JNI 调用门禁拒绝。
- [x] 公共 API 不返回宿主指针，也不允许直接解释 guest handle。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（223/223）。
