# WU-0131 · 最小 AssetManager/InputStream HLE

目标：让框架 HLE 通过真实 VFS APK 挂载读取 `assets/` 文件，不引入 DEX 执行或 Android services。

依赖：WU-0129、WU-0130、WU-0061。

验收：

- [x] 声明式安装 AssetManager 与 InputStream 常用方法。
- [x] Context.getAssets 返回受线程作用域保护的 AssetManager 引用。
- [x] AssetManager.open 只接受安全相对 UTF-16 路径并读取 `/apk/assets/`。
- [x] InputStream.read(byte[])/available/close 具备真实 VFS 行为与 EOF 语义。
- [x] 非 APK 来源、非法路径、未知或已关闭流和 I/O 错误均明确失败。
- [x] 重复 close 幂等，未关闭 descriptor 由 HLE 析构回收。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（225/225）。
