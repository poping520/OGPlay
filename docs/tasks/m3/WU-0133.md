# WU-0133 · 最小 SharedPreferences/Editor HLE

目标：实现样本常用的进程内 MODE_PRIVATE 偏好读写，不引入 Android services 或 XML 持久层。

依赖：WU-0130、WU-0132。

验收：

- [x] getSharedPreferences 按名称返回稳定、相互隔离的对象身份。
- [x] getInt/getLong/getBoolean/getString 支持精确类型与默认值。
- [x] contains/edit 与 putInt/putLong/putBoolean/putString 可用。
- [x] remove/clear、commit/apply 按 Editor 暂存集原子应用，Editor 可复用。
- [x] 非 MODE_PRIVATE、未知对象和类型不匹配均明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（227/227）。
