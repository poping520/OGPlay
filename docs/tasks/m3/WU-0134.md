# WU-0134 · InputStream 范围读取

目标：实现 `InputStream.read(byte[],offset,length)`，并保证参数失败不改变底层 VFS 流状态。

依赖：WU-0131。

验收：

- [x] 声明并绑定 `read([BII)I` 精确重载。
- [x] 数据只写入目标 byte[] 的指定区间。
- [x] 负数、越界和溢出范围在 VFS read 前明确失败。
- [x] 零长度返回 0，部分读和 EOF 返回值符合 InputStream 语义。
- [x] 非法范围测试验证 available 不变，即 descriptor 未推进。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（227/227）。
