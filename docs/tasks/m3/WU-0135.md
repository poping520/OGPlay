# WU-0135 · InputStream 单字节读取与跳过

目标：实现 `InputStream.read()` 与 `skip(long)`，覆盖不分配临时 byte[] 的常用流消费方式。

依赖：WU-0131、WU-0134。

验收：

- [x] 单字节 read 返回 0..255，流末尾返回 -1。
- [x] skip 对零或负数返回 0，且不改变 descriptor。
- [x] 正数 skip 受剩余长度限制并返回实际跳过字节数。
- [x] 单字节、skip、byte[] read 和 available 共享同一流位置。
- [x] 未知、关闭或 VFS 失败继续通过既有错误分类明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（227/227）。
