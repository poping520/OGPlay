# WU-0136 · SharedPreferences receiver 门禁

目标：确保偏好服务入口的 Context receiver 与所有其他框架 HLE 对象一样经过受检引用解析。

依赖：WU-0130、WU-0133。

验收：

- [x] getSharedPreferences 在读取名称或修改状态前解析 Context receiver。
- [x] 伪造、跨线程和已失效 local reference 沿 JNI reference 错误路径失败。
- [x] 合法 Context local/global reference 继续进入既有 MODE_PRIVATE 行为。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（227/227）。
