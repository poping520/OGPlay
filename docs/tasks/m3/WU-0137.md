# WU-0137 · 确定性 Locale HLE

目标：提供可由会话配置注入、跨平台确定的 java.util.Locale 常用查询，不读取宿主区域设置。

依赖：WU-0130、WU-0114。

验收：

- [x] 声明并绑定 Locale.getDefault/getLanguage/getCountry/toString。
- [x] language 仅接受 2/3 位小写 ASCII，country 仅接受空或 2 位大写 ASCII。
- [x] getDefault 返回稳定 Locale 身份，各字符串返回受检 local reference。
- [x] 跨线程使用 Locale local reference 明确失败。
- [x] 不访问宿主 locale，配置相同时结果跨平台一致。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（229/229）。
