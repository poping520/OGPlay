# WU-0139 · HLE Global object 发布边界

目标：允许框架 HLE 把宿主对象以跨线程稳定引用保存进 Java 对象字段，禁止长期保存 local reference。

依赖：WU-0107、WU-0130。

验收：

- [x] HLE 可从强类型对象身份直接发布 Global reference。
- [x] 发布验证调用线程已附着、Global 容量和 pending exception gate。
- [x] 另一附着线程可解析所得引用且对象域和值保持不变。
- [x] DeleteGlobalRef 后所有线程解析均明确失败。
- [x] API 不接受或返回宿主指针。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（230/230）。
