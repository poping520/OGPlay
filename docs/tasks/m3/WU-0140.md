# WU-0140 · 最小 PackageManager/PackageInfo HLE

目标：只为会话当前包提供 packageName、versionName 和 versionCode，不引入完整 PackageManager 服务。

依赖：WU-0121、WU-0138、WU-0139。

验收：

- [x] Context.getPackageName/getPackageManager 返回受检对象。
- [x] getPackageInfo 只接受配置的当前包名及 flags=0。
- [x] PackageInfo 声明真实 versionName String 与 versionCode int 字段。
- [x] versionName 字段使用 Global reference，可由另一附着线程解析。
- [x] 无效配置、未知包、扩展 flags、伪造 manager 均明确失败。
- [x] 不声明或模拟完整 PackageManager/Android services。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（232/232）。
