# WU-0141 · 框架服务累计无界面契约

目标：在同一次 M3 无界面 JNI 运行中装配资源、偏好、Locale 与当前包信息。

依赖：WU-0122、WU-0131、WU-0133、WU-0137、WU-0140。

验收：

- [x] 同一 JNIEnv、类注册表和调用引擎安装四类框架 HLE，不发生 handler 冲突。
- [x] APK asset 经 AssetManager/InputStream 和 byte[] 完成确定性读取与关闭。
- [x] MODE_PRIVATE 偏好完成 putInt/commit/getInt 往返。
- [x] Locale 与 PackageInfo 从注入配置产生确定性语言、地区、包名和版本结果。
- [x] 四类框架结果进入累计报告和稳定 trace，任一未闭合均使样本明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（232/232）。
