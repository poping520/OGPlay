# WU-0142 · Native 工作线程 JNI 累计契约

目标：验证 Unity/Mono 类 native 工作线程可附着 JavaVM、回调框架 HLE 并完整分离。

依赖：WU-0115、WU-0141、M1 宿主线程 HAL。

验收：

- [x] 累计样本通过 HAL 启动两个真实且不同的宿主工作线程。
- [x] 每个线程以 daemon 身份 AttachCurrentThread，并由 GetEnv 取得同一稳定 env handle。
- [x] 两线程并发调用 Locale.getDefault/getLanguage，local reference 保持线程隔离。
- [x] 每个线程显式 detach，join 后 JavaVM 只保留主线程。
- [x] 任一 attach、HLE 回调或 detach 失败均传播到累计契约，不在线程中丢失。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过（232/232；定向契约连续 50 次）。
