# WU-0147 · Runtime 剩余子模块纯机械迁移

目标：一次性把剩余 runtime 公共头和实现移入七个既定子模块并更新全部路径，不改变代码逻辑。

依赖：ADR-0013、WU-0146。

特殊范围：按用户明确授权，本 WU 是纯文件移动与路径替换，不受 10 文件上限限制。

验收：

- [x] bionic、framework、jni、syscall、execution、integration 的公共头和实现位于镜像目录。
- [x] `include/ogplay/runtime/` 根目录不再有 `.h`，`src/runtime/` 根目录不再有 `.cpp`。
- [x] CMake、生产代码和测试不再引用 runtime 根目录旧头文件或旧实现路径。
- [x] 文档布局测试持续禁止 runtime 根目录重新出现散落生产文件。
- [x] 差异仅包含文件移动、include/CMake 路径及相关文档，不修改运行时逻辑。
- [x] Windows/MSVC warnings-as-errors 构建、分域定向测试 109/109 与全量 CTest 232/232 通过。
