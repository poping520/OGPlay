# WU-0150 · ANGLE 后端选择契约

目标：冻结三平台 ANGLE renderer/device 候选顺序与显式失败的选择策略。

依赖：ADR-0003、M3 出口验收、HAL gfx 边界。

验收：

- [x] Windows 依次候选 D3D11、Vulkan、Vulkan/SwiftShader。
- [x] Linux 依次候选 Vulkan、Vulkan/SwiftShader；macOS 依次候选 Metal、Vulkan/SwiftShader。
- [x] automatic、hardware-only、software-only 只从显式可用候选中选择。
- [x] 不可用组合返回空值，非法平台或 renderer/device 组合明确抛错。
- [x] gles 策略层不含平台宏、SDL/EGL 类型或 ANGLE 实现依赖。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 236/236 通过。

非目标：本 WU 不引入 ANGLE 二进制，不创建 EGL 上下文，也不实现 GLES 边界函数。
