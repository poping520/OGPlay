# WU-0151 · ANGLE submodule 与构建边界

目标：以固定的官方 ANGLE submodule 建立默认关闭、缺失产物时明确失败的 GN/CMake 边界。

依赖：WU-0150、ADR-0003。

验收：

- [x] `third_party/angle` 固定官方仓库具体提交，顶层 submodule 使用浅克隆。
- [x] `OGPLAY_ENABLE_ANGLE` 默认关闭，不改变尚未接入图形实现的常规开发构建。
- [x] 开启时验证源码、绝对 GN 输出目录及 `libEGL`/`libGLESv2` 链接与运行时产物。
- [x] 完整产物通过 `ANGLE::EGL`、`ANGLE::GLESv2` imported target 暴露；不回退系统 GL。
- [x] 缺少 GN 产物的启用配置以指定诊断失败；默认 Windows/MSVC 全量 CTest 通过。

非目标：本 WU 不执行完整 gclient/GN 编译，不创建 EGL 上下文或实现 GLES guest 边界。
