# WU-0152 · ANGLE 远端增量隔离

目标：让普通远端增量验证只浅更新 ANGLE 顶层，不无条件拉取其完整 GN 依赖图。

依赖：WU-0151、远端持久目录流程。

验收：

- [x] doctest、SDL、Dynarmic、ext-boost 与 Boost.Pool 继续按既有语义递归初始化。
- [x] ANGLE 顶层使用独立的浅 submodule 更新命令，不继承全局 `--recursive`。
- [x] ANGLE gclient/GN 依赖和产物留给启用图形构建的专用持久步骤管理。
- [x] 远端脚本 self-test 精确锁定核心依赖与 ANGLE 的不同更新策略。
- [x] 工具说明记录边界，且 Windows/MSVC 全量 CTest 通过。
