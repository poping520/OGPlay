# WU-0153 · 可复现 ANGLE 本机构建驱动

目标：以固定 gitlink 和稳定 GN 参数同步、构建并验证本机 ANGLE EGL/GLESv2 产物。

依赖：WU-0151、WU-0152、ADR-0003。

验收：

- [x] ANGLE 固定到同时支持 VS 2026 与 SDK 10.0.26100 的官方 commit，避开更高 SDK
  的隐式系统依赖。
- [x] 构建前校验 ANGLE checkout 与顶层索引 gitlink 完全一致，偏离时明确失败。
- [x] 使用官方 `bootstrap.py`、gclient、GN 和 autoninja，不另造依赖获取方式。
- [x] Windows 固定 MSVC，三平台参数显式关闭无关后端并保留既定 ANGLE 后端。
- [x] 只构建 `libEGL`、`libGLESv2`，按平台接受并验证官方命名的链接及运行时产物。
- [x] 产物目录记录 commit、平台、CPU、完整 GN 参数和文件清单。
- [x] 本机完成真实依赖同步、GN 生成、EGL/GLESv2 编译及 OGPlay 启用构建。
- [x] 驱动 self-test 及默认 Windows/MSVC 全量 CTest 通过。

非目标：本 WU 不创建 EGL 上下文，不构建 ANGLE 测试套件，不执行 Linux/macOS 验收。
