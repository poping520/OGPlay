# WU-0154 · ANGLE 预编译 SDK 打包契约

目标：把固定源码构建结果转换为可重定位、可校验且带许可证的最小 ANGLE SDK。

依赖：WU-0153、ADR-0014。

验收：

- [x] SDK 以平台、CPU 和配置分层，不携带源码、对象文件或构建工具链。
- [x] 包含 EGL/GLES 公共头、链接库、必要运行时文件和许可证。
- [x] 清单记录 ANGLE commit、GN 参数及每个文件的大小和 SHA-256。
- [x] 校验器拒绝缺失、篡改、重复、越界路径及未声明文件。
- [x] Windows Release 真实产物可打包并通过独立复验。
- [x] 构建驱动和打包器 self-test 纳入 CTest。

非目标：本 WU 不创建远程二进制仓库，不切换 CMake 消费入口，不创建 EGL 上下文。
