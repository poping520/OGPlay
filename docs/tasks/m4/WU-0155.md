# WU-0155 · CMake 消费 ANGLE 预编译 SDK

目标：让 OGPlay 配置只从宿主匹配且完整性校验通过的预编译 SDK 导入 ANGLE。

依赖：WU-0154、ADR-0014。

验收：

- [x] CMake 自动选择宿主平台和 CPU，仅允许显式 release/debug 配置。
- [x] 配置阶段核对清单 schema、平台、CPU、配置、逐文件大小和 SHA-256。
- [x] 越界路径、缺失/篡改文件、错误平台及不完整 EGL/GLESv2 产物均明确失败。
- [x] `ANGLE::EGL`、`ANGLE::GLESv2` 的头文件和库只来自 SDK，不读取源码树。
- [x] Windows/MSVC 使用本地打包的 Release SDK 完成启用配置、链接和全量 CTest。

非目标：本 WU 不创建远程二进制仓库，不提交 SDK 二进制，不创建 EGL 上下文。
