# WU-0156 · ANGLE 二进制仓库接入

目标：把已验证的 Windows Release SDK 通过独立浅 submodule 交付给普通构建和 CI。

依赖：WU-0154、WU-0155、ADR-0014。

验收：

- [x] 独立公开仓库只包含 SDK、清单、许可证和说明，不包含源码或构建中间文件。
- [x] Windows x64 Release SDK 已推送并由主仓库 gitlink 固定。
- [x] `angle-prebuilt` 配置为浅 submodule，普通 checkout 不拉取其历史。
- [x] Windows CI 启用 ANGLE 并只初始化预编译 SDK；Linux/macOS 默认构建不初始化源码。
- [x] 远端增量流程浅更新预编译 SDK，不再初始化 ANGLE 源码工作区。
- [x] 全新 submodule 路径可通过 SDK 校验，Windows/MSVC 全量 CTest 通过。

非目标：本 WU 不发布 Linux/macOS 包，不删除维护者源码 submodule，不创建 EGL 上下文。
