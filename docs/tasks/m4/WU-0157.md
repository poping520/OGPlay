# WU-0157 · ANGLE 源码工作区外移

目标：从 OGPlay 删除 ANGLE 源码 submodule，并把维护输入归入本地二进制仓库工作区。

依赖：WU-0156、ADR-0015。

验收：

- [x] ANGLE checkout 与原始归档移动到 `.local/angle-prebuilt-repo` 且被本地排除。
- [x] checkout 转为独立 Git 工作区，保持固定 commit 和干净状态。
- [x] OGPlay 删除 ANGLE 源码 gitlink，只保留 `angle-prebuilt` 浅 submodule。
- [x] 构建驱动以固定 commit 校验任意本地源码路径，不依赖主仓库 gitlink。
- [x] 构建和打包工具默认指向新的本地维护者工作区。
- [x] 工具 self-test、SDK 复验及 Windows/MSVC 全量 CTest 通过。

非目标：本 WU 不提交/上传源码工作区或归档，不改变 ANGLE 二进制，不创建 EGL 上下文。
