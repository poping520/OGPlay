# WU-0158 · ANGLE 生产工具剥离

目标：把 ANGLE 源码构建与 SDK 打包工具完整迁入 `angle-prebuilt-repo`，令 OGPlay 只消费产物。

依赖：WU-0157、ADR-0015。

验收：

- [x] 构建驱动、SDK 打包器和维护说明由 `angle-prebuilt-repo/tools/` 独立拥有。
- [x] 生产仓库 `.gitignore` 排除源码、归档、GN 输出、临时包和 Python 缓存。
- [x] 生产仓库三平台 CI 执行两个工具 self-test 和已发布 SDK 完整性复验。
- [x] OGPlay 删除两个生产脚本及其维护说明，只保留消费配置和清单校验。
- [x] OGPlay 工具测试从固定 submodule commit 执行，不引用仓库内已删除路径。
- [x] 两个仓库状态、SDK 复验及 Windows/MSVC 全量 CTest 通过。

非目标：本 WU 不重编译或修改 ANGLE 二进制，不发布 Linux/macOS SDK，不创建 EGL 上下文。
