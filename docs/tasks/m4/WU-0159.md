# WU-0159 · EGL pbuffer 生命周期

目标：在预编译 ANGLE 上建立可回滚、可测试且不泄漏原生类型的 EGL/GLES2 pbuffer 生命周期。

依赖：WU-0158、WU-0150 的后端选择契约、HAL gfx 边界。

验收：

- [x] 公共接口不暴露 EGL/SDL/平台类型，并允许注入 EGL API 进行确定性契约测试。
- [x] 生命周期依次创建 ANGLE display、初始化 EGL、选择 config、绑定 GLES API、创建
  GLES2 context 与 pbuffer surface，再执行 make-current。
- [x] 任一步失败均保留具体操作和 EGL 错误码，并按已完成阶段逆序回滚，不伪造成功。
- [x] 移动语义只转移一次所有权；析构按 unbind→surface→context→display 顺序无异常清理。
- [x] 关闭 ANGLE 时生产工厂明确报不可用；开启时 Windows/MSVC 真实 D3D11 pbuffer 通过。
- [x] Windows/MSVC warnings-as-errors 构建与启用 ANGLE 的全量 CTest 243/243 通过。

非目标：本 WU 不创建窗口 surface、不实现 swap/present，也不接入 guest EGL/GLES 导出边界。
