# WU-0160 · GLES IDL 与确定性生成器

目标：建立严格校验的 GLES IDL schema，并由单一事实源确定性生成 C++ 调用目录。

依赖：WU-0159、M4 禁止手写 per-function 转译约束。

验收：

- [x] JSON IDL 固定 schema/API/library/function/parameter 与指针搬运元数据。
- [x] 函数名必须唯一有序；类型、重复参数、标量/指针元数据错误均明确拒绝。
- [x] 生成器只使用 Python 标准库，输出稳定的 C++ 参数与函数目录。
- [x] CMake 把生成物纳入 `ogplay_gles` 依赖，并有 self-test 与 stale check。
- [x] 首批 GLES2 标量、输入、输出及像素搬运形状通过生成验证。

非目标：本 WU 不宣称 GLES2 入口完整，不执行 guest 调用或 ANGLE GLES 函数。
