# WU-0161 · GLES2 core 完整入口目录

目标：把 GLES 2.0 core 的全部入口及指针形状纳入 IDL，并以固定 ANGLE 头文件作集合门禁。

依赖：WU-0160、固定 ANGLE SDK 头文件。

验收：

- [x] `gles2.json` 覆盖 `gl2.h` 的 142 个 core 入口和 397 个参数。
- [x] 输入/输出、可空性、长度表达式及一/二级指针均由 IDL 显式描述。
- [x] `glGetString` 的宿主指针返回、`glShaderSource` 字符串数组与
  `glGetVertexAttribPointerv` 二级输出指针不会被压扁为标量。
- [x] 工具测试比较 IDL 与固定 ANGLE `gl2.h` 的函数集合，缺失或多余入口明确失败。
- [x] 生成目录保持唯一稳定排序，重复构建无漂移。

非目标：本 WU 不执行 142 个入口，也不宣称 GLES1.1 已覆盖。
