# WU-0162 · guest 内存受检搬运层

目标：为生成式 GLES 边界提供强类型 guest 指针的预检、暂存和显式回写能力。

依赖：WU-0161、memory `AddressSpace` 权限契约。

验收：

- [x] `GuestBuffer` 仅接受 `GuestAddress`，不向公共接口暴露未经验证的宿主指针。
- [x] input/output/inout 分别预检完整 read/write/read+write 区间，再进行任何搬运。
- [x] input 复制 guest 内容；output 零初始化且不读取 guest；输出仅在显式 `Commit` 时回写。
- [x] nullability、零长度、地址溢出、配置大小上限、重复提交和错误方向均明确失败。
- [x] 搬运对象不可复制，避免重复回写；内存 fault 保留 guest 地址、权限和线程事实。

非目标：本 WU 不求值 IDL 长度表达式，也不调用 ANGLE GLES 入口。
