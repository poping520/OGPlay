# WU-0163 · 生成式 GLES2 分派目录

目标：把生成目录接入稳定 thunk 查找和显式 handler 分派，令未实现调用可失败、可查询。

依赖：WU-0161、WU-0162、未实现能力不得伪造成功约束。

验收：

- [x] 142 个生成入口获得稳定有序 `GlesThunkId`，支持精确名称查找和描述查询。
- [x] 调用前校验 thunk 范围和 guest 参数槽数量，不匹配时不进入 handler。
- [x] 只有非空且唯一绑定的 handler 可执行；未知、空或重复绑定均明确失败。
- [x] 未绑定调用抛出函数名/thunk/guest 线程错误，并累计 hits、first/last thread 查询。
- [x] 分派锁不包围 handler 执行，避免 guest 回调造成锁重入。
- [x] 启用 ANGLE 的 Windows/MSVC warnings-as-errors 构建与全量 CTest 253/253 通过。

非目标：本 WU 不生成每个 ANGLE 调用体，不求值指针长度表达式，也不绑定 Bionic thunk 地址。
