# WU-0164 · GLES 调用长度求值与搬运准备

目标：从生成参数目录安全求值指针长度，并在 handler 前完成 guest 指针搬运准备。

依赖：WU-0161、WU-0162、WU-0163。

验收：

- [x] 专用求值器只接受无符号字面量、标量参数和 `参数*常量`，拒绝负数、未知引用与溢出。
- [x] 状态/格式相关表达式必须通过 `GlesLengthResolver` 显式解析；缺失解析明确失败。
- [x] resolver 可把 VBO 等宿主状态持有的地址标为 deferred，不误读为 guest 指针。
- [x] 按 GL 基础类型和指针层级换算字节数；二级指针数组固定使用 32 位 guest 指针宽度。
- [x] 有界 C 字符串扫描包含终止符；无终止符、权限 fault 和超过限额均明确失败。
- [x] input/output/inout 方向、可空性、线程 ID 与限额传入 `GuestBuffer`，nullable null 不分配。
- [x] 启用 ANGLE 的 Windows/MSVC warnings-as-errors 构建与全量 CTest 258/258 通过。

非目标：本 WU 不实现像素/GL 状态 resolver，不递归搬运字符串数组，也不调用 ANGLE handler。
