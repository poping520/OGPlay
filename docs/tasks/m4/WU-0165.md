# WU-0165 · GLES 状态化搬运长度解析

目标：以可查询的上下文状态解析像素、索引和常用查询的搬运长度，明确区分 guest 内存与缓冲对象偏移。

依赖：WU-0161、WU-0162、WU-0164。

验收：

- [x] `GL_PACK_ALIGNMENT` / `GL_UNPACK_ALIGNMENT` 初值为 4，只接受 1、2、4、8，二维像素跨度只在行间计入对齐填充。
- [x] `glReadPixels`、`glTexImage2D`、`glTexSubImage2D` 按各自参数位置解析尺寸、格式和类型；负尺寸、未知组合及算术溢出明确失败。
- [x] `glDrawElements` 在未绑定 element buffer 时按索引类型搬运 guest 数组，已绑定时把指针保留为 deferred buffer offset。
- [x] client vertex array 指针保持 deferred；array/element buffer 绑定和 pack/unpack 状态可通过快照查询。
- [x] 常用固定查询、纹理参数和 vertex-attrib 查询给出确定元素数；动态枚举和 uniform 形状必须显式登记，未知形状明确失败。
- [x] 非法状态更新不改变既有快照，program 销毁路径可清除其 uniform 形状。
- [x] 启用 ANGLE 的 Windows/MSVC warnings-as-errors 构建与全量 CTest 263/263 通过。

非目标：本 WU 不绑定真实 ANGLE 调用体，不跟踪完整 GL 对象生命周期，也不实现 client array draw 时的延迟搬运。
