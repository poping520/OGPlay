# WU-0166 · ANGLE GLES2 最小帧执行

目标：在真实 ANGLE GLES2 context 上执行最小 viewport/clear/readback 帧，为 guest 调用与窗口呈现提供可验证下游。

依赖：WU-0159、WU-0163、WU-0165。

验收：

- [x] `AngleFrame` 独占真实 ANGLE API 与 pbuffer 生命周期，析构顺序不悬空。
- [x] `Viewport`、`ClearColor`、`Clear` 直接调用 ANGLE GLES2，并在每次调用后检查原生错误。
- [x] RGBA8 readback 在分配前检查尺寸溢出，执行 `glFinish` 后返回完整确定帧。
- [x] 快照累计 clear/readback 次数；负 viewport 尺寸和 ANGLE 不可用均明确失败。
- [x] Windows/MSVC + ANGLE 真实 D3D11 pbuffer 的 4×3 颜色帧逐像素验证通过，全量 CTest 264/264 通过。

非目标：本 WU 不创建窗口 surface，不实现 guest EGL handle，也不绑定通用 GLES2 thunk。
