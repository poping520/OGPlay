# WU-0167 · ELF HLE 边界命名空间装载

目标：让统一 ELF 装载事务接受追加的绝对 HLE 边界模块，同时只映射和重定位真实 guest ELF。

依赖：WU-0061、WU-0063、WU-0166。

验收：

- [x] `Elf32LinkNamespaceBuilder` 可在解析全部 guest 模块后构造最终命名空间。
- [x] builder 可追加绝对 HLE 符号模块；追加模块参与查找但不被当作 ELF 映射或重定位。
- [x] guest 模块必须保持原顺序、名称和 load bias；删除、替换或重排明确失败。
- [x] builder、映射和重定位仍位于同一 address-space snapshot 事务内。
- [x] 默认无 builder 路径保持原有行为，Windows/MSVC 严格构建与全量 CTest 266/266 通过。

非目标：本 WU 不映射 thunk 指令，不执行 HLE trap，也不实现 Android/EGL 具体 handler。
