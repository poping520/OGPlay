# WU-0168 · guest HLE supervisor trap 执行

目标：让统一 guest 线程循环在 Linux syscall 之外只消费显式注入并确认处理的 HLE trap，并把同一 handler 传播给 clone child。

依赖：WU-0068、WU-0075、WU-0167。

验收：

- [x] `ConsumeAndroidArmSupervisorCall` 先尝试既有 `SVC #0` syscall，再把未消费 trap 交给显式 HLE handler。
- [x] handler 必须返回已处理才继续执行；缺失或拒绝仍报告 `unhandled_supervisor_call`。
- [x] handler 可受检更新 A32 返回寄存器，线程生命周期和 TPIDRURO 同步路径保持不变。
- [x] `GuestCloneThreadRuntime` 把同一线程安全 handler 传播到真实 child 宿主线程。
- [x] root 执行器可复用同一消费函数；Windows/MSVC 全量 CTest 267/267 通过。

非目标：本 WU 不定义 HLE thunk 地址、符号目录或 Android/EGL 调用语义。
