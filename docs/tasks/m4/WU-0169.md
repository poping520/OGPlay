# WU-0169 · NativeActivity command pipe syscall

目标：用统一 VFS descriptor 与受检 guest 内存实现 Android ARM `pipe`，支撑 NativeActivity glue 主/工作线程命令通道。

依赖：WU-0080、WU-0083、WU-0168。

验收：

- [x] `VirtualFileSystem::CreatePipe` 原子分配隔离的只读端和只写端，共享有序字节流。
- [x] 读端不能写、写端不能读，关闭后沿用稳定 `EBADF` 失败。
- [x] syscall 42 在创建前完整预检两个 32 位 descriptor 的 guest 输出范围。
- [x] descriptor 数组按 ARM little-endian 发布；写回异常时关闭两端，不泄漏半完成 pipe。
- [x] syscall write/read 可跨两端传输真实 guest 字节，坏输出地址返回 `EFAULT`。
- [x] Windows/MSVC 严格构建与全量 CTest 269/269 通过。

非目标：本 WU 不实现通用 poll/epoll、非阻塞 flag 或宿主 OS pipe。
