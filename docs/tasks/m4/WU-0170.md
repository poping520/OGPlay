# WU-0170 · SDL RGBA8 帧呈现

目标：让宿主 SDL 窗口接收 ANGLE readback 的完整 RGBA8 帧并显式 present。

依赖：WU-0012、WU-0166。

验收：

- [x] `WindowInput` 不暴露 SDL 类型即可提交 RGBA8 帧。
- [x] 零尺寸、溢出和尺寸不匹配在访问像素前明确失败。
- [x] SDL 将源帧缩放到当前窗口 surface，更新成功后才累计 present。
- [x] dummy video backend 上完成真实 surface 更新契约测试。
- [x] Windows/MSVC 全量 CTest 270/270 通过。

非目标：本 WU 不提供 EGL native window surface；当前路径用于显示 guest `eglSwapBuffers` 的 ANGLE pbuffer readback。
