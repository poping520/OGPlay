# WU-0171 · APK stored-entry 读取

目标：从不可信 APK 中按 ABI 名称严格提取未压缩 native ELF。

依赖：WU-0041。

验收：

- [x] 解析单盘 ZIP32 central directory，范围、计数和结束位置全部受检。
- [x] 拒绝重复/不安全路径、加密、多磁盘和 local/central 元数据分歧。
- [x] 只读取 method 0 条目并验证精确尺寸、名称和 CRC32。
- [x] ELF payload 与缺失、压缩和损坏路径均有机器可判定测试。
- [x] Windows/MSVC 全量 CTest 273/273 通过。

非目标：本 WU 不解压资源或 DEX；最小 NDK 样例的 `lib/armeabi-v7a/*.so` 已按 APK 规范对齐存储。
