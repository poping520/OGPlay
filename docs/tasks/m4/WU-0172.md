# WU-0172 · Android Native 边界 HLE

目标：把最小 NativeActivity 样例所需的 Android/Looper/input/EGL/GLES 调用绑定为可执行 guest trap。

依赖：WU-0166、WU-0168。

验收：

- [x] 每个已登记边界符号拥有唯一 Thumb `svc #2; bx lr` thunk，未知 trap 保持未处理。
- [x] Bionic memory intercept、Configuration、Looper 与 input queue 覆盖样例实际导入。
- [x] EGL/GLES 调用在 guest 工作线程创建 ANGLE pbuffer、clear 并发布带序号 RGBA8 帧。
- [x] command write 与宿主输入可唤醒阻塞 `ALooper_pollAll`，数据源指针保持 guest 原值。
- [x] Windows/MSVC 全量 CTest 276/276 通过。

非目标：只实现当前样例需要的常用 native 边界，不声称覆盖完整 NDK 或 GLES2 142 槽调用体。
