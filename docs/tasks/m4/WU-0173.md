# WU-0173 · NativeActivity guest session

目标：在真实 API 19 Bionic 上启动并关闭最小 APK 的 `ANativeActivity_onCreate` 与 glue 工作线程。

依赖：WU-0093、WU-0167、WU-0168、WU-0169、WU-0171、WU-0172。

验收：

- [x] 统一 ELF 事务装载 APK native ELF、libm/libdl/libc 与 HLE boundary namespace。
- [x] 初始化 API 19 TLS/property/stack，执行 guest initializer 后调用真实 `ANativeActivity_onCreate`。
- [x] start/resume/window/input/focus callback 经 command pipe 唤醒 glue child。
- [x] guest `eglSwapBuffers` 产生首帧，键盘输入经 `AInputQueue` 改变后续帧像素。
- [x] focus/input/window/pause/stop/destroy 逆序关闭，clone child clean exit 后执行 finalizer。
- [x] 本地真实 `ogplay-minimal-ndk-armeabi-v7a.apk` 与 API 19 Bionic 集成测试通过。
- [x] Windows/MSVC 全量 CTest 277/277 通过（集成测试启用真实 APK/oracle）。

非目标：本 WU 不声明 API 22/23 NativeActivity 启动完成；当前可测试样例明确使用 API 19。
