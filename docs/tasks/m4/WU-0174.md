# WU-0174 · 最小 APK 交互运行命令

目标：让用户通过 `ogplay run-apk` 打开最小 ARMv7 NativeActivity APK 并交互测试画面与输入。

依赖：WU-0170、WU-0171、WU-0173。

验收：

- [x] CLI 从 APK 选择唯一 armeabi-v7a native ELF，并要求显式 API 19 Bionic 目录。
- [x] SDL 主线程窗口轮询关闭、键盘、鼠标事件并转发 guest input queue。
- [x] guest 最新 RGBA8 frame 在 SDL software surface 上持续 present。
- [x] 关闭窗口后同步停止 NativeActivity；`--exit-after-frames` 提供有界 smoke。
- [x] Windows/MSVC 真实 APK smoke 呈现 2 帧并以 0 退出；带真实 API 19 Bionic/APK
  环境的全量 CTest 277/277 通过。

非目标：不猜测多 native library APK 的入口，不在本 WU 实现 manifest import/profile UI。
