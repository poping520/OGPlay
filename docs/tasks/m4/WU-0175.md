# WU-0175 · GPU Agent 查询契约

目标：让 Agent 以强类型 provider 查询 GPU 统计、渲染目标、能力和有界调用 trace。

依赖：M0 Control Service、WU-0150、WU-0166。

验收：

- [x] core 定义不依赖 GLES/Agent 的只读 `GpuStateProvider` 和结构化快照类型。
- [x] `gpu.stats`、`gpu.render_targets`、`gpu.capabilities` 输出稳定 JSON 对象。
- [x] `gpu.trace` 将 filter 和 1..1000 limit 经 JSON-RPC 传给 provider。
- [x] provider 缺失、非法限额及 provider 超额返回均明确失败。
- [x] Windows/MSVC + ANGLE、真实 API 19 APK/Bionic 环境全量 CTest 280/280 通过。

非目标：本 WU 不接入真实 ANGLE/NativeActivity 指标，不实现纹理/FBO dump 或 shader 查询。
