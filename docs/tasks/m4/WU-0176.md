# WU-0176 · NativeActivity GPU 指标 provider

目标：让真实最小 NativeActivity APK 的 GPU 事实可由 WU-0175 的 provider 查询。

依赖：WU-0166、WU-0173、WU-0175。

验收：

- [x] `NativeActivitySession` 以 core provider 暴露线程安全的 GPU 快照。
- [x] 真实 guest `glClear` 更新计数，默认 FBO 报告实际 RGBA8 尺寸且标记非 guest 创建。
- [x] 能力快照报告实际 ANGLE renderer/device，不伪造未查询的扩展或限制。
- [x] 成功 EGL/GLES 调用记录通用寄存器参数，内部最多保留 2048 条并支持有界过滤。
- [x] EGL terminate 后当前渲染目标快照恢复为空，不保留已销毁 FBO。
- [x] Windows/MSVC + ANGLE、真实 API 19 APK/Bionic 环境全量 CTest 280/280 通过。

非目标：本 WU 不实现 draw/shader/guest FBO 发现，也不把失败调用伪装为可继续的 GL 错误。
