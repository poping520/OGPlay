# WU-0177 · SDL 等比黑边呈现

目标：让不同宽高比的 guest RGBA8 帧在 SDL 窗口中等比居中显示而不被拉伸。

依赖：WU-0170。

验收：

- [x] `FitDisplayRect` 用 64 位中间值处理横屏、竖屏、同宽高和极端非零尺寸。
- [x] SDL 每帧先把目标 surface 清为不透明黑色，再向内容矩形 nearest 缩放。
- [x] dummy surface 像素测试同时验证黑边、内容起点和右侧黑边。
- [x] 无效尺寸明确失败，只有 fill、blit、window update 全部成功才增加 present 计数。
- [x] Windows/MSVC + ANGLE、真实 API 19 APK/Bionic 环境全量 CTest 281/281 通过。
- [x] `ogplay run-apk --exit-after-frames 2` 真实窗口冒烟呈现 2 帧并以 0 退出。

非目标：本 WU 不映射黑边后的输入坐标，不实现超采样或可配置滤波模式。
