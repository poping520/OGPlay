# WU-0178 · 等比内容区输入映射

目标：让可调整大小的 SDL 窗口把 pointer 坐标准确映射到未拉伸的 guest 画面。

依赖：WU-0174、WU-0177。

验收：

- [x] `MapDisplayPoint` 与 present 共用 `FitDisplayRect`，输出 source 坐标及 inside 事实。
- [x] 内容区原点、中心和两侧黑边有确定性坐标测试；非有限坐标明确失败。
- [x] CLI 以最近 guest 帧尺寸映射 pointer，键盘事件保持原样。
- [x] 黑边按下/移动不注入；释放事件夹紧转发，避免 guest 手势无法结束。
- [x] Windows/MSVC + ANGLE、真实 API 19 APK/Bionic 环境全量 CTest 282/282 通过。
- [x] `ogplay run-apk --exit-after-frames 2` 真实窗口冒烟呈现 2 帧并以 0 退出。

非目标：本 WU 不实现多点触控、旋转、DPI 策略或超采样。
