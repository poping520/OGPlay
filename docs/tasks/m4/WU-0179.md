# WU-0179 · ANGLE 左上原点黄金帧

目标：用非对称 GLES2 图案验证 ANGLE readback 与宿主 `ImageView` 的像素方向和内容一致。

依赖：WU-0010、WU-0166、WU-0177。

验收：

- [x] `AngleFrame` 提供受检 scissor 矩形与 enable/disable，负尺寸明确失败。
- [x] `ReadRgba8` 把 `glReadPixels` 底部首行翻转为 SDL/`ImageView` 顶部首行。
- [x] 8×8 非对称红色矩形与 SoftwareSurface 黄金帧逐像素、感知哈希完全一致。
- [x] clear/readback 计数仍准确，所有新增 GLES 调用继续检查原生错误。
- [x] Windows/MSVC + ANGLE、真实 API 19 APK/Bionic 环境全量 CTest 283/283 通过。
- [x] `ogplay run-apk --exit-after-frames 2` 真实窗口冒烟呈现 2 帧并以 0 退出。

非目标：本 WU 不宣称 SwiftShader 或 Linux/macOS 黄金帧完成，也不实现通用 GLES2 绘制器。
