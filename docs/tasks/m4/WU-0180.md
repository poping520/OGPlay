# WU-0180 · 确定性超采样 resolve

目标：提供可供 NativeActivity 复用的受检 1..4× RGBA8 超采样布局和确定性缩小内核。

依赖：WU-0179。

验收：

- [x] 逻辑尺寸非零、factor 1..4，render 尺寸乘法溢出明确失败。
- [x] resolve 重新验证布局和完整 RGBA8 输入字节数，不接受调用方伪造尺寸。
- [x] 2× 四色块 resolve 保持左上方向和精确颜色。
- [x] box filter 使用整数累加、固定四舍五入，避免宿主浮点差异。
- [x] factor、布局、字节数、方向和非整除平均值均有机器测试。
- [x] Windows/MSVC + ANGLE、真实 API 19 APK/Bionic 环境全量 CTest 286/286 通过。

非目标：本 WU 不改变 NativeActivity pbuffer 尺寸，不新增 CLI 参数，也不宣称超采样已对游戏启用。
