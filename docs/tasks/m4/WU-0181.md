# WU-0181 · NativeActivity 超采样接入

目标：让 NativeActivity 在保持 guest 逻辑尺寸的同时使用受检 1..4× ANGLE 内部渲染并
确定性输出逻辑 RGBA8 帧。

依赖：WU-0180。

验收：

- [x] session 请求携带默认 1×、受检范围 1..4× 的超采样倍率。
- [x] ANGLE pbuffer 和 GPU render target 使用放大后的真实尺寸。
- [x] guest `eglQuerySurface`、输出帧和输入坐标继续使用逻辑尺寸。
- [x] guest viewport 的位置和尺寸统一按倍率缩放，32 位有符号溢出明确失败。
- [x] swap readback 通过确定性 box resolve 输出完整逻辑 RGBA8 帧。
- [x] 直接边界测试覆盖非法倍率、逻辑/真实尺寸、viewport 溢出和 2× resolve。
- [x] 真实 API 19 最小 APK 以 2× 运行，画面、输入变色与销毁闭环保持通过。
- [x] Windows/MSVC + ANGLE、真实 API 19 APK/Bionic 环境全量 CTest 287/287 通过。

非目标：本 WU 不新增 CLI 参数；CLI 显式选择倍率由 WU-0182 完成。
