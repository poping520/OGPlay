# WU-0182 · CLI 超采样配置

目标：让 `ogplay run-apk` 可显式选择受检 1..4× 超采样倍率，同时保持默认 1×。

依赖：WU-0181。

验收：

- [x] 新增 `--supersample <1..4>`，并把倍率传入 `NativeActivityRunRequest`。
- [x] 省略选项时保持 1×，不改变已有命令行为。
- [x] 零、越界、非纯数字和缺值在 APK I/O、ANGLE 与窗口创建前明确失败。
- [x] CLI usage 和 frontend 模块契约同步更新。
- [x] CTest 进程级契约覆盖默认值、合法边界 1×/4×、2× 与四类非法输入。
- [x] 真实 API 19 最小 APK 以 2× 呈现 2 帧并正常退出。
- [x] Windows/MSVC + ANGLE、真实 API 19 APK/Bionic 环境全量 CTest 288/288 通过。

非目标：本 WU 不增加自动倍率、持久配置或 GUI 控件。
