# WU-0183 · 多平台 ANGLE SDK 能力门禁

目标：让 OGPlay 只依据逐字节受检的多平台 ANGLE 包与 GN 参数决定是否执行 SwiftShader
黄金帧，禁止凭头文件枚举伪造软件能力。

依赖：WU-0182、独立 angle-prebuilt 仓库的四平台 Release SDK。

验收：

- [x] 浅 submodule 固定共享头、Windows/Linux x64 与 macOS x64/arm64 平台包。
- [x] 预编译仓库禁用 Git 文本转换，四个平台包在全新字节导出后逐文件校验通过。
- [x] CMake 校验平台包与共享头的 schema、ANGLE commit、安全路径、大小和 SHA-256。
- [x] CMake 从平台清单读取 `angle_enable_swiftshader=true/false`，缺失声明明确失败。
- [x] 硬件黄金帧按 Windows D3D11、Linux Vulkan、macOS Metal 的宿主 backend 运行。
- [x] 包启用 SwiftShader 时执行 Vulkan/SwiftShader 黄金帧；未启用时要求 EGL 明确失败。
- [x] 当前 Windows/MSVC 包验证 SwiftShader 不可用且没有静默回退到硬件。
- [x] Windows/MSVC + ANGLE、真实 API 19 APK/Bionic 环境全量 CTest 289/289 通过。

非目标：本 WU 不宣称 Windows 已有 SwiftShader 二进制，也不提前执行 Linux/macOS 出口测试。
