# WU-0184 · 综合 GLES2 样例命名空间

目标：冻结 M4 综合出口 APK 的 EGL/GLES2 导入契约，并让全部 GLES2 core 符号可在 guest
装载时解析，未实现调用继续明确失败。

依赖：WU-0160、WU-0173、WU-0183、`samples/m4_exit` 综合样例。

验收：

- [x] 样例在 Android API 19、armeabi-v7a、NDK r21e 下离线构建、对齐、签名和校验通过。
- [x] `--contract-only` 无需 SDK/NDK 即可核对 12 个 EGL 与 42 个 GLES2 源码调用。
- [x] 42 个 GLES2 调用必须全部存在于仓库 IDL，实际 ELF 图形导入必须与源码精确一致。
- [x] Android HLE 从生成目录追加完整 142 项 GLES2 符号，同时保留既有固定 thunk 地址。
- [x] thunk 数量在写入 guest 页前受检，目录增长不得越界写入。
- [x] 尚未绑定的 `glActiveTexture` 可完成符号解析，但执行时携带函数名明确失败。
- [x] Windows/MSVC + ANGLE 严格构建通过；真实 API 19 APK/Bionic 环境全量 CTest
  291/291 通过。

非目标：本 WU 不实现 shader/program、buffer/texture 或 draw handler，不宣称综合样例已跑出帧。
