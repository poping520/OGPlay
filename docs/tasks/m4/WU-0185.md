# WU-0185 · NativeActivity child 失败上报

目标：让 guest 渲染线程失败立即解除同步等待并携带原始原因返回 CLI，禁止窗口永久无响应。

依赖：WU-0173、WU-0184、真实 M4 综合出口 APK。

验收：

- [x] `FutexTable::WakeAll` 只唤醒调用时已有 waiter，不修改 guest 值或影响后续等待。
- [x] 非 root guest 的 HLE 异常按首次失败保存，并唤醒正在等待 glue condition 的 root。
- [x] root 离开 futex syscall 后、继续执行 guest 指令前检查 child 失败。
- [x] child 失败转换为带原始异常文本的 `NativeActivityRunError`，不得伪装为正常停止。
- [x] 真实综合 APK 在 `glCreateShader` 未实现时约 1.5 秒内返回精确错误，不再无限等待首帧。
- [x] CLI 实测约 3 秒关闭窗口并以非零状态输出同一错误。
- [x] Windows/MSVC + ANGLE、真实 minimal/M4 APK 与 API 19 Bionic 环境全量 CTest
  293/293 通过。

非目标：本 WU 不实现 `glCreateShader` 或其他 shader/program handler；下一 WU 继续该组。
