# WU-0186 · GLES2 shader/program handler

目标：让综合出口样例以受检 guest 内存调用真实 ANGLE 完成 shader 编译和 program 链接。

依赖：WU-0165、WU-0184、WU-0185。

验收：

- [x] `AngleFrame` 直接调用 ANGLE 完成 create/source/compile/query/delete shader。
- [x] program create/attach/link/query、attribute/uniform location、use/delete 真实生效。
- [x] `glShaderSource` 支持受检二级指针、显式长度与负长度 C 字符串，段数和总字节有界。
- [x] 查询输出和符号名在 ANGLE 调用前验证 guest 权限，null/坏地址明确失败。
- [x] 编译与链接状态来自 ANGLE 查询值，不因 API 调用成功而伪造 shader 成功。
- [x] GPU stats 只在真实调用完成后累计 2 次 compile 和 1 次 link。
- [x] 真实综合 APK 越过 shader/program 初始化，下一明确缺口推进到 `glGenBuffers`。
- [x] Windows/MSVC + ANGLE、真实 minimal/M4 APK 与 API 19 Bionic 环境全量 CTest
  294/294 通过。

非目标：本 WU 不实现 buffer、texture、uniform value、vertex attribute 或 draw handler。
