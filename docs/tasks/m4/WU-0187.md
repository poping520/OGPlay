# WU-0187 · GLES2 buffer/texture handler

目标：让综合出口样例以受检 guest 资源搬运完成真实 ANGLE buffer 与 texture 初始化。

依赖：WU-0166、WU-0168、WU-0186。

验收：

- [x] buffer generate/delete/bind/data 与 texture generate/delete/active/bind 真实生效。
- [x] `glPixelStorei`、`glTexParameteri`、`glTexImage2D` 进入真实 ANGLE。
- [x] 名称数组按小端显式回写，输入资源在原生调用前完成方向、范围和 64 MiB 上限校验。
- [x] null buffer/texture 数据保留 GLES 分配语义，坏 guest 地址在 ANGLE 调用前失败。
- [x] texture 像素长度依据受检 unpack alignment、尺寸、格式和类型解析。
- [x] buffer 绑定与像素对齐状态只在 ANGLE 成功后提交，删除绑定 buffer 同步清理状态。
- [x] 真实综合 APK 越过资源初始化，下一明确缺口推进到 `glEnableVertexAttribArray`。
- [x] Windows/MSVC + ANGLE、真实 minimal/M4 APK 与 API 19 Bionic 环境全量 CTest
  295/295 通过。

非目标：本 WU 不实现 vertex attribute、uniform value、查询、draw 或 readback handler。
