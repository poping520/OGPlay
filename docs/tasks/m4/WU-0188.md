# WU-0188 · GLES2 vertex/uniform handler

目标：让综合出口样例以受检 VBO offset 与 uniform 数据完成真实 ANGLE 顶点输入初始化。

依赖：WU-0168、WU-0186、WU-0187。

验收：

- [x] enable/disable vertex attribute array 与 `glVertexAttribPointer` 真实生效。
- [x] stride、pointer 等第五/第六参数按 ARM AAPCS 从 guest 栈读取。
- [x] 仅在 array buffer 已绑定时把 pointer 解释为 VBO offset，client array 明确失败。
- [x] `glUniform1f`、`glUniform1i`、`glUniform4f` 保持 guest 标量位模式。
- [x] `glUniformMatrix3fv` 按 `count*9` 完整搬运，坏地址在 ANGLE 调用前失败。
- [x] 真实综合 APK 越过顶点与 uniform 初始化，下一明确缺口推进到 `glGetIntegerv`。
- [x] Windows/MSVC + ANGLE、真实 minimal/M4 APK 与 API 19 Bionic 环境全量 CTest
  295/295 通过。

非目标：本 WU 不实现状态查询、字符串查询、draw 或 readback handler。
