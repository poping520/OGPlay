# WU-0189 · Android boundary GLES 分派拆分

目标：在不改变 guest 行为的前提下，把资源与顶点 GLES 分派从已达 800 行的主 HLE 提取。

依赖：WU-0187、WU-0188。

验收：

- [x] `AndroidBoundaryGles` 独占 18 项 buffer/texture/vertex/uniform handler 与 transfer state。
- [x] 主 HLE 保留 EGL、shader/program、viewport/clear、超采样、帧和 GPU 指标职责。
- [x] `eglTerminate` 显式重置独立 GLES 搬运状态，不跨 context 泄漏绑定与像素对齐。
- [x] 两个生产源文件分别为 668 行和 277 行，均不超过 800 行。
- [x] 既有真实 ANGLE 资源、栈参数、uniform 与坏指针测试保持通过。
- [x] 真实综合 APK 的下一缺口仍为 `glGetIntegerv`，迁移前后行为一致。
- [x] Windows/MSVC + ANGLE、真实 minimal/M4 APK 与 API 19 Bionic 环境全量 CTest
  295/295 通过。

非目标：本 WU 不新增 GLES handler，不改变能力状态或综合样例出口结论。
