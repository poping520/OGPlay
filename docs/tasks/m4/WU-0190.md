# WU-0190 · 综合样例完整 GLES2 调用面

目标：一次性实现 `samples/m4_exit` 源码使用的全部 GLES2 函数并让真实 APK 健康出帧。

依赖：WU-0186、WU-0187、WU-0188、WU-0189。

验收：

- [x] 从样例源码提取 42 个唯一 `gl*` 调用并与 handler 集合机器运行对照。
- [x] 补齐 `glGetIntegerv`、`glGetString`、`glGetError`，值与字符串来自真实 ANGLE。
- [x] 查询字符串复制到有界只读 guest 页，不返回宿主指针或伪造文本。
- [x] 补齐 `glEnable/glDisable/glScissor/glBlendFunc`，scissor 保持超采样缩放。
- [x] `glDrawElements` 只接受受检 EBO offset，并累计真实 draw 与默认 FBO 指标。
- [x] `glReadPixels` 按 pack state/IDL 预检输出长度，ANGLE 成功后显式回写 guest。
- [x] 真实综合 APK 执行全部 42 项调用，输出绿色健康标记且完整 Stop。
- [x] Windows/MSVC + ANGLE、真实 minimal/M4 APK 与 API 19 Bionic 环境全量 CTest
  295/295 通过。

非目标：本 WU 不承诺绑定其余 100 个样例未使用的 GLES2 core 槽，也不执行 M4 三平台出口。
