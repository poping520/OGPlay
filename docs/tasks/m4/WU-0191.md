# WU-0191 · 综合样例确定性输入回归

目标：让 M4 综合出口 APK 的键盘换色与指针标记移动成为机器可判定的真实渲染回归。

依赖：WU-0190、`samples/m4_exit` 综合样例。

验收：

- [x] 首帧同时校验健康标记与初始调色板的稳定 RGBA8 关键像素。
- [x] 注入按键后等待更高帧序号，并校验调色板像素从红色切换为橙色。
- [x] 注入逻辑坐标指针按下后等待更高帧序号，并校验目标位置出现白色标记。
- [x] 三帧内容各不相同，累计至少 21 次 draw、6 次 clear，且 shader/program 指标不重复初始化。
- [x] Windows/MSVC + ANGLE、真实 minimal/M4 APK 与 API 19 Bionic 环境全量 CTest
  295/295 通过。

非目标：本 WU 不修改综合样例或运行时逻辑，不执行 M4 三平台出口；macOS/Linux 验证留在
对应平台机器本地执行，不从 Windows 主机通过 SSH 代跑。
