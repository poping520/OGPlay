# WU-0193 · M4 严格出口环境

目标：让 M4 出口测试在 fixture 或 ANGLE 缺失时明确失败，禁止以条件跳过伪造验收通过。

依赖：WU-0192、WU-0183。

验收：

- [x] `OGPLAY_REQUIRE_M4_EXIT=1` 时，最小 APK 缺少 Bionic 或 APK 路径会失败。
- [x] `OGPLAY_REQUIRE_M4_EXIT=1` 时，综合 APK 缺少 Bionic 或 APK 路径会失败。
- [x] 严格模式下原生 ANGLE EGL 不可用会让硬件和 SwiftShader 黄金帧明确失败。
- [x] 普通开发模式继续允许未配置大型本地 fixture 的构建执行其余测试。
- [x] CTest 独立清空继承环境并机器验证两个真实 APK 测试不能静默通过。
- [x] Windows/MSVC + ANGLE、真实 minimal/M4 APK 与 API 19 Bionic 环境全量 CTest
  296/296 通过。

非目标：本 WU 不执行三平台出口，也不把本地 fixture 或设备信息写入仓库。
