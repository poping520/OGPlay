# WU-0194 · M4 三平台本机出口入口

目标：提供不依赖 SSH、可在 Windows/Linux/macOS 对应机器直接增量执行的严格 M4 出口命令。

依赖：WU-0193、WU-0183。

验收：

- [x] 预检 API 19 `libc.so`、`libm.so`、`libdl.so` 存在且非空。
- [x] 预检最小 APK 与综合 APK 含预期、非空、未压缩的 armeabi-v7a native 库。
- [x] 预检宿主 ANGLE 平台/CPU/configuration 与共享头 commit 一致。
- [x] Linux/macOS 强制清单启用 SwiftShader；Windows 接受已声明的禁用状态。
- [x] Windows 只使用 `windows-msvc`，Linux/macOS 使用持久 `dev` build 目录增量验证。
- [x] 出口 CTest 注入严格模式和三个 fixture 路径，任一真实前置条件缺失即失败。
- [x] 输入回归跳过更高序号但内容相同的启动帧，按内容变化等待事件生效；连续 5 次通过。
- [x] 工具自测覆盖三平台映射、命令、清单、Bionic 与 APK 预检。
- [x] Windows/MSVC + ANGLE、真实 minimal/M4 APK 与 API 19 Bionic 环境全量 CTest
  297/297 通过。

非目标：本 WU 不执行 Linux/macOS 出口测试，不记录机器、账号、地址、凭据或本地绝对路径。
