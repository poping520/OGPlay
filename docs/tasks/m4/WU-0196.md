# WU-0196 · M4 macOS/arm64 出口测试

目标：在 macOS/arm64 本机执行严格 M4 出口并闭合首次暴露的跨平台问题。

依赖：WU-0195、macOS/arm64 ANGLE SDK、API 19/22/23 Bionic 与两个 ARMv7 出口 APK。

验收：

- [x] `tools/m4_exit.py --self-test` 与 macOS/arm64 严格资源预检通过。
- [x] 出口预检覆盖全量 CTest 会读取的 API 19/22/23 Bionic，不把缺失版本推迟到测试中失败。
- [x] ANGLE backend 选择改用 `eglGetPlatformDisplayEXT` 与 `EGLint` 属性表，并以空 `void*`
  表达默认 native display；避免 macOS 整数型 `EGLNativeDisplayType` 的编译错误及平台包
  EGL 1.5 core 入口返回空 display。
- [x] `cmake --preset dev` 与 `cmake --build --preset dev` 在 ANGLE 开启及 warnings-as-errors
  条件下通过。
- [x] Metal/hardware 与 Vulkan/SwiftShader 黄金帧均通过。
- [x] 两个真实 NativeActivity APK 的渲染、输入和完整销毁通过。
- [x] macOS/arm64 严格全量 CTest 297/297 通过。

稳定性复验：Metal、SwiftShader、Android boundary 和两个真实 APK 的 10 项关键
测试各连续执行 5 次，全部通过。

非目标：本 WU 不执行 Linux 出口，不扩展 GLES2 handler，也不引入完整 Android 系统能力。
