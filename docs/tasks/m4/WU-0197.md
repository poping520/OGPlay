# WU-0197 · M4 原生测试后端统一

目标：让全部直接创建原生 ANGLE pbuffer 的测试按宿主选择 M4 硬件后端。

依赖：WU-0192、WU-0196。

验收：

- [x] ANGLE frame 直接测试在 Windows 使用 D3D11、Linux 使用 Vulkan、macOS 使用 Metal。
- [x] Android boundary 的 frame、shader、resource 与 supersample 测试使用同一平台映射。
- [x] NativeActivity APK 的后端断言使用同一平台映射。
- [x] macOS/arm64 上上述测试在 warnings-as-errors 构建后全部通过。
- [x] Windows/Linux 既有后端映射不变，不允许硬件测试回退 SwiftShader。

非目标：本 WU 不改变生产运行时后端策略，不扩展 GLES2 handler，也不执行 Linux 出口。
