出口中闭合的跨平台问题：

- GCC `-Wmissing-field-initializers`：为 `PreparedGles*` 补齐类内初始化。
- GCC `-Wrange-loop-construct`：EGL 失败表改为 `const auto&` 结构化绑定。
- SwiftShader：ANGLE 原生 `DEVICE_TYPE_SWIFTSHADER` 绕过 Vulkan loader 丢失 WSI；
  Linux SDK 随包交付 loader，OGPlay 从可执行文件同目录定位 ICD，在
  `eglGetPlatformDisplayEXT`→`eglInitialize` 临界区同时作用域覆盖新旧 Vulkan driver
  变量并恢复调用方环境，以 hardware device 属性进入 loader；实际 renderer 必须仍为
  SwiftShader，随后 hardware 会话不得受污染。Vulkan pbuffer 使用 headless display mode。
- 审查补强：移除源码树绝对 ICD 路径；非法非 Vulkan/SwiftShader 组合在任何原生调用前
  失败；Linux 出口预检要求清单 SDK 包含非空 `lib/libvulkan.so.1`。

非目标：本 WU 不扩展 GLES2 handler，也不引入完整 Android 系统能力。
