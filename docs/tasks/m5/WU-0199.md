# WU-0199 · Title Profile v1 schema

目标：冻结 M5 Title Profile v1 的纯数据边界，并提供可在 CTest 中执行的严格校验入口。

依赖：M4 出口验收、`src/session/MODULE.md`、`docs/roadmap/05-title-profiles.md`。

验收：

- [x] schema 覆盖 identity、runtime、data、audio、java、quirks 与 input 七类声明式数据。
- [x] identity 强制 package、versionCode、`.so` SHA-256 与 ABI，文件名必须与 package 一致。
- [x] runtime 只接受 API 19/22/23 与三种通用生命周期模板。
- [x] 未知字段、脚本/代码、非法 guest 路径、重复指纹和超过 200 行的 profile 明确失败。
- [x] 校验器只使用 Python 标准库，并有正反例自测试与仓库 profile 目录 CTest。
- [x] 不提交具体游戏 profile，不在 `src/` 引入游戏名、厂商名、包名或游戏专属分支。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 304/304 通过。

非目标：本 WU 不实现 C++ 运行时加载、指纹识别、quirk 注册表或具体游戏迁移。
