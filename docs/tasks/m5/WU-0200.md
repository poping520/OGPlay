# WU-0200 · C++ Title Profile 基础加载器

目标：把 Title Profile v1 的 identity/runtime TOML 转换为 `session` 强类型只读模型。

依赖：WU-0199、`src/session/MODULE.md`。

验收：

- [x] C++ API 同时支持 UTF-8 文本与 `<package>.profile.toml` 文件加载。
- [x] 受限 TOML 解析器覆盖表、数组表、数组、inline table、字符串、数值和布尔纯数据。
- [x] identity 强制文件名/package、versionCode、SHA-256 和 armeabi-v7a 一致性。
- [x] runtime 只接受 API 19/22/23、三种生命周期和 1..16384 逻辑表面。
- [x] 重复 key、未知字段、非法 UTF-8、超过 200 行和不支持的 TOML 明确失败。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 311/311 通过。

非目标：本 WU 不装配生命周期，不匹配目录，也不提交具体游戏 profile。
