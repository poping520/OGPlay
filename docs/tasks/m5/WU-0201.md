# WU-0201 · Profile data/audio 声明式加载

目标：把 VFS 数据需求与封面音乐资源作为纯数据加载到 Title Profile 模型。

依赖：WU-0200、`src/runtime/vfs/MODULE.md`、`src/audio/MODULE.md`。

验收：

- [x] data 支持 APK/OBB/external 挂载、工作目录和 required 资源清单。
- [x] audio 支持来源、相对资源路径、循环事实，不包含资源编号逻辑。
- [x] guest 路径必须为规范绝对路径，资源路径必须为无逃逸的规范相对路径。
- [x] 未声明字段、非法来源、路径逃逸和错误类型明确失败。
- [x] profile 模型不反向依赖 VFS 或 audio 实现。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 311/311 通过。

非目标：本 WU 不实际挂载 VFS、不播放音频，也不实现导入向导。
