# WU-0202 · Profile Java/quirk/input 扩展加载

目标：加载声明式 Java 绑定、quirk 参数和输入模板，不允许嵌入可执行逻辑。

依赖：WU-0201、`src/runtime/framework/MODULE.md`、`src/input/MODULE.md`。

验收：

- [x] Java 类使用 slash 名称，方法以唯一 name/signature 和 namespaced impl id 表示。
- [x] quirk id 唯一，启用项与参数表一一对应，参数只保留有界递归纯数据。
- [x] input 只引用通用模板 id，不含游戏专属坐标或按键逻辑。
- [x] 重复 Java 绑定、禁用 quirk 参数、缺失参数表和非法 id 明确失败。
- [x] `ProfileValue` 不包含函数、脚本或宿主对象。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 311/311 通过。

非目标：本 WU 不注册或执行 quirk，不解析 JNI 方法语义，也不实现输入映射引擎。
