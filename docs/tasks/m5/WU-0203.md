# WU-0203 · Title Profile 三重指纹目录

目标：按 package + versionCode + `.so` SHA-256 从目录中进行零猜测精确匹配。

依赖：WU-0202、Title Profile identity 契约。

验收：

- [x] 目录只加载 `*.profile.toml`，按路径稳定排序并忽略非 profile 文件。
- [x] 三项身份全部命中才返回 profile；任何一项不匹配均返回无匹配。
- [x] 缺失、零值或非法 SHA-256 的查询明确失败，不降级猜测。
- [x] 构造目录时拒绝非法 identity、重复值和交叠三重指纹。
- [x] 无匹配保留通用 profile/引擎指纹后续路径，不伪造成功。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 311/311 通过。

非目标：本 WU 不实现引擎指纹推断、quirk 注册表或具体游戏 profile。
