# WU-0204 · Quirk 注册表与测试引用门禁

目标：让未注册、无理由或无可定位“关闭即失败”测试的 quirk 在 CTest 中明确失败。

依赖：WU-0203、`data/quirks.toml`、`docs/roadmap/05-title-profiles.md`。

验收：

- [x] 每项 quirk 强制包含 summary、reason、risk、test、owner，未知字段失败。
- [x] id 与 owner 使用稳定模块命名，test 只允许规范 `tests/*.cpp:<case-name>` 引用。
- [x] test 文件必须存在且包含登记的 case name，缺失或路径逃逸失败。
- [x] 所有 profile 的 enabled quirk 必须已注册，未注册引用失败。
- [x] 校验器只使用 Python 标准库，并有完整正反例自测试与仓库目录 CTest。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 318/318 通过。

非目标：本 WU 不执行 quirk，不添加真实游戏 quirk，也不宣称仅凭字符串引用即可证明测试
语义；测试仍须实际覆盖启用/关闭两条路径。
