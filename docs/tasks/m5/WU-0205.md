# WU-0205 · C++ QuirkRegistry 与 Profile 强制联动

目标：运行时加载 UTF-8 quirk 注册表，并禁止含未验证 quirk 的 Profile 进入匹配目录。

依赖：WU-0204、WU-0203、`src/session/MODULE.md`。

验收：

- [x] `QuirkRegistry::Load` 强类型加载 schema、五个必需字段和多行 reason。
- [x] C++ 同样检查测试路径、case name、owner、未知字段与 UTF-8，错误精确可见。
- [x] `Validate` 拒绝 Profile 中未注册的 enabled quirk。
- [x] 含 quirk 的 `TitleProfileCatalog` 必须显式注入注册表；无注册表时失败。
- [x] 无 quirk 的目录保持原有通用路径，空仓库注册表可以正常加载。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 318/318 通过。

非目标：本 WU 不执行 quirk、不添加真实游戏 quirk，也不替代 quirk 行为本身的启用/关闭
回归测试。
