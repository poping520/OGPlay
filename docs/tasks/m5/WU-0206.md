# WU-0206 · 通用生命周期模板与单一帧序列

目标：让三种 Profile 生命周期通过显式回调接口共用唯一的受检帧步骤实现。

依赖：WU-0200、`src/session/MODULE.md`、`src/runtime/framework/MODULE.md`、
`src/runtime/integration/MODULE.md`。

验收：

- [x] native_activity、gl_surface_view、custom_jni 均有稳定、强类型的回调路由描述。
- [x] 三种模板共用输入→生命周期→渲染→present→音频→调度→Clock 计时的单一实现。
- [x] startup、frame、shutdown 只能按状态机顺序执行，重复或跳步明确失败。
- [x] 任一帧回调失败即锁定失败状态且不提交帧号；计时只在前六阶段成功后执行，并仍
  允许显式清理。
- [x] session 只依赖回调接口，不反向依赖 runtime、VFS、Java、audio 或 input 实现。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest 321/321 通过。

非目标：本 WU 不把回调路由接到具体 runner，不增加游戏 profile、方法名或专属帧分支。
