# WU-0207 · Profile VFS 声明装配

目标：把 Profile data 声明与已导入文件精确配对并装配为可直接使用的通用 VFS。

依赖：WU-0201、WU-0203、`src/session/MODULE.md`、`src/runtime/vfs/MODULE.md`。

验收：

- [x] 输入以 guest 根 + source 精确匹配声明，不按顺序或单一来源猜测。
- [x] required mount 缺失、额外/重复输入、source 错配和空输入明确失败。
- [x] APK/OBB/external 继续使用现有 VFS 的来源与可写性事实，不复制文件系统语义。
- [x] required manifest 缺失和未被实际挂载覆盖的 working directory 明确失败。
- [x] 只在全部验证和挂载成功后返回全新 VFS，失败不向调用方发布半成品。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest 324/324 通过。

非目标：本 WU 不读取宿主目录、不实现导入 UI，也不装配 Java、input、audio 或具体游戏
profile。
