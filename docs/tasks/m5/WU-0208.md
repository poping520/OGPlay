# WU-0208 · Profile Java 声明装配

目标：把 Profile Java 类/方法与通用 implementation handler 装配为可调用的 JNI 环境。

依赖：WU-0202、WU-0203、`src/session/MODULE.md`、`src/runtime/jni/MODULE.md`。

验收：

- [x] Profile 类和实例方法进入现有 JniClassRegistry，name/signature/impl 保持精确。
- [x] 只把 Profile 实际引用的通用 handler 注册到 JniInvocationEngine。
- [x] 缺失、重复或空 handler 明确失败，未引用的通用 handler 不影响装配。
- [x] 非法类、重复类和严格 JNI 描述符错误由现有 JNI 契约拒绝。
- [x] 只在所有类与 handler 成功后返回全新 registry/engine，失败不发布半成品。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest
  330/330 通过。

非目标：本 WU 不执行 DEX、不添加静态方法/继承 schema，不实现游戏专属 handler 或具体
profile。
