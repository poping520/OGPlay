# WU-0209 · Profile input 模板选择

目标：让 Profile input id 精确选择 code-defined 通用 mapper，并为无声明路径提供显式默认。

依赖：WU-0202、WU-0203、`src/session/MODULE.md`、`src/input/MODULE.md`、HAL 输入事件契约。

验收：

- [x] InputTemplateCatalog 只接受规范唯一 id、非空 mapper 和已注册默认模板。
- [x] Profile 有 input 声明时精确选择同名模板，未知 id 明确失败且不模糊匹配。
- [x] 无 input 声明时使用 catalog 显式默认项，不读取宿主配置或静默猜测。
- [x] mapper 是代码中已注册的通用实现，Profile 仍只包含纯数据 id。
- [x] 事件顺序由 mapper 明确控制，direct 与过滤模板均有机器正例。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest
  330/330 通过。

非目标：本 WU 不冻结 M6 完整映射 schema，不实现触摸/传感器合成、坐标曲线、录制回放或
具体游戏模板。
