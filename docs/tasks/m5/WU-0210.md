# WU-0210 · Profile audio 资源装配

目标：把 Profile 封面音乐声明精确解析为通用播放器请求，不引入资源名硬编码或音频后端。

依赖：WU-0201、WU-0203、`src/session/MODULE.md`、`src/audio/MODULE.md`。

验收：

- [x] Profile cover music 以 source + path 精确选择已导入的编码资源并保留 loop 事实。
- [x] 无 audio/cover_music 声明时不调用播放器，并返回明确的未启动结果。
- [x] 缺失、重复或空资源明确失败；相同路径但错误 source 不得匹配。
- [x] 播放器错误向调用方传播，不伪造开始播放或吞掉失败。
- [x] 通用 audio 接口不依赖 session/Profile，生产代码不含游戏或厂商特判。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest
  334/334 通过。

非目标：本 WU 不实现 OGG/MP3 解码、混音、设备后端、音频时钟、淡入淡出或具体游戏
profile。
