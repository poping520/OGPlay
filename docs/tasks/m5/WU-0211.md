# WU-0211 · 单一 Profile session plan

目标：把 lifecycle、VFS、Java、input、audio 五条通用装配汇总为一个可执行的只读计划。

依赖：WU-0206、WU-0207、WU-0208、WU-0209、WU-0210、`src/session/MODULE.md`。

验收：

- [x] plan 拥有 Profile、生命周期描述、全新 VFS/JNI 环境、输入目录和预解析音频资源。
- [x] input 在装配时选定精确模板，运行时只通过 plan 的同一 mapper 入口转换事件。
- [x] cover music 在装配时完成资源校验，运行时向播放器提交 plan 自有字节和 loop 事实。
- [x] VFS、Java、input、audio 或生命周期任一装配失败时不返回部分 plan。
- [x] plan 可移动但不可复制，运行期 VFS/JNI 状态由唯一 plan 所有。
- [x] 生产代码不含游戏/厂商特判，不新增完整 Android 系统或 M6 音频/输入实现。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest
  337/337 通过。

非目标：本 WU 不启动 guest、不实现导入 UI、音频解码/设备输出、完整输入 schema、具体
游戏 profile 或 quirk 执行器。
