# WU-0212 · Profile session bootstrap

目标：用单一入口完成三重身份选择与 ProfileSessionPlan 装配，并保留显式通用默认路径。

依赖：WU-0203、WU-0211、`src/session/MODULE.md`。

验收：

- [x] package + versionCode + `.so` SHA-256 全部命中时只装配命中的 Profile。
- [x] 无匹配时只装配调用方显式提供的 generic default，不猜测相近 Profile。
- [x] exact/default 选择事实进入强类型结果，两条路径共用 AssembleProfileSessionPlan。
- [x] 非法身份查询明确失败，不得进入默认路径。
- [x] 已命中 Profile 或 generic default 装配失败时原样暴露，不静默切换路径。
- [x] 不读取导出符号、文件探针、宿主环境或游戏专属配置。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest
  341/341 通过。

非目标：本 WU 不加载 APK 身份、不实现引擎指纹推断、导入流程、guest 启动或具体游戏
profile。
