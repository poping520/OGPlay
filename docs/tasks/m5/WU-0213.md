# WU-0213 · Profile runtime catalog

目标：把通用 Java handler 与 input mapper 目录收敛为有所有权的不可变运行时目录。

依赖：WU-0208、WU-0209、`src/session/MODULE.md`、`src/input/MODULE.md`。

验收：

- [x] catalog 拥有 Java handler 和 InputTemplateCatalog，不保留调用方容器引用。
- [x] Java implementation id 必须是规范 namespaced id，handler 必须非空且 id 唯一。
- [x] 可按精确 id 查询 Java handler，未知 id 不做模糊匹配。
- [x] Java handler 保留稳定注册顺序，input catalog 保留显式默认模板。
- [x] catalog 构造后无可变注册入口，不包含 Profile 或游戏专属数据。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest
  343/343 通过。

非目标：本 WU 不提供具体游戏 handler/mapper，不修改 session bootstrap 或执行 JNI 调用。
