# WU-0214 · Runtime catalog 装配接入

目标：让 ProfileSessionPlan 与 bootstrap 直接消费单一 ProfileRuntimeCatalog。

依赖：WU-0211、WU-0212、WU-0213、`src/session/MODULE.md`。

验收：

- [x] plan 新入口从同一 runtime catalog 获取 Java handlers 与 input templates。
- [x] bootstrap 新入口把同一 runtime catalog 原样传入 exact/default plan 装配。
- [x] exact/default 选择、子装配失败和禁止静默回退语义不变。
- [x] catalog 生命周期无需覆盖返回 plan；plan 继续拥有运行所需 input mapper 副本。
- [x] 原有底层 span API 保留为明确的组合原语，不复制 Java/input 装配逻辑。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest
  343/343 通过。

非目标：本 WU 不增加具体 handler/mapper，不引入全局单例或 service locator。
