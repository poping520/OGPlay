# WU-0215 · Profile imported assets bundle

目标：把已导入的 VFS mount 与 audio 资源收敛为有所有权、构造即验证的资产 bundle。

依赖：WU-0207、WU-0210、`src/session/MODULE.md`、`src/runtime/vfs/MODULE.md`。

验收：

- [x] bundle 拥有 VFS/audio 容器及字节，不保留导入器临时容器引用。
- [x] VFS guest 根必须规范绝对且按 VFS 大小写规则唯一，每个 mount 必须有文件。
- [x] mount entry 必须是规范相对路径，同一 mount 内按 VFS 规则不得重复。
- [x] audio source + path 唯一、路径规范且编码内容非空。
- [x] 空 bundle 合法，构造后只暴露只读 span，不提供追加或修改入口。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest
  346/346 通过。

非目标：本 WU 不读取宿主文件、不解包 APK/OBB、不匹配 Profile 或执行挂载/播放。
