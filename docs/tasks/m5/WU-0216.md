# WU-0216 · Asset bundle 装配接入

目标：让 plan/bootstrap 高层入口同时消费 ProfileRuntimeCatalog 与 ProfileAssetBundle。

依赖：WU-0214、WU-0215、`src/session/MODULE.md`。

验收：

- [x] plan 高层入口从一个 asset bundle 获取 VFS mounts 与 audio resources。
- [x] bootstrap 高层入口只接收 identity、generic default、asset bundle 与 runtime catalog。
- [x] 返回 plan 不依赖 bundle/catalog 生命周期，继续唯一拥有 VFS/JNI/input/audio 状态。
- [x] exact/default、子装配失败与禁止静默回退语义在最高层入口保持不变。
- [x] 底层 span 重载保留为组合原语，高层入口不复制装配或匹配逻辑。
- [x] `cmake --preset dev`、macOS/arm64 warnings-as-errors 构建及全量 CTest 346/346
  通过。

非目标：本 WU 不读取宿主资产、不加载 APK 身份、不启动 guest 或添加具体游戏 profile。
