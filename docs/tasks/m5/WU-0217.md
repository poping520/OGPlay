# WU-0217 · APK Deflate 条目读取

目标：从不可信 APK 中严格读取 stored 与 Deflate 条目，为旧版 APK 身份和资产导入解除压缩前置阻塞。

依赖：WU-0216、`src/loader/MODULE.md`、ADR-0007。

验收：

- [x] `ReadApkEntry` 保留 stored 语义并支持 ZIP method 8 原始 Deflate。
- [x] stored、fixed Huffman 与 dynamic Huffman block 均可读取，重叠回溯按 Deflate 语义执行。
- [x] 截断、保留 block、非法 Huffman、越界回溯、长度和 CRC 不一致明确失败。
- [x] local/central 的 flags、method、尺寸、CRC 与名称继续严格一致，bit 3 data descriptor
  只接受与 central metadata 精确相同的 ZIP32 值。
- [x] 不使用系统压缩库或配置期下载，保持固定 submodule 的离线构建边界。
- [x] `cmake --preset dev`、macOS/arm64 warnings-as-errors 构建及全量 CTest 348/348 通过；
  目标 APK 的真实 Deflate + data descriptor native ELF 解压为 1,919,371 字节并通过 CRC。

非目标：本 WU 不解析二进制 Manifest、不选择 native 库、不导入 Profile 或执行 guest。
