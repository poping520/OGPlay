# WU-0218 · APK 二进制 Manifest 身份读取

目标：从 APK 的二进制 `AndroidManifest.xml` 严格产出 Profile 精确匹配所需身份与 SDK 事实。

依赖：WU-0217、`src/loader/MODULE.md`、`docs/roadmap/04-android-runtime.md`。

验收：

- [x] binary XML 根 chunk、string pool、start/end element 与 typed attribute 全部受检。
- [x] UTF-8 与 UTF-16 string pool 均转换为规范 UTF-8，长度、终止符和 surrogate 受检。
- [x] package、正 versionCode 必需；versionName、minSdk、targetSdk 保留为可选事实。
- [x] 非法 package、错误属性类型、重复事实、索引越界和元素错配明确失败。
- [x] `ReadAndroidManifest` 通过 WU-0217 统一条目入口读取 stored/Deflate Manifest。
- [x] 目标 APK 读出 package `com.gameloft.android.GAND.GloftAsphalt5.asphalt5`、versionCode
  1、versionName 1.1.3、minSdk 5 且无 targetSdk，与独立 JADX 结果一致。
- [x] `cmake --preset dev`、macOS/arm64 warnings-as-errors 构建及全量 CTest 351/351 通过。

非目标：本 WU 不解析 resource table、Activity/NativeActivity 入口、不选择 native 库或匹配 Profile。
