# WU-0219 · APK ARM native library 身份目录

目标：稳定枚举 APK 中所有支持的 32 位 ARM `.so`，拥有解压字节并产出 Profile 匹配所需 SHA-256。

依赖：WU-0217、WU-0218、`src/loader/MODULE.md`。

验收：

- [x] 只接受 `lib/armeabi/*.so` 与 `lib/armeabi-v7a/*.so` 的单层规范路径。
- [x] 每项保留完整 entry、basename、强类型 ABI、自有原始字节和小写 SHA-256。
- [x] 目录按完整 entry path 稳定排序，不按 ABI、大小、符号或文件名猜 main library。
- [x] 非 ARM、嵌套或非 `.so` 条目忽略，空 native library 明确失败。
- [x] SHA-256 由固定内建实现产生并以标准 `abc`/`hello` 向量验证，不依赖系统库。
- [x] 目标 APK 唯一 ARM library 的 ABI、尺寸和 SHA-256 与独立工具一致。
- [x] `cmake --preset dev`、warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不选择入口、不解析 ELF 依赖、不扩展 Profile ABI schema 或启动 guest。
