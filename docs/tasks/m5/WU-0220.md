# WU-0220 · Title Profile legacy ARM ABI identity

目标：让 Title Profile v1 以同一强类型契约表达旧 `armeabi` 与 `armeabi-v7a` 身份。

依赖：WU-0199、WU-0200、WU-0219、`src/session/MODULE.md`。

验收：

- [x] JSON schema、Python 校验器和 C++ loader 只接受 `armeabi`、`armeabi-v7a`。
- [x] C++ Profile identity 使用强类型 ABI，并可稳定转换为规范字符串。
- [x] 两种 ABI 的正例与非 ARM ABI 反例同时覆盖 Python 与 C++ 路径。
- [x] catalog 对手工构造的非法 ABI 明确失败，不扩大现有三重指纹匹配语义。
- [x] `cmake --preset dev`、warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不从 APK 自动选择 Profile、不选择 main library，也不启动 `armeabi` guest。
