# WU-0221 · APK exact Profile identity match

目标：以 APK Manifest 与全部 ARM native library 事实解析唯一精确 Profile/入口候选。

依赖：WU-0218、WU-0219、WU-0220、`src/session/MODULE.md`。

验收：

- [x] package + versionCode + native SHA-256 + ABI 四项一致才发布候选。
- [x] 未匹配任何 Profile 时返回空，不按 ABI、文件名、大小或顺序猜 main library。
- [x] exact hash 命中但 ABI 自相矛盾时明确失败，不降级 generic default。
- [x] 多个 native library 同时精确命中时以 main library 歧义明确失败。
- [x] 无 ARM library 与空 library 镜像明确失败。
- [x] 目标 APK 可由内存 Profile 精确选中唯一 `armeabi` library。
- [x] `cmake --preset dev`、warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不提交具体游戏 Profile、不装载 ELF，也不启动 guest。
