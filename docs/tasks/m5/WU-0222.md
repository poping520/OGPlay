# WU-0222 · Bionic guest dependency closure

目标：从根 ELF 的动态依赖生成拥有字节和装载地址的通用 Bionic guest module set。

依赖：WU-0221、`src/loader/MODULE.md`、`src/runtime/bionic/MODULE.md`。

验收：

- [x] 从 `DT_NEEDED` 递归选择 profile 声明的真实 guest 系统库，每个库最多加入一次。
- [x] HLE boundary library 不作为 guest ELF 输入，未使用的系统库也不进入闭包。
- [x] 未声明/缺失依赖、重复来源、空镜像、非法 basename 与 SONAME 矛盾明确失败。
- [x] module set 拥有根和依赖字节，并能生成生命周期受限的 `Elf32ModuleInput` 视图。
- [x] load bias 自动页对齐、稳定递增并与固定 HLE thunk 区隔离。
- [x] `cmake --preset dev`、warnings-as-errors 构建及全量 CTest 357/357 通过。

非目标：本 WU 不修改 CLI、不绑定 GLES1 handler，也不启动目标 APK。
