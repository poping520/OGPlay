# WU-0223 · Profile-driven APK launch preflight

目标：让 CLI 从精确 Title Profile 生成拥有根 ELF 与 Bionic 依赖闭包的 APK 启动预检。

依赖：WU-0221、WU-0222、`src/session/MODULE.md`、`src/frontend/MODULE.md`。

验收：

- [x] `PrepareApkProfileLaunch` 串联唯一 APK/Profile 候选与 Profile API 对应的 Bionic 闭包。
- [x] 无精确 Profile 返回空；闭包缺失或非法时不发布部分 launch plan。
- [x] `run-apk` 支持压缩 `armeabi`/`armeabi-v7a` 根库，不再扫描 stored v7a 单库或手写依赖。
- [x] CLI 的 API、逻辑 surface、生命周期和根库全部来自已匹配 Profile。
- [x] `--preflight` 在完整身份与 ELF 闭包受检后输出事实，不创建窗口或执行 guest。
- [x] `cmake --preset dev`、warnings-as-errors 构建及全量 CTest 358/358 通过。

非目标：本 WU 不提交具体标题 Profile，也不实现 `gl_surface_view` guest 执行器。
