# WU-0225 · Declarative native JNI lifecycle calls

目标：让 Title Profile 以强类型纯数据描述通用生命周期各 phase 的 native JNI 调用。

依赖：WU-0224、M3 JNI signature 契约、`src/session/MODULE.md`。

验收：

- [x] schema、Python 与 C++ 同步接受 phase/class/method/signature/dispatch/arguments。
- [x] 参数来源仅限常量、surface 尺寸及 pointer/key 输入事实，不提供脚本或地址字段。
- [x] C++ 按 JNI descriptor 校验参数数量与整数类型；constant value 与 input phase 受检。
- [x] 方法名、类名和顺序只能由 Profile 数据提供，`src/` 不增加标题特判。
- [x] Profile 双校验、warnings-as-errors 构建及全量 CTest 359/359 通过。

非目标：本 WU 不提交具体调用序列、不解析 JNI 导出名、不调用 guest，也不实现 GLES1。
