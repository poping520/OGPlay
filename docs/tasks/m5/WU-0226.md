# WU-0226 · First legacy title native-call profile

目标：用 Title Profile 数据声明首个 legacy APK 的 native 生命周期与输入调用序列。

依赖：WU-0225、目标 APK 的 Java native 声明与既有 demo 实证。

验收：

- [x] startup、resume、frame、pause 与 shutdown 调用按 Java 生命周期顺序声明。
- [x] pointer down/move/up 与 key down/up 仅使用受限输入参数来源。
- [x] 类、方法、signature、dispatch 与常量均只存在于标题 Profile，不进入 `src/`。
- [x] schema/Python/C++ 目录校验、真实 APK preflight 与全量严格测试通过。

非目标：本 WU 不解析 JNI 导出名、不调用 guest，也不实现 GLES1。
