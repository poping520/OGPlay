# WU-0227 · Standard JNI native export names

目标：从受检 Java class、method 与 JNI descriptor 通用生成标准 short/long native 导出名。

依赖：WU-0226、M3 JNI signature 契约。

验收：

- [x] `/`、`_`、`;`、`[` 与其他 Unicode 按 JNI 规范转义。
- [x] long 名只包含参数 descriptor，short 名可供非重载优先解析。
- [x] 非法 internal class/simple method、UTF-8 与 JNI descriptor 明确失败。
- [x] 标题与包名不进入生产代码，warnings-as-errors 构建及全量测试通过。

非目标：本 WU 不查找 ELF、不执行 guest native 方法，也不实现 JNIEnv。
