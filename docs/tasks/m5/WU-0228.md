# WU-0228 · Profile native-call target resolution

目标：在 APK launch planning 阶段把 Profile native 调用解析为 root ELF 中的受检 guest 地址。

依赖：WU-0227、WU-0223、loader ELF symbol 契约。

验收：

- [x] 按 JNI 规范优先 short 导出名，并回退到带参数 descriptor 的 long 名。
- [x] 结果保持 Profile 顺序并拥有 export name、call index 与强类型 guest 地址。
- [x] 缺失、重复与地址溢出明确失败；无 native calls 的既有 Profile 行为不变。
- [x] 真实目标 APK 的全部 17 项声明均能在 root ELF 精确解析。
- [x] warnings-as-errors 构建及全量 CTest 364/364 通过。

非目标：本 WU 不执行 guest、不建立 JNIEnv，也不实现 GLES1。
