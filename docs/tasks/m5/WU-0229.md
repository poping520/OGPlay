# WU-0229 · Complete GLES1.1 core IDL catalog

目标：建立与固定 ANGLE `GLES/gl.h` 完全一致的声明式 GLES1.1 core API 目录。

依赖：M4 GLES2 IDL generator、WU-0222 的 `libGLESv1_CM.so` boundary 分类。

验收：

- [x] 145 个 core 入口唯一、稳定排序，并与固定 ANGLE header 双向核对。
- [x] `GLfixed`/`GLclampx` 进入受限标量类型；57 个指针均有 direction/nullable/count。
- [x] GLES1/GLES2 生成物使用 API-specific namespace，既有 GLES2 thunk ID 不漂移。
- [x] warnings-as-errors 构建及全量 CTest 365/365 通过。

非目标：本 WU 不发布 GLES1 HLE thunks、不绑定 handler，也不创建 GLES1 context。
