# WU-0230 · GLES1 core boundary namespace

目标：让 Android HLE boundary 从隔离目录发布完整 `libGLESv1_CM.so` core thunk 空间。

依赖：WU-0229、M4 Android boundary HLE。

验收：

- [x] 145 个 GLES1 core 符号均有独立 Thumb trap，既有 GLES2 地址不漂移。
- [x] boundary dispatch 保留 provider library 身份，同名 GLES1/GLES2 调用不混淆。
- [x] GLES1 调用按完整参数形状读取寄存器/stack；未绑定调用记账后明确失败。
- [x] warnings-as-errors 构建及全量 CTest 366/366 通过。

非目标：本 WU 不绑定 GLES1 fixed-pipeline handler、不发布 OES 扩展，也不创建 GLES1 context。
