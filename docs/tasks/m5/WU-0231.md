# WU-0231 · GLES1 extension subset catalog

目标：为目标 ELF 所需的标准 GLES1 extension 入口建立受 header 约束的隔离目录。

依赖：WU-0230、固定 ANGLE `GLES/glext.h`。

验收：

- [x] generator 的 subset 模式只接受固定 header 中真实声明的函数，不要求收录无关扩展。
- [x] `GL_OES_matrix_palette` 的 3 个目标导入稳定排序，两个指针带显式 client-array 元数据。
- [x] core 与 extension thunk ID 空间隔离，扩展目录不改变既有 145 个 core ID。
- [x] warnings-as-errors 构建及全量 CTest 367/367 通过。

非目标：本 WU 不向 Android boundary 发布扩展 thunk，也不绑定 matrix-palette handler。
