# WU-0232 · Required GLES1 extension boundary

目标：在不改变 GLES1 core thunk 地址的前提下发布目标所需标准 extension boundary。

依赖：WU-0231、WU-0230。

验收：

- [x] 3 个 `GL_OES_matrix_palette` 入口追加发布于 `libGLESv1_CM.so`。
- [x] core 与 extension dispatch 独立记账，未知函数和未绑定调用明确失败。
- [x] 目标 ELF 的 62 个 GL imports 全部由 GLES1/GLES2 生成目录覆盖。
- [x] warnings-as-errors 构建及全量 CTest 368/368 通过。

非目标：本 WU 不执行 extension handler、不创建 GLES1 context，也不实现 profile runner。
