# WU-0233 · Android guest link preflight

目标：让 APK preflight 用生产 Bionic/Android boundary 完成真实模块映射与重定位而不执行 guest。

依赖：WU-0232、WU-0228、M4 module loader。

验收：

- [x] preflight 与正式 runner 使用同一 `BuildBionicLinkNamespace` 与 boundary symbols。
- [x] 只映射/重定位，不执行 initializer 或 guest entry；失败不发布部分报告。
- [x] 真实目标链接为 5 guest + 2 boundary、6503 relocations、17 native calls。
- [x] warnings-as-errors 构建及全量 CTest 369/369 通过。

非目标：本 WU 不实现 `gl_surface_view` runner、JNIEnv 或 GLES1 handler。
