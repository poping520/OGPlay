# WU-0234 · Guest JNIEnv/JavaVM ABI mapping

目标：把现有 JNI/JavaVM 目录物化为通用 guest process 可直接消费的 32 位 Android ABI。

依赖：WU-0233、M3 JNI/JavaVM 目录、`src/runtime/integration/MODULE.md`。

验收：

- [x] JNIEnv 233 槽、JavaVM 8 槽及各自 guest 对象按 32 位小端布局映射。
- [x] reserved 槽保持 null；其余槽均指向带 Thumb 位的独立 SVC trap。
- [x] 函数表与对象页只读、trap 页 RX，冲突构造完整回滚，析构清理全部映射。
- [x] 已有行为目录使用相同可调用 Thumb 地址，未实现槽仍可按精确 slot 识别。
- [x] MSVC 18.8 新增收窄诊断与 doctest `<ostream>` 依赖已做类型/包含级基线修正。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 372/372 通过。

非目标：本 WU 不实现 `gl_surface_view` runner、JNI slot 分派或 GLES1 fixed-pipeline
handler。
