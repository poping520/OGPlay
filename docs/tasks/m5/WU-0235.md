# WU-0235 · Profile native A32 JNI invocation frames

目标：把已解析的 Profile native calls 装配为 guest invoker 可直接执行的 A32 JNI 调用帧。

依赖：WU-0234、WU-0228、`src/session/MODULE.md`。

验收：

- [x] 按 phase 保持 Profile 顺序，并精确组合 call 与同序已解析 target。
- [x] r0 为 guest JNIEnv，r1 按 instance/static 选择实例或 jclass reference。
- [x] Profile 显式参数依次进入 r2/r3 和栈；栈 word 补齐到 8 字节对齐。
- [x] constant、surface width/height 与 pointer/key input 均来自强类型运行期事实。
- [x] target、class reference、input、receiver、surface 或签名不完整时不发布部分帧。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 375/375 通过。

非目标：本 WU 不执行 guest 指令、不处理 JNI SVC trap，也不绑定 GLES1 handler。
