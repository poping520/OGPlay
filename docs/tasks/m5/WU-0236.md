# WU-0236 · Generic A32 guest call executor

目标：让通用执行层按 AAPCS 执行已装配的 A32 guest 调用帧并明确处理返回与 trap。

依赖：WU-0235、M2 guest thread runner、`src/runtime/execution/MODULE.md`。

验收：

- [x] 目标地址决定 A32/Thumb 状态，r0-r3 与额外栈 word 按调用帧装入。
- [x] 栈顶及栈参数保持 8 字节对齐，坏地址、空目标和不完整线程状态明确失败。
- [x] Linux SVC 与显式 HLE handler 复用统一分派，处理后同步当前线程 TPIDRURO。
- [x] 只以受检返回地址的 `SVC #1` 结束；未处理 trap、提前退出及预算耗尽明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 379/379 通过。

非目标：本 WU 不实现 JNI SVC slot 分派、`gl_surface_view` 生命周期或 GLES1 handler。
