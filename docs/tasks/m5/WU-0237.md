# WU-0237 · Guest JNI SVC trap dispatcher

目标：把 Guest JNI ABI 的 `SVC #3` 精确解码为可绑定、可记账的通用宿主调用边界。

依赖：WU-0236、WU-0234、M3 JNI slot 目录、`src/runtime/integration/MODULE.md`。

验收：

- [x] 只消费 trap PC 精确命中的 JNIEnv/JavaVM `SVC #3`，未知地址留为未处理。
- [x] 校验非零线程及 r0 的 interface receiver，发布 r0-r3、SP、LR 与强类型 slot。
- [x] 环境和 JavaVM slot 独立显式绑定并在执行前封口；重复、reserved、空 handler
  及封口后修改明确失败。
- [x] 支持 void、32 位和 64 位返回写回；handler 异常不被吞掉。
- [x] 未绑定 slot 按稳定 capability id 与 caller LR 记账并明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 382/382 通过。

非目标：本 WU 不绑定具体 JNI 行为、不运行 `gl_surface_view` 生命周期或 GLES1 handler。
