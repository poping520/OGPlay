# WU-0238 · Guest JNI core behavior bindings

目标：把 Guest JNI trap 首批绑定到已有真实 M3 引用、异常与 JavaVM 行为。

依赖：WU-0237、M3 `JniEnvironment`/`JniJavaVm`、`src/runtime/integration/MODULE.md`。

验收：

- [x] 16 个 JNIEnv 基础 slot 精确绑定已有引用、异常、local frame 与 VM 导出语义。
- [x] Attach/Detach/GetEnv/AttachDaemon 四个 JavaVM slot 复用同一 M3 线程状态。
- [x] VM 输出在状态变更前预检 guest 指针，并把宿主内部 env handle 转为统一 guest
  JNIEnv；坏指针不留下部分 attach 状态。
- [x] slot handler 不伪造成功；引用、pending exception、坏指针与容量失败原样暴露。
- [x] 未实现的非空 attach arguments 明确失败，不静默忽略结构内容。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 385/385 通过。

非目标：本 WU 不绑定 class/method/field/string/array slot，也不实现
`gl_surface_view` runner。
