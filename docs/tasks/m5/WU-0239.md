# WU-0239 · 通用 API 19 guest process 内存

目标：把 API 19 root guest 执行所需的固定进程内存从 NativeActivity 私有实现抽成可复用契约。

依赖：WU-0238、M2 Bionic TLS、`src/runtime/integration/MODULE.md`。

验收：

- [x] 统一映射 root TLS/thread-info/preinit、4 MiB 栈、返回 trap 与空 property area。
- [x] argv/auxv、deterministic random、线程标识、TLS slots 与 libc property 导出完整发布。
- [x] 非法线程/进程名、缺失或不可写导出、固定布局冲突明确失败。
- [x] 任一步失败逆序回滚新增映射，并保留 libc 导出槽原值。
- [x] NativeActivity 复用通用契约且原有生命周期行为不变。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 388/388 通过。

非目标：本 WU 不执行 Profile native calls，不实现 `gl_surface_view` lifecycle runner。
