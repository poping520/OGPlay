# WU-0240 · Profile native invocation 批执行

目标：把已装配的 Profile JNI 调用帧按声明顺序交给通用 A32 executor，并返回逐调用证据。

依赖：WU-0235、WU-0236、`src/session/MODULE.md`。

验收：

- [x] Profile invocation 精确转换为通用 A32 registers/stack frame 并保持调用顺序。
- [x] 每项结果保留 call index、export name、ticks 与 guest 返回值。
- [x] 执行前完整预检批次身份、地址、顺序、栈对齐、进程内存与 tick budget。
- [x] 预检失败不执行批次中的任何 guest 调用。
- [x] 运行期失败携带 call index、export name 与底层精确原因。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 391/391 通过。

非目标：本 WU 不创建 Android guest process，不绑定额外 JNI/GLES handler，也不实现
`gl_surface_view` lifecycle runner。
