# WU-0241 · 通用 Android guest call session

目标：组合真实 Bionic、API 19 process、syscall/thread、guest JNI 与 Android HLE，
提供不理解 Profile phase 的通用 A32 调用会话。

依赖：WU-0239、WU-0240、M2/M3/M4 runtime integration。

验收：

- [x] 受检加载 guest/Bionic namespace，并执行 guest ELF init/fini 生命周期。
- [x] 复用通用 API 19 process memory，root thread 使用真实 syscall/clone/TLS/VFS。
- [x] 完整 guest JNI ABI、首批 core bindings 与 Android GLES HLE trap 在同一执行器分派。
- [x] 调用方只提交通用 A32 frame，并可查询 guest JNIEnv/JavaVM、frame 与 GPU 证据。
- [x] 缺失模块、VFS、surface、预算或非 API 19 请求明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 392/392 通过。

非目标：本 WU 不解释 Profile phase，不创建 SDL 窗口，也不新增 JNI/GLES handler。
