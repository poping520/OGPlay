# WU-0242 · Host-managed GLSurface ANGLE 生命周期

目标：让 Java/GLSurfaceView lifecycle 可显式拥有 ANGLE surface，而不伪造 guest EGL 调用。

依赖：WU-0241、M4 ANGLE boundary、`src/runtime/integration/MODULE.md`。

验收：

- [x] host 可严格 open/present/close 一个逻辑尺寸与超采样布局一致的 ANGLE pbuffer。
- [x] managed present 复用统一 readback/resolve、frame sequence 与 GPU evidence。
- [x] 重复 open、未 open 的 present/close 明确失败。
- [x] guest EGL 不得替换或终止 host-managed surface。
- [x] Android guest call session 只透传该通用 surface 生命周期。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 393/393 通过。

非目标：本 WU 不执行 Profile phase，不新增 GLES1 handler，也不创建 SDL 窗口。
