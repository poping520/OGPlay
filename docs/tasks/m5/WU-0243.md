# WU-0243 · Profile guest 生命周期编排

目标：把 `gl_surface_view` Profile 的 native phases 与 host-managed surface 编排为
可执行、可测试且不含标题事实的通用生命周期。

依赖：WU-0240、WU-0241、WU-0242、`src/session/MODULE.md`。

验收：

- [x] startup/resume、每帧 input/frame/present、pause/shutdown/close 顺序唯一且受检。
- [x] class instance/jclass 使用附着 root JNIEnv 的稳定 global reference。
- [x] phase invocation 可注入通用 frame executor，完整预检与调用身份错误不丢失。
- [x] 非 GLSurface profile、不完整 callback、越界输入与非法状态明确失败。
- [x] 执行或 present 失败后状态粘滞为 failed，但仍可逆序关闭 surface。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 394/394 通过。

非目标：本 WU 不接入 CLI，不新增 Java/JNI/GLES handler，也不写入标题专属分支。
