# WU-0244 · run-apk 接入 Profile GLSurface 生命周期

目标：让 `run-apk` 对 `gl_surface_view` Profile 创建通用 Android guest session，
执行声明式 lifecycle 并呈现 managed ANGLE 帧。

依赖：WU-0241、WU-0242、WU-0243、`src/frontend/MODULE.md`。

验收：

- [x] `run-apk` 对 `native_activity` 保持既有路径，对 `gl_surface_view` 进入通用 Profile
  guest 生命周期；其他模板继续明确失败。
- [x] SDL input 只映射一次，并分别进入 NativeActivity 或 Profile input 队列。
- [x] GLSurface 每步执行声明式 input/frame、managed present 与最新帧显示。
- [x] `--exit-after-frames` 对两条路径保持有界退出。
- [x] 真实目标 APK 不再因 “lifecycle runner is not implemented” 被前端拒绝，并报告首个
  guest 执行阻塞点。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 394/394 通过。

非目标：本 WU 不新增 JNI/GLES handler，不伪造目标已成功渲染。

机器证据：真实 APK 的 1 帧有界命令已进入第二个 startup native call，并明确失败为
`unbound JNI guest slot: GetStaticMethodID`；不再由前端生命周期分支拒绝。
