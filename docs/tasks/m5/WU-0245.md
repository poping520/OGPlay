# WU-0245 · Profile Java static method 契约

目标：让 Profile Java method 显式声明 instance/static kind，并把该事实交给统一 JNI
class registry。

依赖：M3 JNI class/invocation、WU-0199、`src/session/MODULE.md`。

验收：

- [x] Java method 必须以布尔 `static` 显式声明调用种类，缺失或类型错误明确失败。
- [x] C++/Python/schema 三条验证路径保持一致。
- [x] Profile Java assembly 按声明种类注册 method，错误 kind lookup 不得命中。
- [x] 既有 instance method 可显式写 `static = false` 且行为不变。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 394/394 通过。

非目标：本 WU 不绑定 guest JNI slot，不添加目标 Profile Java 方法。
