# WU-0246 · Guest JNI static method lookup

目标：让 guest `GetStaticMethodID` 精确查询统一 JNI class registry，而不伪造 method ID。

依赖：M3 JNI class/reference、WU-0238、WU-0245、`src/runtime/integration/MODULE.md`。

验收：

- [x] class reference 必须解析为真实 object identity。
- [x] method name/descriptor 从受检 guest C string 读取，null、越界与未终止明确失败。
- [x] 只命中 registry 中同 identity/name/descriptor 且 static 的 method。
- [x] 未声明或 instance/static kind 不符明确失败，不返回伪造 handle。
- [x] Android guest call session 暴露其统一 class registry 供上层声明装配。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 395/395 通过。

非目标：本 WU 不添加 Profile 标题事实，不执行 `CallStatic*Method`。
