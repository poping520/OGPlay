# WU-0247 · Profile guest class registry 装配

目标：让 Profile lifecycle 把 Java declarations 与 native-call class receiver 装入
Android guest session 的同一个 JNI class registry。

依赖：WU-0243、WU-0245、WU-0246、`src/session/MODULE.md`。

验收：

- [x] Profile Java method 按 class/name/signature/static 精确注册进 runtime registry。
- [x] native-call 引用使用相同 registry identity 发布稳定 instance/jclass reference。
- [x] 未声明 Java method 的 native-call class 仍注册为空类，不猜测 method。
- [x] 首个目标 Profile 只声明 JADX 与 ELF 字符串共同确认的三个 GLResLoader static method。
- [x] 真实 APK 越过三个 `GetStaticMethodID`，下一未实现行为继续明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 395/395 通过。

非目标：本 WU 不实现资源 method handler 或 `CallStatic*Method`。

机器证据：真实 APK 已从 startup call 1 推进到 call 2，当前明确失败为
`JNI guest static method is not declared: isSoundLoaded(II)I`。
