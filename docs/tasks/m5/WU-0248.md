# WU-0248 · GLMediaPlayer Java lookup declarations

目标：以纯 Profile 数据声明首个目标在 audio native init 中实际缓存的 Java static
method，使 lookup 批次完整通过而不猜测 method ID。

依赖：WU-0245、WU-0246、WU-0247、`src/session/MODULE.md`。

验收：

- [x] JADX 与目标 ELF 字符串/调用序列共同确认 GLMediaPlayer 的 25 个 static method。
- [x] Profile 使用既有 inline-table 数组表达完整声明，仍不超过 200 行。
- [x] Python 与 C++ Profile 加载均接受相同 name/signature/static/implementation 数据。
- [x] 真实 APK 越过 GLMediaPlayer 的全部 `GetStaticMethodID`，下一未实现行为明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 395/395 通过。

非目标：本 WU 不实现 audio Java handler、`CallStatic*Method` 或媒体播放。

机器证据：真实 APK 已从 startup call 2 推进到 call 3，当前明确失败为
`JNI guest static method is not declared: sendAppToBackground()V`。
