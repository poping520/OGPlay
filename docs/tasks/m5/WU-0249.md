# WU-0249 · Activity Java lookup declarations

目标：以纯 Profile 数据声明首个目标 activity native init 实际缓存的 Java static
method，使 startup call 3 完整通过而不猜测 method ID。

依赖：WU-0245、WU-0246、WU-0247、WU-0248、`src/session/MODULE.md`。

验收：

- [x] JADX 与目标 ELF 字符串/调用序列共同确认 activity 的 5 个 static method。
- [x] Profile 仅删除无语义空行并增加既有 inline-table 声明，仍不超过 200 行。
- [x] Python 与 C++ Profile 加载均接受相同 name/signature/static/implementation 数据。
- [x] 真实 APK 越过 activity 的全部 `GetStaticMethodID`，下一未实现行为明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 395/395 通过。

非目标：本 WU 不实现 Activity、存档、短信或进程退出 handler，也不绑定
`CallStatic*Method`。

机器证据：真实 APK 已从 startup call 3 推进到 call 4，当前明确失败为
`unimplemented GLES1 call glViewport (thunk 144, guest thread 1)`。
