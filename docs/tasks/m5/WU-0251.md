# WU-0251 · GLES1 scissor boundary

目标：让 GLES1 `glScissor` 通过隔离的固定管线 dispatch 转发当前 ANGLE frame。

依赖：WU-0250、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] GLES1 core dispatch 新增且只新增 `glScissor` handler，其他未实现入口继续失败。
- [x] 四个 signed 参数复用受检超采样换算后调用 `AngleFrame::Scissor`。
- [x] 无当前 frame、缩放溢出或 ANGLE 错误不得返回伪造成功。
- [x] 机器测试覆盖 bound scissor 与仍未绑定的相邻入口。
- [x] 真实 APK 越过 `glScissor`，下一未实现行为明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 395/395 通过。

非目标：本 WU 不批量绑定其他 GLES1 状态、矩阵、纹理或绘制入口。

机器证据：真实 APK 已越过 startup call 4 中的 `glScissor`，当前明确失败为
`unbound JNI guest slot: NewStringUTF`。
