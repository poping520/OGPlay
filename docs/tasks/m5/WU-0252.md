# WU-0252 · Guest JNI NewStringUTF binding

目标：让 guest `NewStringUTF` 从受检 guest C string 创建统一 M3 string object 与 local
reference。

依赖：WU-0238、WU-0251、`src/runtime/jni/MODULE.md`、
`src/runtime/integration/MODULE.md`。

验收：

- [x] `NewStringUTF` 读取有界且 NUL 终止的 guest bytes，null、越界和未终止明确失败。
- [x] bytes 由 `JniStringStore::CreateModifiedUtf8` 严格解码，不把普通 UTF-8 当 JNI 编码。
- [x] 成功只发布当前线程 local reference；发布失败时删除尚未发布的 string object。
- [x] Android guest call session 拥有与 JNI dispatcher 同寿命的统一 string store。
- [x] 机器测试覆盖编码 NUL、local identity 与 null guest pointer。
- [x] 真实 APK 越过 `NewStringUTF`，下一未实现行为明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 396/396 通过。

非目标：本 WU 不绑定其他 string 访问槽或 Java method invocation。

机器证据：真实 APK 已越过 startup call 4 中的 `NewStringUTF`，当前明确失败为
`unbound JNI guest slot: CallStaticObjectMethod`。
