# WU-0253 · Guest JNI static object invocation

目标：让 guest `CallStaticObjectMethod` 按 method descriptor 解码 A32 variadic 参数并
进入统一 M3 invocation engine。

依赖：WU-0246、WU-0252、`src/runtime/jni/MODULE.md`、
`src/runtime/integration/MODULE.md`。

验收：

- [x] class reference 与 method ID 必须命中统一 registry，且 method 返回 object/array。
- [x] 32 位参数从 r3 后顺序读取，64 位参数按 AAPCS 对齐从寄存器/受检 guest stack 读取。
- [x] float 按 C variadic promotion 从 double 还原，primitive/reference 位型保持 JNI 宽度。
- [x] 调用进入 session 持有的统一 invocation engine，返回值必须是 `JniReference`。
- [x] 机器测试覆盖 static kind、variadic source、object 参数和 object 返回。
- [x] 真实 APK 越过 unbound slot，并在缺少具体 handler 时明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现任何 Profile Java handler，也不绑定 `V`/`A` 变体。

机器证据：

- `guest JNI static object call decodes descriptor-backed variadics`：1/1 通过。
- exact-APK `run-apk` 已越过 unbound slot，精确停止于
  `JNI method implementation has no registered handler`。
- Windows/MSVC warnings-as-errors 构建及全量 CTest 397/397 通过。
