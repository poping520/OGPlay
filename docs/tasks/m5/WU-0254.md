# WU-0254 · 通用直接 APK 资源 HLE

目标：让 Profile 可用通用 implementation id 直接读取 APK asset，并返回受管 JNI byte
array。

依赖：WU-0208、WU-0253、`src/runtime/framework/MODULE.md`、
`src/runtime/jni/MODULE.md`。

验收：

- [x] handler implementation id 由调用方提供，必须非空、唯一且只可安装一次。
- [x] legacy `.//`/`./` 前缀和 Java trim 规则在路径安全检查前规范化。
- [x] 只允许读取 `/apk/assets/` 下来源为 APK 的受检 VFS 文件。
- [x] full/range/length 三种行为复用同一路径与读取契约。
- [x] full/range 结果进入统一 primitive array store，并发布线程 local reference。
- [x] 非法路径、参数、范围、来源和 I/O 明确失败。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 399/399 通过。

非目标：本 WU 不负责从 APK ZIP 导入 VFS，也不把 handler 接到 Android guest session。

机器证据：

- `framework direct asset implementations return bounded JNI bytes`：1/1 通过。
- `framework direct assets reject unsafe ranges and duplicate install`：1/1 通过。
- Windows/MSVC warnings-as-errors 构建及全量 CTest 399/399 通过。
