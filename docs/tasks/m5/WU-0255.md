# WU-0255 · APK 资源接入 guest session

目标：把真实 APK `assets/` 受检导入 GLSurfaceView guest VFS，并按 Profile 声明安装直接
资源 HLE。

依赖：WU-0254、`src/frontend/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] 只有 Profile 引用完整 full/range/length 通用 implementation set 时才启用。
- [x] implementation set 部分声明必须明确失败，不得猜测或安装未引用 handler。
- [x] APK 只导入非目录 `assets/` 条目，读取继续通过统一 ZIP/CRC 校验入口。
- [x] VFS mount 保持 APK 来源并固定为 `/apk`，供通用 HLE 读取 `/apk/assets/`。
- [x] guest session 拥有与 JNIEnv 同生命周期的 primitive array store 与直接资源 HLE。
- [x] 真实 APK 越过缺少 `resource.load_full` handler 的阻塞并暴露下一精确边界。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不绑定新的 guest JNI array slot，不实现 audio/activity handler。

机器证据：

- exact-APK `run-apk` 已读取并挂载 130 个 asset 条目，越过
  `resource.load_full` handler，精确停止于未绑定 JNI `GetArrayLength`。
- Windows/MSVC warnings-as-errors 构建及全量 CTest 399/399 通过。
