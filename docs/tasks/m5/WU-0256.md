# WU-0256 · Guest JNI primitive array length

目标：让 guest `GetArrayLength` 返回统一 primitive array store 中的真实长度。

依赖：WU-0255、`src/runtime/jni/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] guest array handle 必须先经当前线程 JNIEnv 解析为受管 object identity。
- [x] 长度只能来自 session 持有的统一 primitive array store。
- [x] null、未知或非 primitive array identity 必须明确失败。
- [x] 机器测试覆盖真实 byte array 长度与 null reference 失败。
- [x] 真实 APK 越过未绑定 `GetArrayLength` 并暴露下一精确边界。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不绑定 array elements/region/new-array 槽。

机器证据：

- `guest JNI array length resolves the unified primitive array`：1/1 通过。
- exact-APK `run-apk` 已越过 `GetArrayLength`，精确停止于未绑定 JNI
  `GetByteArrayRegion`。
- Windows/MSVC warnings-as-errors 构建及全量 CTest 400/400 通过。
