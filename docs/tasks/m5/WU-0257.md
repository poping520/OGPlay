# WU-0257 · Guest JNI byte array region

目标：让 guest `GetByteArrayRegion` 从统一 primitive array store 受检复制 byte array 区间到 guest 内存。

依赖：WU-0256、`src/runtime/jni/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] guest array handle 必须先经当前线程 JNIEnv 解析为受管 object identity。
- [x] 只接受统一 primitive array store 中的 byte array；其他 primitive kind 明确失败。
- [x] `start` / `length` 按有符号 `jsize` 解码，并复用 store 的区间校验。
- [x] A32 第 5 个参数 `buf` 从 guest 栈读取，非空区间的 null buffer 明确失败。
- [x] 写入必须经过 `AddressSpace` 的完整 write 权限校验，不可写 guest 内存明确失败。
- [x] 机器测试覆盖真实字节复制、栈参数、错误引用/类型/区间/输出缓冲。
- [x] exact-APK `run-apk` 越过 `GetByteArrayRegion` 并暴露下一精确边界。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不绑定其他 primitive array region、elements、critical 或 new-array 槽。

机器证据：

- `guest JNI byte array region copies checked bytes to guest memory`：1/1 通过。
- exact-APK `run-apk` 已越过 `GetByteArrayRegion`，精确停止于未实现 GLES1
  `glShadeModel`（thunk 122）。
- Windows/MSVC warnings-as-errors 构建及全量 CTest 401/401 通过。
