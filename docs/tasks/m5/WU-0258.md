# WU-0258 · GLES1 shade model state

目标：让 GLES1 `glShadeModel` 以显式 context state 保存标准 flat/smooth shading 模式。

依赖：WU-0257、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] GLES1 core dispatch 新增且只新增 `glShadeModel` handler，相邻未实现入口继续失败。
- [x] 仅接受 `GL_FLAT` / `GL_SMOOTH`；非法枚举明确失败，不得静默成功。
- [x] 调用必须存在当前 ANGLE frame，不能在无 context 状态下修改 fixed-pipeline state。
- [x] shade model 是独立 context state，默认 `GL_SMOOTH`，context 终止后恢复默认值。
- [x] 机器测试覆盖默认值、flat/smooth 切换、reset、非法枚举与无当前 frame。
- [x] exact-APK `run-apk` 越过 `glShadeModel` 并暴露下一精确边界。
- [x] Windows/MSVC warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 lighting、matrix、client array、draw 或完整 GLES1 shader 生成，
也不批量绑定其他 fixed-pipeline 状态入口。

机器证据：

- `GLES1 shade model state validates and resets`：1/1 通过。
- `Android boundary publishes GLES1 core without silent handlers`：1/1 通过。
- exact-APK `run-apk` 已越过 `glShadeModel`，精确停止于未实现 GLES1
  `glClearColor`（thunk 9）。
- Windows/MSVC warnings-as-errors 构建及全量 CTest 402/402 通过。
