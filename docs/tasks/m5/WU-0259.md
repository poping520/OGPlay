# WU-0259 · GLES1 clear color boundary

目标：让 GLES1 `glClearColor` 逐位解码 guest `GLfloat` 并更新当前 ANGLE frame 的真实 clear-color state。

依赖：WU-0258、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] GLES1 core dispatch 新增且只新增 `glClearColor` handler；相邻 `glClear` 继续保持未绑定。
- [x] 四个 guest 32-bit 参数必须以 `GLfloat` 位模式解码，不得做整数数值转换。
- [x] 调用只转发当前 `AngleFrame::ClearColor`；无当前 frame 或 ANGLE 错误必须明确失败。
- [x] 机器测试覆盖无 current frame、真实 clear-color 对后续 ANGLE clear 的影响，以及 `glClear` 仍未绑定。
- [x] exact-APK `run-apk` 越过 `glClearColor` 并暴露下一精确边界。
- [ ] Windows/MSVC warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不绑定 GLES1 `glClear`、`glClearColorx`、depth/stencil clear，也不批量实现其他 fixed-pipeline 状态入口。

机器证据：

- `Android boundary publishes GLES1 core without silent handlers`：1/1 通过（含真实
  clear-color readback）。
- exact-APK `run-apk` 已越过 `glClearColor`，精确停止于未实现 GLES1
  `glClearDepthf`（thunk 11）。
- macOS/arm64 以 `OGPLAY_ENABLE_ANGLE=ON` 全量 CTest 402/402 通过。
- Windows/MSVC warnings-as-errors 与全量 CTest：待执行。
