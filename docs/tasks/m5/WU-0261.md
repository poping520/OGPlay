# WU-0261 · GLES1 clear boundary

目标：让 GLES1 `glClear` 将 guest `GLbitfield` mask 原样转发当前 ANGLE context 的真实 clear 操作。

依赖：WU-0260、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] GLES1 core dispatch 新增且只新增 `glClear` handler；相邻 `glClearStencil` 继续保持未绑定。
- [x] guest mask 必须原样传入 `AngleFrame::Clear`，不得过滤未知 bit、伪造成功或复制 clear state。
- [x] 无当前 ANGLE frame 或原生 GLES mask 错误必须明确失败。
- [x] 机器测试覆盖无 current frame、GLES1 clear 对真实 readback 的影响，以及相邻未绑定入口。
- [x] exact-APK `run-apk` 越过 `glClear` 并暴露下一精确边界。
- [x] macOS/arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不绑定 `glClearStencil`、`glClearColorx`、`glClearDepthx`，也不实现其他 fixed-pipeline 状态或 draw 入口。

机器证据：

- `Android boundary publishes GLES1 core without silent handlers`：1/1 通过。
- exact-APK `run-apk` 已越过 `glClear`，精确停止于未实现 GLES1
  `glEnable`（thunk 37）。
- macOS/arm64 以 `OGPLAY_ENABLE_ANGLE=ON` 全量 CTest 402/402 通过。
