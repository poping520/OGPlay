# WU-0262 · GLES1 scalar state batch

目标：批量闭合目标实际导入的 GLES1 无指针标量状态入口。

依赖：WU-0261、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] GLES1 core dispatch 一次新增 active/bind/blend/color-mask/cull/depth、enable/disable、
  finish/front-face/get-error/hint/pixel-store/texture-parameter 共 17 个 handler。
- [x] GLenum 原样传递，GLboolean 按非零解码，GLint/GLfloat 必须保持 32 位位型。
- [x] buffer binding 与 pixel-store 先验证副本、ANGLE 成功后才提交 GLES1 transfer state。
- [x] GLES1-only hint/capability 进入显式状态，共有状态才转发 ANGLE。
- [x] 无 current frame、非法枚举或原生 GLES 错误必须明确失败。
- [x] 机器测试表驱动覆盖全部 17 个入口，并以真实 scissor readback 证明状态生效。
- [x] 未在本批次声明的 fixed-pipeline、指针和 draw 入口继续明确未绑定。
- [x] exact-APK `run-apk` 越过本批次并暴露下一精确边界。
- [x] Windows-x64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 guest 指针搬运、矩阵/光照/材质、client array 或 fixed-pipeline draw
转换。

机器证据：

- `GLES1 shade model state validates and resets`：1/1 通过，覆盖 transfer、hint、
  per-texture-unit capability 与 reset。
- `Android boundary publishes GLES1 core without silent handlers`：1/1、266 assertions
  通过，覆盖全部 17 个入口与真实 scissor readback。
- exact-APK `run-apk` 已越过 scalar state 批次，精确停止于未实现 GLES1
  `glMatrixMode`（thunk 92）。
- Windows-x64/MSVC + ANGLE warnings-as-errors 构建及全量 CTest 402/402 通过。
