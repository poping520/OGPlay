# WU-0263 · GLES1 matrix state batch

目标：批量闭合目标初始化路径实际调用的 GLES1 浮点矩阵状态入口。

依赖：WU-0262、`src/runtime/integration/MODULE.md`。

验收：

- [x] GLES1 core dispatch 一次新增 matrix-mode/load-identity/load-matrix、push/pop、
  rotate/translate 共 7 个 handler。
- [x] modelview/projection/texture 三套列主序矩阵栈独立保存，变换按 OpenGL 后乘语义组合。
- [x] `glLoadMatrixf` 通过强类型 guest 地址读取完整 16 个 little-endian `GLfloat`，坏地址、
  非有限值和无 current frame 均明确失败且不部分提交。
- [x] 非法 matrix mode、栈上溢/下溢及非法旋转轴均明确失败。
- [x] managed/guest EGL context 结束时恢复默认 modelview mode 与三套 identity 栈。
- [x] 机器测试覆盖矩阵组合、三栈边界、全部 7 个 HLE 入口和生命周期失败。
- [x] exact-APK `run-apk` 越过矩阵批次并暴露下一精确边界。
- [x] Windows-x64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 lighting/material/fog、client array、draw 或 fixed-pipeline shader
转换；矩阵状态由后续 draw 转换消费，不伪造渲染成功。

机器证据：

- `GLES1 matrix state composes and bounds stacks` 覆盖列主序 translate/rotate、mode、
  push/pop、reset、非法值及深度 32 边界。
- `Android boundary publishes GLES1 core without silent handlers` 对新增 7 个入口执行
  无 frame fail-closed 与 Windows 原生 ANGLE managed-frame 调用。
- exact-APK `run-apk --exit-after-frames 1` 已越过本批次，精确停止于未实现 GLES1
  `glMaterialfv`（thunk 89）。
- Windows-x64/MSVC + ANGLE warnings-as-errors 构建及全量 CTest 403/403 通过。
