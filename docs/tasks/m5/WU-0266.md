# WU-0266 · GLES1 material face quirk runtime mapping

目标：把已验证 Profile quirk 映射为默认关闭的通用 GLES1 material face 边界选项。

依赖：WU-0265、`src/frontend/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] Android boundary 与 guest-session request 新增默认 false 的强类型通用选项。
- [x] 前端只按已验证 quirk id 映射选项，不把 Profile 或目标身份传入 runtime。
- [x] 启用时仅将 `GL_FRONT` 归一为 `GL_FRONT_AND_BACK`，其他非法 face 继续失败。
- [x] context reset 保留配置策略，状态数据仍恢复规范默认值。
- [x] 注册表引用测试证明关闭选项即失败；exact-APK smoke 证明启用路径越过边界。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现其他 GLES1 状态、client array、draw 或 fixed-pipeline shader。

机器证据：

- `GLES1 material front face quirk is required when disabled` 证明默认 false 路径明确失败。
- exact-APK 已越过首个 `GL_FRONT (0x0404)` material 更新，精确停止于随后传入的
  `GL_BACK (0x0405)`；现有 quirk 声明范围过窄，须由下一 WU 修订而非静默扩权。
- macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 405/405 通过。
