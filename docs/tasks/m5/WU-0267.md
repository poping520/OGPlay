# WU-0267 · GLES1 single-face material quirk state

目标：依据 exact-APK 新证据，让 quirk 路径独立保存桌面 GL 风格的前后单面 material。

依赖：WU-0266、`src/frontend/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] quirk reason/risk 覆盖目标实际依次使用的 `GL_FRONT` 与 `GL_BACK`。
- [x] 默认关闭时两种单面 face 均失败；标准 `GL_FRONT_AND_BACK` 同时更新两面。
- [x] 启用时 front/back material 独立保存，非法 face 继续明确失败。
- [x] context reset 恢复两面规范默认值但保留已注入策略。
- [x] quirk 注册表引用测试覆盖关闭失败与开启后的两面独立状态。
- [x] exact-APK 越过两种单面 material 并暴露下一精确边界。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 fixed-pipeline shader/draw 对两面材质的消费。

机器证据（macOS-arm64）：

- `cmake --build --preset dev -j 8` 通过。
- 定向 CTest 5/5 通过，覆盖 single-face material、quirk registry、title profile 与
  `run-apk` 参数契约。
- exact-APK 已越过 `GL_FRONT`/`GL_BACK` material 调用，下一精确边界为
  `unbound JNI guest slot: CallStaticIntMethod`。
- `cmake --preset dev && cmake --build --preset dev -j 8 && ctest --preset dev
  --output-on-failure` 全量验证通过。
