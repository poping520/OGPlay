# WU-0268 · Guest JNI static int invocation

目标：让 guest `CallStaticIntMethod` 按 method descriptor 解码 A32 variadic 参数并进入
统一 M3 invocation engine。

依赖：WU-0253、WU-0267、`src/runtime/jni/MODULE.md`、
`src/runtime/integration/MODULE.md`。

验收：

- [x] class reference 与 method ID 必须命中统一 registry，且 method 返回 `int`。
- [x] 参数复用已有 descriptor-backed A32 variadic 解码与受检 guest stack 读取。
- [x] 调用进入 session 持有的统一 invocation engine，有符号 `JniInt` 位型原样返回 r0。
- [x] 机器测试覆盖 reference 参数、负 int 返回与错误 return descriptor。
- [x] exact-APK 越过 unbound slot 并暴露下一精确边界。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不绑定其他 `CallStatic*Method`、`V`/`A` 变体或新增 Java handler。

机器证据（macOS-arm64）：

- `guest JNI static int call preserves signed variadic result`：1/1 通过。
- exact-APK 已越过 `CallStaticIntMethod` 并进入既有 `resource.length` handler，下一精确
  边界为 `unimplemented GLES1 call glGenTextures (thunk 49, guest thread 1)`。
- `cmake --preset dev && cmake --build --preset dev -j 8 && ctest --preset dev
  --output-on-failure` 通过，CTest 406/406。
