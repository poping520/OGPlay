# WU-0269 · GLES1 texture name lifecycle

目标：让 GLES1 guest 通过受检名称数组使用 ANGLE texture name 的生成与删除生命周期。

依赖：WU-0268、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] `glGenTextures` 与 `glDeleteTextures` 调用当前 managed ANGLE frame 的真实实现。
- [x] `GLsizei` 负值、null 与越界 guest 数组在 ANGLE 状态变化前明确失败。
- [x] 生成名称以小端 32 位数组一次提交，删除名称从同一受检表示完整读取。
- [x] 机器测试覆盖 GLES1 生成、使用、删除与失败路径。
- [x] exact-APK 越过 `glGenTextures` 并暴露下一精确边界。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现纹理像素上传、查询或 fixed-pipeline draw 消费。

机器证据（macOS-arm64）：

- `Android boundary publishes GLES1 core without silent handlers`：1/1 通过。
- exact-APK 已越过 `glGenTextures`，下一精确边界为
  `unimplemented GLES1 call glGetString (thunk 63, guest thread 1)`。
- `cmake --preset dev && cmake --build --preset dev -j 8 && ctest --preset dev
  --output-on-failure` 通过，CTest 406/406。
