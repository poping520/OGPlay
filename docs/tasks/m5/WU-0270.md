# WU-0270 · GLES1 query strings

目标：把 GLES1 `glGetString` 的真实 ANGLE 结果发布为稳定、只读的 guest 字符串。

依赖：WU-0269、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] 仅接受 GLES1 vendor/renderer/version/extensions 四种合法枚举。
- [x] 返回值来自当前 managed ANGLE context，不伪造 vendor、renderer 或扩展。
- [x] 四种结果使用独立有界槽并以 NUL 结尾，发布后 guest 页恢复只读。
- [x] GLES1 查询页与 GLES2 shading-language 查询页隔离。
- [x] 机器测试覆盖真实非空结果、只读保护与非法枚举失败。
- [x] exact-APK 越过 `glGetString` 并暴露下一精确边界。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 `glGetFloatv` 或纹理像素上传。

机器证据（macOS-arm64）：

- `Android boundary publishes GLES1 core without silent handlers`：1/1 通过。
- exact-APK 的 extensions 字符串超过 1 KiB，最终采用每槽 16 KiB、总计 64 KiB 的
  有界只读区域；运行已越过全部 `glGetString`，下一精确边界为
  `glTexParameterf failed with GLES error 1280`。
- `cmake --preset dev && cmake --build --preset dev -j 8 && ctest --preset dev
  --output-on-failure` 通过，CTest 406/406。
