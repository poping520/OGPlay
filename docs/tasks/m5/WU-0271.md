# WU-0271 · GLES1 automatic mipmap texture state

目标：把 GLES1 `GL_GENERATE_MIPMAP` 保存为按 texture object 隔离的显式状态。

依赖：WU-0270、`src/runtime/integration/MODULE.md`。

验收：

- [x] `glTexParameterf/i` 的 `GL_GENERATE_MIPMAP` 不再错误转发 GLES2 ANGLE。
- [x] 仅接受 `GL_TEXTURE_2D` 与精确 `GL_FALSE`/`GL_TRUE` 值。
- [x] 状态按 active unit 当前绑定 texture 隔离，delete 解除绑定并清除，reset 恢复默认。
- [x] 其他 texture parameter 继续调用真实 ANGLE。
- [x] 机器测试覆盖隔离、删除、reset、非法 target/value 与边界调用。
- [x] exact-APK 越过 `GL_GENERATE_MIPMAP=false` 并暴露下一精确边界。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 texture upload 或在 true 状态下生成 mipmap。

机器证据（macOS-arm64）：

- GLES1 状态与边界定向 CTest 2/2 通过。
- exact-APK 下一精确边界为
  `unimplemented GLES1 call glGetFloatv (thunk 56, guest thread 1)`。
- `cmake --preset dev && cmake --build --preset dev -j 8 && ctest --preset dev
  --output-on-failure` 通过，CTest 406/406。
