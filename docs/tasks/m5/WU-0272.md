# WU-0272 · GLES1 legacy fixed-state batch

目标：批量闭合目标剩余的 7 个 fixed-pipeline 状态与浮点查询入口。

依赖：WU-0271、`src/runtime/integration/MODULE.md`。

范围：`glAlphaFunc`、`glClientActiveTexture`、`glColor4f`、`glColor4ub`、
`glGetFloatv`、`glTexEnvfv`、`glTexEnvi`。

验收：

- [x] alpha、client texture、current color 与 texture environment 保存规范默认值并 reset。
- [x] texture environment 按 server active texture unit 隔离，枚举、元素数与有限值受检。
- [x] `glGetFloatv` 返回受管矩阵/颜色/alpha/client texture 状态。
- [x] `GL_MAX_TEXTURE_MAX_ANISOTROPY_EXT` 查询真实 ANGLE context，不伪造上限。
- [x] 所有 guest 输入/输出指针在状态变化或 ANGLE 查询前完整预检。
- [x] exact-APK 越过全部 7 个入口并暴露下一精确边界。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 fixed-pipeline shader/draw 消费或 texture upload。

机器证据（macOS-arm64）：

- legacy state 与 GLES1 boundary 定向 CTest 2/2 通过。
- exact-APK 下一精确边界为
  `unimplemented GLES1 call glCompressedTexImage2D (thunk 22, guest thread 1)`。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest
  407/407 通过。
