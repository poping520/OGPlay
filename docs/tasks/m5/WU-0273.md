# WU-0273 · GLES1 texture image batch

目标：批量闭合目标剩余的 4 个 texture image/copy 入口并消费 automatic mipmap 状态。

依赖：WU-0271、WU-0272、`src/gles/MODULE.md`、
`src/runtime/integration/MODULE.md`。

范围：`glCompressedTexImage2D`、`glCopyTexImage2D`、`glTexImage2D`、
`glTexSubImage2D` 与 `GL_GENERATE_MIPMAP` 消费。

验收：

- [x] 四个入口转发当前 ANGLE context，参数保持 GLES1 guest ABI 宽度与符号。
- [x] compressed image size、pixel byte count、nullable 与 guest 范围在 ANGLE 前受检。
- [x] pixel byte count 服从 GLES1 独立 unpack alignment。
- [x] level-0 image/copy 成功后按 bound texture 的保存状态实际生成 mipmap。
- [x] exact-APK 越过全部 4 个入口并暴露下一精确边界。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 client arrays、draw 转换或 matrix-palette extension。

机器证据（macOS-arm64）：

- GLES1 boundary 定向 CTest 1/1 通过。
- exact-APK 下一精确边界为
  `unimplemented GLES1 call glEnableClientState (thunk 38, guest thread 1)`。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest
  407/407 通过。
