# WU-0274 · GLES1 client-array draw batch

目标：批量闭合目标 8 个 client-array/draw 入口并让 exact-APK 提交首个 ANGLE frame。

依赖：WU-0272、WU-0273、`src/gles/MODULE.md`、
`src/runtime/integration/MODULE.md`。

范围：`glColorPointer`、`glDisableClientState`、`glDrawArrays`、`glDrawElements`、
`glEnableClientState`、`glNormalPointer`、`glTexCoordPointer`、`glVertexPointer`。

验收：

- [x] 四类 pointer 保存调用时 array-buffer binding，client texture coordinate 按 unit 隔离。
- [x] draw 按 first/count 或 guest index 最大值计算并预检全部启用的 client array 范围。
- [x] guest array/index 经内部 VBO/EBO 上传，draw 后恢复 guest buffer binding。
- [x] 内部 GLES2 shader 消费目标所需矩阵、颜色、light0、texture、fog 与 alpha state。
- [x] 非法 size/type/stride/count、坏 guest pointer 与不安全混合 buffer 路径明确失败。
- [x] exact-APK 越过全部 8 个入口并成功提交一个 managed ANGLE frame。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 matrix-palette extension、完整多纹理、多光源或全部 texture env mode。

机器证据（macOS-arm64）：

- client state 与 GLES1 boundary 定向 CTest 2/2 通过。
- exact-APK `--exit-after-frames 1` 正常输出
  `OGPlay: stopped after 1 presented frames.` 并以状态 0 退出。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest
  408/408 通过。
