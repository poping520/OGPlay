# WU-0275 · GLES1 matrix-palette state batch

目标：批量闭合目标最后 3 个 matrix-palette extension import，保持未完成 draw 语义显式。

依赖：WU-0274、`src/runtime/integration/MODULE.md`。

范围：`glCurrentPaletteMatrixOES`、`glMatrixIndexPointerOES`、
`glWeightPointerOES`。

验收：

- [x] 三个入口绑定独立 GLES1 extension dispatch，不改变 core thunk id。
- [x] current palette index 受 0..31 上限校验并随 context reset。
- [x] matrix-index/weight pointer 校验 size/type/stride 并保存调用时 array-buffer binding。
- [x] matrix-index/weight client state 可显式启停，尚未实现的 skinning draw 明确失败。
- [x] exact-APK 一帧 smoke 继续成功，目标 ELF 62/62 GL import 均有行为 handler。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 palette matrix stack 或 weighted skinning shader。

机器证据（macOS-arm64）：

- matrix-palette state 与 extension boundary 定向 CTest 2/2 通过。
- exact-APK `--exit-after-frames 1` 正常输出
  `OGPlay: stopped after 1 presented frames.` 并以状态 0 退出。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest
  408/408 通过。
