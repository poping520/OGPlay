# WU-0276 · JNI static invocation family batch

目标：一次闭合全部 `CallStatic*Method` 普通、`V`、`A` guest 调用槽，消除目标的静态
void 调用阻塞。

依赖：WU-0268、`src/runtime/integration/MODULE.md`、M3 JNI invocation engine。

范围：Object、Boolean、Byte、Char、Short、Int、Long、Float、Double、Void 十种返回类型，
每种覆盖 `...`、`va_list` 与 `jvalue[]` 三种参数来源，共 30 个 JNIEnv 槽。

验收：

- [x] 30 个槽全部显式绑定，且调用名返回类型必须匹配 method descriptor。
- [x] A32 variadic 按默认参数提升和偶数寄存器/栈双字对齐解码。
- [x] A32 `va_list` 按 4/8 字节类型对齐解码，空参数方法允许 null list。
- [x] `jvalue[]` 按 8 字节 union 步长及未提升的 float/窄整数布局解码。
- [x] object、所有 primitive 与 void 返回按 A32 word/double-word ABI 编码。
- [x] 非法 class、错误返回 descriptor、非空参数的 null `va_list/jvalue[]` 明确失败。
- [x] exact-APK `--exit-after-frames 1` 越过 `CallStaticVoidMethod` 并正常停止。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现实例/非虚调用、字段、数组、字符串或 native 注册系列。

机器证据（macOS-arm64）：

- static family 定向 CTest 5/5 通过，覆盖全部 30 个槽、10 种返回 ABI 与 `V/A` 差异布局。
- exact-APK 输出 `OGPlay: stopped after 1 presented frames.` 并以状态 0 退出。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest 410/410 通过。
