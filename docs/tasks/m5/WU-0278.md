# WU-0278 · Java SoundPool stop-control batch

目标：以通用的分类 voice 状态批量闭合 exact-APK shutdown 的 SoundPool stop-all 行为。

依赖：WU-0277、`src/audio/MODULE.md`、`src/runtime/integration/MODULE.md`。

范围：`audio.stop_all_sounds`、`audio.stop_all_pool`、`audio.stop_all_big`。

验收：

- [x] voice 以 resource + instance 标识，并隔离普通 pool 与 big 类别。
- [x] stop-all-sounds 清空全部 voice；分类 stop 不影响另一类别。
- [x] `stop_all_pool(I)` / `stop_all_big(I)` 保留参数指定的 resource，`-1` 清空该类别。
- [x] destroy 清空 voice，initialize 不恢复旧 voice，重复生命周期调用继续幂等。
- [x] 状态访问受锁保护，可供不同 guest JNI 线程使用。
- [x] 三个 handler 进入统一 invocation engine，不发布 loaded/playing 或音频输出成功。
- [x] exact-APK 120 帧和 shutdown 正常完成，状态 0。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现资源加载、解码、play/pause/resume 或宿主音频输出。

机器证据（macOS-arm64）：

- `Android guest Java audio handlers own SoundPool lifecycle` 定向测试通过，覆盖三种 stop。
- exact-APK `--exit-after-frames 120` 输出 `stopped after 120 presented frames`，状态 0。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest（411/411）通过。
