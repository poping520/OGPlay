# WU-0280 · Java SoundPool resource-state queries

目标：以通用分类资源目录闭合 SoundPool loaded 查询与卸载行为。

依赖：WU-0278、WU-0279、`src/audio/MODULE.md`、`src/runtime/integration/MODULE.md`。

范围：`audio.is_sound_loaded`、`audio.is_sound_loaded_big`、`audio.unload_sound`、
`audio.unload_sound_big`。

验收：

- [x] loaded identity 由类别 + group + resource 组成，普通 pool 与 big 相互隔离。
- [x] 两种查询从目录事实返回 `0` / `1`，不使用恒定返回值。
- [x] 两种卸载只删除精确键；stop 不卸载，destroy 清空所有资源。
- [x] inactive 状态不得接受 loaded 发布，initialize 不恢复已销毁资源。
- [x] 未接入加载器、解码和输出时不伪报 loaded/playing。
- [x] exact-APK 120 帧和 shutdown 正常完成，状态 0。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现资源读取、声音解码、play/pause/resume 或宿主音频输出。

机器证据（macOS-arm64）：

- 定向测试覆盖 false/true 查询、类别隔离、精确卸载与 destroy 清理。
- exact-APK `--exit-after-frames 120` 输出 `stopped after 120 presented frames`，状态 0。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest（411/411）通过。
