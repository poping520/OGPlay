# WU-0281 · Java SoundPool load/play state

目标：以不伪造加载或输出的通用状态机闭合 SoundPool 普通/big load 与 play 调用。

依赖：WU-0280、`src/audio/MODULE.md`、`src/runtime/integration/MODULE.md`。

范围：`audio.load_sound`、`audio.load_sound_big`、`audio.play_sound`、
`audio.play_sound_big`，以及 loaded 返回契约修正。

验收：

- [x] loaded identity 为类别 + resource；stream instance 只属于 voice identity。
- [x] 查询遵循 legacy Java 契约：loaded 返回 `0`，unavailable 返回 `-1`。
- [x] load 记录去重的 pending request，不在资源/解码缺失时 `MarkLoaded`。
- [x] play 对 unavailable resource 执行 lazy request 且不创建 voice。
- [x] loaded resource 才能 play；音量必须有限且处于 `[0, 1]`。
- [x] unload 同时清理对应 pending、loaded 与 voice；destroy 清空全部状态。
- [x] exact-APK 600 帧和 shutdown 正常完成，状态 0。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 Android resources.arsc 解析、声音解码或宿主音频输出。

机器证据（macOS-arm64）：

- 定向测试覆盖 pending 去重、loaded gate、lazy request、类别隔离、音量校验与清理。
- exact-APK `--exit-after-frames 600` 输出 `stopped after 600 presented frames`，状态 0。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest（411/411）通过。
