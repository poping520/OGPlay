# WU-0282 · Java SoundPool voice-control batch

目标：以统一 voice 状态批量闭合 SoundPool 播放控制家族，消除启动期 control handler 崩溃。

依赖：WU-0281、`src/audio/MODULE.md`、`src/runtime/integration/MODULE.md`。

范围：普通/big 的 pause、resume、stop、set-volume，以及普通 pool set-pitch、big reset。

验收：

- [x] 10 个 handler 使用类别 + resource + instance 精确寻址同一 voice 目录。
- [x] pause/resume 迁移 playing/paused；stop 删除 voice 且不隐式卸载资源。
- [x] volume 只接受有限 `[0, 1]`，pitch 只接受有限 `[0.5, 2]`。
- [x] reset 记录可查询事实且不伪造播放状态变化。
- [x] 不存在的 voice 与无效参数不发布成功状态。
- [x] exact-APK 越过 `audio.set_pitch`，无界运行约 90 秒后正常停止，状态 0。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现资源解码、混音、宿主音频输出，也不以帧存活代替 UI 视觉验收。

机器证据（macOS-arm64）：

- 定向测试覆盖全部 10 个 handler、状态迁移、参数更新、reset 与 stop。
- exact-APK 运行约 90 秒并提交 1323 帧；Ctrl-C 后输出正常停止，进程状态 0。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest（411/411）通过。
