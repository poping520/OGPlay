# WU-0283 · Java display sleep-policy state

目标：以通用 framework 屏幕策略状态闭合 legacy Java display mode 调用。

依赖：WU-0282、`src/runtime/framework/MODULE.md`、
`src/runtime/integration/MODULE.md`。

范围：`display.change_mode` 与线程安全的允许休眠/保持唤醒请求状态。

验收：

- [x] APK Java 证据确认 mode `1` 清除 `FLAG_KEEP_SCREEN_ON`，其他值设置该 flag。
- [x] handler 不依赖标题、包名、类名或资源编号，只消费规范 implementation ID 与参数。
- [x] 未请求策略保持未知；每次请求保存最新状态并累计可查询计数。
- [x] 宿主防休眠未接入时能力保持 partial，不伪造平台窗口变更。
- [x] exact-APK 越过 `display.change_mode` 并暴露下一真实边界。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现 Activity 后台切换、进程退出、短信、RMS 存储或宿主屏幕保护控制。

机器证据（macOS-arm64）：

- exact-APK 越过 `display.change_mode`，随后精确暴露 GLES1 texture environment 边界。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest（412/412）通过。
