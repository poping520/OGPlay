# WU-0284 · GLES1 texture environment draw batch

目标：让通用 GLES1 fixed renderer 按纹理格式执行目标实际使用的 texture environment。

依赖：WU-0283、WU-0272、WU-0274、`src/runtime/integration/MODULE.md`。

范围：纹理 level-0 base format 状态，以及 `GL_REPLACE`、`GL_ADD` 和单纹理
`GL_COMBINE` fixed shader 语义。

验收：

- [x] texture image/copy 成功后按 texture object 保存 level-0 base format，delete/reset 清理。
- [x] REPLACE/MODULATE/ADD 按 ALPHA、RGB/LUMINANCE、RGBA/LUMINANCE_ALPHA 分量执行。
- [x] COMBINE 保存并验证 RGB/alpha function、三组 source/operand、scale 与 constant color。
- [x] 单纹理 shader 覆盖 REPLACE/MODULATE/ADD/ADD_SIGNED/INTERPOLATE/SUBTRACT/DOT3。
- [x] 未知 base format 或未实现的其他 texture environment 继续携带枚举明确失败。
- [x] exact-APK 越过三种新模式，用户确认进入游戏主界面；517 帧后正常停止且状态 0。
- [x] macOS-arm64 + ANGLE warnings-as-errors 构建及全量 CTest 通过。

非目标：本 WU 不实现多 active texture、GL_DECAL、GL_BLEND、matrix-palette skinning 或
完整 fixed renderer。

机器证据（macOS-arm64）：

- exact-APK 依次越过 `GL_REPLACE`、`GL_ADD` 与 `GL_COMBINE_RGB`，用户确认进入游戏
  主界面；Ctrl-C 后输出 `stopped after 517 presented frames`，状态 0。
- 定向状态与真实 ANGLE draw 测试通过。
- `cmake --preset dev`、`cmake --build --preset dev -j 8` 与全量 CTest（412/412）通过。
