# WU-0286 · ANGLE pbuffer depth/stencil attachment

目标：让 host-managed ANGLE pbuffer 提供游戏 3D 绘制所需的真实默认 depth/stencil buffer。

依赖：WU-0285、`src/gles/MODULE.md`。

范围：ANGLE pbuffer EGL config 的 depth/stencil 规格、真实配置查询回归与 exact-APK 视觉验收。

验收：

- [x] pbuffer config 明确请求 RGBA8、至少 24-bit depth 与 8-bit stencil。
- [x] 真实 ANGLE `GL_DEPTH_BITS` / `GL_STENCIL_BITS` 查询验证所选默认 framebuffer 附件。
- [x] GLES1 depth-test/depth-mask/depth-func 继续直接进入同一 ANGLE context。
- [x] 所有临时跳 draw 与扩大 trace ring 的诊断代码均已移除。
- [x] exact-APK 主界面人工确认远侧几何不再覆盖车身，两个黑块消失。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 通过。

非目标：不引入游戏专属 draw 过滤，不实现离屏 FBO attachment 管理或窗口 EGL surface。

机器证据（macOS-arm64）：

- `ANGLE frame clears and reads back an exact GLES2 pbuffer` 在真实 Metal ANGLE pbuffer
  查询 `GL_DEPTH_BITS >= 24`、`GL_STENCIL_BITS >= 8`。
- GLES1 fixed draw 与 lighting alpha 的真实 ANGLE readback 回归继续通过。
- 用户在未启用任何诊断开关的 exact-APK 运行中确认黑块消失。
- `cmake --preset dev`、`cmake --build --preset dev -j8` 与全量 CTest（413/413）通过。
