# WU-0287 · run-apk realtime FPS title

目标：在通用 `run-apk` 窗口界面持续显示基于实际 present 的实时 FPS。

依赖：WU-0286、`src/hal/MODULE.md`、`src/frontend/MODULE.md`。

范围：显式 ticks FPS sampler、窗口标题更新契约及两种 `run-apk` 生命周期的统一接入。

验收：

- [x] 初始窗口标题显示 `FPS --`，不伪造尚未采样的数值。
- [x] NativeActivity 与 GLSurfaceView 都只在成功 present 后累计帧数。
- [x] 每 0.5 秒更新一位小数 FPS，不逐帧修改宿主窗口标题。
- [x] FPS 时间来自统一 `RealtimeClock`，sampler 自身只消费显式单调 ticks。
- [x] sampler 拒绝 frame/tick 倒退，SDL 标题拒绝关闭窗口与内嵌 NUL。
- [x] 确定性 sampler 与 SDL dummy window 标题测试通过。
- [x] exact-APK 人工确认标题实时更新。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 通过（414/414）。

非目标：不向 guest RGBA 帧绘制文字，不改变 guest 时间、渲染节奏或 Profile schema。
