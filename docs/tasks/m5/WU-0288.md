# WU-0288 · bulk CPU state snapshot import

目标：消除 Dynarmic 状态快照逐寄存器调用开销，同时保持完整 A32/VFP 状态语义。

依赖：WU-0287、`src/cpu/MODULE.md`。

范围：A32 核心/扩展寄存器组等尺寸批量导入及 Dynarmic 快照接入。

验收：

- [x] 批量导入精确保留 16 个核心寄存器与 64 个扩展寄存器。
- [x] 批量导入不改变 thread ID、guest thread pointer 或状态寄存器元数据。
- [x] Release exact-APK 复测证明逐槽 setter 热点消失。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 通过。

非目标：不改变 guest 指令、tick、异常或快照格式。
