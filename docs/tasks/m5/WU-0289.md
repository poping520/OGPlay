# WU-0289 · zero-copy 1x frame resolve

目标：让默认 1× 输出直接转移 ANGLE readback 存储，避免无意义的逐像素超采样还原。

依赖：WU-0287、`src/gles/MODULE.md`。

范围：拥有型 RGBA8 resolve 重载及 1× 存储转移契约。

验收：

- [x] 1× resolve 完整验证布局与字节数后保留输入存储地址。
- [x] 2..4× resolve 继续使用确定性整数 box filter。
- [x] Release exact-APK 复测证明 1× resolve 热点消失。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 通过。

非目标：不改变 ANGLE readback、像素方向、超采样算法或窗口 present。
