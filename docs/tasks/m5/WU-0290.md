# WU-0290 · guarded Dynarmic data page table

目标：让无 observer 的普通 RW guest 数据页安全进入 Dynarmic 页表快路，同时保留权限、
跨页与 fault 契约。

依赖：WU-0288、ADR-0011、ADR-0016、`src/memory/MODULE.md`、`src/cpu/MODULE.md`。

范围：稳定 4 KiB 直接页表、映射生命周期同步、observer/execute 排除、跨页回退、标量
callback 访问及 Dynarmic 配置。

验收：

- [x] 仅无 observer 的 RW 非执行页发布宿主页地址，保护、卸载与快照恢复同步撤销/恢复。
- [x] 只读、可执行、未映射、observer 与跨页访问继续走受检 callback。
- [x] callback fault、状态快照与 A32/T32 执行契约测试通过。
- [x] Debug exact-APK 主菜单由约 4 FPS 提升到约 7 FPS，采样中的数据 callback 显著下降。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 通过。

非目标：不为执行页开放 fastmem，不绕过 observer，不改变 guest 页尺寸或 fault 类型。
