# WU-0291 · reusable GLES1 client staging

目标：消除 GLES1 高频 client pointer/draw 的整状态复制和重复宿主暂存分配，同时保持
每次 draw 重新读取 guest 内容。

依赖：WU-0290、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

范围：可复用 input 暂存、client VBO/EBO/顺序索引高水位存储，以及 pointer 状态的
验证候选/原子提交。

验收：

- [x] 重复 input 搬运复用宿主存储并返回精确 span，每次都重新预检和读取 guest。
- [x] pointer 候选在提交前不改变状态，非法参数或 frame 失败不得部分提交。
- [x] client array、DrawArrays、DrawElements 与真实 ANGLE 生命周期测试通过。
- [x] 用户在同一 Debug exact-APK 主菜单确认约 13.7 FPS，较本轮 7 FPS 基线接近翻倍。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 通过。

非目标：不缓存 guest 顶点内容，不改变 fixed-pipeline shader、draw 结果或游戏帧率上限。
