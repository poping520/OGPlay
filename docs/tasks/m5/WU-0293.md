# WU-0293 · declarative SoundPool resource paths

目标：让 Title Profile 以受检纯数据规则把 SoundPool resource 编号映射为编码音频路径，
不在生产代码硬编码游戏、资源编号或文件命名。

依赖：WU-0201、WU-0281、`src/session/MODULE.md`、`src/audio/MODULE.md`。

范围：M5 声音出口要求、Profile `audio.sound_pool` schema、资源路径格式化及首个目标数据。

验收：

- [x] M5 出口明确要求实际声音/音效输出，不能以 JNI 调用存活替代。
- [x] `audio.sound_pool` 只接受 source 与包含唯一 `{resource}` 或
  `{resource:0N}` 占位符的规范相对路径。
- [x] 非负 resource 产生确定性路径；负数、重复/未知占位符、路径逃逸及非法 width 明确失败。
- [x] 首个目标只在 Profile 声明自身 raw-resource 命名规则，`src/` 不出现游戏或厂商分支。
- [x] Profile loader、Python 目录门禁与资源格式化机器测试通过。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 421/421 通过。

非目标：本 WU 不解码 OGG、不混音、不打开宿主音频设备，也不把资源存在伪装为 loaded。
