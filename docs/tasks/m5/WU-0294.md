# WU-0294 · bounded Ogg Vorbis decoding

目标：把不可信的内存 Ogg Vorbis 资源解码为拥有型、受检的 PCM16 音频事实。

依赖：WU-0293、`src/audio/MODULE.md`。

验收：

- [x] 解码只接受有界输入、1/2 声道、正采样率及不会溢出的 frame/sample 数。
- [x] 空、损坏、非 Vorbis、超限及不支持格式明确失败，不发布部分 PCM。
- [x] 使用仓库内固定版本并记录来源/许可的跨平台 decoder，不调用平台音频 API。
- [x] 真实小型 OGG fixture 与畸形输入测试通过。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 423/423 通过。

非目标：本 WU 不实现 voice、混音、重采样或设备输出。
