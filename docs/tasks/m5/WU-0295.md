# WU-0295 · SoundPool decoded voices and offline mixer

目标：让 Java SoundPool load/play/control 驱动真实 decoded resource 与确定性离线混音。

依赖：WU-0294、WU-0282、`src/audio/MODULE.md`、
`src/runtime/integration/MODULE.md`。

验收：

- [x] load 只有在资源读取和解码成功后才提交 loaded；失败保留明确 pending/失败事实。
- [x] play/pause/resume/stop/volume/pitch/reset/unload/destroy 同步驱动 state 与 mixer voice。
- [x] mono/stereo PCM 以有界线性重采样混入 stereo PCM16，饱和转换且完成 voice 自动清理。
- [x] 并发 guest 控制与宿主 render 线程安全；无设备离线测试产生确定性非零样本。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 427/427 通过。

非目标：本 WU 不打开 SDL/CoreAudio/WASAPI/ALSA 设备。
