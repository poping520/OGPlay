# WU-0296 · SDL3 audio output and exact-APK sound

目标：通过 HAL `AudioOutput` 把通用 mixer PCM 提交到 SDL3 默认设备，并让声明了声音资源的
exact APK 实际可听。

依赖：WU-0295、`src/hal/MODULE.md`、`src/frontend/cli/MODULE.md`。

验收：

- [x] SDL3 backend 实现格式、started、queued frames、start/stop/submit 完整契约。
- [x] 无设备或 SDL3 缺失明确失败；dummy driver 契约测试不依赖真实扬声器。
- [x] `run-apk` 有界补充 mixer 队列，不阻塞 guest frame loop，关闭时严格停止设备。
- [x] Debug + Asphalt5 实机听到菜单音乐/音效，画面 FPS 不发生不可接受回退。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 429/429 通过。

非目标：本 WU 不实现 UI 音量设置、空间音频、麦克风、现代媒体 DRM 或游戏专属补播。
