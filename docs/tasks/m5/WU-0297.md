# WU-0297 · backend-independent pointer buttons

目标：让 HAL 以稳定语义报告鼠标按钮，禁止 SDL 按钮数值泄漏到输入映射层。

依赖：WU-0296、`src/hal/MODULE.md`。

验收：

- [x] `PointerButton` 覆盖 primary、middle、secondary 与两个 auxiliary 按钮。
- [x] SDL3 后端把已知按钮映射为稳定语义，未知按钮明确标记为 unknown。
- [x] SDL dummy window 契约测试证明主键不再暴露 SDL 数值。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 429/429 通过。

非目标：本 WU 不把鼠标事件翻译成 guest 触摸，也不维护手势状态。
