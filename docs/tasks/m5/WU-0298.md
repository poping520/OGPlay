# WU-0298 · mouse drag as single-touch input

目标：让通用桌面窗口以鼠标主键点击拖拽模拟成对的 Android 单点触摸。

依赖：WU-0297、`src/input/MODULE.md`、`src/frontend/MODULE.md`。

验收：

- [x] 主键 down/move/up 使用固定 pointer id 0，并保留映射后的 guest 坐标。
- [x] 悬停、非主键、黑边起始、重复按下与其他设备事件均不进入手势。
- [x] 移出内容区时暂停 move，release 仍以合法夹紧坐标闭合已捕获手势。
- [x] NativeActivity 与 GLSurfaceView `run-apk` 生命周期共用相同 mapper。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 432/432 通过。
- [x] Debug + exact APK 人工确认水平拖拽可驱动游戏触摸交互；窗口正常关闭于 3407 帧。

非目标：本 WU 不实现多点触摸、触控板手势、按键映射 UI 或游戏专属坐标分支。
