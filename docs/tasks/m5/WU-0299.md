# WU-0299 · opaque RGBA framebuffer presentation

目标：让桌面窗口按 Android opaque surface 语义呈现 guest RGBA framebuffer，不把像素
alpha 错误混入宿主黑底。

依赖：WU-0298、`src/hal/MODULE.md`。

验收：

- [x] SDL 缩放复制显式使用 `SDL_BLENDMODE_NONE`，RGB 呈现不受 framebuffer alpha 影响。
- [x] 黑边仍由宿主 surface 清黑，只有等比内容矩形被 guest RGB 覆盖。
- [x] SDL dummy window 测试证明 alpha=0 的红色 guest 像素仍呈现为红色。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 432/432 通过。
- [x] Debug + exact APK 人工确认启动 Logo 为完整白底且主界面无回归；窗口正常关闭于
  424 帧。

非目标：本 WU 不实现透明 Activity、桌面窗口 alpha 合成，也不修改游戏纹理或 clear color。
