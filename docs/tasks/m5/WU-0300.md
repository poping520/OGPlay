# WU-0300 · lazy read-only APK asset mount

目标：让 direct-asset Profile 启动时只索引 APK 资源，首次读取才受检解压并缓存。

依赖：WU-0299、`src/runtime/vfs/MODULE.md`、`src/frontend/MODULE.md`。

验收：

- [x] APK/OBB 懒挂载的 `Stat`、`Open`、`Seek` 不调用 backing loader。
- [x] 首次 `Read` 物化并核对声明尺寸，成功结果只加载一次，失败保持可重试且明确报错。
- [x] `run-apk` 不在 guest 启动前解压全部 `assets/`，仍通过统一 `ReadApkEntry` 校验实际读取。
- [x] 同一 Debug exact APK 单帧总耗时由约 12.75 秒降至 3.78、3.81、3.80 秒，稳定缩短
  约 70%；120 帧 bounded smoke 正常退出。
- [x] macOS-arm64 + ANGLE warnings-as-errors 配置、构建及全量 CTest 434/434 通过。

非目标：本 WU 不修改 Deflate/CRC 算法，不按游戏筛选资源，也不引入无界后台预取。
