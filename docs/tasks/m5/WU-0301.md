# WU-0301 · lazy external host-directory mount

目标：把独立宿主数据目录安全索引为按需读取、会话内可写的通用 external VFS mount。

依赖：WU-0207、WU-0300、`src/runtime/vfs/MODULE.md`。

验收：

- [x] 宿主目录启动时只索引普通文件的相对路径与尺寸，不预读文件内容。
- [x] 首次读取才从固定宿主路径物化并严格核对尺寸，成功结果只缓存一次。
- [x] external 文件保持会话内可写；首次非截断写入不得丢失尚未物化的原内容。
- [x] 根目录、符号链接、特殊文件、遍历错误、空目录与大小写冲突均明确失败，挂载事务化。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest 436/436 通过。

非目标：本 WU 不增加 CLI 参数、不选择 Profile guest 根、不持久化 guest 修改，也不增加
具体游戏 Profile。
