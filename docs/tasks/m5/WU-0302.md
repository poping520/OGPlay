# WU-0302 · run-apk external data directory

目标：让 `run-apk` 把一个显式宿主目录精确挂到 Title Profile 声明的 external guest 根。

依赖：WU-0201、WU-0301、`src/frontend/MODULE.md`、`src/session/MODULE.md`。

验收：

- [x] `--external-dir <host-dir>` 在 APK I/O 前完成参数形状检查，且帮助文本公开该参数。
- [x] guest 根只来自精确匹配 Profile；无声明、多个声明或 required 输入缺失均明确失败。
- [x] 宿主目录在窗口创建前通过通用 lazy external VFS API 挂载，required manifest 同步受检。
- [x] Profile 未声明 external 时保持现有 APK 行为，参数不得被静默忽略。
- [x] macOS/arm64 `cmake --preset dev`、warnings-as-errors 构建及全量 CTest 436/436 通过。

非目标：本 WU 不增加 OBB、多 external 根、guest working directory 切换或具体游戏 Profile。
