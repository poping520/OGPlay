# WU-0303 · second exact title profile preflight

目标：用纯数据 Title Profile 闭合第二个 legacy APK 的身份、external 数据和静态 JNI 生命周期预检。

依赖：WU-0200..0205、WU-0235、WU-0302、`src/session/MODULE.md`。

验收：

- [x] Profile 只记录 Manifest、SO、DEX、JNI 导出及已验证 surface/lifecycle 事实。
- [x] external guest 根与关键 payload manifest 由 Profile 声明，不进入 `src/`。
- [x] startup/resume/frame/pause/shutdown、pointer 与 key 调用均使用强类型通用 phase。
- [x] 真实 APK + API 19 Bionic + external 数据目录通过 `run-apk --preflight`。
- [x] Profile validator、macOS/arm64 配置、warnings-as-errors 构建及全量 CTest 436/436 通过。

非目标：本 WU 不执行 guest 初始化、不补 Java callback、syscall、音频或 GLES 能力。
