# WU-0304 · GLES1 integer state query boundary

目标：让 legacy guest 通过 `glGetIntegerv` 读取转换器拥有状态与真实 ANGLE 设备状态。

依赖：WU-0262、WU-0263、WU-0303、`src/runtime/integration/MODULE.md`。

验收：

- [x] matrix/texture/buffer/pixel-store 与 fixed-renderer 上限查询返回当前转换器状态。
- [x] 兼容的设备限制、framebuffer 位数和采样查询读取真实 ANGLE context。
- [x] 查询形状与 guest 输出范围受检，结果仅在成功后一次提交。
- [x] 未知 pname、坏 guest 地址和缺失 current frame 均明确失败。
- [x] 第二个 exact APK 越过 `glGetIntegerv`，明确停在下一独立缺口 `glPointSize`。
- [x] macOS/arm64 配置、warnings-as-errors 构建及全量 CTest 436/436 通过。

非目标：本 WU 不实现 `glPointSize`、压缩纹理格式模拟或任何 title 专属查询结果。
