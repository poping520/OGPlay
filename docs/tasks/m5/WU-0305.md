# WU-0305 · ANGLE scalar raster state surface

目标：为 GLES1/2 共用的光栅、深度和模板状态建立真实 ANGLE 调用面。

依赖：M4 `AngleFrame`、`src/gles/MODULE.md`。

验收：

- [x] depth range、line width 与 polygon offset 保持 guest float 位型进入 ANGLE。
- [x] stencil clear/function/mask/operation 保持 signed integer 与 mask 位型进入 ANGLE。
- [x] 每次原生调用后立即检查 GLES error，无 ANGLE 构建明确 unavailable。
- [x] 原生 pbuffer 查询验证 stencil 状态确实提交。
- [x] `AngleFrame` scalar/query 实现拆分后所有生产源文件低于 800 行。
- [x] macOS/arm64 warnings-as-errors 构建及全量 CTest 436/436 通过。

非目标：本 WU 只建立下层调用面，不发布新的 guest GLES1 handler。
