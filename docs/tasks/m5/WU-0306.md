# WU-0306 · GLES1 raster depth stencil and point state

目标：闭合第二个 legacy guest 导入的九项 raster/depth/stencil/point 状态入口。

依赖：WU-0305、WU-0264、`src/runtime/integration/MODULE.md`。

验收：

- [x] clear-stencil、depth-range、line-width、polygon-offset 与 stencil 三项状态进入 ANGLE。
- [x] point size/min/max/fade-threshold 是可验证、可重置的 fixed state。
- [x] fixed vertex shader 实际消费 point size/min/max，禁止 silent no-op。
- [x] 非有限/非法 point 参数、无 current frame 与 ANGLE 错误明确失败。
- [x] 机器测试覆盖全部九个入口、point reset 及真实 stencil 状态。
- [x] 第二个 exact APK 从 `glPointSize` 推进并停在下一缺口 `glIsEnabled`。
- [x] macOS/arm64 warnings-as-errors 构建及全量 CTest 436/436 通过。

非目标：本 WU 不实现其他 query、buffer、matrix 或 readback 入口。
