# WU-0307 · GLES1 boolean pointer and texture-environment queries

目标：闭合第二个 legacy guest 导入的 boolean/capability、client pointer 与标量 texture-environment 入口。

依赖：WU-0306、WU-0304、`src/runtime/integration/MODULE.md`。

验收：

- [x] `glIsEnabled` 区分 server capability 与按 client texture unit 隔离的 array enable。
- [x] `glGetBooleanv` 以逐字节 `GLboolean` 返回 owned/native 状态并事务提交 guest 输出。
- [x] `glGetPointerv` 返回 vertex/normal/color/texture-coordinate 保存的 guest pointer。
- [x] `glTexEnvf` 保留受检浮点值，不经整数路径丢失语义。
- [x] `glGetIntegerv` 覆盖 client-array descriptor 和 GLES1 blend source/destination alias。
- [x] 第二个 exact APK 越过上述入口并停在下一独立 client-array type 边界。
- [x] macOS/arm64 warnings-as-errors 构建及全量 CTest 436/436 通过。

非目标：本 WU 不实现 buffer lifecycle/readback、矩阵乘法、current normal 或 clip plane。
