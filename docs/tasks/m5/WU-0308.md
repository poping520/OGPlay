# WU-0308 · GLES1 buffer resources and readback

目标：闭合 legacy guest 的 buffer 生命周期、数据上传和 framebuffer readback 入口。

依赖：WU-0307、WU-0305、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] `glGenBuffers`/`glDeleteBuffers` 使用真实 ANGLE name，guest 数组先预检后提交。
- [x] 删除当前 array/element buffer 后同步转换器 transfer binding。
- [x] `glBufferData` 支持 nullable allocation，`glBufferSubData` 转发精确受检子区间。
- [x] 负 count/size/offset、坏 guest 范围、无 current frame 与 ANGLE 错误明确失败。
- [x] `glReadPixels` 服从当前 pack alignment，原生成功后才提交 guest 输出。
- [x] 定向测试执行真实 buffer subdata 与 RGBA readback；第二个 exact APK 无倒退。
- [x] macOS/arm64 warnings-as-errors 构建及全量 CTest 436/436 通过。

非目标：本 WU 不实现矩阵乘法、current normal、clip plane 或扩展 client-array type。
