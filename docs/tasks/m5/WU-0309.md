# WU-0309 · GLES1 matrix normal and clip planes

目标：闭合 legacy guest 的 current-matrix 右乘、current normal 与用户裁剪平面入口。

依赖：WU-0308、WU-0274、`src/runtime/integration/MODULE.md`。

验收：

- [x] `glMultMatrixf` 完整预检 16 个 guest float，并按 GLES1 规则右乘当前 matrix。
- [x] `glNormal3f` 保存有限 current normal，fixed vertex shader 在 normal array 禁用时消费。
- [x] `glClipPlanef` 验证六个标准 plane，并按调用时 modelview 的逆转置保存 eye equation。
- [x] 奇异 modelview、非有限 equation、非法 plane、坏 guest 范围与无 current frame 明确失败。
- [x] fixed shader 按六项 capability 执行真实 fragment clipping；`GL_MAX_CLIP_PLANES` 为 6。
- [x] ANGLE 行为测试证明启用恒负 plane 后三角形完全被裁剪，关闭时同一三角形可见。
- [x] Dungeon Hunter 目标 ELF 的 74 个 GL import 均有显式 handler，缺口为 0。
- [x] macOS/arm64 warnings-as-errors 构建及全量 CTest 437/437 通过。

非目标：本 WU 不扩展 client-array element type；真实 APK 当前后续边界仍为该独立能力。
