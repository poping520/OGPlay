# WU-0310 · GLES1 client-array 规范默认状态

目标：让 client-array descriptor 在 context 创建与 reset 后返回 GLES1 规范默认值，使通用状态保存/恢复闭环可执行。

依赖：WU-0307、WU-0309、runtime/integration 模块契约。

验收：

- [x] vertex/color/texture-coordinate array 默认 size 为 4、type 为 `GL_FLOAT`，normal array 默认 size 为 3、type 为 `GL_FLOAT`。
- [x] matrix-index/weight extension array 分别恢复 size 4 + `GL_UNSIGNED_BYTE` 与 size 4 + `GL_FLOAT`。
- [x] 所有 array 默认 stride/pointer/buffer 为 0、enable 为 false，并在 context reset 后一致恢复。
- [x] `glGetIntegerv` 可机器判定 vertex/texture-coordinate 默认 descriptor，不再返回非法零 type。
- [x] Dungeon Hunter bounded smoke 越过 client-array 恢复与全部 GL 初始化，明确推进至独立 JNI 缺口 `sendAppToBackground()V`。
- [x] macOS/arm64 ANGLE warnings-as-errors 构建与全量 CTest 通过。
