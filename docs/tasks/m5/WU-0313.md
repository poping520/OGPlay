# WU-0313 · guest process exit request

目标：把 legacy Java `process.exit` 实现为可查询的 OGPlay guest 会话退出请求，并由前端正常清理会话。

依赖：WU-0241、WU-0244、WU-0312、`src/runtime/integration/MODULE.md`、
`src/frontend/MODULE.md`。

验收：

- [x] `process.exit` handler 原子记录退出事实与请求次数，不直接终止宿主进程且不静默吞掉。
- [x] `AndroidGuestCallSession` 暴露退出请求，GLSurfaceView 帧循环观察请求后进入正常 teardown。
- [x] 单元测试验证 handler 调用前后状态迁移及精确请求计数。
- [x] 第二个 exact APK 的有界 smoke 越过 shutdown `process.exit` 并正常结束。
- [x] macOS/arm64 warnings-as-errors 构建与全量 CTest 通过。
