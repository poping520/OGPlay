# WU-0315 · explicit VFS working directory

目标：让 guest 相对文件路径从 Profile 显式声明的 VFS 工作目录安全解析。

依赖：WU-0301、WU-0302、WU-0314、`src/runtime/vfs/MODULE.md`、
`src/frontend/MODULE.md`。

验收：

- [x] LLDB 与目标 ELF 反汇编确认 guest fault 源于相对资源打开失败后的空对象解引用。
- [x] VFS 只在显式设置受检绝对工作目录后解析相对路径，继续拒绝 traversal。
- [x] Profile 以纯数据声明工作目录，前端在 guest 启动前注入，不含单资源或游戏分支。
- [x] 第二个 exact APK 越过 `RenderFX::Load` 空对象 guest fault，并推进到独立的 guest
  call tick-budget 边界。
- [x] macOS/arm64 warnings-as-errors 构建与全量 CTest 通过。
