# WU-0317 · declarative guest-call budget

目标：允许精确 Title Profile 以受限纯数据声明单次 guest 调用预算。

依赖：WU-0316、`src/session/MODULE.md`、`src/runtime/execution/MODULE.md`。

验收：

- [x] 未声明 Profile 保持 200,000,000 tick 默认值。
- [x] schema、Python validator 与 C++ loader 同步接受 1..1,000,000,000。
- [x] 零、超限、未知和非整数值明确失败，不发布未受限预算。
- [x] 强类型 Profile runtime 向前端提供唯一预算事实，不引入游戏身份分支。
