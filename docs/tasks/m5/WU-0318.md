# WU-0318 · exact Profile loading-call budget

目标：让第二个 exact Profile 以实测受限预算越过首次 PVRTC 加载调用。

依赖：WU-0317、`src/frontend/MODULE.md`、`src/runtime/execution/MODULE.md`。

验收：

- [x] `run-apk` 对两种已支持生命周期均只消费 Profile 的强类型预算事实。
- [x] 第二个 exact Profile 纯数据声明 1,000,000,000 tick，其他 Profile 保持默认值。
- [x] Windows/MSVC warnings-as-errors 与 focused CTest 13/13 通过；full CTest 439/441，
  两项失败分别为 ANGLE D3D11 ETC1 枚举拒绝和 Windows 反斜杠 VFS fixture，均与本 WU
  无关且有精确错误记录。
- [x] exact APK 单帧以退出码 0 返回并提交 1 frame，证明 2 亿边界属于有限加载工作量
  而非自旋。
- [x] 120 帧有界 smoke 已越过加载预算边界并明确失败于未注册 handler
  `audio.load_movie`；未宣称达到 120 帧或完成 readback。
