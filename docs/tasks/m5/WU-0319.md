# WU-0319 · queryable legacy movie request

目标：把 legacy `loadMovie(String)` 转换为受检、可查询的异步电影请求。

依赖：WU-0318、`src/runtime/integration/MODULE.md`、`src/runtime/jni/MODULE.md`。

验收：

- [x] handler 从统一 JNI environment/string store 解析精确 UTF-16 名称。
- [x] 请求按线程安全递增序号保存；null、未知或超过 4096 code unit 明确失败且不提交。
- [x] 会话公开最新请求供宿主消费，不把“请求已发布”伪装为视频已经播放。
- [x] Windows/MSVC warnings-as-errors 与 focused CTest 5/5 通过；full CTest 440/442，
  仅保留 ANGLE D3D11 ETC1 枚举拒绝和 Windows 反斜杠 VFS fixture 两项独立既有失败。
- [x] exact APK 不再停在 `audio.load_movie` missing-handler；后续边界有明确记录。
