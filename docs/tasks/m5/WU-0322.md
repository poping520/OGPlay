# WU-0322 · A32 guest call 有界切片 observer

目标：让长 A32 guest call 在不改变总 tick 预算的前提下发布确定性切片进度。

依赖：WU-0321、`src/runtime/execution/MODULE.md`。

验收：

- [x] 单次 CPU Run 不超过 500 万 tick，剩余预算继续受原总上限约束。
- [x] 只有需要继续 guest call 时才在 slice 边界调用显式 observer。
- [x] 返回值、累计 tick、return trap 与预算耗尽语义保持不变。
- [x] Windows/MSVC warnings-as-errors 与 focused CTest 通过。
- [x] full CTest 441/443；失败仅为独立既有 ETC1 参数与 VFS 大小写目录树用例。

非目标：本 WU 不接入 SDL；前端 observer 接线由后续独立 WU 完成。
