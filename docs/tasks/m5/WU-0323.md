# WU-0323 · 非消费式宿主窗口 event pump

目标：允许主线程长任务处理 SDL 宿主消息而不消费待轮询输入事件。

依赖：WU-0322、`src/hal/MODULE.md`。

验收：

- [x] `PumpEvents` 只泵宿主消息，规范输入仍由 `PollEvents` 取出。
- [x] 关闭窗口上调用明确失败，打开窗口可重复调用。
- [x] Windows/MSVC warnings-as-errors、focused CTest 通过；full CTest 441/443，失败仅为
  独立既有 ETC1 参数与 VFS 大小写目录树用例。

非目标：本 WU 不把 event pump 接入 guest observer；前端接线由下一 WU 完成。
