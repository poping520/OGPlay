# WU-0324 · GLSurfaceView 长 guest call 窗口响应

目标：在 GLSurfaceView 长 guest call 的 A32 slice 边界泵宿主窗口消息。

依赖：WU-0322、WU-0323、`src/runtime/integration/MODULE.md`、`src/frontend/MODULE.md`。

验收：

- [x] Android guest session 把上层 observer 传给每次通用 A32 guest call。
- [x] `run-apk` observer 只调用非消费式 `WindowInput::PumpEvents`。
- [x] observer 不消费输入、不 present 半帧、不推进 guest Clock。
- [x] exact APK 长帧期间多次现场采样均为 `Responding=True` 且 CPU 持续增长，进程随后自退。
- [x] Windows/MSVC warnings-as-errors、focused CTest 通过；full CTest 441/443，失败仅为
  独立既有 ETC1 参数与 VFS 大小写目录树用例。
