目标：在保持 Windows 窗口响应上界时降低 Dynarmic guest-call 切片重入次数。

依赖：WU-0324、`src/runtime/execution/MODULE.md`。

验收：

- [x] slice 上限从 500 万调整为 2000 万 tick，原总预算与返回语义不变。

- [x] exact APK 长帧保持 `Responding=True`；80 帧 122.645 秒、退出码 0，较 500 万 tick
  超过 240 秒的基线至少减半。

  独立既有 ETC1 参数与 VFS 大小写目录树用例。
