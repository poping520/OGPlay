# WU-0328 · MCP protocol and latest-frame capture

目标：建立传输无关的 MCP 最小协议，并把最近一次已呈现 guest frame 作为只读 PNG 工具返回。

依赖：WU-0327、`src/agent/MODULE.md`、`docs/roadmap/10-ai-automation-testing.md`。

验收：

- [x] initialize/ping/tools/list/tools/call 返回受检 JSON-RPC，notification 不伪造 response。
- [x] `frame_capture` 返回标准 MCP `image/png` content 与精确 sequence/width/height。
- [x] 无帧、非法帧、未知工具和畸形请求明确失败。
- [x] 最新帧以移动所有权交换，截图只在调用时复制与编码，不改变 guest 或 input 状态。
- [x] Windows/MSVC warnings-as-errors 构建与 focused CTest 5/5 通过；full CTest 446/448，
  失败仅为进入本 WU 前已存在的 ETC1 参数和 VFS 大小写目录树用例。
