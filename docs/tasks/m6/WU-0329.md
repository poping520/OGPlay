# WU-0329 · Loopback MCP Streamable HTTP transport

目标：为传输无关的 MCP adapter 增加仅监听本机回环地址的有界 Streamable HTTP 入口。

依赖：WU-0328、`src/frontend/MODULE.md`、MCP Streamable HTTP 规范。

验收：

- [x] server 只绑定 `127.0.0.1`，endpoint 固定为 `/mcp`，端口 0 可用于测试临时端口。
- [x] JSON POST 返回 MCP JSON-RPC response；notification 返回 202 且无伪 response。
- [x] 非 loopback Origin、错误 route/method/media type、chunked 与超限 body 明确失败。
- [x] 真实 loopback HTTP 测试可取得最新 frame 的 PNG ImageContent 与元数据。
- [x] Windows/MSVC warnings-as-errors 构建与 focused CTest 4/4 通过；full CTest 449/451，
  失败仅为进入本 WU 前已存在的 ETC1 参数和 VFS 大小写目录树用例。

非目标：本 WU 不修改 `run-apk` 参数，不发布 guest frame。`--mcp-port` 与帧循环接线由
WU-0330 完成。
