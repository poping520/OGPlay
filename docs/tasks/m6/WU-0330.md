# WU-0330 · Optional run-apk MCP and presented-frame publication

目标：让 `run-apk` 可选启动 loopback MCP，并把已成功呈现的最新 guest frame 发布给
`frame_capture`。

依赖：WU-0328、WU-0329、`src/frontend/MODULE.md`、精确 Asphalt 5 Profile。

验收：

- [x] `--mcp-port <1..65535>` 完整受检、最多一次、默认关闭，且拒绝与 `--preflight` 组合。
- [x] 服务在 guest 交互运行前绑定 `127.0.0.1`，stdout 报告精确 `/mcp` endpoint。
- [x] 只发布成功 present 的帧；替换和 shutdown 均把 RGBA8 buffer 交还原 guest session。
- [x] 指定 Asphalt 5 exact APK 经真实 MCP initialize/tools/call 取得 800×480 PNG，
  sequence=2，视觉检查为正常 Gameloft 启动画面；`--exit-after-frames 2` 退出码为 0。
- [x] Windows/MSVC warnings-as-errors Debug/Release 构建与 focused CTest 9/9 通过；full CTest
  449/451，失败仅为进入本 WU 前已存在的 ETC1 参数和 VFS 大小写目录树用例。

非目标：本 WU 不增加输入、step/until 或场景断言工具，也不自动修改用户的 Codex MCP
配置；这些能力按 M6 后续工作单继续拆分。
