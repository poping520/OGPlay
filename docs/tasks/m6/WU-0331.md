# WU-0331 · Cross-backend ETC1 upload fallback

目标：在 ANGLE 后端未发布 ETC1 扩展时，仍以 Khronos 规范解码器闭合 GLES1 ETC1 texture
上传，而不把原生 `GL_INVALID_ENUM` 误报为 guest 参数错误。

依赖：WU-0273、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`、Khronos
`OES_compressed_ETC1_RGB8_texture` 规范。

验收：

- [x] individual/differential base color、flip、selector/modifier 与边缘部分块按规范解码。
- [x] 压缩长度、零尺寸和越界 differential color 明确失败。
- [x] ANGLE 原生 ETC1、ANGLE lossy ETC1、宿主 RGBA8 fallback 按顺序选择；其他格式不变。
- [x] Windows D3D11 原失败的 GLES1 boundary 用例通过；focused CTest 5/5。
- [x] 指定 Asphalt 5 exact APK Release 2 帧 smoke 退出码 0；full CTest 454/454。

非目标：本 WU 不声明 ETC2/EAC、ATC、PVRTC 或 S3TC 软件解码能力。
