# WU-0332 · Portable VFS host-mount transaction fixture

目标：用三平台都能实际构造的大小写折叠冲突，验证 host-directory mount 失败时不发布
任何部分结果。

依赖：WU-0301、`src/runtime/vfs/MODULE.md`。

验收：

- [x] host tree 与已有 guest path 的 ASCII 大小写折叠冲突明确失败。
- [x] 冲突前已有文件保持不变，冲突事务中的其他 host file 不可见。
- [x] symlink（宿主支持时）和空目录拒绝路径保持覆盖。
- [x] 测试不再依赖 Windows 会解释为目录分隔符的反斜杠文件名。
- [x] focused CTest 5/5；Windows full CTest 454/454。

非目标：生产 VFS 事务实现未发现缺陷，本 WU 不改变路径语义或宿主文件写回策略。
