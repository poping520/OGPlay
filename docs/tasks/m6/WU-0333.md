# WU-0333 · yyjson core foundation

目标：引入固定版本 yyjson，并提供唯一的严格 JSON 解析与构造基础设施。

依赖：ADR-0007、`src/core/MODULE.md`。

验收：

- [x] yyjson 0.12.0 以固定 git submodule 接入构建，缺失时配置阶段明确失败。
- [x] `JsonDocument` 以 RAII 保有解析树，默认限制 1 MiB、64 层，并拒绝语法错误与重复键。
- [x] `JsonWriter` 覆盖 null/bool/signed/unsigned/real/string/object/array 和受检树复制。
- [x] UTF-8、嵌入 NUL、精确 `uint64_t`、边界限制、转义、往返及重复输出键均有机器测试。
- [x] Windows/MSVC warnings-as-errors 构建与相关 focused CTest 31/31 通过。

非目标：不向模块暴露 yyjson 原生指针，也不引入 DOM 式业务模型或 JSON Schema 引擎；
配置/代码生成阶段的 CMake `string(JSON)` 与 Python 标准库不能依赖尚未构建的 C 库，保持
宿主原生解析器，不属于 C++ 生产运行时 JSON 边界。
