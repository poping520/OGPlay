# WU-0334 · MCP strict JSON migration

目标：让 MCP adapter 的所有 JSON-RPC 解析与响应构造统一经过 core yyjson 契约。

依赖：WU-0328、WU-0329、WU-0333、`src/agent/MODULE.md`。

验收：

- [x] initialize、ping、tools/list、tools/call 不再扫描字符串或手写 JSON。
- [x] JSON-RPC envelope、id、initialize client 信息与工具参数按所属对象严格读取。
- [x] 语法错误返回 -32700；重复键、超限、非法 envelope 返回 -32600；非法参数返回 -32602。
- [x] `frame_capture` 声明 input/output schema，并保留 ImageContent 与结构化帧元数据。
- [x] MCP adapter 与真实 loopback HTTP transport 回归测试通过。

非目标：不增加新 MCP transport、鉴权、输入或 guest 推进工具。
