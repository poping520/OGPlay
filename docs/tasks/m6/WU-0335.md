目标：清除剩余生产代码手写 JSON，使 Control Service、JSON-RPC、日志与诊断包统一走
core yyjson。

依赖：WU-0333、`src/core/MODULE.md`、`src/agent/MODULE.md`。

- [x] Control Service 的 session/GPU/HLE/log 响应由强类型 writer 构造。

- [x] core/agent/HTTP 相关 focused CTest 31/31、Windows full CTest 460/460 通过。

非目标：不改变 Control Service 方法集合、日志字段模型或诊断包目录布局。
