# WU-0336 · 失败清理的 futex sticky interruption

目标：让 Android guest 调用失败后可显式中断当前及未来的 futex wait，避免生命周期清理
永久阻塞宿主线程。

依赖：WU-0321、WU-0324、`src/cpu/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] `FutexTable::InterruptAll` 唤醒当前 waiter，并使之后的匹配等待立即返回 interrupted。
- [x] 普通 value mismatch 与 WAKE N 语义不变；sticky interruption 后 WAKE 不伪造成功。
- [x] Android syscall 将 interruption 映射为 Linux `-EINTR`，guest call session 发布显式入口。
- [x] focused futex/syscall CTest 与 Windows warnings-as-errors 构建通过。

非目标：不实现 futex timeout、信号系统或可复位中断。
