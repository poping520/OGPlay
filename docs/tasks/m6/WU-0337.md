# WU-0337 · Profile 失败清理

目标：Profile guest phase 失败时先中断阻塞等待并保留原始调用错误，使清理保持有界。

依赖：WU-0336、`src/session/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] startup/frame/suspend/resume 任一 guest phase 失败均先发布 wait interruption，再进入清理。
- [x] shutdown/finalizer 等清理错误不覆盖原始 native call 错误，surface 仍按既定顺序关闭。
- [x] exact Asphalt 5 失败复现不再显示“未响应”，而是明确上报第三次 `nativeRender` 的
  2 亿 tick exhaustion；focused lifecycle CTest 通过。

非目标：不改变 guest call tick budget 或错误诊断格式。
