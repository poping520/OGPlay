# WU-0339 · PowerVR 官方 PVRTC 解码器接入

目标：原样 vendor PowerVR Native SDK 的 MIT `PVRTDecompress.cpp/.h`，以薄适配层向 OGPlay
提供受检 PVRTC1 2bpp/4bpp RGBA8 解码，不维护自写解码算法。

依赖：WU-0331、WU-0338、`src/gles/MODULE.md`。

验收：

- [x] 上游文件固定到 commit `2b1bf2f14d3365d0bb801e2a6a131a319d3a2e48`，源码、头文件
  与 MIT license 原样入库，SHA-256 记录且复核一致。
- [x] 上游源码在独立 CMake target 编译，不受 OGPlay adapter 修改。
- [x] adapter 只负责尺寸/长度/溢出校验、对齐输入、输出分配、RGB alpha 修正和返回值检查。
- [x] 2bpp/4bpp、透明度、非法输入及非均匀 twiddled word 黄金哈希 focused CTest 3/3 通过。

非目标：不自行移植或修改 PVRTC 算法，不支持 PVRTC2 或离线纹理转码。
