# WU-0340 · PVRTC fallback 与 exact-frame 验证

目标：ANGLE 缺少 PVRTC 时接入官方 decoder 的 RGBA8 上传，并通过 MCP 实时帧验证 exact
Asphalt 5 纹理清晰且渲染有界。

依赖：WU-0339、WU-0328、WU-0330、`src/gles/MODULE.md`。

验收：

- [x] ANGLE 原生 `GL_IMG_texture_compression_pvrtc` 优先；缺失时才调用官方软件 decoder。
- [x] 仅因 fallback 真实可用才向 guest 发布扩展，未知压缩格式继续明确失败。
- [x] MCP `frame_capture` 取得 sequence 686、800×480 PNG；Logo、车身和背景纹理清晰，
  无旧版自写解码器产生的周期条带、重影和错误插值。
- [x] Release exact APK 300 帧、15.058 秒正常退出，exit code 0；Windows full CTest
  464/464 通过。

非目标：不按标题提高 tick budget，不以桌面窗口截图替代 MCP 原始呈现帧。
