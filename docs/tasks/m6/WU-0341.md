# WU-0341 · MCP click 协议与有界输入队列

目标：为 MCP 增加严格 `click{x,y}` 工具，把最近 guest frame 内的一次主指针点击排入有界
线程安全队列，而不让网络线程直接调用 guest。

依赖：WU-0328、WU-0334、WU-0340、`src/agent/MODULE.md`。

验收：

- [x] `tools/list` 发布完整 click input/output schema，标记非只读、非幂等、非 open-world。
- [x] 坐标只接受最近 frame 内的非负整数 guest 像素；无帧、越界、缺失/额外字段明确失败。
- [x] 队列最多保留 64 个 click；每项 down/up 使用同一 request sequence 并按连续 take 输出。
- [x] agent focused CTest 6/6 与 Windows warnings-as-errors 构建通过。

非目标：本 WU 不接 guest loop、不实现 drag/多点/按住或窗口坐标换算。
