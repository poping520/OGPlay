# WU-0342 · MCP click loopback HTTP 接线

目标：让 loopback MCP HTTP server 接受调用方 click queue，并以真实 POST 验证协议结果抵达
同一个有界队列。

依赖：WU-0341、WU-0329、`src/frontend/MODULE.md`。

验收：

- [x] `McpHttpServer::Start` 要求 frame store 与 input queue，worker 只委托协议 adapter。
- [x] 真实 `tools/call click` 返回 request/frame sequence 与坐标，down/up 可从同一队列取出。
- [x] 原有 loopback、Origin、route、method、media type 与 body 限制保持不变。
- [x] frontend MCP HTTP focused CTest 3/3 通过。

非目标：本 WU 不消费 click、不调用 guest lifecycle，也不定义桌面鼠标互斥。
