# WU-0345 · MCP JPEG/压缩 PNG 截图

目标：让 `frame_capture` 缺省返回 quality 85 JPEG，并按严格 `format` 参数返回 JPEG 或
压缩 PNG，消除 stored-block PNG 的近原始帧体积。

依赖：WU-0344、WU-0334、WU-0330、`src/agent/MODULE.md`。

验收：

- [x] input schema 仅接受可选 `format: "jpeg" | "png"`，缺省为 `jpeg`；错误类型、值、
  未知字段和多余字段明确返回 tool error。
- [x] output schema、structured content 与 ImageContent MIME 精确报告实际格式。
- [x] 800×480 合成帧测试 JPEG/PNG signature、尺寸和显著压缩，PNG 可由 SDL 解码。
- [x] Asphalt 5 Release exact MCP：默认 JPEG sequence 483 为 82,349 字节，显式 PNG
  sequence 484 为 790,327 字节；二者均为 800×480，进程在请求后保持运行。
- [x] MCP focused CTest 15/15、Windows/MSVC full CTest 470/470 与 `git diff --check` 通过。

非目标：不增加 quality、缩放、裁剪、增量帧、WebP 或客户端缓存参数。
