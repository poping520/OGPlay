# WU-0348 · MCP 截图坐标网格

目标：为 `frame_capture` 增加不污染实时帧的可选 guest 像素坐标网格，辅助 AI 计算点击坐标。

依赖：WU-0345、WU-0347。

验收：

- [x] `overlay: "coordinates"` 在原尺寸截图副本上绘制每 100 px 主线、每 25 px 边缘刻度
  及顶部/左侧坐标标签；默认/缺省时不绘制。
- [x] `tools/list` 声明严格 overlay 输入与输出 schema，响应返回 `none` 或 `coordinates`；
  未知字段和非法值明确失败。
- [x] 像素级测试覆盖主线、边缘刻度、未覆盖区域和 alpha，协议测试证明 guest 帧不被修改。
- [x] Asphalt 5 exact APK 的 800×480 MCP JPEG 截图可读（93,136 字节），且 full Windows
  CTest 472/472 通过。

非目标：不做 UI 元素识别、OCR、语义坐标、点击热区推断或连续视频标注。
