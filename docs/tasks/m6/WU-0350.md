# WU-0350 · MCP 确定性手势队列

目标：把 MCP click 队列泛化为可逐 guest step 派发 down/move/up 的有界确定性手势队列。

依赖：WU-0343。

验收：

- [x] click 仍按连续 guest loop step 输出 down/up，既有行为不变。
- [x] swipe 按 1..120 个 motion 步数进行整数线性插值，精确包含起点和终点，最后独立 up。
- [x] click 与 swipe 共用 64 个待处理手势的 FIFO，并保持同一请求序号和起始帧序号。
- [x] 前端 dispatcher 保真生成 pointer button/motion，活动期间继续与桌面鼠标互斥。
- [x] focused agent/frontend CTest 5/5 与 warnings-as-errors 构建通过。

非目标：本 WU 不发布 MCP `swipe` tool schema，不按宿主毫秒计时，不实现多点触控。
