# WU-0351 · MCP swipe 工具协议

目标：发布严格、有界且可由 AI 复现的 MCP `swipe` 工具，接入确定性手势队列。

依赖：WU-0350、WU-0348。

验收：

- [x] `tools/list` 声明必填 `startX/startY/endX/endY/steps`、整数类型、1..120 步和禁止
  未知字段的 input/output schema。
- [x] 两个端点按最新 guest 帧验证且必须不同；无帧、未接输入、负数、越界、零/超限步数、
  缺字段、未知字段和队列满均返回显式 tool error。
- [x] 成功响应返回 request/frame sequence、端点与步数；loopback HTTP 使用同一队列。
- [x] focused MCP protocol/HTTP CTest 4/4 与 warnings-as-errors 构建通过。
- [x] Asphalt 5 exact APK 在 800×480 guest 帧执行 `(100,450)→(700,450)` 12 步 swipe，
  frame 500→518 且进程持续响应；full CTest 476/476 通过。

非目标：不按宿主毫秒控制速度，不实现拖放保持、多点触控、手势识别或 UI 语义定位。
