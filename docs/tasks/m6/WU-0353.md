# WU-0353 · exact-APK 场景与 checkpoint schema

目标：冻结 exact-APK 自动化场景的身份、fixture、全局预算和有界 checkpoint 纯数据契约，
并提供严格目录校验与自检。

依赖：WU-0352、WU-0333、`docs/roadmap/10-ai-automation-testing.md`。

验收：

- [x] Scenario v1 只接受精确 Profile 身份、逻辑 fixture id、完整全局预算和至少一个
  checkpoint；APK、外部数据和测试机绝对路径不得进入场景。
- [x] 每个 checkpoint 都有唯一 id、受限 provider、frame/tick/wall-time 上限和非空证据类型；
  所有局部最坏预算与 startup 预算之和不得超过场景总预算。
- [x] 校验器拒绝未知字段、重复 id、无匹配 Profile、缺 APK fixture、无界或越界预算、空
  checkpoint、非法证据、超长文件和畸形 TOML。
- [x] JSON Schema 与 Python 校验器的根字段、版本、枚举和限制保持机器核对；self-test 与
  当前场景目录均接入 CTest。
- [x] macOS-arm64 warnings-as-errors 构建、focused CTest 24/24、全量 CTest 478/478 与
  `git diff --check` 通过。

非目标：本 WU 不实现 action/assertion/result C++ 模型、Profile-backed runner、guest 推进、
输入执行、黄金帧比较或首个 exact-title 场景。
