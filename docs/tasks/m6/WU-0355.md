# WU-0355 · action/assertion/result 强类型契约

目标：为 Scenario v1 增加 closed-enum action/assertion，并冻结 AI/CI 共用的稳定结果模型。

依赖：WU-0353、WU-0354。

验收：

- [x] action 严格区分 step/click/swipe/suspend/resume/shutdown 载荷，未知、缺失、额外或越界
  参数明确失败。
- [x] assertion 严格区分 frame/movie_request/lifecycle/process_exit/no_guest_fault 期望，禁止
  自由表达式和未知状态。
- [x] 强类型模型只能从已验证 Scenario 构造，结果稳定包含 checkpoint frame/tick/wall-time、
  逐断言实测、首个失败、证据引用和 shutdown 清理状态。
- [x] Scenario/Result JSON Schema 与模型枚举、根字段和版本保持机器自检。
- [x] focused tests 3/3、macOS-arm64 warnings-as-errors build、full CTest 479/479 与
  `git diff --check` 通过。

非目标：不执行 guest、不打开 MCP、不中转 fixture 路径，也不实现 checkpoint provider。
