# WU-0356 · 确定性 MCP session 控制面

目标：为 MCP 建立不直接调用 guest 的原子状态快照与有界 step/lifecycle/shutdown 命令面。

依赖：WU-0355。

验收：

- [x] `McpSessionControl` 在线程安全边界发布 lifecycle/frame/ticks/presented-frame/movie/
  process-exit/guest-fault/shutdown 原子快照。
- [x] step、suspend、resume、shutdown 进入最多 64 项 FIFO；step 严格限制 1..1,000,000 帧，
  响应稳定返回请求序号与 frame 范围。
- [x] MCP 发布 `session_state`、`step`、`lifecycle`、`shutdown` 的 closed input/output schema；
  未接控制面、未知/缺失/额外/越界参数和满队列明确失败。
- [x] 控制面只跨线程传递纯数据，网络 worker 不直接调用 lifecycle/guest/window。
- [x] focused tests 6/6、macOS-arm64 warnings-as-errors build、full CTest 482/482 与
  `git diff --check` 通过。

非目标：本 WU 不修改 `run-apk` guest loop，不启动 exact APK，也不执行 Scenario。
