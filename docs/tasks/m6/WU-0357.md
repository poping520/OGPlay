# WU-0357 · `run-apk` MCP 手动步进会话

目标：让 GLSurfaceView exact guest 主循环消费 MCP session 命令并发布统一原子状态。

依赖：WU-0356。

验收：

- [x] `--mcp-manual-step` 必须显式组合 MCP transport，仅支持 `gl_surface_view` Profile，
  且在 APK I/O 前严格拒绝缺 transport、重复或 preflight 冲突。
- [x] 手动模式启动后不自行推进 guest；step 帧许可由 guest 主线程逐帧消费，输入仍在正常
  lifecycle frame 边界派发，普通交互模式保持原行为。
- [x] suspend/resume/shutdown 只由 guest 主线程执行；隐藏 SDL3/ANGLE 窗口仍走同一
  bootstrap、Profile lifecycle、present、audio 与 teardown 路径。
- [x] 每次启动、命令转移和完成帧发布 lifecycle/frame/ticks/presented-frame/movie/exit/fault
  原子快照；guest fault 在手动模式保持可查询直到 shutdown，并最终以非零退出报告。
- [x] loopback HTTP 与 CLI option focused tests 7/7、macOS-arm64 warnings-as-errors build、
  full CTest 483/483 与 `git diff --check` 通过；Asphalt 5 exact 冒烟从 frame/ticks 0/0 由
  step(1) 精确到 1/1000，suspend/resume 后正常 shutdown、进程退出 0。

非目标：本 WU 不解析 Scenario、不写证据、不增加 Profile 或标题分支。
