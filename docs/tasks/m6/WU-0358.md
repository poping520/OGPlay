# WU-0358 · Scenario runner、断言、证据与清理闭环

目标：让 AI 与 CI 通过同一 Python runner 有界执行 Scenario v1 并稳定产出 Result v1。

依赖：WU-0357。

验收：

- [x] runner 只从严格验证后的强类型计划执行；required logical fixture 必须由 `ID=PATH`
  完整映射，结果和场景不写宿主路径。
- [x] 以独立 loopback 端口启动同一 `run-apk --mcp-manual-step` exact Profile 会话；startup、
  checkpoint、total 的 frame/tick/wall-time 预算均实时门禁。
- [x] step/click/swipe/suspend/resume/shutdown action 与 frame/movie/lifecycle/process-exit/
  no-guest-fault assertion 机器判定；未满足断言只在 running 状态逐帧推进直到有界终止。
- [x] Result v1 稳定记录逐断言 expected/actual、首个失败、frame/ticks/wall time；frame/state/
  logs 证据使用相对引用，当前不可用的 gpu_trace 明确失败。
- [x] 成功、断言失败、预算失败和异常路径均请求正常 shutdown；仅对自己启动且超时的子进程
  执行 terminate/kill，并把非零退出或强制清理记入结果。
- [x] happy/failure fake-MCP focused tests 6/6、macOS-arm64 warnings-as-errors build、full
  CTest 484/484 与 `git diff --check` 通过。

非目标：本 WU 不提交具体标题场景，不实现 OBB 或 GPU trace MCP 工具。
