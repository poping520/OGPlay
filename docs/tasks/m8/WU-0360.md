# WU-0360 · Asphalt 6 exact 身份与静态能力矩阵

目标：为 Asphalt 6 v1.3.2 建立纯数据 exact Profile，冻结静态能力矩阵，并让
APK basename 与根 SONAME 不同的合法入口通过通用 Bionic 预检。

依赖：WU-0359、M6 Scenario runner、`src/session/MODULE.md`、
`src/runtime/integration/MODULE.md`、`src/gles/MODULE.md`。

静态矩阵：

- Manifest：package `com.gameloft.android.GAND.GloftAPHP`、versionCode `132`、
  minSdk `8`、landscape GLSurfaceView Activity。
- APK 入口：`lib/armeabi-v7a/libasphalt6.so`，SHA-256
  `567a0caf773f8edcc2f81e8fc8b6437b1664cbc22514c22e3019b6f8550377a7`。
- ELF：273 个唯一未定义导入，其中 GL/EGL 96 个、pthread 30 个；需要
  `libGLESv1_CM.so` / `libGLESv2.so` / `libdl.so` / `liblog.so` /
  `libstdc++.so` / `libm.so` / `libc.so`。
- JNI：57 个已定义 `Java_*` 入口；主路径类为 `GLUtils/Device`、`GLGame`、
  `GLResLoader`、`GLMediaPlayer`、`GameRenderer` 和 `GameGLSurfaceView`。
- payload：本地 `files/` 共 972 个文件、约 1.0 GiB；`InsTime`、
  `file000000.dat` 与 `intro.mp4` 可作为根目录/完整性探针。

验收：

- [x] Profile 仅保存精确身份、通用 GLSurfaceView 生命周期、声明式 native call、
  单一 external mount 和 payload manifest，不保存宿主路径或标题分支。
- [x] `tools/validate_title_profiles.py` 与 profile 目录 CTest 通过。
- [x] 当前 `ogplay run-apk --preflight` 唯一匹配 APK 入口，并完成 API 19
  Bionic/边界库映射与重定位；不把 preflight 伪作已执行 guest。
- [x] Bionic module set 保留 APK 根 basename 且接受其不同 SONAME 别名；依赖库
  来源与 SONAME 不一致仍明确失败。
- [x] 后续缺口按 M8 索引的 JNI/Java、GLES2、线程/VFS、媒体批次建账，
  不为单个缺失函数创建 WU。
- [x] warnings-as-errors build、focused tests、full CTest 485/485、capabilities/CURRENT 与
  `git diff --check` 通过。

非目标：本 WU 不声称 A6 已启动或出画，不实现新 JNI/GLES/音频语义，
不提交 APK、payload、反编译产物或运行证据。
