# WU-0361 · Asphalt 6 有界启动采样与缺口矩阵

目标：用 Scenario runner 对 exact Asphalt 6 和 external payload 做一次有界启动采样，
将静态与动态缺口合并为可批量实现的能力组。

依赖：WU-0360、M6 Scenario runner、exact APK、API 19 ARMv7 Bionic fixture 和
Asphalt 6 `files/` payload。

验收：

- [x] 场景只提交 exact Profile 身份及 `asphalt6.apk` / `asphalt6.external` 逻辑
  fixture，不含宿主路径、APK、payload 或反编译产物。
- [x] 有界启动采样保存 result/stdout/stderr，能在首帧成功或首个真实失败处
  确定停止，并正常 shutdown 或清理自己启动的进程。
- [x] 以 ELF/DEX/JNI 静态清单与运行采样交叉建立缺口矩阵，按 JNI/Java、
  GLES2/RTT、线程/VFS、媒体四组排序，不为单个函数新建 WU。
- [x] Scenario validator/model/runner focused tests、warnings-as-errors build、full CTest、
  capabilities/CURRENT 与 `git diff --check` 通过。

非目标：本 WU 不声称已进入主菜单，不以帧数推进伪作 UI 成功，
不把宿主证据或受版权保护的 fixture 提交入库。

采样结果：启动在第 0 帧、第 1 个 Profile native call
`GLUtils/Device.nativeInit` 内明确失败，首缺口是已调用但未声明的
`Device.a()[B`；进程退出 1，runner 保留 Result 与两路日志，没有将失败
伪作 clean shutdown。

聚合缺口矩阵：

| 批次 | 静态清单 | 当前结论 |
| --- | ---: | --- |
| JNI/Java | 5 个回调类、76 个精确 method descriptor | Device 8、GameRenderer 4、GLGame 18、GLMediaPlayer 41、GLResLoader 5；必须按设备/活动、音频、资源三族批量声明并绑定，不只补 `a()[B` |
| GLES2/RTT | 96 个 GL 导入 | 当前 GLES2 路径明确处理 41 个，静态差集 55 个；按 state/resource+FBO/query+uniform/draw 子批次闭合 |
| 线程/VFS | 30 个 pthread 导入、972 个 payload 文件 | 真宿主 clone 线程和 external mount 已有通用基础；缺少在声明式生命周期中把 working directory 传给 `nativeGetSDFolder(String)` |
| 媒体 | GLMediaPlayer 41 + GLResLoader 数字音频 2 | 复用现有 Ogg/SoundPool/mixer，批量增加 music/emitter 类型语义和 `raw_NNN.ogg` 资源查找；不伪造网络/商店成功 |

GLES2 静态差集已从 exact ELF 导入与当前显式 dispatch 交叉生成；
`glEnableClientState` / `glLoadIdentity` / `glMatrixMode` / `glShadeModel` 由同一 ELF
同时链接 GLES1 带入，动态采样将决定它们是否进入 GLES2 批次，不以
静态出现直接猜测调用。

验证：Scenario validator/model/runner focused 3/3，`cmake --preset dev`、
warnings-as-errors build、full CTest 485/485 与 capability 单调门禁通过。
