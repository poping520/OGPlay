# WU-0362 · 通用设备、Activity 与键盘 Java 回调批次

目标：一次闭合 Asphalt 6 启动所查询的 Device、GLGame 平台与
GameRenderer 键盘回调族，用通用可查询状态和明确离线失败代替空 stub。

依赖：WU-0361 聚合缺口矩阵、runtime/integration 契约、exact DEX method
descriptor 清单。

验收：

- [x] Profile 批量声明 Device 8、GLGame 18、GameRenderer 4 个精确静态方法，
  只引用通用 implementation id。
- [x] 设备身份、版本、主机名、运营商、Wi-Fi/网络与旧固件查询返回
  注入或确定性离线事实；唯一码、fully-loaded、background 和键盘/交换请求可查询。
- [x] 浏览器、商店、付费、GLive/IGP 与 trophy 回调在无宿主实现时明确失败，
  不静默 no-op，`process.exit` 继续走已有可查询退出请求。
- [x] focused 行为测试、warnings-as-errors build、exact bootstrap Scenario 新采样、
  full CTest、MODULE/CURRENT 与 `git diff --check` 通过。

非目标：不实现资源/音频回调，不打开宿主浏览器或支付页，
不伪造网络成功，不固化标题专属实现。
