# WU-0363 · Asphalt 6 资源与 Java 媒体回调批次

目标：一次闭合 native bootstrap 缓存的 GLResLoader 5 项与 GLMediaPlayer 41 项
精确回调，以通用 APK asset、编号音频资源和可查询 Java 兼容状态替代逐项补洞。

依赖：WU-0362、exact DEX/ELF descriptor 清单、Profile VFS/direct-asset 与
SoundPool 编号资源契约。

验收：

- [x] Profile 声明完整 5 + 41 descriptor、APK `raw_NNN.ogg` 模式及三项 direct-asset
  implementation，保持纯数据、少于 200 行。
- [x] 字符串资源走 `/apk/assets` 受检 VFS；编号音频资源返回真实 APK 字节/长度，
  缺失、负编号、空资源和过大资源明确失败。
- [x] Java 原版 no-op/固定返回媒体语义有逐方法调用计数，音量状态可查询；电影请求
  延续已有 UTF-16 状态，不宣称宿主播放或伪造音频成功。
- [x] focused 测试、warnings-as-errors build、exact bootstrap 新采样、full CTest、
  MODULE/CURRENT 与 `git diff --check` 通过。

非目标：本 WU 不扩展 Profile native string 参数，不实现 Android AudioTrack，
不针对单个资源名或标题写生产分支。
