# WU-0364 · JNI guest modified UTF-8 字符串槽批次

目标：一次闭合 guest JNI modified UTF-8 字符串访问族，使真实 native 代码获得
有界 guest 指针、精确长度、region 与配对 release，而非只补一个 trap。

依赖：WU-0363、233-slot JNI ABI、`JniStringStore` token/modified-UTF-8 契约。

验收：

- [x] 在已有 `NewStringUTF` 之外绑定 `GetStringUTFLength`、`GetStringUTFChars`、
  `ReleaseStringUTFChars`、`GetStringUTFRegion` 四个精确槽。
- [x] chars 进入独立 64 KiB guest lease arena，带 NUL、`isCopy=true`、first-fit
  回收和 object/token/kind 配对；空引用、坏 region、坏输出与错误 release 明确失败。
- [x] binder 晚于 string store 析构时不反向访问已销毁 owner；活跃 lease 的会话失败
  清理由行为测试覆盖，不产生宿主二次崩溃。
- [x] focused 测试、warnings-as-errors build、exact bootstrap 新采样、full CTest、
  MODULE/CURRENT、`git diff --check` 与独立 Git 提交通过。

非目标：本 WU 不实现 UTF-16/critical 字符串族，不实现 `FindClass`，
不把 Profile working directory 固化进 JNI binder。
