# WU-0365 · JNI guest class、object 与 instance call 批次

目标：一次闭合 guest native 创建并调用普通 Java 对象所需的完整 JNI 路径，
使 class/method/object 身份和 30 种返回类型/参数来源都走严格 registry/descriptor。

依赖：WU-0364、JNI class registry/invocation engine、A32 variadic/va_list/jvalue 解码。

验收：

- [x] `FindClass`、`GetMethodID`、`GetObjectClass`、`IsInstanceOf` 与
  `NewObject/NewObjectV/NewObjectA` 全部绑定且未知 class/method 明确失败。
- [x] Object/Boolean/Byte/Char/Short/Int/Long/Float/Double/Void 的普通 instance
  Call、CallV、CallA 共 30 槽按 descriptor 解码和编码，不复用静态 dispatch。
- [x] 构造只接受 void instance `<init>`；对象身份映射到精确 class，构造失败回滚
  local ref 与映射，receiver/return type/class assignability 均受检。
- [x] focused 测试、warnings-as-errors build、exact bootstrap 新采样、full CTest、
  MODULE/CURRENT、`git diff --check` 与独立 Git 提交通过。

非目标：本 WU 不伪造未声明 Android class，不实现 field/nonvirtual call，
不实现具体 AudioTrack 或平台身份语义。
