# WU-0366 · JNI guest static field family

目标：一次闭合 guest native 查询和读写 Java static field 所需的完整 JNI ABI，
为平台常量与共享状态 HLE 提供严格、可复用的字段通路。

依赖：WU-0365、JNI class registry、field store 与 Guest JNI ABI。

验收：

- [x] `GetStaticFieldID` 精确查询 class registry，未知 class/field/descriptor 明确失败。
- [x] Object/Boolean/Byte/Char/Short/Int/Long/Float/Double 的 9 个 getter 与 9 个
  setter 全部绑定，按 A32 soft-float ABI 编解码 word/double-word 与栈参数。
- [x] 调用槽类型必须与字段 descriptor 匹配；static/instance 混用、无效引用及错误值
  均明确失败，不静默返回默认成功。
- [x] focused 测试覆盖基础类型、对象、64 位栈参数与负例；warnings-as-errors build、
  full CTest、MODULE/CURRENT、`git diff --check` 与独立 Git 提交通过。

非目标：本 WU 不声明 Android framework class，不实现 instance field 或具体游戏逻辑。
