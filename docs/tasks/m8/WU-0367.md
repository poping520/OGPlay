# WU-0367 · JNI guest framework object class bridge

目标：让 framework HLE 创建的 host object 与 guest `NewObject` 共享同一精确 class
注册表，一次闭合 Context/service/UUID 等对象进入普通 JNI 调用链的基础设施。

依赖：WU-0365、JNI class registry/environment 与 guest instance call family。

验收：

- [x] 会话拥有一个可注入的 guest object registry，支持受检 allocate/register/forget/
  class lookup，拒绝 null、非 host、未知 class 与重复 object。
- [x] `NewObject`、`GetObjectClass`、`IsInstanceOf` 和 30 个 instance call 槽统一查询该
  registry；未注入调用方仍获得 binder 自有且生命周期安全的 registry。
- [x] framework HLE 预注册对象可直接通过 local/global reference 接受 descriptor-backed
  instance call，并保持 Java assignability 与未知对象明确失败。
- [x] focused 测试、warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、
  `git diff --check` 与独立 Git 提交通过。

非目标：本 WU 不声明具体 Android framework class，不增加游戏专属分支。
