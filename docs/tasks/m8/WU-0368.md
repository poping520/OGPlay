# WU-0368 · Android legacy platform identity class group

目标：一次安装 Asphalt 6 静态盘点到的 Android 2.x 平台身份类、字段、方法与服务对象链，
用注入配置提供确定性离线设备事实。

依赖：WU-0366、WU-0367、Android guest platform config/string/field/object stores。

验收：

- [x] 批量声明 Object、Context、ContentResolver、TelephonyManager、Build、Build$VERSION、
  SystemProperties、Settings$Secure、Bundle、ViewRoot 与 UUID，精确 member descriptor 可查询。
- [x] SDK_INT、SERIAL、TELEPHONY_SERVICE static field 走统一 field store；设备 ID、serial、
  android_id、system property 与 UUID 均来自确定性通用配置/常量，不读取宿主隐私。
- [x] Context→TelephonyManager/ContentResolver 和 UUID→toString 的 HLE object 链注册到统一
  guest object registry；未知 system service/property/settings key 使用 Android 兼容空值。
- [x] exact APK 复采样越过 `android/os/Build` 类缺口并一次暴露下一能力类别；focused、
  warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、`git diff --check` 与独立
  Git 提交通过。

非目标：本 WU 不实现 AudioTrack、Settings 持久化、真实 Telephony 或宿主设备指纹。
