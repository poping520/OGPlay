# WU-0369 · Guest JNI library load lifecycle

目标：冻结 Android Java library load 所需的 root-only `JNI_OnLoad(JavaVM*, nullptr)`
选择、调用帧和返回契约，为下一 WU 的 Profile 声明预装与执行顺序接线提供单一基础设施。

依赖：Guest JNI ABI/JavaVM、ELF link namespace、A32 guest call runner 与 module lifecycle。

验收：

- [x] 从 root module 的精确 exported/defined function symbol 构建唯一可选 JNI_OnLoad call；
  不调用仅作为 ELF 依赖加载的库，不跨模块误解析同名符号。
- [x] 调用帧传入统一 guest JavaVM、null reserved 参数并保留 ARM/Thumb symbol state。
- [x] 返回只接受 JNI 1.1/1.2/1.4/1.6，错误/未知版本明确失败；无导出保持合法无调用。
- [x] focused、warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、
  `git diff --check` 与独立 Git 提交通过；执行顺序集成显式依赖 WU-0370。

非目标：本 WU 不调用依赖库 JNI_OnLoad，不实现动态 dlopen/class-loader 或 JNI_OnUnload。
