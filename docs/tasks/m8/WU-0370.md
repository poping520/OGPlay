# WU-0370 · Profile Java registration before root JNI_OnLoad

目标：把 exact Profile Java 声明注册、root `JNI_OnLoad` 与 native callback 固定为
constructors→Profile registry→JNI_OnLoad→callback 的单一路径，消除未初始化 JavaVM。

依赖：WU-0369 root-only JNI_OnLoad 规划器、Android guest call session 与 Profile lifecycle。

验收：

- [x] guest session 提供一次性 JNI library 初始化，执行 root JNI_OnLoad 并校验返回版本；
  重复调用、停止后调用和 guest 失败均明确失败。
- [x] GLSurfaceView 前端只在 Profile lifecycle 注册全部 Java class 后执行 JNI_OnLoad，
  且 JNI_OnLoad 完成前不执行 startup native callback。
- [x] Asphalt 6 Profile 一次声明静态盘点得到的 SUtils、Device、GameInstaller 三个 OnLoad
  class lookup 与五个 method lookup；生产代码不含标题身份分支。
- [x] exact 自动化越过 JNI_OnLoad 与前五个 startup callback，稳定进入后续 GLES 批次。
- [x] warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、`git diff --check`
  与独立 Git 提交通过。

非目标：本 WU 不实现 JNI_OnUnload、动态 dlopen/class-loader，也不闭合后续 GLES 调用。
