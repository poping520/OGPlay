# WU-0371 · Mixed GLES capability query batch

目标：批量闭合同时链接 GLES1/GLES2 的 guest 经共享符号查询 GLES2 string、capability 与
binding-state 的 12 项初始化能力，使渲染器越过完整 capability discovery 阶段。

依赖：GLES1 query string guest region、ANGLE query API 与 WU-0370 exact startup。

验收：

- [x] GLES1 boundary 为 `GL_SHADING_LANGUAGE_VERSION` 分配独立有界只读槽，不覆盖
  vendor/renderer/version/extensions 的稳定 guest 指针。
- [x] `glGetIntegerv` 一次接入 vertex/texture/uniform/varying/shader-binary 8 项 GLES2
  capability 与 current-program/framebuffer/renderbuffer 3 项 binding state 查询。
- [x] 所有查询转发当前真实 ANGLE context；无 frame、坏输出与未知 pname 仍明确失败。
- [x] exact 自动化越过 capability discovery 并稳定进入下一整组 FBO/resource 边界。
- [x] focused、warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、
  `git diff --check` 与独立 Git 提交通过。

非目标：本 WU 不实现 framebuffer/renderbuffer 生命周期，也不放宽任意未知 GLES1 pname。
