# WU-0372 · GLES2 framebuffer resource batch

目标：一次闭合 GLES2 framebuffer/renderbuffer 的 10 项资源族与 mipmap 生成，使 Asphalt 6
初始化越过 FBO 建立阶段并暴露下一批独立渲染状态边界。

依赖：ANGLE 当前 context、生成 GLES2 catalog/dispatch、受检 guest 名称数组搬运与 WU-0371
exact capability discovery。

验收：

- [x] framebuffer/renderbuffer 的生成、删除、绑定、storage、两类 attachment 与 status
  共 10 项全部转发真实 ANGLE，名称数组在任何 GPU 状态变化前完整预检。
- [x] `glFramebufferTexture2D` 从 A32 guest 栈读取第五参数，`glGenerateMipmap` 复用真实
  texture 能力；所有原生调用即时检查 GLES 错误，不伪造完整性或成功。
- [x] 聚焦测试覆盖 renderbuffer 与 texture 两条完整 FBO，以及 mipmap 和资源释放闭环。
- [x] exact 自动化越过 `glBindFramebuffer`，稳定进入下一独立批次的 `glBlendEquation`。
- [x] focused、warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、
  `git diff --check` 与独立 Git 提交通过。

非目标：本 WU 不实现 shader/uniform/client-array 扩展，也不将 `glFlush` 用作 present。
