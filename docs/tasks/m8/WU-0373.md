# WU-0373 · GLES blend/raster state batch

目标：按 Asphalt 6 静态导入差集一次闭合 blend/raster 状态剩余四项，并正确处理混合
GLES1/GLES2 链接下的共享 `glSampleCoverage` 符号归属。

依赖：ANGLE scalar state API、隔离 GLES1/GLES2 dispatch 与 WU-0372 exact FBO 建立。

验收：

- [x] `glBlendColor`、`glBlendEquation`、`glSampleCoverage`、`glFlush` 全部逐位解码 A32
  浮点/布尔参数并转发当前真实 ANGLE context，原生错误明确失败。
- [x] GLES1 core dispatch 同时绑定 `glSampleCoverage`，混合链接解析到 GLES1 trap 时保持
  与 GLES2 相同语义。
- [x] 测试证明 `glFlush` 不 present、不产生 frame；未知 GLES2 handler 仍明确失败。
- [x] exact 自动化越过剩余图形状态批次，稳定进入独立的 `android/media/AudioTrack`
  Java/JNI 媒体类边界。
- [x] focused、warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、
  `git diff --check` 与独立 Git 提交通过。

非目标：本 WU 不实现 AudioTrack、shader/uniform/client-array，也不扩展 present 所有权。
