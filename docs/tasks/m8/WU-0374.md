# WU-0374 · Legacy AudioTrack framework batch

目标：按 Asphalt 6 ELF 与 `docs/demo` 已验证调用面一次闭合 legacy AudioTrack 的完整
Java/JNI 类族，使 native renderer 越过音频 bootstrap 并进入资源 worker 阶段。

依赖：Profile Java class registry、NewObject/instance/static invocation、primitive byte-array
store 与 legacy media session state。

验收：

- [x] Profile 声明 constructor、minimum-buffer、play/pause/stop/release/write 七项精确签名，
  游戏差异不进入 `src/`。
- [x] PCM16 mono/stereo 配置、stream mode、buffer 下限、receiver/array/range 均受检；track
  状态按 host object identity 隔离，write 记录实际消费字节并返回精确 count。
- [x] 测试覆盖构造、静态查询、byte-array 子区间写、play/pause/stop/release 状态及 release
  后失败，并固定 Profile 完整类契约。
- [x] exact 自动化越过 AudioTrack lookup/calls，首次启动资源 worker；随后稳定暴露独立的
  guest worker 失败清理/析构竞态，不再出现 AudioTrack 未声明错误。
- [x] focused、warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、
  `git diff --check` 与独立 Git 提交通过。

非目标：本 WU 不把 PCM 队列接入宿主 mixer，也不修复 worker teardown 竞态。
