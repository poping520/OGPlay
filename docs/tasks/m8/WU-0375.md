# WU-0375 · Guest worker failure teardown batch

目标：批量闭合 guest worker 在启动失败后的退出请求、futex 中断、全量 join 与 session
析构顺序，使 exact 失败保留可诊断边界而不再造成宿主 SIGSEGV。

依赖：GuestThreadLifecycle、GuestCloneThreadRuntime、GuestThreadGroup 与 WU-0374 首次资源
worker 启动证据。

验收：

- [x] child 在首次执行前或 budget slice 之间收到外部退出请求时，均完成 guest-exit、
  clear-child-tid/futex 与 outcome 发布，不因 running 前置条件竞态失败。
- [x] session stop 先请求全部 running child 退出并中断 futex，再无条件尝试 join 全部 child；
  单个失败延迟到全量 join 后作为首错上报。
- [x] 回归测试覆盖 clone child 的早期外部退出并确认 host thread active count 归零。
- [x] exact 自动化由宿主 SIGSEGV 转为正常 status 1，明确报告下一批 `glGetActiveAttrib`
  GLES 边界；不再访问已析构 lifecycle。
- [x] focused、warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、
  `git diff --check` 与独立 Git 提交通过。

非目标：本 WU 不实现 shader reflection/uniform，也不把 guest 渲染错误伪装成 clean shutdown。
