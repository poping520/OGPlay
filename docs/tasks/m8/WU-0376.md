# WU-0376 · GLES2 shader reflection and uniform batch

目标：按 Asphalt 6 静态导入差集一次闭合 shader/program 反射、info-log、uniform vector/
matrix4 与 constant vertex attribute 共 14 项 GLES2 入口。

依赖：WU-0371 GLES2 query、WU-0375 可诊断 worker teardown、生成 GLES2 IDL 与 guest
transfer 契约。

验收：

- [x] `glGetActiveAttrib`、`glGetActiveUniform` 从真实 ANGLE 对象读取 name/size/type，按 guest
  `bufSize` 截断并 NUL 结尾，可选 length 与其余三个输出均经统一 transfer 预检/提交。
- [x] program/shader info-log 使用真实 ANGLE 长度与内容，并保持 GLES 截断语义。
- [x] 八项 float/int vector uniform、matrix4 与 `glVertexAttrib4f` 保持 A32 位型、IDL 数量和栈
  参数；坏地址、负数和不匹配 payload 在原生调用前失败。
- [x] 聚焦机器测试覆盖 14 项入口；exact 越过整个批次，明确进入 client-side vertex array
  staging 边界，而非逐项暴露下一个 shader/uniform 缺口。
- [x] warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、`git diff --check` 与
  独立 Git 提交通过。

非目标：本 WU 不实现 client-side vertex/index staging 或 texture subimage。
