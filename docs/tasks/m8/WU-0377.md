# WU-0377 · GLES2 client vertex/index staging and TexSubImage

目标：按 Asphalt 6 当前边界一次闭合 GLES2 client-side vertex/index staging、
`glDrawArrays`、`glTexSubImage2D`，并处理混合 GLES1/GLES2 链接下的 draw 归属。

依赖：WU-0376、`src/gles/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] `glVertexAttribPointer` 在 array-buffer 为 0 时延迟保存 guest pointer/size/type/
  stride/normalized，不再伪造成功或立即把 guest 地址交给 ANGLE。
- [x] `glDrawArrays` 与 client-index `glDrawElements` 按 first/count 或 guest 索引最大值
  预检启用 client attribute，经内部 VBO/EBO 上传后 draw，并恢复 guest buffer binding。
- [x] 已绑定 element buffer 且仍有启用 client attribute 时明确失败；VBO offset 路径保持。
- [x] `glTexSubImage2D` 按 IDL/unpack 完整搬运像素后转发 ANGLE。
- [x] 混合链接解析到 GLES1 `glDrawArrays`/`glDrawElements` 且未启用 `GL_VERTEX_ARRAY`、
  但已有启用的 GLES2 vertex attribute 时，转入同一 GLES2 staging/draw 路径。
- [x] 聚焦机器测试覆盖上述入口；exact 越过 client-array staging 边界。
- [x] warnings-as-errors build、full CTest、MODULE/CURRENT/capabilities、`git diff --check`
  通过。

非目标：本 WU 不实现 license/VFS 缺口、主界面 Scenario，也不从 opaque EBO 猜测 client
array 范围。
