# WU-M8-001 · JNI Guest Binding 统一注册入口

目标：让 production 通过唯一 aggregate binder 注册当前全部 JNI guest family，并保持
既有 JNIEnv/JavaVM slot 集合不变。

依赖：M5 guest JNI ABI、static/instance call、static field 与 string binding；
`src/runtime/jni/MODULE.md`、`src/runtime/integration/MODULE.md`。

验收：

- [x] `BindJniGuestSlots` 通过统一 context 显式组合 Core、Class/Instance、Static Call、
  Static Field、Modified UTF-8 与 JavaVM family。
- [x] `AndroidGuestCallSession` 只有一次 aggregate registration，随后立即 `Seal`。
- [x] Core binder 不再隐式注册其他 family。
- [x] exact binding contract 验证 JNIEnv 110、JavaVM 4，未实现 `GetFieldID` 保持 unbound，
  aggregate 内无重复/reserved binding，Seal 后拒绝继续注册。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过。

非目标：本 WU 不增加任何 JNI API，不改变 233/8 槽 ABI，也不实现后续 field、array、
native registration、nonvirtual 或 monitor 语义。
