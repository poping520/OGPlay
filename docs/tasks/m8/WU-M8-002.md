# WU-M8-002 · RegisterNatives / UnregisterNatives

目标：把 ARM32 guest `RegisterNatives` / `UnregisterNatives` 接入唯一
`JniNativeRegistry`，并让注册 target 可进入真实 guest 执行器。

依赖：WU-M8-001、M3 `JniNativeRegistry`、M5 guest JNI trap/A32 executor。

验收：

- [x] ARM32 `JNINativeMethod` 按 12 字节读取，负 count、乘法/地址范围、字符串、descriptor、
  null target、class reference 与 method declaration 全部严格校验。
- [x] 完整 methods array 先预检并整批 resolve，再由 `JniNativeRegistry` 一次提交；后项失败
  不残留前项。
- [x] guest target bit 0 原样保存，`ResolveJniRegisteredNativeCall` 把唯一 registry mapping
  交给通用 A32 执行链。
- [x] 端到端测试经 guest binding 注册 Thumb target、解析 mapping、执行真实指令并返回 42。
- [x] `UnregisterNatives` 只清除指定 class，其他 class mapping 保持可解析；注销后原方法明确
  unresolved。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过。

非目标：本 WU 不改变标准 `Java_xxx` export fallback，不实现 instance field、array、
nonvirtual、exception 或 monitor family。
