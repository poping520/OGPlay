# WU-M8-003 · Instance Field + UTF-16 String

目标：补齐 19 个 instance field 槽和 5 个 UTF-16 string 槽，并复用统一 JNI semantic store。

依赖：WU-M8-001、M3 class/environment/field/string/object semantic、WU-0366 static field ABI。

验收：

- [x] `GetFieldID` 与 Object/Boolean/Byte/Char/Short/Int/Long/Float/Double getter/setter
  全部绑定，receiver 经 reference resolve→object identity→object registry→receiver class。
- [x] static/instance field ID、descriptor/getter kind 严格区分；long/double 复用既有 A32
  word-pair 与对齐 stack 参数编码。
- [x] `NewString`、`GetStringLength`、`GetStringChars`、`ReleaseStringChars`、
  `GetStringRegion` 按 UTF-16 code unit 工作，surrogate pair 长度保持 2。
- [x] chars 返回独立 guest lease 且 `isCopy=JNI_TRUE`；wrong string、double release、坏 range
  和坏 guest pointer 明确失败。
- [x] NewString 先完整读取 guest range，local reference 发布失败回滚 semantic string；region
  输出先完整预检再一次提交。
- [x] Windows/MSVC warnings-as-errors 构建与全量 CTest 通过。

非目标：本 WU 不绑定 `GetStringCritical` / `ReleaseStringCritical`，不实现 array、
nonvirtual、exception 或 monitor family。
