# WU-M8-004 · Primitive Array + Object Array

目标：补齐 primitive array 40 槽与 object array 3 槽，并让 GetArrayLength 显式支持两类 store。

依赖：WU-M8-001、M3 primitive/object array semantic、统一 JNIEnv reference 与 ARM32 dispatcher。

验收：

- [x] 8 类 `New<Type>Array`、Get/Set Region、Get/Release Elements 全部由统一 binder 注册，
  已有 GetByteArrayRegion 已迁移且没有重复 binding。
- [x] length/range/乘法溢出与第五个 ARM32 栈参数在 semantic mutation 前完整校验；创建后
  local reference 发布失败会删除 semantic array。
- [x] Elements 返回 4 MiB 有界 guest lease，不暴露 host pointer；lease 记录 array/kind/
  element size/address/byte size/token，严格支持 0、JNI_COMMIT、JNI_ABORT。
- [x] invalid mode、wrong pointer、double release、wrong array kind 和坏 guest range 明确失败。
- [x] Object Array 复用 `JniObjectArrayStore`；initial/set 的非 null value 均校验
  assignability，null 始终允许。
- [x] GetArrayLength 通过 object store 的显式 `Contains` 区分 primitive/object array，
  不使用 exception probing。
- [x] aggregate contract 为 JNIEnv/JavaVM 178/4；Windows/MSVC warnings-as-errors 构建、
  focused 与全量 CTest 通过。

非目标：本 WU 不实现 nonvirtual call、完整 exception API 或 monitor family。
