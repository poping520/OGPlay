# WU-M8-005 · Nonvirtual Call + Exception API

目标：补齐 CallNonvirtual 三变体全家桶，并让 ThrowNew/ExceptionDescribe 使用真实 throwable
语义与结构化诊断。

依赖：WU-M8-001、M3 invocation/class/exception semantic、WU-M8-003 object registry 与既有
A32 descriptor 参数解码器。

验收：

- [x] Object/Boolean/Byte/Char/Short/Int/Long/Float/Double/Void 的 normal/V/A 共 30 槽绑定。
- [x] nonvirtual ABI 从 r3 读取 method，从 guest 栈读取首参数、va_list 或 jvalue pointer；
  64 位 alignment、float promotion 和返回编码复用现有 decoder。
- [x] 所有调用进入 `JniInvocationEngine::InvokeNonvirtual`；integration 不复制 method
  resolution、receiver/dispatch class assignability 或 handler 选择语义。
- [x] ThrowNew 完整读取并严格解码 Modified UTF-8 message，创建非零 throwable identity，
  并在 runtime/jni 保存 identity、exception class 和 message。
- [x] ExceptionDescribe 通过现有 Logger 写结构化 diagnostic，不清除 exception；前后
  ExceptionCheck 均为 true，ExceptionOccurred identity 保持相同。
- [x] aggregate contract 为 JNIEnv/JavaVM 210/4；Windows/MSVC warnings-as-errors 构建、
  focused 与全量 CTest 通过。

非目标：本 WU 不实现 FatalError、DefineClass、AllocObject 或 monitor family。
