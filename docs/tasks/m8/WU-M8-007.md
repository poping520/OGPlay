# WU-M8-007 · JNI M8 验收闭环

目标：修复 JNI monitor 生命周期缺陷，把 guest binding 契约改成精确集合等价，并让 M8 JNI
的工作单索引、能力记录与状态快照与代码一致。

依赖：WU-M8-001..WU-M8-006。本 WU 不新增任何 JNI family。

验收：

- [x] monitor 的临时中断与永久关闭拆成两个语义。`JniMonitorTable::InterruptWaiters` 以
  interrupt generation 唤醒当前 waiter，被唤醒者以 `interrupted` 失败且不取得 ownership；
  之后新的 `Enter` 使用新 generation 仍能正常竞争。`Shutdown` 才唤醒 waiter 并让当前及
  后续 `Enter` 一律以 `shut_down` 失败。
- [x] `AndroidGuestCallSession::InterruptBlockingWaits` 只做临时唤醒，不再永久停用 monitor；
  session `Stop` 顺序固定为请求 child 退出 → 临时中断 → join child → guest fini/destructor →
  root JNI detach → 永久 monitor shutdown，guest finalizer 阶段的 `MonitorEnter` 仍可成功。
- [x] monitor 验收矩阵机器可判定：首次/重入 enter、recursion exit、竞争阻塞与 owner exit
  唤醒、非 owner exit 失败、detach 释放、临时中断不禁用后续 enter、shutdown 唤醒并拒绝后续
  enter 且无死锁、teardown 顺序下 finalizer 仍可加锁。
- [x] aggregate binding test 改为精确集合等价：实际绑定名称集合与 expected manifest 相等
  （JNIEnv 212、JavaVM 4），数量只作辅助诊断；manifest 逐项覆盖 native registration、
  instance field、UTF-16 string、primitive/object array、nonvirtual、exception 与 monitor。
- [x] 显式 expected-unbound 清单验证 Critical array/string、DirectByteBuffer、Reflection、
  FatalError 与 `DestroyJavaVM` 仍未绑定；reserved 槽拒绝绑定且 ABI 表项为 0；重复绑定与
  Seal 后绑定明确失败。
- [x] `docs/tasks/m8/README.md` 列出 WU-M8-001..007 的标题、状态与目标，并改用里程碑内
  `WU-M<里程碑>-<三位序号>` 命名；`docs/tasks/README.md` 中与之直接冲突的全局四位编号
  规则同步修正，历史编号不重命名。
- [x] `capabilities.toml` 为 instance field、UTF-16 string、array、nonvirtual call、exception、
  monitor 与 binding manifest 分别建立能力记录并写明排除项；M3 的 `runtime.jni` 历史结论
  不改写。
- [x] `docs/state/CURRENT.md` 记录 JNI contract 完成，并如实保留 exact-title 在
  `CallStaticIntMethodV` class reference 的独立阻塞。
- [x] Windows/MSVC warnings-as-errors 构建、focused monitor/binding 7/7 与全量 CTest 通过。

非目标：不实现 Critical array/string、DirectByteBuffer、Reflection、`FatalError`、
`DestroyJavaVM`；不重构 `JniObjectArrayStore` 的所有权，不触碰 GLES/EGL/VFS/Bionic/syscall
与游戏 profile。

文件预算说明：本 WU 触及 12 个文件——推荐预算的 10 项，外加 `src/runtime/jni/MODULE.md`
与 `src/runtime/integration/MODULE.md` 两处契约同步（AGENTS.md 要求修改模块时同步更新
`MODULE.md`），以及 `docs/tasks/README.md` 中与新命名规则直接冲突的两行修正。
