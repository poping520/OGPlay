# WU-M8-008 · 迁移 guest JNI ABI 到 runtime/jni_guest 子模块

一句话目标:把 8 个 `jni_guest_*` 实现与 7 个公共头从 `runtime/integration` 纯机械
迁移到新子模块 `runtime/jni_guest`,行为与命名空间零变更。

依赖:ADR-0018;WU-M8-007(绑定集合封板,保证迁移前后契约可对照)。

## 范围

- `src/runtime/jni_guest/` 新目录:`jni_guest_abi`、`jni_guest_dispatch`、
  `jni_guest_bindings`、`jni_guest_array_bindings`、`jni_guest_static_calls`、
  `jni_guest_static_fields`、`jni_guest_string_bindings`、`jni_guest_library_lifecycle`。
- 公共头迁到 `include/ogplay/runtime/jni_guest/`,全仓 include 路径同步改写。
- CMake 源列表、`cmake/CheckDocumentationLayout.cmake` 子模块清单、
  `src/runtime/jni_guest/MODULE.md`(不变量自 integration 契约原文迁出)。
- 基线修复(macOS AppleClang -Werror,迁移前置):删除 `gles::GuestBuffer` 残留
  `thread_id_` 成员与 `jni_guest_bindings.cpp` 未使用的 `Read32`。

非目标:不改任何 slot 语义、不动 `ogplay::runtime` 命名空间、不拆 CMake target、
不迁移 boundary 与 session 文件(见 WU-M8-009/010)。

## 验收(机器可判定)

- [x] `rg 'runtime/integration/jni_guest'` 全仓零命中。
- [x] `cmake --build --preset dev` 零警告零错误。
- [x] `ctest --preset dev` 全量通过,数量与迁移前基线一致(macOS/arm64 524/524;
  基线中 `guest clone observes an external exit request between slices` 偶发超时,
  复跑 3/3 通过,与本迁移无关)。
- [x] `tests/runtime/jni_guest_bindings_tests.cpp` 的精确集合等价断言不变
  (JNIEnv 212 / JavaVM 4)。
