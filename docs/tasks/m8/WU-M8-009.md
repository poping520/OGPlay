# WU-M8-009 · 迁移 Android native 边界到 runtime/boundary 子模块

一句话目标:把 Android/GLES 边界的 9 个实现文件从 `runtime/integration` 纯机械迁移到
新子模块 `runtime/boundary`,行为与命名空间零变更。

依赖:ADR-0018;WU-M8-008(先迁 jni_guest,避免同一批次交叉改写 include)。

## 范围

- `src/runtime/boundary/` 新目录:`android_boundary_hle`、`android_boundary_gles`、
  `android_boundary_gles1`(含 `_draw`/`_fixed`/`_query`/`_support` 私有头)、
  `android_boundary_symbols`、`guest_gl_context`、`a32_call_frame`。
- 公共头 `android_boundary_hle.h`、`android_boundary_gles.h`、`guest_gl_context.h`、
  `a32_call_frame.h` 迁到 `include/ogplay/runtime/boundary/`;GLES1 私有头保持
  实现目录内并随目录迁移。全仓 include 路径(含 tests 的相对路径引用)同步改写。
- CMake 源列表、`cmake/CheckDocumentationLayout.cmake` 子模块清单、
  `src/runtime/boundary/MODULE.md`(GLES/boundary 不变量自 integration 契约原文迁出)。

非目标:不改 handler 语义、不动 namespace、不拆 CMake target、不迁 session 装配文件。

## 验收(机器可判定)

- [x] `rg 'runtime/integration/(android_boundary|guest_gl_context|a32_call_frame)'`
  全仓零命中,且无任何文件再包含 `src/runtime/integration/android_boundary*` 相对路径。
- [x] `cmake --build --preset dev` 零警告零错误。
- [x] `ctest --preset dev` 全量通过,数量与 WU-M8-008 完成时一致(macOS/arm64 524/524)。
