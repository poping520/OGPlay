# WU-M9-016 · Manifest launcher activity 读取

## 目标（一句话）

二进制 Manifest 解析扩展出 launcher activity 事实（action MAIN + category
LAUNCHER 的第一个 activity，相对名按 package 规范化），`dex_activity` 的
入口发现不再靠 profile 手写。

## 变更

- `loader::AndroidManifestFacts` 新增 `launcher_activity`；解析循环跟踪
  `application/activity` 与其 `intent-filter` 的 action/category。
- run-apk 由此派生入口类 descriptor（`com.x.Y` → `Lcom/x/Y;`）。

## 验收

- pilot exact APK 解析出真实 launcher（三轮 gate 的入口即来自它）；
  full CTest 无回归（Manifest 严格解析语义不变）。
