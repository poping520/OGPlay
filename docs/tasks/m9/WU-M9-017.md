## 目标（一句话）

新增 schema v2：`lifecycle = "dex_activity"`、可选 `[runtime.dexvm]` 受检
预算（heap/max_frames/ticks），**禁止** `native_call` 与 `[[java.class]]`；
v1 保持冻结，校验器双版本并行。

  schema 1..2 与互斥门（v2 强制 dex_activity/无胶水段；v1 拒绝
  dex_activity；`runtime.dexvm` 仅 v2）。

  （dexvm 预算受检范围 1MiB..1GiB / 16..65536 / 1..10^10）；v1 路径零改动。
