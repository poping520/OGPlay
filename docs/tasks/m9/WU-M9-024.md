# WU-M9-024 · guest 静态字段预设

## 目标（一句话）

在目标 guest 类真实完成初始化后原子应用 Profile 基元/String 静态字段预设。

## 验收

- 覆盖 Z/B/C/S/I/J/F/D/String，字段/类型/静态性不匹配明确失败。
- `<clinit>` 的原值先发生，preset 随后覆盖；无 preset 保持原值。
- 逐条写结构化日志并保留 reason。

## 结果（已完成）

- `Interpreter::SetStaticFieldBits` 只写已初始化真实类的同名同 descriptor static slot。
- 行为测试覆盖 Z/B/C/S/I/J/F/D/String、非 static、字段/类缺失、`<clinit>` 先于覆盖和
  无 preset 保持原值。
- 每条成功预置输出 `session.profile_entry` 结构化日志，包含 class/field/type/reason。
