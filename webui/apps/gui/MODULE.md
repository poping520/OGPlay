# 模块：Web 启动器

Preact 游戏库与导入向导，只显示宿主返回的事实，经 closed-schema JSON-RPC 操作宿主。
不执行 guest，不判断游戏兼容性。以 installation id 区分实例，不能按包名合并。

导入只接受单体 APK。原生选择器返回宿主路径；拖放读取 File 并以 192 KiB 顺序分块传输，
不构造虚假文件路径。分析与入库使用宿主 job，终态后刷新并选中新实例；重复包名确认新建。
原生选择器/后台操作未结束时不关闭向导、不允许重复请求。失败显式显示，可重新选择。
全局设置按宿主字段定义渲染，先编辑草稿，再校验并保存；未保存离开须确认，
恢复默认只修改草稿，版本冲突必须重新载入。预留项明确标注仅保存，不声称运行时生效。
主界面（console.css，“主机之夜”）：顶部 L/R 分类与搜索、选中实例的主视觉与卡带、底部卡带轨道；卡带色取自图标主体色（32px 采样，30° 色相分桶按色度与居中加权；外圈过半的背景/边框色相排除，
主体色彩不足 12% 时才回退，近中性取冷石墨色），LED/磨损/金手指只反映宿主状态（损坏条目磨损、缺数据包无金手指），
信息只用宿主事实（版本、数据包、导入时间、运行 PID/端口；仅有精确 Profile 时显示 Profile），无数据的游玩时长等不显示。
卡带默认 3D（全局设置 `cartridge`=`3d`，可改 `css`）：gui.js 只在 3d 时按需插入同目录 `cart3d.js`（three、纯 JS Draco 解码器、内联 `cartridge.glb`/AO，模型由 `tools/build_cartridge_model.py` 生成），
主线程解码，不放宽 CSP（无 fetch、worker、wasm）；主视觉为单个 WebGL 画布，轨道用渲染出的 PNG 静帧，印刷内容同样只用宿主事实。
css 或加载/WebGL 失败时显示 CSS 卡带；失败只报告一次，不伪装成 3D。启动闪屏（图标 + OGPlay）两种模式都显示，
至少 0.9 秒，并等游戏库、设置及（3D 时）主视觉首帧与前 12 个轨道静帧就绪后退场，最长 8 秒。键盘对应手柄提示：
←/→ 选择、Enter 主操作、Esc 返回、X 按键设置、Y 游戏设置、Q/E 切换分类、⌘K 或 / 搜索；设置页打开时主界面不响应按键。
主界面固定深色；主题/密度在新界面中为预留项。全局 `language`（zh-CN/en-US，GUI-14）切换界面语言：`i18n.ts` 以中文原文为键，
`t()`/`tj()` 在英文时查 `i18n-en.ts`，缺词回退中文；根组件订阅语言后整体重绘，设置页草稿即时预览、未保存离开恢复，
最近一次语言存 localStorage 仅用于闪屏前预设，以宿主设置为准。宿主字段名/说明按其中文原文翻译显示，宿主下发的详情与错误不翻译。
3D 卡带印刷文字经 CartFace.captions 传入。`i18n.test.ts` 要求源码中文字面量与宿主设置文字均有英文、占位符一致。退出日志提示与导入目录预填读取全局值。运行实例/选中实例可打开宿主核对 PID 后就绪的独立 Dashboard 窗口，以及就绪后的“按键设置”窗口（`controls.open`，ADR-0134）。
游戏退出事件后查询 `library.data_hint`（ADR-0146）；有建议时弹窗显示当前→建议挂载、缺失示例与
挂载预览（与导入向导共用 MountPreview），“挂载并重新启动 / 仅修改 / 忽略”；needs_data 只给示例和
“选择数据包目录”，选后由宿主重新判断。查询失败视为无建议。
主题位于 packages/ui-kit，产物由 Vite 生成，Node 仅构建期使用。

## 代码复用原则

GUI 各视图必须复用同一套令牌、控件与组件，禁止复制后改写：
- 颜色、字体、颗粒纹理等令牌只在 ui-kit `:root` 定义；页面只引用 `var(--*)`，取值不同时在自身作用域覆盖令牌
  （如设置页 `--line`/`--panel`、玻璃紫皮肤），不复制整组令牌。
- 两个及以上视图使用的控件（`.pill`、`.seg`、`.key`、`.led`、`.kicker`、`.brand`）只在 ui-kit 定义一次，
  页面样式只补尺寸、间距等上下文差异。页面专用控件留在本页样式；第二个视图要用时先移入 ui-kit 再复用。
- 共享 TSX 片段放 `kit.tsx`（`Brand`、`Key`，并负责最先加载 ui-kit）；库条目对话框共用 `game-dialogs.tsx`
  的游戏卡与弹窗逻辑，以及 console.css 中 `.import-wizard` 的头部、卡片、字段和按钮样式；不在多个文件里各写同名组件。
- 新增样式或组件前先搜索现有类名和组件。纯样式重构须外观不变，以重构前后计算样式对比或截图为证。

全局与每实例设置页共用 settings-ui.tsx/settings.css（“主机之夜”布局：顶栏保存操作、分组侧栏、字段行、手柄键位脚注），
`settings_style`=`glass` 时同一布局换为“玻璃紫”皮肤；全局页随草稿即时预览，游戏设置页读已保存值。宿主 `pending` 以“预留”开头才标为预留，
否则作为说明显示；标签末尾全角括号内为数值单位或说明。实例页侧栏卡带与主界面一致（3D 静帧，css/失败时 CSS 卡带）。
键盘：↑/↓ 选择行、←/→ 调整、Enter/A 切换、Esc/B 返回、X 恢复默认/全部继承、Y 保存、Q/E 切换分组、I 切换继承。

每实例设置以 installation id 路由，九组控件使用宿主字段定义。继承项从覆盖集合删除，
数据包继承导入记录；恢复继承须保存，未保存离开需确认。全局或实例版本变化拒绝旧稿。
高级/兼容性页显示已保存设置生成的 argv，草稿未保存时禁止启动。正常/预检/诊断仅传枚举，
不拼接自由参数。缺少管理接口的沙盒操作禁用，运行时预留项只保存。

验证：npm run check，宿主 GUI CTest，以及 Windows 原生窗口交互。

“更多”菜单提供目录打开、安装信息与“移除库中实例”，移除在运行中或正在入库时禁用；默认展示对象身份、删除范围与“同时删除存档”勾选（默认不勾，保留的存档在重新导入时恢复）。
全局 confirm_delete 关闭时跳过二次对话框，宿主仍要求显式 confirmed=true 并重新检查运行状态。
操作成功刷新列表并清除选中；失败显示宿主错误，不伪报成功。

Profile 只在宿主给出时显示身份与 quirk，无 Profile 不显示占位或“未匹配”；导入不再读取 requires_external；外部数据目录
是用户可选输入，是否指定不阻止导入，已配置目录的可用性由宿主独立检查。选定目录后可选“复制到游戏库”（默认）
或“引用原目录”（分段控件）；挂载位置按宿主同一规则即时校验（末尾斜杠去除），挂载预览以宿主
`library.external.inspect` 的真实顶层条目显示其在 guest 路径下的树形位置与文件数/大小。复制时显示宿主
字节进度，可“取消导入”。向导使用 console.css 的胶囊字段/分段/标签样式；主按钮为“导入到游戏库”。

逻辑画面宽高和超采样由宿主 settings 定义提供字段，全局与游戏页均可编辑；实例继承
规则由宿主统一计算，输入不提供官方键位或类型模板。
