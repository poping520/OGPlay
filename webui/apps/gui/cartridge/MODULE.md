# 模块：卡带

卡带默认 3D（全局设置 `cartridge`=`3d`，可改 `css`）：gui.js 只在 3d 时按需插入同目录 `cart3d.js`（[cart3d](cart3d/MODULE.md)），
主视觉为单个 WebGL 画布，轨道用渲染出的 PNG 静帧，印刷内容同样只用宿主事实，印刷文字经 CartFace.captions 传入（随界面语言）。
css 或加载/WebGL 失败时显示 CSS 卡带（cartridge.tsx）；失败只报告一次，不伪装成 3D。

卡带展示（cart-viewer.tsx）：仅 3D 可用时由主视觉单击、“更多 › 查看卡带”或 V 打开，否则入口禁用并说明；
复用主界面顶栏/脚注/背景，cart3d `inspect()` 接管同一画布（旋转/缩放、六预设、拆开、自转、部件提示），
页面持有视角/拆开/自转状态，←/→ 沿当前列表切换并回写选中，印刷与状态灯只用宿主事实，不做状态模拟、材质切换、截图或录像。
