# 模块：导入与数据包

- 原生选择器可选单体 APK 或游戏压缩包（ZIP/RAR/7z/.gpk，由宿主按内容判断），显示宿主给的 `label`；拖放只收 APK
  （压缩包提示改用选择文件），读取 File 并以 192 KiB 顺序分块传输，不构造虚假文件路径。
- 压缩包（摘要 `archive`）：多个 APK 时列出可改选（重新分析）；宿主识别出的数据包直接显示挂载位置与预览，此时
  不再提供“选择目录”；无法识别的顶层内容列为“其他内容”默认不导入，勾选后挂载位置变为 /sdcard（用户改过则保持），
  预览合并显示（`archivePreview`）；导入时显示“正在解压数据包”字节进度；失败时切换到失败状态并显示宿主返回的错误。
  分析与入库使用宿主 job，终态后刷新并选中新实例；重复包名确认新建。原生选择器/后台操作未结束时不关闭向导、不允许重复请求。
  失败显式显示，可重新选择。
- 未从 APK 压缩包取数据时，数据包可“选择目录”或“选择压缩包”（二选一，选定后只留“清除”），都经 `library.data_pack`
  由宿主规划，与 APK 压缩包同样显示挂载位置、挂载预览（预览展开到包名目录）和“其他内容”；压缩包没有可识别数据时杂项
  默认全选（/sdcard），全不选时不能导入。目录显示识别结论：只导入包名目录、包名目录与 APK 包名不同（按它导入）、
  或未找到包名目录（导入整个目录）。目录可选“复制到游戏库”（默认）或“引用原目录”（分段控件，有宿主路径能力时），
  引用时不提供其他内容；挂载位置按宿主同一规则即时校验（末尾斜杠去除）。导入时显示宿主字节进度（压缩包为解压），
  可“取消导入”。设置的默认数据包目录在分析完成后自动选入。
- 导入不读取 requires_external；数据包是用户可选输入，是否指定不阻止导入。向导使用 library/library.css 的
  胶囊字段/分段/标签样式；主按钮为“导入到游戏库”。
- 游戏退出事件后查询 `library.data_hint`（ADR-0146，data-hint.tsx）；有建议时弹窗显示当前→建议挂载、缺失示例与挂载预览
  （与导入向导共用 MountPreview），“挂载并重新启动 / 仅修改 / 忽略”；needs_data 只给示例和“选择数据包目录”，
  选后由宿主重新判断。查询失败视为无建议。
