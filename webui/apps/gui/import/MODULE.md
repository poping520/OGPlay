# 模块：导入与数据包

- 导入只接受单体 APK。原生选择器返回宿主路径；拖放读取 File 并以 192 KiB 顺序分块传输，不构造虚假文件路径。
  分析与入库使用宿主 job，终态后刷新并选中新实例；重复包名确认新建。原生选择器/后台操作未结束时不关闭向导、不允许重复请求。
  失败显式显示，可重新选择。
- 导入不读取 requires_external；外部数据目录是用户可选输入，是否指定不阻止导入，已配置目录的可用性由宿主独立检查。
  选定目录后可选“复制到游戏库”（默认）或“引用原目录”（分段控件）；挂载位置按宿主同一规则即时校验（末尾斜杠去除），
  挂载预览（mount-preview.tsx）以宿主 `library.external.inspect` 的真实顶层条目显示其在 guest 路径下的树形位置与文件数/大小。
  复制时显示宿主字节进度，可“取消导入”。向导使用 library/library.css 的胶囊字段/分段/标签样式；主按钮为“导入到游戏库”。
- 游戏退出事件后查询 `library.data_hint`（ADR-0146，data-hint.tsx）；有建议时弹窗显示当前→建议挂载、缺失示例与挂载预览
  （与导入向导共用 MountPreview），“挂载并重新启动 / 仅修改 / 忽略”；needs_data 只给示例和“选择数据包目录”，
  选后由宿主重新判断。查询失败视为无建议。
