# 模块：游戏库主界面

主界面（library.css，“磨砂黑”）：顶部 L/R 分类（全部/可启动/需检查；运行中的游戏看“N 运行中”入口）与搜索、选中实例的主视觉与卡带、
底部卡带轨道（“导入游戏”固定在轨道右侧，不随卡带滚动）。library.ts 负责筛选、排序、状态与卡带色：卡带色取自图标主体色
（32px 采样，30° 色相分桶按色度与居中加权；外圈过半的背景/边框色相排除，主体色彩不足 12% 时才回退，近中性取冷石墨色），
LED/磨损/金手指只反映宿主状态（损坏条目磨损、缺数据包无金手指），信息只用宿主事实（版本、数据包、导入时间、运行 PID/端口；
仅有精确 Profile 时显示 Profile），无数据的游玩时长等不显示。Profile 只在宿主给出时显示身份与 quirk，无 Profile 不显示占位或“未匹配”。

- 启动闪屏（splash.tsx，图标 + OGPlay）CSS/3D 两种卡带模式都显示，至少 0.9 秒，并等游戏库、设置及（3D 时）主视觉首帧与
  前 12 个轨道静帧就绪后退场，最长 8 秒。
- 轨道排序用页内菜单（sort-menu.tsx，与“更多”同一 `.menu` 样式，↑/↓、Esc 可操作），不用会弹出系统菜单的原生 `<select>`。
- 安装信息弹窗显示导入时间、安装 ID/包名/数据包及挂载位置、APK/数据包/游戏数据占用（打开时经 `library.storage`
  统计）与沙盒/日志目录；运行时 Dashboard 与按键设置状态不在此弹窗。
- 删除内置 Demo（`builtin_demo`）时确认框说明会同时关闭「展示内置 Demo 游戏」。
- “更多”菜单提供目录打开、安装信息、“清空游戏数据”与“移除库中实例”，后两者在运行中或正在入库时禁用；清空数据总要确认
  （列出清空/保留范围、不可撤销警告，默认焦点在取消），以 `library.clear_data` confirmed 执行，成功后提示；删除默认展示对象身份、
  删除范围与“同时删除存档”勾选（默认不勾，保留的存档在重新导入时恢复）。删除同样总要确认，不提供跳过确认的设置；宿主要求显式
  confirmed=true 并重新检查运行状态。
- 操作成功刷新列表并清除选中；失败显示宿主错误（modal.tsx），不伪报成功。
