# 模块：手机布局

Android 手机（宿主声明 `window.__ogplayLayout='phone'`）的竖屏触屏界面，面向 19:9～20:9、约 360–412 CSS px 宽的屏幕；
桌面与平板不用。状态与操作全部来自 `library/launcher.ts`，视觉沿用 ui-kit 令牌与两种皮肤，不另起一套。

- `phone-app.tsx`：页面栈（游戏库 → 游戏页；全局设置、游戏设置、卡带展示整屏接管）。游戏库为搜索、筛选标签、排序面板与两列卡带网格，
  长按卡片或游戏页“⋯”打开该游戏的操作面板，导入按钮固定在右下；游戏页为卡带、宿主事实（不靠悬停提示）与拇指区操作栏。
- `parts.tsx`：返回/更多图标按钮与底部面板 `Sheet`（模态 `<dialog>`，返回键、点遮罩或选择后关闭）。设置页的长选项列表也用它。
- `phone.css`：布局、底部面板，以及把共用弹窗改成底部面板、导入向导改成整屏；安全区取宿主写入的 `--safe-top/--safe-bottom`。
- 返回键（`ogplay-back`）：最上层弹窗/面板 → 整屏视图（按 Esc 交给它；设置页先从分组回到分组列表）→ 游戏页 → 搜索 → 筛选，
  均无则不取消，由宿主退出。
- 设置页的手机排布在 `settings/settings-ui.tsx`（`PhoneFrame`：分组列表 → 单组页，宽控件占整行，选项多时用底部面板）。

验证：npm run check；Android 真机（root，push 后 pm install）截图核对游戏库、游戏页、操作面板、设置两级页、导入向导与返回键。
