# 模块：手机布局

Android 构建（入口 `phone/main.tsx`）唯一的界面：竖屏触屏，面向 19:9～20:9、约 360–412 CSS px 宽的屏幕；平板暂也用它，
桌面构建不含它。状态与操作全部来自 `library/launcher.ts`，视觉沿用 ui-kit 令牌与两种皮肤，不另起一套。

- `phone-app.tsx`：页面栈（游戏库 → 游戏页；全局设置、游戏设置、卡带展示整屏接管）。游戏库为搜索、筛选标签（全部、待排查；不设“可启动”）、排序面板与游戏网格：四列图标（默认；应用图标，无图标时首字）或三列卡带（卡带即卡片），
  顶栏按钮切换，选择存于本机；下方只写名称，就绪不写，其他状态才写出来；筛选行随列表滚走、上滑即回。有游戏运行时列表顶部显示运行条，点按回到游戏；游戏页主按钮为“返回游戏”，操作面板可“关闭游戏”（确认后）；
  启动另一个游戏先询问返回运行中的游戏，或关闭它后再启动（等它退出，超时报错）。长按卡片或游戏页“⋯”打开该游戏的操作面板，导入按钮固定在右下；游戏页头部随游戏库模式：卡带模式为卡带（3D 可拖动），图标模式为大图标（卡带仍可经“⋯”查看）；其下为宿主事实（不靠悬停提示）与拇指区操作栏。
- `parts.tsx`：返回/更多图标按钮与底部面板 `Sheet`（模态 `<dialog>`，返回键、点遮罩或选择后关闭）。设置页的长选项列表也用它。
- `phone.css`：布局、底部面板，以及把共用弹窗改成底部面板、导入向导改成整屏；安全区取宿主写入的 `--safe-top/--safe-bottom`。
- 返回键（`ogplay-back`）：最上层弹窗/面板 → 整屏视图（按 Esc 交给它；设置页先从分组回到分组列表）→ 游戏页 → 搜索 → 筛选，
  均无则不取消，由宿主退出。
- 设置页的手机排布在 `settings/settings-ui.tsx`（`PhoneFrame`：分组列表 → 单组页，宽控件占整行，选项多时用底部面板）。

验证：npm run check；Android 真机（root，push 后 pm install）截图核对游戏库、游戏页、操作面板、设置两级页、导入向导与返回键。
