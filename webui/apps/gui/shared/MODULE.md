# 模块：启动器共享逻辑

各功能共用、无界面的部分：
- `rpc.ts`：经宿主 webview 绑定调用 closed-schema JSON-RPC，校验响应结构，失败显式抛错。
- `i18n.ts`/`i18n-en.ts`：全局 `language`（zh-CN/en-US，GUI-14）切换界面语言，以中文原文为键，
  `t()`/`tj()` 在英文时查 `i18n-en.ts`，缺词回退中文；根组件订阅语言后整体重绘。宿主字段名/说明按其中文原文翻译显示，
  宿主下发的详情与错误不翻译。`i18n.test.ts` 要求 gui 全部源码的中文字面量与宿主设置文字均有英文、占位符一致
  （cart3d 解码器错误除外：cart3d.js 读不到启动器语言）。
- `prefs.ts`：最近一次语言与界面风格存 localStorage，仅供闪屏前预设，以宿主设置为准；存储不可用时按默认值。
